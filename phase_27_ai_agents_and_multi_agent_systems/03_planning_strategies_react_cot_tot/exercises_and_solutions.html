Topic 27.3: Exercises & Solutions

Computational complexity bounds, search tree evaluations, and error recovery proofs in Tree-of-Thoughts.

Exercise 1: Search Space Complexity: CoT vs. BFS-ToT vs. Beam-ToT

Consider a task of depth $D$ where an agent can generate $k$ thought candidates per step.

Question: Derive the state evaluation count for linear CoT, exhaustive BFS-ToT, and Beam Search ToT (width $b$). Calculate the counts for $k = 5, D = 4, b = 3$.

View Complete Solution
  • CoT: $N_{\text{CoT}} = D = 4$ evaluations.
  • Exhaustive BFS: $N_{\text{BFS}} = \sum_{d=1}^D k^d = \frac{k(k^D - 1)}{k - 1} = 5 + 25 + 125 + 625 = \mathbf{780}$ evaluations.
  • Beam Search: $N_{\text{Beam}} = k + (D - 1)bk = 5 + 3 \times 3 \times 5 = \mathbf{50}$ evaluations.

Beam Search reduces computational overhead by $93.5\%$ while preserving multi-hypothesis tracking.

Exercise 2: Mathematical Proof of Error Recovery in DFS Backtracking vs. Linear CoT

Suppose a problem requires $T=6$ steps, where a single-step greedy decision fails with probability $\epsilon = 0.30$. In DFS Tree-of-Thoughts, the agent explores up to $B=3$ alternate thought branches per step.

Question: Derive the full success probability formulas and compare the numerical rates.

View Complete Solution

1. Linear CoT: Every step must succeed on turn 1:

$$\mathbb{P}(\text{Success}_{\text{CoT}}) = (1 - \epsilon)^T = (0.70)^6 \approx \mathbf{11.76\%}$$

2. DFS Backtracking (Branching $B=3$): A step fails only if all $B$ candidate thoughts fail:

$$\mathbb{P}(\text{Step succeeds}) = 1 - \epsilon^B = 1 - (0.30)^3 = 0.973$$ $$\mathbb{P}(\text{Success}_{\text{ToT}}) = (1 - \epsilon^B)^T = (0.973)^6 \approx \mathbf{84.88\%}$$

Backtracking increases the mission success probability from $11.76\%$ to $84.88\%$.
