Topic 27.3

Planning Strategies: ReAct, Chain-of-Thought & Tree-of-Thoughts

Linear reasoning vs. interleaved Thought-Action-Observation loops, heuristic branch evaluation, beam search, and backtracking.

1. Introduction & 12-Year-Old Intuition

Imagine trying to escape a giant hedge maze in an amusement park. You have four possible strategies:

  • The Blind Sprinter (Chain-of-Thought): You close your eyes, plan 50 turns in your head, and sprint blindly. If turn 2 is off by 10 centimeters, you crash into the hedge at turn 3, and the other 47 turns are wasted.
  • The Observant Hiker (ReAct): You take three steps, pause, open your eyes, check the compass, and read the signpost. You interleave Thinking with Acting and Observing.
  • The Grandmaster (Tree-of-Thoughts): You reach a 3-way fork. You look down each path, score them, reject dead-ends, follow the most promising trail, and if you get stuck, you calmly backtrack to your last decision point.
  • The Journaler (Reflexion): You record notes in your pocket journal: "Never pull the red lever; it activates a water sprinkler." Next time you run the maze, you consult your notes and never repeat past errors.

2. Mathematical Symbol Decoder

Symbol Name Formal Type Intuitive Interpretation
$x \in \mathcal{X}$ Task Input / Goal Token Sequence The user prompt, constraint puzzle, or objective.
$y_t$ Intermediate Thought Token Sequence A discrete reasoning step or cognitive deliberation token.
$a_t \in \mathcal{A}$ Environment Action Tool Call An external tool call or command sent to the environment.
$o_t \in \Omega$ Observation Text / Object The response or error emitted by the environment after action $a_t$.
$G(p_\theta, s, k)$ Thought Generator Function: $\mathcal{S} \to 2^{\mathcal{S}}$ Samples $k$ candidate next reasoning thoughts from state node $s$.
$V(p_\theta, s)$ State Evaluator Function: $\mathcal{S} \to [0, 1]$ Heuristic rating measuring the probability that branch $s$ reaches a solution.

3. The Taxonomy of Planning Topology

1. Standard Chain-of-Thought (Linear) Input ──▶ Thought 1 ──▶ Thought 2 ──▶ Thought 3 ──▶ Output 2. ReAct (Interleaved Closed-Loop) Thought 1 ──▶ Action 1 ──▶ Observation 1 ──▶ Thought 2 ──▶ Action 2 ──▶ Output 3. Tree-of-Thoughts (Branching + Backtracking) ┌──▶ [Thought 1A] (Score: 0.1) ── [PRUNED] [Input State]├──▶ [Thought 1B] (Score: 0.8) ──▶ [Thought 2A] (Solved! 1.0) └──▶ [Thought 1C] (Score: 0.4) ── [BACKTRACK] 4. Reflexion (Episodic Verbal Reinforcement) Attempt 1 (Failed) ──▶ Self-Reflection Summary ──▶ Memory Buffer ──▶ Attempt 2 (Success)

4. Tree-of-Thoughts (ToT) Formalism

In Tree-of-Thoughts, problem solving is framed as search over a tree where each node represents a partial state $s = [x, y_{1:i}]$.

ToT Search Objective: Find a terminal state $s^*$ such that $V(s^*) = 1.0$ using Depth-First Search with backtracking: $$\text{DFS}(s): \text{if } V(s) = \text{"impossible"} \implies \text{return None (Backtrack)}$$ $$\text{for } s' \in G(s): \text{res} = \text{DFS}(s'); \text{if res} \neq \text{None} \implies \text{return res}$$
