Exercise 1: Multi-Factor Memory Scoring & Ranking

Given weights $w_r = 0.25, w_i = 0.35, w_s = 0.40$ and decay rate $\lambda = 0.05$ at $t = 50$:

Memory ID Content $t_m$ Importance $I(m)$ Cosine Sim $\text{Sim}(m, q)$
$m_1$ User preferred language: Rust 10 0.90 0.85
$m_2$ Compiler error: unresolved import 48 0.60 0.40
$m_3$ GC freed 42MB 49 0.10 0.05

Question: Calculate composite scores $S(m, q, 50)$ and determine which memory is retrieved #1 into active context.

View Complete Solution

1. Recency Scores:

  • $R(m_1) = \exp(-0.05 \times 40) = e^{-2} \approx 0.1353$
  • $R(m_2) = \exp(-0.05 \times 2) = e^{-0.1} \approx 0.9048$
  • $R(m_3) = \exp(-0.05 \times 1) = e^{-0.05} \approx 0.9512$

2. Composite Retrieval Scores $S = 0.25 R + 0.35 I + 0.40 \text{Sim}$:

  • $S(m_1) = 0.25(0.1353) + 0.35(0.90) + 0.40(0.85) = 0.0338 + 0.3150 + 0.3400 = \mathbf{0.6888}$
  • $S(m_2) = 0.25(0.9048) + 0.35(0.60) + 0.40(0.40) = 0.2262 + 0.2100 + 0.1600 = \mathbf{0.5962}$
  • $S(m_3) = 0.25(0.9512) + 0.35(0.10) + 0.40(0.05) = 0.2378 + 0.0350 + 0.0200 = \mathbf{0.2928}$

Result: $m_1$ is ranked #1 ($0.6888$). Its high importance and relevance dominate its older age.

Exercise 2: Deriving the Memory Half-Life under Exponential Decay

For decay function $R(\Delta t) = \exp(-\lambda \Delta t)$, derive the half-life $T_{1/2}$ and determine $\lambda$ for $T_{1/2} = 25$ steps.

View Complete Solution

Setting $R(T_{1/2}) = 0.5 \implies \exp(-\lambda T_{1/2}) = 0.5 \implies -\lambda T_{1/2} = -\ln 2$:

$$\boxed{T_{1/2} = \frac{\ln 2}{\lambda} \approx \frac{0.69315}{\lambda}}$$

For $T_{1/2} = 25$:

$$\lambda = \frac{0.69315}{25} \approx \mathbf{0.0277}$$
