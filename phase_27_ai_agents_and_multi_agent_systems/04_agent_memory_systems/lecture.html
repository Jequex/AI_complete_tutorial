Topic 27.4

Agent Memory Systems

Cognitive architectures: working, episodic, semantic, and procedural tiers; multi-factor scoring; eviction and generative reflection.

1. Introduction & 12-Year-Old Intuition

Think about how your own brain handles information throughout a busy day:

  • Working Memory (Your Desk): You sit at your desk. It is small and can only hold a notebook and a pencil. This is whatever you are thinking about right this second.
  • Episodic Memory (Your Diary): The chronological movie of your day: "At 10:15 AM the fire alarm went off; at 12:30 PM Marcus spilled soup."
  • Semantic Memory (Your Mental Encyclopedia): Consolidated abstract knowledge: "Paris is in France; fire is dangerously hot." You don't remember the exact minute you learned it.
  • Procedural Memory (Muscle Memory): How to pedal a bike or tie shoes. For agents, this is system instructions and tool signatures.
  • Sleep & Consolidation: While sleeping, your brain discards useless trivia (bus driver's sock color), retains critical formulas, and turns daily experiences into wiser habits.

2. Mathematical Symbol Decoder

Symbol Name Formal Type Intuitive Interpretation
$\mathcal{M}_{\text{working}}$ Working Memory Token Buffer $L \le L_{\max}$ Active prompt context processed by Transformer self-attention.
$\mathcal{M}_{\text{episodic}}$ Episodic Memory Event Stream $\{m_1, m_2, \dots\}$ Chronological log of historical agent-environment interactions.
$\mathcal{M}_{\text{semantic}}$ Semantic Memory Vector Store / Knowledge Base Collection of timeless principles, summarized insights, and domain facts.
$\lambda > 0$ Temporal Decay Rate Positive Real Scalar Exponential decay constant governing recency.
$R(m, t)$ Recency Score Real $\in (0, 1]$ $\exp(-\lambda(t - t_m))$, measuring freshness since last access.
$I(m)$ Importance Score Real $\in [0, 1]$ Inherent operational criticality of memory $m$.
$\text{Sim}(m, q)$ Relevance Score Real $\in [-1, 1]$ Cosine similarity between query embedding $\mathbf{e}_q$ and memory embedding $\mathbf{e}_m$.

3. Tri-Factor Memory Scoring Formulation

$$\boxed{S(m, q, t) = w_r \cdot R(m, t) + w_i \cdot I(m) + w_s \cdot \text{Sim}(m, q)}$$

where $w_r + w_i + w_s = 1$, balancing temporal recency, intrinsic importance, and topical query relevance.
