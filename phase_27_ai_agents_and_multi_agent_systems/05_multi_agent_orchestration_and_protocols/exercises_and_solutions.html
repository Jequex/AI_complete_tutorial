Exercise 1: Quantitative Condorcet Jury Amplification in Multi-Agent Consensus

Assume each debating agent has independent accuracy $p = 0.70$.

Question: Derive the exact ensemble accuracy under majority rule for $N=1, 3, 5$, and determine the relative error reduction.

View Complete Solution

General Formula:

$$P_N = \sum_{k=\frac{N+1}{2}}^N \binom{N}{k} p^k (1 - p)^{N - k}$$
  • $P_1 = p = \mathbf{70.00\%}$
  • $P_3 = 3(0.7^2)(0.3) + 0.7^3 = 0.441 + 0.343 = \mathbf{78.40\%}$
  • $P_5 = 10(0.7^3)(0.3^2) + 5(0.7^4)(0.3) + 0.7^5 = \mathbf{83.69\%}$

Relative Error Reduction: From $30.0\%$ to $16.31\%$ is a $45.64\%$ reduction in error simply by orchestrating 5 debating agents.

Exercise 2: Communication Message Complexity in Contract Net Protocol (CNP)

Analyze the 4-phase Contract Net Protocol (CFP broadcast, Propose/Refuse replies, Award/Reject decisions, Inform result) for 1 Manager and $N$ Workers.

View Complete Solution

Message Breakdown:

  • Phase 1 (CFP broadcast): $N$ messages
  • Phase 2 (Worker proposals): $N$ messages
  • Phase 3 (Award + Rejections): $N$ messages
  • Phase 4 (Final result return): $1$ message
$$M_{\text{CNP}}(N) = 3N + 1 = \mathcal{O}(N)$$

Compared to uncoordinated peer-to-peer all-to-all negotiation which scales quadratically as $\mathcal{O}(N^2)$ ($2 \binom{N}{2} = N(N-1)$), CNP reduces communication overhead by over $83.9\%$ for $N = 20$.
