Topic 27.1

Agent Architectures & Perception-Action Loops

From passive next-token prediction to cybernetic closed-loop agency, POMDPs, and Bayesian belief state tracking.

1. Introduction & 12-Year-Old Intuition

Imagine you are captaining a submarine 2,000 meters beneath the frozen Arctic Ocean. Through the thick steel hull, you cannot see anything with your eyes. Pitch-black water surrounds you.

How do you keep the submarine from crashing into jagged underwater mountains? You have three systems working in harmony:

  • Sensors (Sense): Every few seconds, your sonar emits a high-pitched "ping" and listens for echoes. The dials register water pressure, engine temperature, and magnetic orientation. These readings are incomplete and noisy—a school of fish might look like an iceberg for a split second!
  • A Nautical Map & Mental Model (Plan): You do not just react blindly to a single ping. You have a nautical chart and a track record of past pings. In your head (or on the navigation table), you maintain a belief about where the submarine probably is: "Based on the last three pings and our speed, we are 90% likely in Sector 4, but there is a 10% chance ocean currents pushed us toward Sector 5."
  • Propellers & Rudders (Act): You order the helm: "Turn rudder 15 degrees starboard, engines half ahead!" The submarine cuts through the water, changing its physical position.

A few seconds later, you ping again. The new echo confirms or refutes your belief, and the cycle repeats.

Model vs. Agent: A standard Large Language Model (like raw GPT-4 or Gemini) is like a world-class encyclopedia sitting on a shelf. If you read a sentence, it predicts the next word. It does not decide anything, possesses no continuous memory, cannot touch the world, and receives no feedback from the consequences of its outputs. An AI Agent takes that predictive engine, places it in the captain's chair, connects it to sensors (terminal outputs, web search results, sensor readings), connects it to rudders and motors (code execution, database queries, robotic arms), and loops its outputs back into its inputs over time.

2. Mathematical Symbol Decoder

Symbol Name Formal Domain / Type Intuitive Interpretation
$\mathcal{S}$ Environmental State Space Set $\{s_1, s_2, \dots\}$ or $\mathbb{R}^d$ The true, underlying physical configuration of the world (often hidden from the agent).
$\mathcal{A}$ Action Space Set $\{a_1, a_2, \dots\}$ or $\mathbb{R}^k$ The set of valid commands or actions the agent can project onto the environment.
$\mathcal{T}$ (or $P$) Transition Function $\mathcal{S} \times \mathcal{A} \times \mathcal{S} \to [0, 1]$ Environmental dynamics: $\mathbb{P}(s_{t+1}=s' \mid s_t=s, a_t=a)$, the law governing how states mutate.
$\mathcal{R}$ Reward Function $\mathcal{S} \times \mathcal{A} \to \mathbb{R}$ Scalar feedback signal scoring agent progress toward an objective.
$\Omega$ Observation Space Set $\{o_1, o_2, \dots\}$ or $\mathbb{R}^m$ The set of signals, tokens, or perceptual readings the agent can directly observe.
$\mathcal{O}$ Observation Function $\mathcal{S} \times \mathcal{A} \times \Omega \to [0, 1]$ Sensor emissions: $\mathbb{P}(o_{t+1}=o \mid s_{t+1}=s', a_t=a)$, the noisy lens over true reality.
$b(s)$ Belief State Probability distribution $\Delta(\mathcal{S})$ Sufficient statistic: $b_t(s) \triangleq \mathbb{P}(S_t = s \mid h_t)$, the agent's probability distribution over world states.
$h_t$ History / Trajectory $(a_0, o_1, a_1, o_2, \dots, a_{t-1}, o_t)$ The complete historical trace of actions taken and sensory observations gathered.
$\pi_\theta(a \mid b)$ Agent Policy $\Delta(\mathcal{S}) \times \mathcal{A} \to [0, 1]$ The agent's decision rule mapping its current belief state (or prompt context) to an action.
$H(b)$ Belief Entropy Scalar $\ge 0$ (in bits / nats) Information-theoretic measure of epistemic uncertainty: $-\sum_{s} b(s) \log_2 b(s)$.

3. The Cybernetic Sense-Plan-Act Feedback Loop

Autonomous agency is grounded in Cybernetics (Norbert Wiener, 1948) and control theory:

┌────────────────────────────────────────────────────────┐ │ ENVIRONMENT │ │ True State S_t │ └──────────────┬──────────────────────────▲──────────────┘ │ │ Sensory Emission (O) Action Effectuation (A) │ │ ┌──────────────▼──────────────────────────┴──────────────┐ │ AGENT │ │ ┌───────────────┐ ┌───────────────┐ ┌──────────┐ │ │ │ SENSE │──▶│ PLAN │──▶│ ACT │ │ │ │ (Observation) │ │ (Belief/State)│ │ (Policy) │ │ │ └───────────────┘ └───────────────┘ └──────────┘ │ └────────────────────────────────────────────────────────┘

Ashby's Law of Requisite Variety (1956): Only variety in the agent's internal policy can destroy variety in the environment. Formally: $$\mathcal{V}(\text{Controller}) \ge \mathcal{V}(\text{Disturbances})$$ If an environment can exhibit $K$ distinct operational failures or configurations, an agent architecture lacking at least $K$ distinct sensing and remedial action pathways will inevitably enter unrecoverable failure states.

4. Step-by-Step Mathematical Derivation: Exact Bayesian Belief State Updating

Tracking the full arbitrary-length history $h_t = (a_0, o_1, \dots, a_{t-1}, o_t)$ is computationally impossible over long horizons. However, the Belief State $b_t(s) \triangleq \mathbb{P}(S_t = s \mid h_t)$ is a sufficient statistic for history.

Let us rigorously derive the recursive update rule $b_{t+1} = \text{BayesFilter}(b_t, a_t, o_{t+1})$:

Step 1: Definition of Posterior Belief

$$b_{t+1}(s') = \mathbb{P}(S_{t+1} = s' \mid h_{t+1}) = \mathbb{P}(S_{t+1} = s' \mid h_t, a_t, o_{t+1})$$

Step 2: Applying Bayes' Rule

$$\mathbb{P}(S_{t+1} = s' \mid h_t, a_t, o_{t+1}) = \frac{\mathbb{P}(o_{t+1} \mid S_{t+1} = s', h_t, a_t) \cdot \mathbb{P}(S_{t+1} = s' \mid h_t, a_t)}{\mathbb{P}(o_{t+1} \mid h_t, a_t)}$$

Step 3: Conditional Independence of Observations

Under the POMDP assumption, observation $o_{t+1}$ depends only on state $S_{t+1} = s'$ and action $a_t$:

$$\mathbb{P}(o_{t+1} \mid S_{t+1} = s', h_t, a_t) = \mathcal{O}(o_{t+1} \mid s', a_t)$$

Step 4: Marginalizing Over Prior States (Prediction Step)

$$\mathbb{P}(S_{t+1} = s' \mid h_t, a_t) = \sum_{s \in \mathcal{S}} \mathbb{P}(S_{t+1} = s' \mid S_t = s, h_t, a_t) \cdot \mathbb{P}(S_t = s \mid h_t, a_t) = \sum_{s \in \mathcal{S}} \mathcal{T}(s' \mid s, a_t) b_t(s)$$

Step 5: Normalization Factor & Master Closed Form

Combining the numerator and denominator yielding evidence normalization $Z$:

$$\boxed{b_{t+1}(s') = \frac{\mathcal{O}(o_{t+1} \mid s', a_t) \sum_{s \in \mathcal{S}} \mathcal{T}(s' \mid s, a_t) b_t(s)}{\sum_{s'' \in \mathcal{S}} \mathcal{O}(o_{t+1} \mid s'', a_t) \sum_{s \in \mathcal{S}} \mathcal{T}(s'' \mid s, a_t) b_t(s)}}$$

5. The LLM Context Window as an Empirical Belief State

In modern LLM-based autonomous agent architectures, the agent does not maintain a closed-form probability vector across billions of physical world states. Instead:

  • Observations $\Omega$: Text tokens (JSON payloads, shell stdout/stderr, HTML DOM trees, tool execution returns).
  • Actions $\mathcal{A}$: Structured tool invocations (JSON function calls, SQL commands, terminal commands).
  • Belief State Approximation: Autoregressive context buffer: $$\tau_t = [\text{System Prompt}, o_1, a_1, o_2, a_2, \dots, o_t]$$ The Transformer self-attention mechanism computes deep latent representations $\mathbf{h}_L \in \mathbb{R}^{d_{\text{model}}}$, approximating the posterior belief $\hat{b}_t \approx \phi(\tau_t)$.
