Exercise 1: Analytical Bayesian Belief State Update in a 3-State POMDP

Consider an autonomous cleaning robot navigating a 1D corridor with three discrete cells: $\mathcal{S} = \{s_1, s_2, s_3\}$.

At time $t=0$, the robot has uniform uncertainty over its location:

$$b_0 = [b(s_1), b(s_2), b(s_3)] = \left[\frac{1}{3}, \frac{1}{3}, \frac{1}{3}\right]$$

The robot takes action $a = \text{RIGHT}$. The transition matrix $\mathcal{T}(s' \mid s, \text{RIGHT})$ is given by:

  • From $s_1$: transitions to $s_2$ with probability 0.8, remains at $s_1$ with probability 0.2.
  • From $s_2$: transitions to $s_3$ with probability 0.8, remains at $s_2$ with probability 0.2.
  • From $s_3$: bumper hits wall, remains at $s_3$ with probability 1.0.

The robot then takes an acoustic sonar reading $o \in \{\text{OPEN}, \text{WALL}\}$. State $s_3$ is adjacent to the end wall. The sensor model satisfies:

$$\mathcal{O}(\text{WALL} \mid s_1) = 0.05, \quad \mathcal{O}(\text{WALL} \mid s_2) = 0.10, \quad \mathcal{O}(\text{WALL} \mid s_3) = 0.90$$

Question: If the robot takes action $a = \text{RIGHT}$ and subsequently perceives observation $o = \text{WALL}$, compute the exact posterior belief distribution $b_1 = [b_1(s_1), b_1(s_2), b_1(s_3)]$.

View Complete Step-by-Step Solution

Step 1: Compute the prior predictive distribution (prediction step):

$$\bar{b}_1(s') = \sum_{s \in \mathcal{S}} \mathcal{T}(s' \mid s, \text{RIGHT}) \cdot b_0(s)$$
  • $\bar{b}_1(s_1) = (0.2)(1/3) + (0)(1/3) + (0)(1/3) = \frac{0.2}{3} \approx 0.0667$
  • $\bar{b}_1(s_2) = (0.8)(1/3) + (0.2)(1/3) + (0)(1/3) = \frac{1.0}{3} \approx 0.3333$
  • $\bar{b}_1(s_3) = (0)(1/3) + (0.8)(1/3) + (1.0)(1/3) = \frac{1.8}{3} = 0.6000$

Step 2: Measurement update with observation $o = \text{WALL}$ (unnormalized):

$$\tilde{b}_1(s') = \mathcal{O}(\text{WALL} \mid s') \cdot \bar{b}_1(s')$$
  • $\tilde{b}_1(s_1) = 0.05 \times \frac{0.2}{3} = \frac{0.010}{3}$
  • $\tilde{b}_1(s_2) = 0.10 \times \frac{1.0}{3} = \frac{0.100}{3}$
  • $\tilde{b}_1(s_3) = 0.90 \times \frac{1.8}{3} = \frac{1.620}{3}$

Step 3: Normalizing constant $Z = \mathbb{P}(\text{WALL} \mid b_0, \text{RIGHT})$:

$$Z = \frac{0.010 + 0.100 + 1.620}{3} = \frac{1.730}{3} \approx 0.57667$$

Step 4: Normalized posterior distribution:

  • $b_1(s_1) = \frac{0.010}{1.730} \approx \mathbf{0.00578}$ ($0.58\%$)
  • $b_1(s_2) = \frac{0.100}{1.730} \approx \mathbf{0.05780}$ ($5.78\%$)
  • $b_1(s_3) = \frac{1.620}{1.730} \approx \mathbf{0.93642}$ ($93.64\%$)

The robot's belief shifts decisively toward certainty that it is at the wall ($93.6\%$).

Exercise 2: Proof that a POMDP is an MDP over Continuous Belief Space $\Delta(\mathcal{S})$

Let $\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{T}, \mathcal{R}, \Omega, \mathcal{O}, \gamma \rangle$ be a discrete POMDP.

Define the continuous belief space $\mathcal{B} \triangleq \Delta(\mathcal{S}) = \left\{ b \in \mathbb{R}^{|\mathcal{S}|} : \sum_s b(s) = 1, \, b(s) \ge 0 \right\}$.

Question: Prove that belief state transitions satisfy the Markov property: $$\mathbb{P}(b_{t+1} \mid b_t, a_t, b_{t-1}, a_{t-1}, \dots, b_0, a_0) = \mathbb{P}(b_{t+1} \mid b_t, a_t)$$ and define the continuous Belief MDP transition and reward operators.

View Complete Mathematical Proof

Proof:

The updated belief $b_{t+1}$ is a deterministic map $\psi(b_t, a_t, o_{t+1})$ determined by Bayes' rule:

$$b_{t+1} = \psi(b_t, a_t, o_{t+1}) = \frac{\mathcal{O}(o_{t+1} \mid \cdot, a_t) \odot (\mathcal{T}(\cdot \mid \cdot, a_t) b_t)}{\mathbb{P}(o_{t+1} \mid b_t, a_t)}$$

The observation $o_{t+1}$ is sampled from the distribution:

$$\mathbb{P}(o_{t+1} = o \mid b_t, a_t) = \sum_{s' \in \mathcal{S}} \mathcal{O}(o \mid s', a_t) \sum_{s \in \mathcal{S}} \mathcal{T}(s' \mid s, a_t) b_t(s)$$

Crucially, this probability distribution depends strictly on $b_t$ and $a_t$, and is conditionally independent of all preceding history $(b_{t-1}, a_{t-1}, \dots, b_0, a_0)$.

Therefore, the transition probability density to any next belief $b' \in \mathcal{B}$ satisfies:

$$\mathbb{P}(b_{t+1} = b' \mid b_t, a_t, \dots, b_0, a_0) = \sum_{o \in \Omega} \mathbb{I}(\psi(b_t, a_t, o) = b') \mathbb{P}(o \mid b_t, a_t) = \mathbb{P}(b_{t+1} = b' \mid b_t, a_t)$$

The expected reward is defined as $\rho(b, a) = \sum_{s \in \mathcal{S}} b(s) \mathcal{R}(s, a)$. Thus, the Belief MDP $\langle \mathcal{B}, \mathcal{A}, \mathcal{T}_{\mathcal{B}}, \rho, \gamma \rangle$ is a fully observable Markov Decision Process. $\blacksquare$

Exercise 3: Context Window Truncation and Epistemic Drift in LLM Agents

In an LLM-based autonomous agent, the context window length is bounded by $L_{\max} = 8192$ tokens. When an execution trajectory exceeds $L_{\max}$, a naive FIFO sliding window discards the earliest tokens $(o_1, a_1, \dots)$.

Question: Using POMDP theory, explain why FIFO context truncation breaks the sufficient statistic property of the agent's belief state, and describe two concrete failure modes (loops or contradictions) that arise in practice.

View Complete Architectural Analysis

1. Violation of Sufficient Statistic Property:

In POMDP theory, the belief state $b_t$ is a sufficient statistic because it preserves all mutual information regarding the underlying state: $I(S_t; h_t) = I(S_t; b_t)$. When FIFO drops history $h_{0:k}$ without state consolidation:

$$I(S_t; h_t^{\text{FIFO}}) < I(S_t; h_t)$$

The agent loses conditioning on past environmental feedback, violating the Markov property in prompt space.

2. Concrete Failure Modes:

  • Action Cycling (Infinite Oscillation): If an agent attempts an action that fails at step 2 (e.g. attempting to bind to an in-use port), discarding that step at step 25 causes the agent to re-attempt the exact same invalid action at step 26, entering an infinite loop.
  • Goal Drift & Constraint Inversion: When initial user safety guidelines or constraints (e.g., "Do not alter the production database schema") get pushed out of the active context window, subsequent model generations may violate those core constraints during error recovery.
