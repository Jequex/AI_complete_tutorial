Topic 27.2

Tool Use & Function Calling

JSON Schema definitions, grammar-constrained decoding via FSM logit masking, sandboxed execution, and self-correction error loops.

1. Introduction & 12-Year-Old Intuition

Imagine the world's most brilliant chef locked inside a windowless library. The chef knows every recipe in human history, from French soufflés to ramen broths. But if someone asks the chef to bake a real cake, the chef has a problem: there is no oven, no flour, no eggs, no mixer, and no timer. In the library, all the chef can do is write essays describing food.

Now, connect that chef to an automated smart kitchen with appliances:

  • A mixer: mix(speed=3, duration_sec=60)
  • An oven: bake(temperature_c=180, time_min=35)

Each appliance comes with a strict instruction manual (a Schema). If the chef shouts: "Bake at temperature 'extra hot'!", the oven rejects the command with a red screen: Error: 'temperature_c' must be an integer, got string 'extra hot'. The chef reads the feedback, corrects the command to bake(temperature_c=200, time_min=30), and the cake bakes successfully.

Core Agent Concept: Without tools, a Large Language Model is a closed-world text simulator. With tools, schemas, and execution sandboxes, the model becomes an active agent capable of modifying databases, running compilers, fetching live weather, and manipulating real environments.

2. Mathematical Symbol Decoder

Symbol Name Formal Type Intuitive Interpretation
$\mathcal{T}_{\text{tools}}$ Tool Library / Registry Set $\{f_1, f_2, \dots, f_M\}$ The collection of executable functions exposed to the agent.
$\Sigma_i$ Tool Schema JSON Schema specification The formal specification of parameter names, data types, and constraints for tool $f_i$.
$\mathcal{G}_{\text{CFG}}$ Context-Free Grammar 4-Tuple $(V_N, V_T, P, S)$ Formal grammar specifying valid structural syntax (e.g. JSON grammar).
$q \in Q$ FSM State Finite Automaton State Current state of the parser tracking valid next tokens during generation.
$\mathcal{M}(q)$ Admissible Token Mask Subset of Vocabulary $\mathcal{V}$ Tokens whose emission leaves the prefix legally completable under grammar $\mathcal{G}$.
$\tilde{z}_t$ Masked Logits Real Vector $\mathbb{R}^{|\mathcal{V}|}$ Logits after grammar filtering: $\tilde{z}_{t, v} = z_{t, v}$ if $v \in \mathcal{M}(q)$, else $-\infty$.

3. Grammar-Constrained Decoding: FSM Logit Masking

A critical challenge in tool-using agents is ensuring that the LLM generates 100% syntactically valid JSON matching the exact expected parameter schema. Grammar-constrained decoding achieves this mathematically by masking vocabulary logits before sampling:

$$\tilde{z}_{t, v} = \begin{cases} z_{t, v} & \text{if } v \in \mathcal{M}(q) \\ -\infty & \text{if } v \notin \mathcal{M}(q) \end{cases}$$ $$\mathbb{P}(w_t = v \mid w_{1:t-1}) = \frac{\exp(\tilde{z}_{t, v})}{\sum_{v' \in \mathcal{M}(q)} \exp(z_{t, v'})}$$

Tokens that violate JSON syntax or schema rules are masked to $-\infty$, rendering syntax hallucination mathematically impossible.
