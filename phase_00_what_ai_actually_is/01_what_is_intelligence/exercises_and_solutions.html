Topic 0.1: Practice Exercises & Solutions

Test your understanding of intelligence vs. computation, discounted return calculations, and generalization risk.

Problem 1: The Smart Thermostat (Conceptual Drill)

A home thermostat measures temperature $T$. If $T < 68^\circ\text{F}$, it turns on the furnace. If $T > 72^\circ\text{F}$, it turns off the furnace.

  • Part A: Is this thermostat performing computation, or does it exhibit genuine intelligence? Explain using the definition of intelligence from the lecture.
  • Part B: What specific capability would you need to add to this thermostat for it to qualify as an adaptive, intelligent agent?
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: Pure Computation
The basic thermostat is performing pure computation. It evaluates a hard-coded deterministic conditional rule:

$$\text{Action} = \begin{cases} \text{Heater ON} & \text{if } T < 68^\circ\text{F} \\ \text{Heater OFF} & \text{if } T > 72^\circ\text{F} \\ \text{Maintain} & \text{otherwise} \end{cases}$$

It possesses no internal model of the environment, cannot learn from experience, and cannot adapt to novel situations (e.g., if a window is left wide open in winter, it will fire continuously without realizing the room is not retaining heat).

Part B: Transforming into an Intelligent Agent
To become an intelligent agent, it requires:

  1. Broader Observation Space: Ingesting external weather forecasts, time-of-day occupancy, and indoor humidity.
  2. Environmental Learning: Learning the specific thermal inertia of the home (e.g., "It takes 40 minutes to raise the master bedroom by $3^\circ\text{F}$ when exterior temperature is $20^\circ\text{F}$").
  3. Objective Optimization: Balancing the trade-off between human comfort and energy bill minimization ($$$).

Problem 2: Mathematical Return Calculation (Hand Derivation)

An intelligent cleaning robot explores a room modeled as an MDP. At time step $t=0$, it takes 4 sequential actions, receiving the following scalar rewards:

  • $t=1$: $R_1 = -1.0$ (energy spent moving forward)
  • $t=2$: $R_2 = -1.0$ (energy spent turning left)
  • $t=3$: $R_3 = +10.0$ (vacuumed a pile of dust)
  • $t=4$: $R_4 = +50.0$ (safely docked and recharged)

The discount factor is set to $\gamma = 0.5$.

  • Part A: State the formal mathematical formula for the discounted return $G_0$.
  • Part B: Calculate the exact numerical value of $G_0$ step-by-step.
  • Part C: Recalculate the return for $\gamma = 0.9$. Compare the two results: how does $\gamma$ influence agent behavior?
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: The Formula
The discounted cumulative return $G_t$ is defined as:

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots$$

For our 4-step trajectory starting at $t=0$:

$$G_0 = R_1 + \gamma R_2 + \gamma^2 R_3 + \gamma^3 R_4$$

Part B: Arithmetic with $\gamma = 0.5$

  1. Calculate powers of $\gamma$: $$\gamma^0 = 1.0, \quad \gamma^1 = 0.5, \quad \gamma^2 = 0.25, \quad \gamma^3 = 0.125$$
  2. Multiply each reward: $$\text{Step 1: } 1.0 \times (-1.0) = -1.0$$ $$\text{Step 2: } 0.5 \times (-1.0) = -0.5$$ $$\text{Step 3: } 0.25 \times (+10.0) = +2.5$$ $$\text{Step 4: } 0.125 \times (+50.0) = +6.25$$
  3. Sum terms: $$G_0 = -1.0 - 0.5 + 2.5 + 6.25 = \mathbf{7.25}$$

Part C: Arithmetic with $\gamma = 0.9$

  1. Calculate powers of $\gamma$: $$\gamma^0 = 1.0, \quad \gamma^1 = 0.9, \quad \gamma^2 = 0.81, \quad \gamma^3 = 0.729$$
  2. Multiply each reward: $$\text{Step 1: } 1.0 \times (-1.0) = -1.0$$ $$\text{Step 2: } 0.9 \times (-1.0) = -0.9$$ $$\text{Step 3: } 0.81 \times (+10.0) = +8.1$$ $$\text{Step 4: } 0.729 \times (+50.0) = +36.45$$
  3. Sum terms: $$G_0 = -1.0 - 0.9 + 8.1 + 36.45 = \mathbf{42.65}$$

Behavioral Insight: When $\gamma = 0.5$, distant rewards decay sharply (the $+50$ reward shrank to only $+6.25$). When $\gamma = 0.9$, the distant goal dominates ($+36.45$), making the agent willing to incur small negative step penalties to achieve long-term success.

Problem 3: The Generalization Gap (Overfitting Proof)

A team trains an image classifier on 5,000 photos of cats and dogs. The model achieves:

$$\widehat{\mathcal{R}}_{\text{train}} = 0.00 \quad (0\% \text{ error on training data})$$

When tested on real-world photos submitted by users, the error is:

$$\mathcal{R}_{\text{test}} = 0.48 \quad (48\% \text{ error on test data})$$

  • Part A: Compute the Generalization Gap.
  • Part B: What does this result tell us about what the model learned?
  • Part C: In a balanced binary classification task (cat vs. dog), how does 48% error compare to chance?
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: Generalization Gap Calculation

$$\text{Generalization Gap} = |\mathcal{R}_{\text{test}} - \widehat{\mathcal{R}}_{\text{train}}| = |0.48 - 0.00| = \mathbf{0.48 \quad (48\%)}$$

Part B: Interpretation
The model severely overfitted. It memorized the 5,000 specific training images (perhaps by background pixel colors, file artifacts, or unique noise) rather than learning invariant morphological features of cats and dogs.

Part C: Comparison with Random Guessing
For a balanced 2-class problem, a random coin flip has an expected error rate of $50\%$ ($0.50$). An error rate of $48\%$ ($0.48$) means this multi-layer neural network is performing almost identically to a random coin flip on unseen images.
