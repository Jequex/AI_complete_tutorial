Problem 1: Manual One-Step Gradient Descent by Hand

Given $N=2$ data points: $(x^{(1)}, y^{(1)}) = (2.0, 5.0)$ and $(x^{(2)}, y^{(2)}) = (4.0, 9.0)$.

Model: $\hat{y} = w x + b$. Objective: MSE Loss $\mathcal{L}(w, b) = \frac{1}{2} \sum_{i=1}^2 (\hat{y}^{(i)} - y^{(i)})^2$.

Initial parameters: $w_0 = 1.0, b_0 = 0.0$. Learning rate: $\eta = 0.05$.

  • Part A: Calculate initial predictions, errors, and loss $\mathcal{L}(w_0, b_0)$.
  • Part B: Compute analytical partial derivatives $\frac{\partial \mathcal{L}}{\partial w}$ and $\frac{\partial \mathcal{L}}{\partial b}$.
  • Part C: Update $w_1 = w_0 - \eta \frac{\partial \mathcal{L}}{\partial w}$ and $b_1 = b_0 - \eta \frac{\partial \mathcal{L}}{\partial b}$.
  • Part D: Compute new loss $\mathcal{L}(w_1, b_1)$ and verify error reduction.
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: Initial Predictions and Errors

  • $\hat{y}^{(1)} = (1.0)(2.0) + 0.0 = 2.0 \implies e^{(1)} = 2.0 - 5.0 = -3.0$
  • $\hat{y}^{(2)} = (1.0)(4.0) + 0.0 = 4.0 \implies e^{(2)} = 4.0 - 9.0 = -5.0$
  • $\mathcal{L}(w_0, b_0) = \frac{1}{2} [(-3.0)^2 + (-5.0)^2] = \frac{9 + 25}{2} = \mathbf{17.0}$

Part B: Computing Analytical Gradients

$$\frac{\partial \mathcal{L}}{\partial w} = e^{(1)} x^{(1)} + e^{(2)} x^{(2)} = (-3.0)(2.0) + (-5.0)(4.0) = -6.0 - 20.0 = \mathbf{-26.0}$$

$$\frac{\partial \mathcal{L}}{\partial b} = e^{(1)} + e^{(2)} = -3.0 + (-5.0) = \mathbf{-8.0}$$

Part C: Parameter Updates

$$w_1 = 1.0 - [0.05 \times (-26.0)] = 1.0 - (-1.30) = \mathbf{2.30}$$

$$b_1 = 0.0 - [0.05 \times (-8.0)] = 0.0 - (-0.40) = \mathbf{0.40}$$

Part D: New Loss Verification

  • $\hat{y}^{(1)}_{\text{new}} = (2.30)(2.0) + 0.40 = 5.00 \implies e^{(1)} = 0.00$
  • $\hat{y}^{(2)}_{\text{new}} = (2.30)(4.0) + 0.40 = 9.60 \implies e^{(2)} = +0.60$
  • $\mathcal{L}(w_1, b_1) = \frac{1}{2} [(0.0)^2 + (0.6)^2] = \frac{0.36}{2} = \mathbf{0.18}$

The loss collapsed from $17.0 \to 0.18$ in a single step—a $98.9\%$ error reduction!

Problem 2: The Analytic Closed-Form Normal Equation

For model $\hat{y} = w x$ and MSE loss $\mathcal{L}(w) = \frac{1}{N} \sum_{i=1}^N (w x^{(i)} - y^{(i)})^2$:

  • Part A: Take the derivative $\frac{d\mathcal{L}}{dw}$.
  • Part B: Set $\frac{d\mathcal{L}}{dw} = 0$ to solve for optimal $w^*$ in closed form.
  • Part C: Evaluate $w^*$ for $x=[2, 4], y=[5, 9]$.
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: Using the chain rule: $\frac{d\mathcal{L}}{dw} = \frac{2}{N} \sum_{i=1}^N (w x^{(i)} - y^{(i)}) x^{(i)}$.

Part B: Setting $\frac{d\mathcal{L}}{dw} = 0$ yields:

$$w \sum_{i=1}^N (x^{(i)})^2 = \sum_{i=1}^N x^{(i)} y^{(i)} \implies \mathbf{w^* = \frac{\sum_{i=1}^N x^{(i)} y^{(i)}}{\sum_{i=1}^N (x^{(i)})^2}}$$

Part C: $\sum x y = (2 \times 5) + (4 \times 9) = 10 + 36 = 46$. $\sum x^2 = 4 + 16 = 20$.

$$w^* = \frac{46}{20} = \mathbf{2.30}$$

Problem 3: Learning Rate Stability Threshold

Let loss $\mathcal{L}(w) = 3w^2$ with update $w_{t+1} = w_t - \eta \frac{d\mathcal{L}}{dw}$. Determine the maximum threshold $\eta_{\text{crit}}$ to avoid exponential divergence.

💡 Click to Reveal Step-by-Step Solution

Solution:

Derivative: $\frac{d\mathcal{L}}{dw} = 6w$.
Recurrence: $w_{t+1} = w_t - 6\eta w_t = (1 - 6\eta)w_t$.
For convergence, $|1 - 6\eta| < 1 \implies -1 < 1 - 6\eta < 1$.
Solving bounds: $6\eta < 2 \implies \eta < \frac{1}{3}$.
$$\mathbf{\eta_{\text{crit}} = \frac{1}{3} \approx 0.3333}$$
