Problem 1: Manual Synthesis of a Perceptron (NAND Gate)

The logical NAND gate is the fundamental universal gate of computing:

$x_1$ $x_2$ Target $y$
001
011
101
110
  • Part A: Is the NAND function linearly separable? Explain geometrically.
  • Part B: Write down the 4 linear inequalities corresponding to the NAND truth table for decision rule $z = w_1 x_1 + w_2 x_2 + b \geq 0 \implies \hat{y} = 1$.
  • Part C: Find an explicit set of integer values for $w_1, w_2, b$ that satisfy all 4 conditions. Verify your solution.
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: Geometric Linear Separability
Yes! On a 2D Cartesian plane, three points ($(0,0), (0,1), (1,0)$) have label $1$, and only one point ($(1,1)$) has label $0$. A straight line such as $x_1 + x_2 = 1.5$ easily separates the positive points from the negative point.

Part B: The 4 Inequalities

  1. For $(0, 0) \to 1$:   $w_1(0) + w_2(0) + b \geq 0 \implies \mathbf{b \geq 0}$
  2. For $(0, 1) \to 1$:   $w_1(0) + w_2(1) + b \geq 0 \implies \mathbf{w_2 + b \geq 0}$
  3. For $(1, 0) \to 1$:   $w_1(1) + w_2(0) + b \geq 0 \implies \mathbf{w_1 + b \geq 0}$
  4. For $(1, 1) \to 0$:   $w_1(1) + w_2(1) + b < 0 \implies \mathbf{w_1 + w_2 + b < 0}$

Part C: Explicit Integer Parameter Synthesis
By symmetry, set $w_1 = w_2 = w$.
From (4): $2w + b < 0 \implies 2w < -b$.
From (1): $b \geq 0$. Choose $b = 2$.
Then $2w < -2 \implies w < -1$. Choose $w_1 = -2, w_2 = -2$.

Verification:

  • $(0, 0): (-2)(0) + (-2)(0) + 2 = +2 \geq 0 \implies \hat{y} = 1$ (Correct)
  • $(0, 1): (-2)(0) + (-2)(1) + 2 = 0 \geq 0 \implies \hat{y} = 1$ (Correct)
  • $(1, 0): (-2)(1) + (-2)(0) + 2 = 0 \geq 0 \implies \hat{y} = 1$ (Correct)
  • $(1, 1): (-2)(1) + (-2)(1) + 2 = -2 < 0 \implies \hat{y} = 0$ (Correct)

Problem 2: The Minsky-Papert XOR Proof

Reconstruct the 1969 proof showing that no single-layer perceptron can classify XOR: $(0,0)\to 0, (1,0)\to 1, (0,1)\to 1, (1,1)\to 0$.

💡 Click to Reveal Step-by-Step Solution

Solution:

Assume there exist real numbers $w_1, w_2, b$ that solve XOR. Then:

(1) $b < 0$

(2) $w_1 + b \geq 0$

(3) $w_2 + b \geq 0$

(4) $w_1 + w_2 + b < 0$

Add (2) and (3):

$$(w_1 + w_2 + b) + b \geq 0$$

From (4), $(w_1 + w_2 + b) < 0$. From (1), $b < 0$. The sum of two strictly negative values must be strictly negative:

$$(w_1 + w_2 + b) + b < 0$$

A quantity cannot be simultaneously $\geq 0$ and $< 0$. Contradiction! $\blacksquare$

Problem 3: Comparative Analysis of AI Paradigms

Compare a 1982 Medical Expert System (2,000 hand-crafted rules) with a modern 70B parameter Foundation Model across input robustness, interpretability, and scalability.

Solution:

Dimension 1982 Expert System (Symbolic) 2024 Foundation Model (Deep Learning)
Noisy / Corrupted Inputs Brittle: A single typo or missing measurement causes the logic rule to fail. Robust: Continuous vector embeddings map synonyms and typos to nearby latent space.
Interpretability 100% Explainable: Exact rule-firing chains can be printed step-by-step. Emergent / Black Box: Reasoning is distributed across billions of weights; requires probing or CoT.
