Problem 1: First-Principles Limit Derivation of $f(x) = 1/x$

Medium

🧒 The Context: Maya is designing a power meter for a toy robot where power drops with distance: $f(x) = \frac{1}{x}$. Using only the limit definition $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$:

  1. Derive the formula for $f'(x)$.
  2. Verify against the Power Rule for $n = -1$.
  3. Find the tangent line equation at $x = 2$.
Click to view solution for Problem 1
1. Difference Quotient Setup: $$f'(x) = \lim_{h \to 0} \frac{\frac{1}{x+h} - \frac{1}{x}}{h}$$
2. Common Denominator & Cancellation: $$\frac{\frac{x - (x+h)}{x(x+h)}}{h} = \frac{-h}{x(x+h)h} = \frac{-1}{x(x+h)}$$
3. Taking the Limit: $$f'(x) = \lim_{h \to 0} \frac{-1}{x(x+h)} = \mathbf{-\frac{1}{x^2}}$$ Power Rule check: $\frac{d}{dx}(x^{-1}) = (-1)x^{-2} = -\frac{1}{x^2}$ ✅.
4. Tangent Line at $x = 2$: Point: $(2, 0.5)$, Slope: $m = -1/(2^2) = -0.25$. $$y - 0.5 = -0.25(x - 2) \implies \mathbf{y = -0.25x + 1.0}$$

Problem 2: Derivation of the $\tanh(x)$ Activation Derivative

Medium

🧒 The Context: In Timmy's recurrent neural network, signals are bounded with $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$.

  1. Using the Quotient Rule, derive $\frac{d}{dx}\tanh(x)$.
  2. Prove it simplifies to $\tanh'(x) = 1 - \tanh^2(x)$.
  3. If forward activation is $a = 0.8$, compute gradient $da$ with mental arithmetic.
Click to view solution for Problem 2
1. Quotient Rule Application: $$\frac{d}{dx}\tanh(x) = \frac{(e^x + e^{-x})(e^x + e^{-x}) - (e^x - e^{-x})(e^x - e^{-x})}{(e^x + e^{-x})^2}$$
2. Algebraic Simplification: $$= \frac{(e^x + e^{-x})^2}{(e^x + e^{-x})^2} - \frac{(e^x - e^{-x})^2}{(e^x + e^{-x})^2} = \mathbf{1 - \tanh^2(x)}$$
3. Fast Backprop Calculation: For forward activation $a = 0.8$: $$da = 1 - a^2 = 1 - (0.8)^2 = 1 - 0.64 = \mathbf{0.36}$$ Zero exponential calls required!

Problem 3: Optimal Finite Difference Step Size $h$

Challenging

🧒 The Context: Total numerical gradient error balances Taylor truncation ($c_1 h^2$) against computer floating-point roundoff ($\frac{\epsilon_{\text{mach}}}{h}$).

  1. Minimize $E(h) = c_1 h^2 + \frac{\epsilon_{\text{mach}}}{h}$ to find $h^*$.
  2. For $\epsilon_{\text{mach}} \approx 10^{-16}$, find the optimal order of magnitude.
  3. Compare with Forward Difference where error is $c_1 h + \frac{\epsilon_{\text{mach}}}{h}$.
Click to view solution for Problem 3
1. Finding the Minimum: $$\frac{dE}{dh} = 2 c_1 h - \frac{\epsilon_{\text{mach}}}{h^2} = 0 \implies h^3 \propto \epsilon_{\text{mach}} \implies h^* \propto \epsilon_{\text{mach}}^{1/3}$$
2. Numerical Order of Magnitude: $$h^* \approx (10^{-16})^{1/3} \approx \mathbf{10^{-5.3} \approx 10^{-5} \text{ to } 10^{-6}}$$ This proves why deep learning libraries pick `eps = 1e-5` for gradient checks!
3. Forward vs Central Accuracy: Forward difference has optimal $h^* \approx \sqrt{10^{-16}} = 10^{-8}$ with error $\approx 10^{-8}$. Central difference achieves error $\approx (10^{-5.3})^2 \approx 10^{-11}$—1,000x more precise!
