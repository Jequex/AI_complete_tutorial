Problem 1: First-Principles Limit Derivation of $f(x) = 1/x$

Medium

Using only the limit definition $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$, derive the derivative of $f(x) = \frac{1}{x}$, verify against the Power Rule, and find the tangent line equation at $x = 2$.

Click to Reveal Step-by-Step Solution
1. Limit Derivation: $$f'(x) = \lim_{h \to 0} \frac{\frac{1}{x+h} - \frac{1}{x}}{h} = \lim_{h \to 0} \frac{-h}{x(x+h)h} = \lim_{h \to 0} \frac{-1}{x(x+h)} = \mathbf{-\frac{1}{x^2}}$$
2. Power Rule Check: $$\frac{d}{dx} x^{-1} = -1 \cdot x^{-2} = -\frac{1}{x^2}$$
3. Tangent Line at $x = 2$: Point: $(2, 0.5)$, Slope: $m = -1/4 = -0.25$. $$y - 0.5 = -0.25(x - 2) \implies \mathbf{y = -0.25x + 1.0}$$

Problem 2: Derivation of the $\tanh(x)$ Activation Derivative

Medium

Using the Quotient Rule, derive $\frac{d}{dx} \tanh(x)$ and prove that it simplifies to $\tanh'(x) = 1 - \tanh^2(x)$.

Click to Reveal Step-by-Step Solution
Derivation: $$\frac{d}{dx} \left( \frac{e^x - e^{-x}}{e^x + e^{-x}} \right) = \frac{(e^x + e^{-x})^2 - (e^x - e^{-x})^2}{(e^x + e^{-x})^2} = 1 - \left(\frac{e^x - e^{-x}}{e^x + e^{-x}}\right)^2 = \mathbf{1 - \tanh^2(x)}$$
Backprop Efficiency: For forward activation $a = 0.8$, the gradient is simply $da = 1 - (0.8)^2 = \mathbf{0.36}$ with zero exponent calculations!

Problem 3: Optimal Finite Difference Step Size $h$

Challenging

Total numerical error combines truncation error ($c_1 h^2$) and machine roundoff ($\epsilon_{\text{mach}} / h$). Prove that the optimal step size for central difference is $h^* \approx \epsilon_{\text{mach}}^{1/3} \approx 10^{-5}$.

Click to Reveal Step-by-Step Solution
Minimizing Error: $$\frac{d}{dh} \left( c_1 h^2 + \frac{\epsilon_{\text{mach}}}{h} \right) = 2 c_1 h - \frac{\epsilon_{\text{mach}}}{h^2} = 0 \implies h^3 \propto \epsilon_{\text{mach}} \implies h^* \propto \epsilon_{\text{mach}}^{1/3}$$ For $\epsilon_{\text{mach}} \approx 10^{-16}$, $h^* \approx 10^{-16/3} \approx \mathbf{10^{-5.3} \approx 10^{-5} \text{ to } 10^{-6}}$. This mathematically explains why frameworks pick `eps = 1e-5` for gradient checking.
