Topic 3.4: Jacobians & Vector Calculus in Deep Learning

Bridging vector-to-vector mappings, the full Softmax Jacobian derivation, gradient collapse in cross-entropy, and modern Vector-Jacobian Products (VJP).

1. Executive Summary & The Mixing Console Analogy

In single-variable calculus, functions map a single number to another number: $f: \mathbb{R} \to \mathbb{R}$. In Topic 3.2, loss functions mapped high-dimensional weight vectors down to a single scalar error: $f: \mathbb{R}^n \to \mathbb{R}$.

In deep learning, almost every internal transformation (dense layers, attention projections, LayerNorm, and Softmax) takes a vector of inputs and emits a vector of outputs:

$$\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$$ $$\mathbf{f}(\mathbf{x}) = \begin{bmatrix} f_1(x_1, \dots, x_n) \\ f_2(x_1, \dots, x_n) \\ \vdots \\ f_m(x_1, \dots, x_n) \end{bmatrix}$$

The 12-Year-Old Analogy: The Sound Engineer's Mixing Console

Imagine a soundboard with $n$ input sliders (bass, treble, reverb, echo) and $m$ output stadium speakers (front left, front right, overhead, subwoofers).

If you nudge Slider $j$ up by 1 millimeter:

  • Speaker 1 might get louder by 0.5 decibels.
  • Speaker 2 might get quieter by 0.2 decibels.
  • Subwoofer 3 might boom with 2.0 decibels.

To capture how every single slider influences every single speaker, you need a 2D table of numbers: the Jacobian Matrix! Row $i$ tells you how Speaker $i$ responds to each slider. Column $j$ tells you how Slider $j$ radiates its effects across all speakers.

2. Mathematical Definition of the Jacobian Matrix

Let $\mathbf{f}: \mathbb{R}^n \to \mathbb{R}^m$ be a differentiable vector-valued function. The Jacobian matrix $J \in \mathbb{R}^{m \times n}$ gathers all $m \times n$ first-order partial derivatives:

$$J = \frac{\partial \mathbf{f}}{\partial \mathbf{x}} = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \frac{\partial f_1}{\partial x_2} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \frac{\partial f_2}{\partial x_1} & \frac{\partial f_2}{\partial x_2} & \cdots & \frac{\partial f_2}{\partial x_n} \\ \vdots & \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \frac{\partial f_m}{\partial x_2} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix}$$

The 3 Structural Invariants

  1. Rows ($m$): Each row $i$ is the transposed gradient of output component $f_i$: $\text{Row } i = \nabla f_i(\mathbf{x})^T$.
  2. Columns ($n$): Each column $j$ is the derivative vector of the entire output with respect to input scalar $x_j$: $\text{Col } j = \frac{\partial \mathbf{f}}{\partial x_j}$.
  3. Index notation: $J_{ij} = \frac{\partial f_i}{\partial x_j}$.

3. Mathematical Decoder Table

Symbol Mathematical Name Plain-English Meaning Dimension
$\mathbf{x}$ Input vector Features entering the transformation $n \times 1$
$\mathbf{f}(\mathbf{x})$ Output vector Features emitted after transformation $m \times 1$
$J \text{ or } \frac{\partial \mathbf{f}}{\partial \mathbf{x}}$ Jacobian Matrix Complete table of all output-input partial sensitivities $m \times n$
$\delta_{ij}$ Kronecker Delta Filter flag: $1$ if $i = j$, and $0$ if $i \neq j$ Scalar
$\mathbf{z}$ Logits vector Raw scores entering Softmax classification $K \times 1$
$\mathbf{p}$ Probability vector Normalized probabilities summing to 1.0 $K \times 1$
$\mathbf{v}^T J$ Vector-Jacobian Product (VJP) The efficient reverse-mode autodiff primitive (adjoint multiplication) $1 \times n$

4. First-Order Linear Approximation

The Jacobian represents the optimal local linear mapping from perturbations in the input space to perturbations in the output space:

$$\mathbf{f}(\mathbf{x} + \Delta\mathbf{x}) \approx \mathbf{f}(\mathbf{x}) + J \Delta\mathbf{x}$$

If an autonomous car or robotic arm moves its joints by a tiny amount $\Delta\mathbf{x}$, the new position of its gripper $\mathbf{f}(\mathbf{x})$ changes directly by the matrix product $J \Delta\mathbf{x}$.

5. Complete Derivation of the Softmax Jacobian

The Softmax function normalizes a vector of logits $\mathbf{z} = [z_1, \dots, z_K]^T$ into probabilities:

$$p_i = \frac{e^{z_i}}{\sum_{k=1}^K e^{z_k}}$$

Every output probability $p_i$ is coupled to every input logit $z_j$ through the common sum in the denominator. Let numerator $u = e^{z_i}$ and denominator $v = \sum_{k=1}^K e^{z_k}$. We use the quotient rule:

$$\frac{\partial p_i}{\partial z_j} = \frac{\frac{\partial u}{\partial z_j} v - u \frac{\partial v}{\partial z_j}}{v^2}$$

Case 1: Diagonal Elements ($i = j$)

When differentiating $p_i$ with respect to its own logit $z_i$:

$$\frac{\partial u}{\partial z_i} = e^{z_i}, \quad \frac{\partial v}{\partial z_i} = e^{z_i}$$ $$\frac{\partial p_i}{\partial z_i} = \frac{e^{z_i} \left( \sum_k e^{z_k} \right) - e^{z_i} e^{z_i}}{\left( \sum_k e^{z_k} \right)^2} = \frac{e^{z_i}}{\sum_k e^{z_k}} - \left( \frac{e^{z_i}}{\sum_k e^{z_k}} \right)^2$$ $$\mathbf{\frac{\partial p_i}{\partial z_i} = p_i - p_i^2 = p_i(1 - p_i)}$$

Case 2: Off-Diagonal Elements ($i \neq j$)

When differentiating $p_i$ with respect to a competing logit $z_j$ ($j \neq i$):

$$\frac{\partial u}{\partial z_j} = 0 \quad (\text{since } u = e^{z_i} \text{ does not contain } z_j!), \quad \frac{\partial v}{\partial z_j} = e^{z_j}$$ $$\frac{\partial p_i}{\partial z_j} = \frac{0 \cdot v - e^{z_i} e^{z_j}}{v^2} = -\frac{e^{z_i}}{\sum_k e^{z_k}} \cdot \frac{e^{z_j}}{\sum_k e^{z_k}} = \mathbf{-p_i p_j}$$

Unified Matrix Representation

Using the Kronecker delta $\delta_{ij}$ ($1$ when $i=j$, $0$ when $i \neq j$):

$$J_{ij} = p_i(\delta_{ij} - p_j)$$

In matrix notation:

$$\mathbf{J_{\text{softmax}} = \operatorname{diag}(\mathbf{p}) - \mathbf{p} \mathbf{p}^T}$$

6. The Miracle of Gradient Collapse: Softmax + Cross-Entropy

In neural networks, Softmax is almost universally combined with Cross-Entropy Loss:

$$\mathcal{L} = -\sum_{k=1}^K y_k \ln(p_k)$$

Using the multivariable chain rule to find $\frac{\partial \mathcal{L}}{\partial z_j}$:

$$\frac{\partial \mathcal{L}}{\partial z_j} = \sum_{i=1}^K \frac{\partial \mathcal{L}}{\partial p_i} \frac{\partial p_i}{\partial z_j} = \sum_{i=1}^K \left( -\frac{y_i}{p_i} \right) \left[ p_i(\delta_{ij} - p_j) \right]$$

The probability $p_i$ in the denominator cancels with $p_i$ from the Jacobian:

$$\frac{\partial \mathcal{L}}{\partial z_j} = -\sum_{i=1}^K y_i(\delta_{ij} - p_j) = -\sum_{i=1}^K y_i \delta_{ij} + p_j \sum_{i=1}^K y_i$$

Because $\sum_{i=1}^K y_i \delta_{ij} = y_j$ and $\sum_{i=1}^K y_i = 1$ (the true distribution sums to 1):

$$\mathbf{\frac{\partial \mathcal{L}}{\partial z_j} = p_j - y_j \implies \nabla_{\mathbf{z}} \mathcal{L} = \mathbf{p} - \mathbf{y}}$$
The Deep Learning Miracle: The gradient of the entire classification head is literally just: $$\mathbf{\text{Gradient}} = \mathbf{\text{Prediction}} - \mathbf{\text{Target}}$$ All exponential divisions, outer products, and logarithms cancel out into an astonishingly simple difference!

7. Vector-Jacobian Products (VJP) in Autodiff Engines

For a language model with a vocabulary of size $V = 128{,}000$, a materialized Jacobian matrix would contain:

$$128{,}000 \times 128{,}000 = 16{,}384{,}000{,}000 \text{ floats} \approx \mathbf{65.5 \text{ Gigabytes!}}$$

PyTorch and JAX never materialize this matrix. Instead, when an upstream gradient $\mathbf{v} \in \mathbb{R}^{1 \times K}$ arrives, they compute the Vector-Jacobian Product (VJP) directly:

$$\mathbf{v}^T J = \mathbf{v}^T (\operatorname{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^T) = (\mathbf{v} \odot \mathbf{p}) - (\mathbf{v} \cdot \mathbf{p}) \mathbf{p}$$

This requires only $O(K)$ time and $O(K)$ memory, avoiding 65 GB of memory overhead completely!
