Topic 3.3: The Chain Rule & Backpropagation

Composite Functions, Computational Graphs, Forward vs Reverse Autodiff & Backprop Derivation

1. The Multivariable Chain Rule

Paths Multiply, Forks Add

If input $x$ influences loss $z$ through intermediate channels $u_1, u_2, \dots, u_K$:

$$\mathbf{\frac{\partial z}{\partial x} = \sum_{k=1}^K \frac{\partial z}{\partial u_k} \frac{\partial u_k}{\partial x}}$$

  • Along any single serial chain: derivatives multiply.
  • Across multiple parallel branches: derivatives add!

2. Forward-Mode vs Reverse-Mode Autodiff

Mode Direction Complexity Application
Forward-Mode Inputs $\to$ Outputs $\mathcal{O}(N)$ passes Few inputs, many outputs ($N \ll M$)
Reverse-Mode (Backprop) Loss $\to$ Inputs $\mathcal{O}(1)$ pass Billions of weights, single scalar loss ($N \gg 1$)

3. The Backpropagation Node Update Rule

Adjoint Accumulation:
For any node $i$, with adjoint $\bar{v}_i = \frac{\partial \mathcal{L}}{\partial v_i}$: $$\bar{v}_i = \sum_{j \in \text{Children}(i)} \bar{v}_j \cdot \frac{\partial v_j}{\partial v_i}$$ Initialized with $\bar{v}_{\text{loss}} = 1.0$ at the terminal loss node.
