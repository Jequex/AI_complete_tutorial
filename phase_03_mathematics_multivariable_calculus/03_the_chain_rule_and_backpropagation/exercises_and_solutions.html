Problem 1: Step-by-Step Manual Backpropagation on a DAG

Medium

Consider the computational graph evaluating:

$$f(x, y, z) = (x + y) \cdot z$$

Given the specific numerical input values:

$$x = 2.0, \quad y = 3.0, \quad z = 4.0$$

Define intermediate node $q = x + y$, so that $f = q \cdot z$.

  1. Execute the Forward Pass: Compute the numerical values of $q$ and $f$.
  2. Compute the Local Derivatives: $\frac{\partial f}{\partial q}$, $\frac{\partial f}{\partial z}$, $\frac{\partial q}{\partial x}$, and $\frac{\partial q}{\partial y}$.
  3. Execute the Backward Pass: Apply the chain rule to compute adjoints $\bar{f}$, $\bar{z}$, $\bar{q}$, $\bar{x}$, and $\bar{y}$.
  4. State the numerical sensitivity interpretation: If $x$ is increased by $+0.01$, by how much does $f$ change?
Click to Reveal Step-by-Step Solution

1. Forward Pass

  • $q = x + y = 2.0 + 3.0 = \mathbf{5.0}$
  • $f = q \cdot z = 5.0 \cdot 4.0 = \mathbf{20.0}$

2. Local Derivatives

  • $\frac{\partial f}{\partial q} = z = 4.0$
  • $\frac{\partial f}{\partial z} = q = 5.0$
  • $\frac{\partial q}{\partial x} = 1.0$
  • $\frac{\partial q}{\partial y} = 1.0$

3. Backward Pass (Adjoint Propagation)

  1. Seed upstream loss adjoint: $$\bar{f} = \frac{\partial f}{\partial f} = \mathbf{1.0}$$
  2. Backprop through multiplication node $f = q \cdot z$: $$\bar{z} = \bar{f} \cdot \frac{\partial f}{\partial z} = 1.0 \times 5.0 = \mathbf{5.0}$$ $$\bar{q} = \bar{f} \cdot \frac{\partial f}{\partial q} = 1.0 \times 4.0 = \mathbf{4.0}$$
  3. Backprop through addition node $q = x + y$: $$\bar{x} = \bar{q} \cdot \frac{\partial q}{\partial x} = 4.0 \times 1.0 = \mathbf{4.0}$$ $$\bar{y} = \bar{q} \cdot \frac{\partial q}{\partial y} = 4.0 \times 1.0 = \mathbf{4.0}$$
Sensitivity Check: Since $\frac{\partial f}{\partial x} = 4.0$, perturbing $x$ by $\Delta x = +0.01$ changes $f$ by: $$\Delta f \approx \bar{x} \cdot \Delta x = 4.0 \times 0.01 = \mathbf{+0.04}$$ Direct check: $((2.01 + 3) \times 4) = 5.01 \times 4 = 20.04$ (exact match!).

Problem 2: Multi-Path Gradient Accumulation Calculus

Medium

In modern architectures (such as Transformer multi-head attention and Residual connections $x + F(x)$), gradients flow through multiple parallel paths and must accumulate at branching inputs.

Consider the multivariable scalar function:

$$f(x, y) = x^2 y + x y^2$$
  1. Differentiate directly with respect to $x$ using standard calculus rules.
  2. Break $f(x, y)$ into intermediate nodes: $u = x^2 y$, $v = x y^2$, and $f = u + v$.
  3. Apply the multivariable chain rule $\frac{\partial f}{\partial x} = \frac{\partial f}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial f}{\partial v}\frac{\partial v}{\partial x}$ and prove that it yields the identical formula.
  4. Evaluate numerically at $(x = 2, y = 3)$.
Click to Reveal Step-by-Step Solution

1. Direct Differentiation

$$\frac{\partial f}{\partial x} = \frac{\partial}{\partial x}(x^2 y) + \frac{\partial}{\partial x}(x y^2) = \mathbf{2xy + y^2}$$

2. Intermediate Node Derivatives

  • $u = x^2 y \implies \frac{\partial u}{\partial x} = 2xy$
  • $v = x y^2 \implies \frac{\partial v}{\partial x} = y^2$
  • $f = u + v \implies \frac{\partial f}{\partial u} = 1, \quad \frac{\partial f}{\partial v} = 1$

3. Multivariable Chain Rule Verification

$$\frac{\partial f}{\partial x} = \frac{\partial f}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial f}{\partial v} \frac{\partial v}{\partial x} = (1)(2xy) + (1)(y^2) = \mathbf{2xy + y^2} \quad \blacksquare$$

4. Numerical Evaluation at $(x = 2, y = 3)$

$$\frac{\partial f}{\partial x}(2, 3) = 2(2)(3) + 3^2 = 12 + 9 = \mathbf{21.0}$$
Key Architectural Principle: In PyTorch, anytime a variable $x$ is used more than once in the forward pass, its gradient accumulator grad += incoming ensures that all incoming chain rule signals from parallel branches sum together automatically.

Problem 3: Vectorized Matrix Backpropagation Derivation ($Y = XW + b$)

Challenging

In deep learning frameworks, neural layers execute batched linear transformations:

$$Y = X W + b$$

Where:

  • $X \in \mathbb{R}^{B \times D_{\text{in}}}$ (Input batch of size $B$)
  • $W \in \mathbb{R}^{D_{\text{in}} \times D_{\text{out}}}$ (Weight matrix)
  • $b \in \mathbb{R}^{D_{\text{out}}}$ (Bias row vector broadcasted across batch)
  • $Y \in \mathbb{R}^{B \times D_{\text{out}}}$ (Output activation matrix)

Let $\mathcal{L}$ be the scalar objective loss. Assume the upstream gradient matrix $\frac{\partial \mathcal{L}}{\partial Y} \in \mathbb{R}^{B \times D_{\text{out}}}$ has already been backpropagated.

  1. Using summation index notation, express $Y_{i, j}$ in terms of elements of $X$, $W$, and $b$.
  2. Derive the weight gradient matrix $\frac{\partial \mathcal{L}}{\partial W}$. Show that $\frac{\partial \mathcal{L}}{\partial W} = X^T \left(\frac{\partial \mathcal{L}}{\partial Y}\right)$.
  3. Derive the input gradient matrix $\frac{\partial \mathcal{L}}{\partial X}$. Show that $\frac{\partial \mathcal{L}}{\partial X} = \left(\frac{\partial \mathcal{L}}{\partial Y}\right) W^T$.
  4. Derive the bias gradient vector $\frac{\partial \mathcal{L}}{\partial b}$.
Click to Reveal Step-by-Step Solution

1. Element-wise Index Expression

$$Y_{i, j} = \sum_{k=1}^{D_{\text{in}}} X_{i, k} W_{k, j} + b_j$$

2. Derivation of $\frac{\partial \mathcal{L}}{\partial W}$

By the multivariable chain rule, $W_{k, j}$ affects the loss through all batch samples $i \in \{1, \dots, B\}$ in output column $j$:

$$\frac{\partial \mathcal{L}}{\partial W_{k, j}} = \sum_{i=1}^B \frac{\partial \mathcal{L}}{\partial Y_{i, j}} \frac{\partial Y_{i, j}}{\partial W_{k, j}}$$

Since $\frac{\partial Y_{i, j}}{\partial W_{k, j}} = X_{i, k}$:

$$\frac{\partial \mathcal{L}}{\partial W_{k, j}} = \sum_{i=1}^B X_{i, k} \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j} = \sum_{i=1}^B (X^T)_{k, i} \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j}$$

Recognizing the definition of matrix multiplication:

$$\mathbf{\frac{\partial \mathcal{L}}{\partial W} = X^T \left( \frac{\partial \mathcal{L}}{\partial Y} \right)} \quad \blacksquare$$

Dimension Check: $(D_{\text{in}} \times B) \times (B \times D_{\text{out}}) = (D_{\text{in}} \times D_{\text{out}})$. Perfect!

3. Derivation of $\frac{\partial \mathcal{L}}{\partial X}$

Input activation $X_{i, k}$ affects loss through all output features $j \in \{1, \dots, D_{\text{out}}\}$ for sample $i$:

$$\frac{\partial \mathcal{L}}{\partial X_{i, k}} = \sum_{j=1}^{D_{\text{out}}} \frac{\partial \mathcal{L}}{\partial Y_{i, j}} \frac{\partial Y_{i, j}}{\partial X_{i, k}} = \sum_{j=1}^{D_{\text{out}}} \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j} W_{k, j} = \sum_{j=1}^{D_{\text{out}}} \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j} (W^T)_{j, k}$$

In matrix notation:

$$\mathbf{\frac{\partial \mathcal{L}}{\partial X} = \left( \frac{\partial \mathcal{L}}{\partial Y} \right) W^T} \quad \blacksquare$$

Dimension Check: $(B \times D_{\text{out}}) \times (D_{\text{out}} \times D_{\text{in}}) = (B \times D_{\text{in}})$. Perfect!

4. Derivation of Bias Gradient $\frac{\partial \mathcal{L}}{\partial b}$

The parameter $b_j$ is shared across all batch items $i \in \{1, \dots, B\}$:

$$\frac{\partial \mathcal{L}}{\partial b_j} = \sum_{i=1}^B \frac{\partial \mathcal{L}}{\partial Y_{i, j}} \frac{\partial Y_{i, j}}{\partial b_j} = \sum_{i=1}^B \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j} \cdot 1$$

Vectorized across all output units:

$$\mathbf{\frac{\partial \mathcal{L}}{\partial b} = \sum_{i=1}^B \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, :}}$$
The Deep Learning Triad: Every dense linear layer in modern hardware (PyTorch, JAX, CUDA) executes these three tensor operations:
  1. Forward: $Y = XW + b$
  2. Backward Weights: $\nabla_W = X^T \nabla_Y$
  3. Backward Inputs: $\nabla_X = \nabla_Y W^T$
