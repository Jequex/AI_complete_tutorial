Problem 1: Step-by-Step Manual Backpropagation on a Computational Graph

Medium

🧒 The Context: Maya's arithmetic calculator evaluates $f(x, y, z) = (x + y) \cdot z$ with inputs $x = 2.0, y = 3.0, z = 4.0$. Intermediate node is $q = x + y$.

  1. Compute the Forward Pass values for $q$ and $f$.
  2. Find local derivatives $\frac{\partial f}{\partial q}, \frac{\partial f}{\partial z}, \frac{\partial q}{\partial x}, \frac{\partial q}{\partial y}$.
  3. Run Backward Pass for adjoints $\bar{f}, \bar{z}, \bar{q}, \bar{x}, \bar{y}$.
  4. Verify output change if $x$ is nudged by $+0.01$.
Click to view solution for Problem 1
1. Forward Pass: $q = 2.0 + 3.0 = \mathbf{5.0}$;   $f = 5.0 \cdot 4.0 = \mathbf{20.0}$.
2. Local Derivatives: $\frac{\partial f}{\partial q} = z = 4.0, \quad \frac{\partial f}{\partial z} = q = 5.0, \quad \frac{\partial q}{\partial x} = 1.0, \quad \frac{\partial q}{\partial y} = 1.0$.
3. Backward Adjoints:
  • $\bar{f} = 1.0$
  • $\bar{z} = 1.0 \times 5.0 = \mathbf{5.0}$
  • $\bar{q} = 1.0 \times 4.0 = \mathbf{4.0}$
  • $\bar{x} = 4.0 \times 1.0 = \mathbf{4.0}$
  • $\bar{y} = 4.0 \times 1.0 = \mathbf{4.0}$
4. Sensitivity Verification: $\Delta f \approx \bar{x} \Delta x = 4.0 \times 0.01 = \mathbf{+0.04}$. Direct check: $(2.01 + 3) \times 4 = 20.04$ ✅.

Problem 2: Multi-Path Gradient Accumulation Calculus

Medium

🧒 The Context: In Transformer residual connections, gradients split and recombine. Consider $f(x, y) = x^2 y + x y^2$.

  1. Differentiate directly with respect to $x$.
  2. Break into branches $u = x^2 y$ and $v = x y^2$ with $f = u + v$.
  3. Apply multivariable chain rule $\frac{\partial f}{\partial x} = \frac{\partial f}{\partial u}\frac{\partial u}{\partial x} + \frac{\partial f}{\partial v}\frac{\partial v}{\partial x}$.
  4. Evaluate at $(x = 2, y = 3)$.
Click to view solution for Problem 2
1. Direct Derivative: $\frac{\partial f}{\partial x} = \mathbf{2xy + y^2}$.
2. Branch Derivatives: $\frac{\partial u}{\partial x} = 2xy, \quad \frac{\partial v}{\partial x} = y^2, \quad \frac{\partial f}{\partial u} = 1, \quad \frac{\partial f}{\partial v} = 1$.
3. Chain Rule: $$\frac{\partial f}{\partial x} = (1)(2xy) + (1)(y^2) = \mathbf{2xy + y^2} \quad \blacksquare$$
4. Numerical Value: $\frac{\partial f}{\partial x}(2, 3) = 2(2)(3) + 3^2 = 12 + 9 = \mathbf{21.0}$.

Problem 3: Vectorized Matrix Backpropagation Derivation ($Y = XW + b$)

Challenging

🧒 The Context: The core backward pass in PyTorch linear layers with inputs $X \in \mathbb{R}^{B \times D_{\text{in}}}$, weights $W \in \mathbb{R}^{D_{\text{in}} \times D_{\text{out}}}$, and downstream gradient $\frac{\partial \mathcal{L}}{\partial Y}$.

  1. Express $Y_{i, j}$ using summation.
  2. Derive $\frac{\partial \mathcal{L}}{\partial W} = X^T \left( \frac{\partial \mathcal{L}}{\partial Y} \right)$.
  3. Derive $\frac{\partial \mathcal{L}}{\partial X} = \left( \frac{\partial \mathcal{L}}{\partial Y} \right) W^T$.
  4. Derive bias gradient $\frac{\partial \mathcal{L}}{\partial b}$.
Click to view solution for Problem 3
1. Summation Formula: $Y_{i, j} = \sum_{k=1}^{D_{\text{in}}} X_{i, k} W_{k, j} + b_j$.
2. Weight Matrix Gradient: $$\frac{\partial \mathcal{L}}{\partial W_{k, j}} = \sum_{i=1}^B \frac{\partial \mathcal{L}}{\partial Y_{i, j}} X_{i, k} = \sum_{i=1}^B (X^T)_{k, i} \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j} \implies \mathbf{\frac{\partial \mathcal{L}}{\partial W} = X^T \left( \frac{\partial \mathcal{L}}{\partial Y} \right)}$$
3. Input Feature Gradient: $$\frac{\partial \mathcal{L}}{\partial X_{i, k}} = \sum_{j=1}^{D_{\text{out}}} \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j} W_{k, j} = \sum_{j=1}^{D_{\text{out}}} \left(\frac{\partial \mathcal{L}}{\partial Y}\right)_{i, j} (W^T)_{j, k} \implies \mathbf{\frac{\partial \mathcal{L}}{\partial X} = \left( \frac{\partial \mathcal{L}}{\partial Y} \right) W^T}$$
4. Bias Gradient: $\frac{\partial \mathcal{L}}{\partial b} = \sum_{i=1}^B \left( \frac{\partial \mathcal{L}}{\partial Y} \right)_{i, :}$ (Sum across batch dimension 0).
