Topic 3.2: Partial Derivatives, Gradients & Steepest Descent

Multivariable Functions, Directional Derivatives, Steepest Ascent Proof & Gradient Descent

1. Symbol Decoder Table

Symbol Name Formal Meaning Child-Friendly Analogy
$\frac{\partial f}{\partial x}$ Partial Derivative Slope in the $x$-direction while holding $y$ fixed Walking strictly East-West on a mountain
$\nabla f$ Gradient Vector Column vector of all partial derivatives A 3D compass pointing directly uphill toward the peak
$-\nabla f$ Negative Gradient Direction of steepest descent The path a marble rolls down a foggy mountain valley
$D_{\mathbf{u}} f$ Directional Derivative $\nabla f \cdot \mathbf{u}$ (slope along unit vector $\mathbf{u}$) Slope experienced when hiking in an arbitrary compass direction

2. Mathematical Proof: Why $\nabla f$ Points Steepest Uphill

The Dot Product Maximization

For any unit direction vector $\mathbf{u}$ ($\|\mathbf{u}\| = 1$):

$$D_{\mathbf{u}} f = \nabla f \cdot \mathbf{u} = \|\nabla f\| \cdot \|\mathbf{u}\| \cos \theta = \|\nabla f\| \cos \theta$$

  • Maximum Slope (+Steepest Ascent): Occurs when $\cos \theta = +1 \implies \theta = 0^\circ$. The walking vector $\mathbf{u}$ must align exactly with $\nabla f$!
  • Minimum Slope (-Steepest Descent): Occurs when $\cos \theta = -1 \implies \theta = 180^\circ$. Moving along $-\nabla f$ drops altitude as fast as physically possible!
  • Contour / Level Curve ($\Delta f = 0$): When $\theta = 90^\circ$, $\cos(90^\circ) = 0$. The gradient is always perpendicular to contour lines!

3. The Gradient Descent Update Rule

The Universal Machine Learning Update Rule:
$$\mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla \mathcal{L}(\mathbf{w}_t)$$ Where $\eta > 0$ is the learning rate step size.
