Exercise 1: KV-Cache Sizing & Inference Arithmetic Intensity Analysis

An inference engine serves a 70B model ($L=80, d_{model}=8192, H_Q=64, d_{head}=128$) on an NVIDIA H100 GPU ($80\text{ GB}$ HBM, $3.35\text{ TB/s}$ bandwidth) at context length $T = 32,768$ tokens in 16-bit precision.

  1. Compute single-request KV-cache size under MHA ($H_{KV}=64$) and GQA-8 ($H_{KV}=8$).
  2. Calculate the arithmetic intensity ($\text{FLOPs} / \text{Bytes}$) for batch size $B = 1$.
  3. Explain why GQA's $8\times$ bandwidth reduction directly increases token generation speed.
View Complete Mathematical Solution

1. KV-Cache Footprint:

$$\text{Bytes} = 2 \cdot L \cdot T \cdot H_{KV} \cdot d_{head} \cdot 2 \text{ bytes}$$ $$\text{MHA } (H_{KV}=64): 2 \cdot 80 \cdot 32,768 \cdot 64 \cdot 128 \cdot 2 \approx \mathbf{85.90\text{ GB}} \quad (\text{Exceeds single 80GB GPU!})$$ $$\text{GQA-8 } (H_{KV}=8): 2 \cdot 80 \cdot 32,768 \cdot 8 \cdot 128 \cdot 2 \approx \mathbf{10.74\text{ GB}} \quad (\text{Fits cleanly with 8x compression})$$

2. Arithmetic Intensity at $B = 1$:

$$\text{Compute} \approx 2N = 140 \times 10^9 \text{ FLOPs}, \quad \text{Weight Read} = 140\text{ GB}$$ $$\text{Intensity}_{\text{MHA}} = \frac{140 \times 10^9}{140\text{GB} + 85.9\text{GB}} = \frac{140}{225.9} \approx \mathbf{0.62\text{ FLOPs/byte}}$$ $$\text{Intensity}_{\text{GQA}} = \frac{140 \times 10^9}{140\text{GB} + 10.74\text{GB}} = \frac{140}{150.74} \approx \mathbf{0.93\text{ FLOPs/byte}}$$

3. Hardware Speedup:

Because the H100's ridge point is $\frac{1000\text{ TFLOPS}}{3.35\text{ TB/s}} \approx 298.5\text{ FLOPs/byte}$, generation is strictly memory-bandwidth bound. Reducing memory traffic from $225.9\text{ GB}$ to $150.74\text{ GB}$ per step enables the GPU to complete decoding steps significantly faster.
Exercise 2: Analytical Derivation of SwiGLU Backpropagation Gradients

For the layer $\text{SwiGLU}(x) = ( (x W_g) \odot \text{SiLU}(x W_u) ) W_d$, derive the gradient with respect to input $x$.

View Complete Mathematical Solution

1. SiLU Derivative:

$$\text{SiLU}(u) = u \cdot \sigma(u) \implies \text{SiLU}'(u) = \sigma(u) \left( 1 + u (1 - \sigma(u)) \right)$$

2. Intermediate Gradient:

$$y = z W_d \implies \delta_z = \delta_y W_d^T$$ $$\delta_{h_g} = \delta_z \odot \text{SiLU}(x W_u)$$ $$\delta_{h_u} = \delta_z \odot (x W_g) \odot \text{SiLU}'(x W_u)$$

3. Input Gradient:

$$\frac{\partial \mathcal{L}}{\partial x} = \delta_{h_g} W_g^T + \delta_{h_u} W_u^T = \left(\delta_z \odot \text{SiLU}(x W_u)\right) W_g^T + \left(\delta_z \odot (x W_g) \odot \text{SiLU}'(x W_u)\right) W_u^T$$ Both channels smoothly propagate error signals, preventing dead-neuron saturation.
Exercise 3: Manual Trace of FlashAttention Online Softmax

Trace online softmax for $x = [2.0, 4.0, 1.0, 5.0]$ partitioned into Block 1: $[2.0, 4.0]$ and Block 2: $[1.0, 5.0]$.

View Complete Mathematical Solution

1. Block 1:

$$m_1 = 4.0, \quad d_1 = e^{2-4} + e^{4-4} = e^{-2} + 1 \approx 1.135335$$

2. Block 2:

$$\tilde{m}_2 = 5.0 \implies m_2 = \max(4.0, 5.0) = 5.0$$ $$\text{Rescaled } d_1 = 1.135335 \times e^{4 - 5} = 1.135335 \times 0.367879 \approx 0.417666$$ $$\text{Block 2 exp sum} = e^{1-5} + e^{5-5} = e^{-4} + 1 \approx 1.018316$$ $$d_2 = 0.417666 + 1.018316 = \mathbf{1.435982}$$

3. Probabilities:

$$p_0 = e^{-3} / 1.435982 = \mathbf{0.03467}, \quad p_1 = e^{-1} / 1.435982 = \mathbf{0.25619}$$ $$p_2 = e^{-4} / 1.435982 = \mathbf{0.01275}, \quad p_3 = e^0 / 1.435982 = \mathbf{0.69639}$$ The probabilities are mathematically identical to standard monolithic softmax to machine precision.
