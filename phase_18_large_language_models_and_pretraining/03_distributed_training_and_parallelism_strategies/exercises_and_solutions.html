Exercise 1: Memory Wall & ZeRO Sharding Sizing for a 175B Model

An engineering team prepares to train a 175B parameter model on 80GB H100 GPUs using AdamW in mixed precision.

  1. Calculate monolithic static memory $M_{\text{static}}$ ($16N$ bytes).
  2. Compute memory per GPU for DDP, ZeRO-1, ZeRO-2, and ZeRO-3 across $N_d \in \{16, 64, 256\}$.
  3. Determine the minimum number of 80GB GPUs required for ZeRO-3 with a 20GB activation budget.
View Complete Mathematical Solution

1. Monolithic Static Memory:

$$M_{\text{static}} = 16 \times 175 \times 10^9 \text{ bytes} = 2,800 \text{ GB (2.8 Terabytes)}$$

2. Memory per GPU:

  • At $N_d = 16$: ZeRO-1 = $831\text{ GB}$, ZeRO-2 = $503\text{ GB}$, ZeRO-3 = $175\text{ GB}$ (All OOM on 80GB GPUs).
  • At $N_d = 64$: ZeRO-1 = $733\text{ GB}$, ZeRO-2 = $388\text{ GB}$, ZeRO-3 = $\mathbf{43.75\text{ GB}}$ (Fits in 80GB!).
  • At $N_d = 256$: ZeRO-3 = $\mathbf{10.94\text{ GB}}$ per GPU.

3. Minimum GPUs with 20GB Activations:

$$\text{Max Static Budget} = 80 - 20 = 60 \text{ GB}$$ $$\frac{2800}{N_d} \le 60 \implies N_d \ge 46.7 \implies \mathbf{64\text{ GPUs}}$$
Exercise 2: Megatron-LM Tensor Parallelism Communication Overhead

For a Transformer layer with hidden size $d = 8192$, batch size $B = 4$, sequence length $S = 4096$, and TP world size $K = 8$:

  1. State the number of forward All-Reduce operations.
  2. Compute the total megabytes transferred per GPU across the layer using ring All-Reduce volume formula: $$\text{Volume} = 2 \cdot \left(\frac{K - 1}{K}\right) \cdot T \cdot 2 \text{ bytes}$$
  3. Calculate communication latency at $600\text{ GB/s}$ NVLink bandwidth.
View Complete Mathematical Solution

1. Forward Communication: Exactly 2 All-Reduces per layer (1 after Attention output $W_O$, 1 after MLP down-projection $W_{down}$).

2. Transferred Volume: Tensor has $4 \times 4096 \times 8192 = 134,217,728$ elements ($256\text{ MB}$ in BF16). $$\text{Volume per All-Reduce} = 2 \cdot \left(\frac{7}{8}\right) \times 256 \text{ MB} = 448 \text{ MB}$$ $$\text{Total per Layer} = 2 \times 448 = 896 \text{ MB (0.896 GB)}$$

3. NVLink Latency:

$$\text{Latency} = \frac{0.896 \text{ GB}}{600 \text{ GB/s}} \approx 1.49 \text{ milliseconds}$$ This 1.5 ms communication cost is negligible compared to tens of milliseconds of tensor math.
Exercise 3: Pipeline Parallelism Bubble Fraction and 1F1B Scheduling

A model is partitioned across $p = 8$ pipeline stages with $m = 64$ microbatches.

  1. Compute the pipeline bubble fraction $F_{\text{bubble}} = \frac{p - 1}{m + p - 1}$.
  2. Compare the peak activation memory between GPipe and 1F1B.
View Complete Mathematical Solution

1. Bubble Fraction:

$$F_{\text{bubble}} = \frac{8 - 1}{64 + 8 - 1} = \frac{7}{71} \approx 9.86\% \implies 90.14\% \text{ utilization}$$

2. Activation Memory Comparison:

  • GPipe stores all $m = 64$ microbatch activations simultaneously before backward begins.
  • 1F1B alternates forward and backward steps, bounding peak stored activations to $p = 8$.
  • 1F1B delivers an exact $\frac{64}{8} = \mathbf{8\times}$ reduction in peak activation memory.
