Topic 18.3: Distributed Training & Parallelism Strategies

Scaling Beyond the Memory Wall with 3D Parallelism, ZeRO Sharding, and Megatron-LM Tensor Slicing.

🏗️ 12-Year-Old Analogy: The Giant Construction Crew Splitting a Skyscraper

You must construct a 100-story mega-skyscraper in one week. The blueprints, concrete mixers, steel beams, and inspection logbooks weigh 1,000 tons. A single worker carrying 1,000 tons will be crushed instantly.

  • Data Parallelism (ZeRO Sharding): Instead of giving all 16 workers a redundant 1,000-ton backpack, you tear the blueprint into 16 slips, give each worker one tiny tool, and when someone needs to pour concrete, they radio a teammate, borrow the tool for 2 seconds, and return it!
  • Tensor Parallelism (Megatron-LM): A single 40-foot steel girder is too heavy for one person. Four workers stand side-by-side, each lifting a 10-foot section simultaneously in perfect unison over high-speed headsets (NVLink).
  • Pipeline Parallelism (1F1B): Worker A builds floors 1–25, then hands off to Worker B for floors 26–50. Rather than waiting for the entire building to finish, work flows in a continuous, smooth conveyor belt!

3. ZeRO Stage Memory Formulas

The ZeRO memory hierarchy eliminates redundant state across $N_d$ data-parallel GPUs:

  • DDP (ZeRO-0): Replicates everything: $$M_{\text{DDP}} = 16N$$
  • ZeRO-1 ($P_{os}$): Shards optimizer states: $$M_{\text{ZeRO-1}} = 4N + \frac{12N}{N_d}$$
  • ZeRO-2 ($P_{os+g}$): Shards optimizer states and gradients: $$M_{\text{ZeRO-2}} = 2N + \frac{14N}{N_d}$$
  • ZeRO-3 (FSDP): Shards parameters, gradients, and optimizer: $$M_{\text{ZeRO-3}} = \frac{16N}{N_d}$$

4. Megatron-LM Tensor Parallelism

Megatron-LM eliminates communication between layers by interleaving Column-Parallel and Row-Parallel GEMMs:

  • Column-Parallel Linear: $W = [W_1 \mid W_2]$. Forward pass $Y_i = X W_i$ requires zero communication. Non-linear activation $\text{GELU}(Y_i)$ executes locally.
  • Row-Parallel Linear: $V = \begin{bmatrix} V_1 \\ V_2 \end{bmatrix}$. Forward pass computes local partial sum $Z_i = Y_i V_i$, followed by an All-Reduce (SUM): $$Z = \sum_{i=1}^K Z_i$$

This requires only 2 All-Reduces per Transformer block (1 for self-attention and 1 for MLP).
