Exercise 1: Joint & Conditional Entropy from a Contingency Table

A delivery robot tracks Weather $X \in \{\text{Sunny}, \text{Rainy}\}$ and Delay $Y \in \{\text{On Time}, \text{Delayed}\}$:

$Y = \text{On Time}$$Y = \text{Delayed}$
$X = \text{Sunny}$0.400.10
$X = \text{Rainy}$0.100.40

Tasks:

  1. Compute the marginal entropies $H(X)$ and $H(Y)$.
  2. Compute the joint entropy $H(X, Y)$.
  3. Compute the conditional entropy $H(Y \mid X)$ and verify the Chain Rule.
  4. How much does knowing the weather reduce uncertainty about delay?
Click to reveal Step-by-Step Solution

Solution:

1. Marginal Entropies:

$P(X=\text{Sunny}) = 0.50, \quad P(X=\text{Rainy}) = 0.50 \implies H(X) = 1.0\text{ bit}$.

$P(Y=\text{On Time}) = 0.50, \quad P(Y=\text{Delayed}) = 0.50 \implies H(Y) = 1.0\text{ bit}$.

2. Joint Entropy:

$$H(X, Y) = -2(0.40 \log_2 0.40) - 2(0.10 \log_2 0.10) \approx 1.0575 + 0.6644 = 1.7219\text{ bits}$$

3. Conditional Entropy & Chain Rule:

For both weather conditions, the distribution over delay is $(0.80, 0.20)$, with entropy:

$$H_b(0.80) = -0.80\log_2 0.80 - 0.20\log_2 0.20 \approx 0.7219\text{ bits}$$ $$H(Y \mid X) = 0.50(0.7219) + 0.50(0.7219) = 0.7219\text{ bits}$$ $$H(X) + H(Y \mid X) = 1.0000 + 0.7219 = 1.7219\text{ bits} = H(X, Y) \quad \text{(Verified!)}$$

4. Uncertainty Reduction:

$$\Delta H = H(Y) - H(Y \mid X) = 1.0000 - 0.7219 = 0.2781\text{ bits}$$

Exercise 2: The Three-Variable Chain Rule

Using the two-variable rule $H(A, B) = H(A) + H(B \mid A)$, prove:

$$H(X, Y, Z) = H(X) + H(Y \mid X) + H(Z \mid X, Y)$$
Click to reveal Step-by-Step Solution

Solution:

Group $(X, Y)$ into a composite variable $W = (X, Y)$.

$$H(X, Y, Z) = H(W, Z) = H(W) + H(Z \mid W)$$

Substitute $W = (X, Y)$:

$$H(X, Y, Z) = H(X, Y) + H(Z \mid X, Y)$$

Expand $H(X, Y) = H(X) + H(Y \mid X)$:

$$H(X, Y, Z) = H(X) + H(Y \mid X) + H(Z \mid X, Y) \quad \blacksquare$$

Autoregressive LLM Interpretation: Each word's uncertainty is added to the sum, conditioned on all words generated before it.

$$H(X_1, \dots, X_T) = H(X_1) + \sum_{t=2}^T H(X_t \mid X_{t-1})$$
