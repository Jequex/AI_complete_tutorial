Introductory (Age 12+)

Exercise 1: Mutual Information of a Binary Symmetric Channel

A channel flips bits with error rate $p = 0.10$. Inputs $0$ and $1$ are equally likely.

  1. Compute $H(X)$ and $H(Y \mid X)$.
  2. Compute Mutual Information $I(X; Y) = H(Y) - H(Y \mid X)$ in bits.
Click to reveal Step-by-Step Solution

Solution:

1. Entropies:

$$H(X) = 1.0\text{ bit}$$ $$H(Y \mid X) = H_b(0.10) = -0.10 \log_2(0.10) - 0.90 \log_2(0.90) \approx 0.4690\text{ bits}$$

2. Mutual Information:

$$I(X; Y) = 1.0000 - 0.4690 = 0.5310\text{ bits}$$

Each bit sent through this noisy channel transmits $0.5310$ bits of clean information.

Intermediate (Proof)

Exercise 2: The Data Processing Inequality

For Markov chain $X \to Y \to Z$, prove that $I(X; Y) \ge I(X; Z)$.

Click to reveal Step-by-Step Solution

Solution:

Expand mutual information by the chain rule:

$$I(X; Y, Z) = I(X; Y) + I(X; Z \mid Y) = I(X; Z) + I(X; Y \mid Z)$$

Since $X \to Y \to Z$ is Markov, $I(X; Z \mid Y) = 0$. Thus:

$$I(X; Y) = I(X; Z) + I(X; Y \mid Z)$$

Since $I(X; Y \mid Z) \ge 0$, we have:

$$I(X; Y) \ge I(X; Z) \quad \blacksquare$$

AI Insight: Successive layers in a deep neural network cannot create information about the original input; they can only isolate and extract task-relevant signals!

Applied (Feature Selection)

Exercise 3: Ranking Features via Mutual Information

Target $H(Y) = 0.80\text{ bits}$. Feature A has $H(Y \mid X_A) = 0.25$ bits. Feature B has $H(Y \mid X_B) = 0.70$ bits.

Click to reveal Step-by-Step Solution

Solution:

$$I(X_A; Y) = 0.80 - 0.25 = 0.55\text{ bits}$$ $$I(X_B; Y) = 0.80 - 0.70 = 0.10\text{ bits}$$

Feature A shares $5.5\times$ more information with the target label and resolves $68.75\%$ of all uncertainty. It should be selected first.
