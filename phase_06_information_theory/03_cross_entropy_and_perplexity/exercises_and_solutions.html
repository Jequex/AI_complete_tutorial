Exercise 1: Cross-Entropy vs. Entropy on 3-Class Animal Classification

Ground-truth reality $P = [0.50, 0.25, 0.25]$ for `[Dog, Cat, Bird]`.

Model 1: $Q_1 = [0.50, 0.25, 0.25]$

Model 2: $Q_2 = [0.25, 0.50, 0.25]$

Tasks:

  1. Compute $H(P)$, $H(P, Q_1)$, and $H(P, Q_2)$ in bits.
  2. How many excess bits are wasted by Model 2?
Click to reveal Step-by-Step Solution

Solution:

1. Entropies:

$$H(P) = - [0.50 \log_2 0.50 + 2(0.25 \log_2 0.25)] = -[-0.50 - 1.00] = 1.50\text{ bits}$$ $$H(P, Q_1) = H(P) = 1.50\text{ bits}$$ $$H(P, Q_2) = - [0.50 \log_2 0.25 + 0.25 \log_2 0.50 + 0.25 \log_2 0.25] = -[-1.00 - 0.25 - 0.50] = 1.75\text{ bits}$$

2. Wasted Bits:

$$H(P, Q_2) - H(P) = 1.75 - 1.50 = 0.25\text{ bits}$$

Exercise 2: Perplexity of an LLM on a Test Sentence

A language model generates `"AI changes the world"` with target probabilities:

$P(\text{"AI"}) = 0.50, \quad P(\text{"changes"}) = 0.25, \quad P(\text{"the"}) = 0.50, \quad P(\text{"world"}) = 0.125$.

  1. Compute average cross-entropy $\bar{\mathcal{L}}$ in bits/token.
  2. Compute Perplexity $\text{PPL} = 2^{\bar{\mathcal{L}}}$ and interpret it.
Click to reveal Step-by-Step Solution

Solution:

1. Average Loss:

$$\mathcal{L}_1 = -\log_2(0.50) = 1.0\text{ bit}$$ $$\mathcal{L}_2 = -\log_2(0.25) = 2.0\text{ bits}$$ $$\mathcal{L}_3 = -\log_2(0.50) = 1.0\text{ bit}$$ $$\mathcal{L}_4 = -\log_2(0.125) = 3.0\text{ bits}$$ $$\bar{\mathcal{L}} = \frac{1 + 2 + 1 + 3}{4} = 1.75\text{ bits / token}$$

2. Perplexity:

$$\text{PPL} = 2^{1.75} \approx 3.36$$

Interpretation: The model generates each word with the uncertainty of randomly picking between roughly 3.36 equally likely alternatives.

Exercise 3: Complete Softmax Cross-Entropy Gradient

Prove that for logits $\mathbf{z}$ and Softmax probabilities $\mathbf{Q}$, the derivative of cross-entropy $\mathcal{L} = -\sum y_k \ln Q_k$ is:

$$\frac{\partial \mathcal{L}}{\partial z_i} = Q_i - y_i$$
Click to reveal Step-by-Step Solution

Solution:

Recall $\frac{\partial Q_i}{\partial z_i} = Q_i(1 - Q_i)$ and $\frac{\partial Q_k}{\partial z_i} = -Q_k Q_i$ ($k \ne i$).

$$\frac{\partial \mathcal{L}}{\partial z_i} = -\sum_{k} \frac{y_k}{Q_k} \frac{\partial Q_k}{\partial z_i} = -\frac{y_i}{Q_i} [Q_i(1 - Q_i)] - \sum_{k \ne i} \frac{y_k}{Q_k} [-Q_k Q_i]$$ $$= -y_i(1 - Q_i) + \sum_{k \ne i} y_k Q_i = -y_i + y_i Q_i + Q_i \sum_{k \ne i} y_k$$ $$= -y_i + Q_i \left( y_i + \sum_{k \ne i} y_k \right) = -y_i + Q_i(1) = Q_i - y_i \quad \blacksquare$$

The backpropagation gradient is simply (Predicted Probability - True Target)!
