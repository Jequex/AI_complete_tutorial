Exercise 1: Surprisal and Units of Information

An AI agent receives three weather updates from three distinct stations:

  1. Station A (Rain in the Sahara Desert): $P(\text{Rain}) = \frac{1}{64}$.
  2. Station B (Cloudy in Seattle): $P(\text{Cloudy}) = \frac{1}{2}$.
  3. Station C (Sun in Cairo): $P(\text{Sun}) = 1.0$.

Tasks:

  1. Compute the self-information (surprisal) $I(x) = -\log_2 P(x)$ in bits for each report.
  2. Convert Station A's surprisal from bits to nats ($\ln 2 \approx 0.69315$).
  3. Why does Station C convey exactly $0$ bits of information?
Click to reveal Step-by-Step Solution

Solution:

1. Surprisal in Bits:

  • Station A: $I(\text{Rain}) = -\log_2(2^{-6}) = 6\text{ bits}$.
  • Station B: $I(\text{Cloudy}) = -\log_2(2^{-1}) = 1\text{ bit}$.
  • Station C: $I(\text{Sun}) = -\log_2(1.0) = 0\text{ bits}$.

2. Conversion to Nats:

$$I_{\text{nats}}(\text{Rain}) = 6 \times \ln(2) \approx 6 \times 0.693147 = 4.1589\text{ nats}$$

3. Zero Information Explanation:

Station C's sunny forecast has a probability of $1.0$ (complete certainty). Before the message arrives, the observer already knows with $100\%$ certainty that it is sunny. Zero uncertainty was resolved, no beliefs were updated, and therefore zero information was communicated.

Intermediate (Calculus)

Exercise 2: Analytical Maximization of the Binary Entropy Function

The binary entropy function is given by:

$$H_b(p) = -p \log_2(p) - (1-p) \log_2(1-p), \quad p \in (0, 1)$$

Tasks:

  1. Express $H_b(p)$ using the natural log $\ln$.
  2. Compute $\frac{dH_b}{dp}$ and determine the critical point $p^*$.
  3. Use the second derivative $\frac{d^2H_b}{dp^2}$ to prove that $p^*$ is a unique global maximum.
  4. What is the value of $H_b(p^*)$?
Click to reveal Step-by-Step Solution

Solution:

Step 1: Change of Base

$$H_b(p) = -\frac{1}{\ln 2} \left[ p \ln p + (1-p) \ln(1-p) \right]$$

Step 2: First Derivative

$$\frac{d}{dp}[p \ln p] = \ln p + 1$$ $$\frac{d}{dp}[(1-p)\ln(1-p)] = -\ln(1-p) - 1$$ Combining: $$\frac{dH_b}{dp} = -\frac{1}{\ln 2}\Big[ (\ln p + 1) - (\ln(1-p) + 1) \Big] = -\frac{1}{\ln 2} \ln\left(\frac{p}{1-p}\right)$$ Setting to zero: $$\ln\left(\frac{p}{1-p}\right) = 0 \implies \frac{p}{1-p} = 1 \implies p^* = 0.5$$

Step 3: Second Derivative Test

$$\frac{d^2H_b}{dp^2} = -\frac{1}{\ln 2}\left[\frac{1}{p} + \frac{1}{1-p}\right] = -\frac{1}{\ln 2} \cdot \frac{1}{p(1-p)}$$ For $p = 0.5$: $$\left.\frac{d^2H_b}{dp^2}\right|_{p=0.5} = -\frac{1}{\ln 2}\cdot \frac{1}{0.25} = -\frac{4}{\ln 2} \approx -5.77 < 0$$ Since the second derivative is strictly negative everywhere on $(0, 1)$, $p^* = 0.5$ is the unique global maximum.

Step 4: Maximum Value

$$H_b(0.5) = -0.5 \log_2(0.5) - 0.5 \log_2(0.5) = 1.0\text{ bit}$$
Advanced (Lagrange Multipliers)

Exercise 3: Maximum Entropy Distribution for a Discrete Alphabet

Given a discrete random variable $X$ with $K$ states $\{x_1, \dots, x_K\}$ and probabilities $p_i$, find the distribution that maximizes Shannon entropy $H(X) = -\sum_{i=1}^K p_i \ln p_i$ subject to $\sum_{i=1}^K p_i = 1$.

Click to reveal Step-by-Step Solution

Solution:

Step 1: Formulate the Lagrangian

$$\mathcal{L}(p_1, \dots, p_K, \lambda) = -\sum_{i=1}^K p_i \ln p_i - \lambda\left(\sum_{i=1}^K p_i - 1\right)$$

Step 2: Differentiate & Solve

$$\frac{\partial \mathcal{L}}{\partial p_i} = -(\ln p_i + 1) - \lambda = 0 \implies \ln p_i = -(1 + \lambda) \implies p_i = e^{-(1+\lambda)}$$ Because the right side does not depend on index $i$, all $p_i$ must be equal to a constant $c$: $$\sum_{i=1}^K c = K \cdot c = 1 \implies c = \frac{1}{K}$$ Thus, the uniform distribution $p_i^* = \frac{1}{K}$ maximizes entropy, yielding: $$H_{\max}(X) = \log_2 K\text{ bits}$$

Exercise 4: Constructing an Optimal Huffman Code

A vocabulary has 5 tokens with probabilities:

$P(A) = 0.40, \quad P(B) = 0.20, \quad P(C) = 0.15, \quad P(D) = 0.15, \quad P(E) = 0.10$

Tasks:

  1. Compute Shannon entropy $H(X)$ to 4 decimal places.
  2. Construct the Huffman tree and determine binary prefix codes.
  3. Compute average length $L = \sum P(x_i) l_i$ and check $H(X) \le L < H(X) + 1$.
  4. Calculate coding efficiency $\eta = \frac{H(X)}{L} \times 100\%$.

Solution:

1. Shannon Entropy:

$$H(X) = -(0.40 \log_2 0.40 + 0.20 \log_2 0.20 + 0.30 \log_2 0.15 + 0.10 \log_2 0.10) = 2.1464\text{ bits}$$

2. Codewords:

$$L = 0.40(1) + 0.20(3) + 0.15(3) + 0.15(3) + 0.10(3) = 2.20\text{ bits}$$ $$2.1464 \le 2.20 < 3.1464 \quad \text{(Strictly Verified!)}$$
