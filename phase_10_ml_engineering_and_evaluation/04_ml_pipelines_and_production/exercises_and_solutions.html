Problem 1: Algebraic Proof of PSI Symmetric KL Divergence

Information Theory Proof

The Population Stability Index is defined as:

$$\text{PSI}(P, Q) = \sum_{b=1}^B (P_b - Q_b) \ln\left(\frac{P_b}{Q_b}\right)$$
  1. Prove that $\text{PSI}(P, Q) = D_{\text{KL}}(P \parallel Q) + D_{\text{KL}}(Q \parallel P)$.
  2. Prove that $\text{PSI}(P, Q) \ge 0$, and identify when it equals 0.
  3. Why is symmetry important for monitoring pipelines?
View Complete Solution

1. Proof:

$$D_{\text{KL}}(P \parallel Q) + D_{\text{KL}}(Q \parallel P) = \sum P_b \ln\frac{P_b}{Q_b} + \sum Q_b \ln\frac{Q_b}{P_b}$$ $$= \sum P_b \ln\frac{P_b}{Q_b} - \sum Q_b \ln\frac{P_b}{Q_b} = \sum (P_b - Q_b) \ln\left(\frac{P_b}{Q_b}\right) = \text{PSI}(P, Q)$$

2. Non-negativity: By Gibbs' inequality, both $D_{\text{KL}}$ terms are non-negative, hence $\text{PSI} \ge 0$, with equality if and only if $P_b = Q_b \ \forall b$.

3. Symmetry: Standard KL divergence is asymmetric. PSI guarantees that swapping baseline and current production batches produces the exact same drift severity score.

Problem 2: Importance Weighting Under Covariate Shift

Statistical Risk Minimization

Assume $P_{\text{deploy}}(Y \mid X) = P_{\text{tr}}(Y \mid X)$, but $P_{\text{deploy}}(X) \ne P_{\text{tr}}(X)$.

  1. Derive the training expectation for $R_{\text{deploy}}(f) = \mathbb{E}_{\text{deploy}}[L(f(X), Y)]$.
  2. Define the importance weight function $w(x)$.
  3. What happens when the training distribution has zero density where production data exists?
View Complete Solution

1. Derivation:

$$R_{\text{deploy}}(f) = \int L(f(x), y) P_{\text{tr}}(y \mid x) P_{\text{deploy}}(x) dx dy = \int L(f(x), y) \left[\frac{P_{\text{deploy}}(x)}{P_{\text{tr}}(x)}\right] P_{\text{tr}}(x, y) dx dy$$ $$R_{\text{deploy}}(f) = \mathbb{E}_{\text{tr}}[w(X) L(f(X), Y)]$$

2. Weight Function: $w(x) = \frac{P_{\text{deploy}}(x)}{P_{\text{tr}}(x)}$.

3. Support Violation: When $P_{\text{tr}}(x) = 0$ while $P_{\text{deploy}}(x) > 0$, the ratio explodes to infinity and the model has zero data to generalize to that domain.

Problem 3: Pickle Security Exploit vs. Safetensors Defense

Software Security

An attacker crafts a file using Python's __reduce__ hook that triggers os.system(...) during unpickling.

  1. Why does pickle.load() automatically execute this code?
  2. Why is Python pickle inherently unsafe for untrusted models?
  3. How does the Safetensors format eliminate remote code execution?
View Complete Solution

1. Unpickling Execution: pickle operates a virtual stack machine. The __reduce__ method instructs the unpickler to instantiate an object by calling a specified callable (e.g. os.system) with arbitrary arguments.

2. Inherent Flaw: Pickle does not store pure data; it serializes arbitrary Python execution state and callable hooks.

3. Safetensors Defense: Safetensors uses an 8-byte length header, a pure UTF-8 JSON header for tensor metadata, and raw contiguous binary buffers. It has no bytecode VM or execution hooks, enabling safe, zero-copy memory mapping.
