Topic 10.2: Feature Engineering, Scaling & Encoding

Preparing numerical and categorical data for mathematical optimizers: standardization vs normalization, condition numbers, high-cardinality encodings, and non-linear feature maps.

1. Executive Summary & The 12-Year-Old Analogy

Machine learning models operate entirely on pure numerical matrices. When one column has magnitudes in thousands ($x_1 \in [600, 5000]$) and another is near zero ($x_2 \in [1, 5]$), numerical optimization algorithms like Gradient Descent struggle because the loss surface becomes an extremely steep, elongated elliptical canyon.

🧭 The 12-Year-Old Analogy: Converting Inches and Miles

Imagine two bridge builders collaborating on blueprints:

  • Bob writes all distances in Miles ($0.002$ miles).
  • Alice writes all distances in Inches ($126,720$ inches).

If a calculator simply adds their numbers together without checking the units, Alice's numbers will completely drown out Bob's measurements! Feature Scaling gives all features the exact same standard ruler so no single feature dominates purely because of its measurement units.

2. Mathematical Symbol Decoder

$x_{\min}, x_{\max}$ Scalars Minimum and maximum observed training values
$Q_1, Q_2, Q_3, \text{IQR}$ Scalars 25th percentile, Median (50th), 75th percentile, and Interquartile Range
$H = \nabla^2 \mathcal{L}(w)$ $\mathbb{R}^{d \times d}$ matrix Hessian matrix of loss function second derivatives
$\kappa(H) = \frac{\lambda_{\max}}{\lambda_{\min}}$ $\mathbb{R}_{\ge 1}$ Condition number of the Hessian: ratio of maximum to minimum curvature
$S_c$ Scalar Empirical Bayes smoothed target encoding for category $c$

3. The Mechanics of Feature Scalers

3.1 Z-Score Standardization

$$z_i = \frac{x_i - \mu_{\text{train}}}{\sigma_{\text{train}}}$$

Centers features around $0$ with unit variance ($\sigma^2 = 1$). Essential for gradient descent, logistic regression, support vector machines, and PCA.

3.2 Min-Max Normalization

$$x'_i = \frac{x_i - x_{\min}}{x_{\max} - x_{\min}} \in [0, 1]$$

Binds all values strictly between 0 and 1. Highly sensitive to outliers, but required for neural networks with bounded activation functions or image pixel processing.

3.3 Robust Scaler (Median & IQR)

$$x_{\text{robust}} = \frac{x_i - \text{Median}(X)}{\text{IQR}(X)} = \frac{x_i - Q_2}{Q_3 - Q_1}$$

Uses order statistics (percentiles) rather than sums of squares. Immune to extreme anomalies and heavy-tailed outliers.

4. The Hessian Condition Number: Why Scaling Speeds Convergence

For linear regression with MSE loss, the Hessian is $H = \frac{1}{N} X^T X$. The maximum safe learning rate is bounded by the steepest curvature direction:

$$\eta_{\max} < \frac{2}{\lambda_{\max}(H)}$$

The convergence rate along the slowest direction is governed by $\lambda_{\min}(H)$:

$$\text{Rate} \approx 1 - \frac{\lambda_{\min}}{\lambda_{\max}} = 1 - \frac{1}{\kappa(H)}$$

When features are unscaled, $\kappa(H) \gg 10^5$, forcing an ultra-small learning rate $\eta$, causing gradient descent to take tens of thousands of steps. Standardizing features aligns eigenvalues so $\kappa(H) \approx 1$, allowing massive learning rates and rapid direct convergence.

5. Categorical Feature Encoding

  • One-Hot Encoding (OHE): Expands $K$ unique categories into $K$ binary indicator columns. For linear models with an intercept, drop 1 column ($K-1$ dummy columns) to prevent collinearity.
  • Ordinal Encoding: Maps ordered values to integers ($[0, 1, 2]$). Never use on unordered categories like city names.
  • Target Encoding with Smoothing: For high-cardinality features (e.g. zip codes), replace category $c$ with its blended target mean: $$S(c) = \frac{n_c \bar{y}_c + m \mu_{\text{global}}}{n_c + m}$$

6. Algorithm Scaling Dependency Matrix

Model Architecture Scaling Required? Underlying Reason
Linear / Logistic Regression YES $L_1/L_2$ penalties unfairly penalize small features; GD bounces in narrow loss canyons.
K-Nearest Neighbors (KNN) CRITICAL Euclidean distance $d(u,v) = \sqrt{\sum (u_j - v_j)^2}$ is hijacked by large-scale dimensions.
Principal Component Analysis (PCA) CRITICAL Eigenvectors maximize variance; columns with large variance capture all top components.
Deep Neural Networks (MLP/CNN) YES Unscaled inputs saturate sigmoid/tanh activations and cause exploding gradients.
Decision Trees / Random Forest / XGBoost NO Splits evaluate threshold inequalities $x_j \le \theta$, which are invariant to monotonic scaling.
