Exercise 1: Sizing 3D Parallelism for GPT-3 (175B) on 512 A100s

You train a 175B model ($\Phi = 175 \times 10^9$, 96 layers, 96 heads) on $N = 512\text{ A100 (80GB)}$ GPUs arranged in 64 8-GPU NVLink nodes. Global batch size is 1,536.

  1. Why choose $T = 8$? Why not $T = 16$?
  2. With $T = 8$ and $p = 8$, find the Data Parallel degree $D$.
  3. To achieve bubble fraction $F \le 8\%$, find the minimum micro-batches $m$.
  4. What is the micro-batch size if global batch is 1,536?
Click to view Solution

Solution:

1. Tensor Parallel Degree $T = 8$:

TP performs 2 All-Reduces per layer. Intra-node NVLink provides $600\text{ GB/s}$, whereas InfiniBand provides only $25\text{ GB/s}$. Choosing $T = 8$ confines all high-frequency TP communication to the physical 8-GPU node. Also, 96 attention heads divides cleanly by 8 (12 heads/GPU).

2. Data Parallel Degree $D$:

$$D = \frac{N}{p \times T} = \frac{512}{8 \times 8} = \mathbf{8}$$

3. Minimum Micro-Batches $m$:

$$F = \frac{p - 1}{m + p - 1} \le 0.08 \implies \frac{7}{m + 7} \le 0.08 \implies m \ge \mathbf{81\text{ micro-batches}}$$

4. Micro-batch size:

Per DP replica: $\frac{1536}{8} = 192$ sequences. With $m = 96$ microbatches, micro-batch size $b = \frac{192}{96} = \mathbf{2\text{ sequences}}$.

Exercise 2: Megatron-LM All-Reduce Volume per Transformer Layer

Given $H = 4{,}096$, $S = 2{,}048$, batch size $B = 4$, FP16 precision ($2\text{ bytes/elem}$), and $T = 4$ GPUs.

  1. Identify all All-Reduce points in the layer.
  2. Find the tensor size transmitted in each All-Reduce.
  3. Calculate total data transmitted per GPU for one forward-backward step.
Click to view Solution

Solution:

1. All-Reduce Points: 1 at end of Attention block (row-parallel $W_O$) + 1 at end of MLP block (row-parallel $W_2$) = 2 in forward, 2 in backward.

2. Tensor Size: $B \times S \times H \times 2 = 4 \times 2{,}048 \times 4{,}096 \times 2\text{ bytes} = \mathbf{67.11\text{ MB}}$.

3. Total Data Transferred per GPU:

Per All-Reduce: $2 \cdot \frac{T-1}{T} M = 2 \cdot \frac{3}{4} \times 67.11\text{ MB} = 100.66\text{ MB}$.

$$\text{Total per layer} = 4 \times 100.66\text{ MB} = \mathbf{402.66\text{ MB}}$$

Exercise 3: ZeRO-2 vs ZeRO-3 on an 8-GPU Node for 13B Model

Model has $\Phi = 13 \times 10^9$ params ($16\Phi = 208\text{ GB}$ total states). Available VRAM is 80GB, with activations requiring 25GB ($55\text{ GB}$ available for states). $N = 8$ GPUs.

  1. Compute memory per GPU under DDP, ZeRO-1, ZeRO-2, and ZeRO-3.
  2. Which strategies fit without OOM?
  3. Compare network transfer volume between ZeRO-2 and ZeRO-3.
Click to view Solution

Solution:

1. Memory per GPU:

  • DDP: $16\Phi = \mathbf{208.0\text{ GB}}$
  • ZeRO-1: $4\Phi + \frac{12\Phi}{8} = 52 + 19.5 = \mathbf{71.5\text{ GB}}$
  • ZeRO-2: $2\Phi + \frac{14\Phi}{8} = 26 + 22.75 = \mathbf{48.75\text{ GB}}$
  • ZeRO-3: $\frac{16\Phi}{8} = \mathbf{26.0\text{ GB}}$

2. OOM Assessment: DDP ($208\text{ GB}$) and ZeRO-1 ($71.5\text{ GB}$) exceed the $55\text{ GB}$ state budget. Both ZeRO-2 and ZeRO-3 fit.

3. Communication: ZeRO-2 sends $2\Phi = 52\text{ GB}$; ZeRO-3 sends $3\Phi = 78\text{ GB}$. Because ZeRO-2 fits within memory ($48.75 + 25 = 73.75\text{ GB} < 80\text{ GB}$), ZeRO-2 is optimal, saving $26\text{ GB}$ of network traffic per step.
