Topic 28.5: Exercises & Solutions

Quantitative problems on activation memory explosion, hierarchical 2-level checkpointing ($\mathcal{O}(L^{1/3})$), and FlashAttention HBM IO reduction factors.

Exercise 1: Transformer Activation Memory Scaling

For LLaMA-70B ($D = 8{,}192, H = 64, d_{\text{ffn}} = 28{,}672$) in FP16 with $B = 2$, compute activation memory at context lengths $S = 2{,}048$, $S = 8{,}192$, and $S = 32{,}768$. Across 80 layers, does it fit on an 80GB GPU at $S = 32{,}768$? What does checkpointing achieve?

Click to view Solution

Solution:

1. Single Layer Activations:

$$A_{\text{layer}}(S) = 327{,}680 \cdot S + 256 \cdot S^2\text{ bytes}$$
  • $S = 2{,}048$: $671\text{ MB} + 1{,}074\text{ MB} = \mathbf{1.745\text{ GB}}$.
  • $S = 8{,}192$: $2.68\text{ GB} + 17.18\text{ GB} = \mathbf{19.86\text{ GB}}$.
  • $S = 32{,}768$: $10.74\text{ GB} + 274.88\text{ GB} = \mathbf{285.62\text{ GB}}$!

2. 80 Layers Total:

At $S = 32{,}768$: $80 \times 285.62\text{ GB} = \mathbf{22{,}849.6\text{ GB}} \approx \mathbf{22.85\text{ TB}}$ (completely impossible on one 80GB GPU!).

3. With Activation Checkpointing ($k = 9$) & FlashAttention:

FlashAttention eliminates the quadratic term entirely. Peak activation memory drops to:

$$M_{\text{peak}} \approx 2\sqrt{80} \times A_{\text{linear}} \approx 18 \times 0.67\text{ GB} \approx \mathbf{12.0\text{ GB}}$$

Fits comfortably within the 80GB GPU budget!

Exercise 2: Hierarchical 2-Level Activation Checkpointing ($\mathcal{O}(L^{1/3})$)

For an ultra-deep model with $L = 1{,}000$ layers, consider a 2-level hierarchical checkpointing strategy: top-level checkpoints every $k_1$ layers, sub-checkpoints every $k_2$ layers inside active segment $k_1$.

  1. Formulate the memory objective $M(k_1, k_2)$.
  2. Derive optimal intervals $k_1^*$ and $k_2^*$.
  3. Compare peak memory for $L = 1{,}000$ across standard, 1-level, and 2-level checkpointing.
Click to view Solution

Solution:

1. Memory Objective:

$$M(k_1, k_2) = \frac{L}{k_1} + \frac{k_1}{k_2} + k_2$$

2. Optimization:

$$\frac{\partial M}{\partial k_2} = -\frac{k_1}{k_2^2} + 1 = 0 \implies k_2^* = \sqrt{k_1}$$ $$M(k_1) = \frac{L}{k_1} + 2\sqrt{k_1} \implies \frac{dM}{dk_1} = -\frac{L}{k_1^2} + \frac{1}{\sqrt{k_1}} = 0 \implies \mathbf{k_1^* = L^{2/3}}, \quad \mathbf{k_2^* = L^{1/3}}$$

3. Peak Memory Comparison ($L = 1{,}000$):

  • Standard Backprop: $L = \mathbf{1{,}000\text{ units}}$.
  • 1-Level Checkpointing: $2\sqrt{1{,}000} \approx \mathbf{63.2\text{ units}}$ ($93.7\%$ savings).
  • 2-Level Checkpointing: $3 L^{1/3} = 3 \times 10 = \mathbf{30.0\text{ units}}$ ($97.0\%$ savings).

Exercise 3: FlashAttention HBM IO Reduction

Calculate HBM data traffic for an attention head with sequence length $S = 16{,}384$ and head dimension $d = 128$ in FP16.

  1. Compute total bytes transferred in standard attention (writing/reading $S \times S$ scores and probabilities).
  2. Compute bytes transferred in FlashAttention (only reading $Q, K, V$ and writing $O$).
  3. Compute the IO reduction factor.
Click to view Solution

Solution:

1. Standard Attention HBM Traffic:

Read $Q, K$ ($8.39\text{ MB}$) + Write $S$ ($536.87\text{ MB}$) + Read/Write Softmax $P$ ($1{,}073.74\text{ MB}$) + Compute $O$ ($545.25\text{ MB}$) = $\mathbf{2{,}164.25\text{ MB}} \approx \mathbf{2.164\text{ GB}}$.

2. FlashAttention HBM Traffic:

Read $Q, K, V$ ($3 \times 4.19\text{ MB}$) + Write Output $O$ ($4.19\text{ MB}$) = $\mathbf{16.78\text{ MB}}$.

3. IO Reduction Factor:

$$\text{Reduction Factor} = \frac{2{,}164.25\text{ MB}}{16.78\text{ MB}} \approx \mathbf{129.0\times}$$

FlashAttention eliminates $99.2\%$ of off-chip memory traffic, removing memory bus contention entirely.
