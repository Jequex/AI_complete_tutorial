Exercise 1: Ring All-Reduce vs. Parameter Server for LLaMA-70B

You synchronize gradients for a 70B parameter model in FP16 ($M = 140\text{ GB}$) across $N = 128\text{ GPUs}$ connected via $400\text{ Gbps}$ InfiniBand ($B = 50\text{ GB/s}$ sustained).

  1. Compute total volume handled by the server in Parameter Server and its execution time.
  2. Compute volume transferred per GPU in Ring All-Reduce and its execution time.
  3. Calculate the speedup of Ring All-Reduce.
Click to view Solution

Solution:

1. Parameter Server:

The server receives $(N-1)M$ and transmits $(N-1)M \implies 2(127) \times 140\text{ GB} = \mathbf{35{,}560\text{ GB}}$.

$$T_{\text{PS}} = \frac{35{,}560\text{ GB}}{50\text{ GB/s}} = \mathbf{711.2\text{ seconds}} \approx \mathbf{11.85\text{ minutes/step}}$$

2. Ring All-Reduce:

Each GPU sends $2 \cdot \frac{N-1}{N} M = 2 \cdot \frac{127}{128} \times 140\text{ GB} \approx \mathbf{277.81\text{ GB}}$.

$$T_{\text{ring}} = \frac{277.81\text{ GB}}{50\text{ GB/s}} = \mathbf{5.556\text{ seconds}}$$

3. Speedup:

$$\text{Speedup} = \frac{711.2\text{ s}}{5.556\text{ s}} \approx \mathbf{128\times}$$

Exercise 2: Hockney Model & Ring vs. Tree Crossover

For $N = 64\text{ GPUs}$, latency $\alpha = 5\ \mu\text{s}$, bandwidth $\beta = 50\text{ GB/s}$:

$$T_{\text{ring}}(M) = 2(N - 1)\alpha + 2\frac{N - 1}{N}\frac{M}{\beta}$$ $$T_{\text{tree\_contention}}(M) = 2\log_2(N)\alpha + 4\frac{N - 1}{N}\frac{M}{\beta}$$

Derive the crossover message size $M^*$ where Ring All-Reduce overtakes Tree All-Reduce.

Click to view Solution

Solution:

Equating $T_{\text{ring}}(M^*) = T_{\text{tree}}(M^*)$:

$$2(63)\alpha + 2\frac{63}{64}\frac{M^*}{\beta} = 2(6)\alpha + 4\frac{63}{64}\frac{M^*}{\beta}$$ $$2(57)\alpha = 2\frac{63}{64}\frac{M^*}{\beta} \implies M^* = \frac{57 \times 64 \times \beta \cdot \alpha}{63}$$ $$M^* = \frac{57 \times 64 \times (50 \times 10^9) \times (5 \times 10^{-6})}{63} \approx \mathbf{14.48\text{ MB}}$$

For tensors $< 14.5\text{ MB}$, Tree is faster; for tensors $> 14.5\text{ MB}$ (standard gradient buckets), Ring achieves optimal bandwidth.

Exercise 3: Step-by-Step 4-GPU State Trace

Trace 4 GPUs synchronizing 4 scalars $M = 4$ through Scatter-Reduce:

GPU 0: [1, 2, 3, 4], GPU 1: [10, 20, 30, 40], GPU 2: [100, 200, 300, 400], GPU 3: [1000, 2000, 3000, 4000].

Click to view Solution

Solution:

At step $k$, rank $i$ transmits chunk $(i - k) \pmod 4$ to rank $(i + 1) \pmod 4$.

  • Step 1 ($k=0$): GPU 0 sends chunk 0 to 1 ($10+1=11$), GPU 1 sends chunk 1 to 2 ($200+20=220$), GPU 2 sends chunk 2 to 3 ($3000+300=3300$), GPU 3 sends chunk 3 to 0 ($4+4000=4004$).
  • Step 2 ($k=1$): GPU 0 sends chunk 3 to 1 ($40+4004=4044$), GPU 1 sends chunk 0 to 2 ($100+11=111$), GPU 2 sends chunk 1 to 3 ($2000+220=2220$), GPU 3 sends chunk 2 to 0 ($3+3300=3303$).
  • Step 3 ($k=2$): GPU 0 sends chunk 2 to 1 ($30+3303=3333$), GPU 1 sends chunk 3 to 2 ($400+4044=4444$), GPU 2 sends chunk 0 to 3 ($1000+111=1111$), GPU 3 sends chunk 1 to 0 ($2+2220=2222$).

Each GPU holds one complete global sum: GPU 3 has chunk 0 ($1111$), GPU 0 has chunk 1 ($2222$), GPU 1 has chunk 2 ($3333$), GPU 2 has chunk 3 ($4444$).
