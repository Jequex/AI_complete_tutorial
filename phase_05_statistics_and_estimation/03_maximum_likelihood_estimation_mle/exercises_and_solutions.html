Problem 1: Exponential Distribution MLE for Server Hardware Lifetime

Easy

A GPU cluster tracks continuous hardware failure times $x_1, \dots, x_n$ following an Exponential distribution:

$$P(x \mid \lambda) = \lambda e^{-\lambda x}, \quad x \ge 0$$
  1. Write the joint likelihood $L(\lambda)$ and log-likelihood $\ell(\lambda)$.
  2. Differentiate with respect to $\lambda$ and solve for $\hat{\lambda}$.
  3. Verify the second derivative concavity check.
  4. Express $\hat{\lambda}_{\text{MLE}}$ in terms of the sample mean $\bar{X}$.
Click to Reveal Step-by-Step Solution

1. Likelihood & Log-Likelihood

$$L(\lambda) = \prod_{i=1}^n (\lambda e^{-\lambda x_i}) = \lambda^n \exp\left(-\lambda \sum_{i=1}^n x_i\right)$$ $$\mathbf{\ell(\lambda) = n \ln\lambda - \lambda \sum_{i=1}^n x_i}$$

2. Derivative & Solution

$$\frac{d\ell}{d\lambda} = \frac{n}{\lambda} - \sum_{i=1}^n x_i = 0 \implies \mathbf{\hat{\lambda} = \frac{n}{\sum_{i=1}^n x_i} = \frac{1}{\bar{X}}}$$

3. Second Derivative

$$\frac{d^2\ell}{d\lambda^2} = -\frac{n}{\lambda^2} < 0 \quad (\text{Strictly concave } \implies \text{Global Maximum!})$$
Result: $\hat{\lambda}_{\text{MLE}} = \frac{1}{\bar{X}}$. If average GPU lifespan is 4 years, the estimated failure rate is $\frac{1}{4} = 0.25$ per year.

Problem 2: Poisson Distribution MLE for AI API Request Traffic

Medium

Inference requests arriving per minute follow a Poisson distribution $P(k \mid \lambda) = \frac{\lambda^k e^{-\lambda}}{k!}$. Over $n = 5$ minutes, counts are $D = \{5, 8, 3, 4, 10\}$.

  1. Derive the analytical formula for $\hat{\lambda}_{\text{MLE}}$.
  2. Calculate the numerical estimate for dataset $D$.
Click to Reveal Step-by-Step Solution

1. Derivation

$$\ell(\lambda) = \sum_{i=1}^n [k_i \ln\lambda - \lambda - \ln(k_i!)] = \left(\sum_{i=1}^n k_i\right) \ln\lambda - n\lambda - \sum_{i=1}^n \ln(k_i!)$$ $$\frac{d\ell}{d\lambda} = \frac{\sum k_i}{\lambda} - n = 0 \implies \mathbf{\hat{\lambda}_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n k_i = \bar{K}}$$

2. Numerical Evaluation

$$\hat{\lambda}_{\text{MLE}} = \frac{5 + 8 + 3 + 4 + 10}{5} = \frac{30}{5} = \mathbf{6.0 \text{ requests / minute}}$$

Problem 3: Formal Proof: The Gaussian MLE Variance is Systematically Biased

Challenging

Recall the Gaussian log-likelihood for unknown $\mu$ and $\sigma^2$:

$$\ell(\mu, \sigma^2) = -\frac{n}{2}\ln(2\pi) - \frac{n}{2}\ln(\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (X_i - \mu)^2$$
  1. Derive $\hat{\sigma}^2_{\text{MLE}}$ by setting $\frac{\partial \ell}{\partial (\sigma^2)} = 0$.
  2. Calculate $\mathbb{E}[\hat{\sigma}^2_{\text{MLE}}]$.
  3. Is MLE always unbiased? What happens as $n \to \infty$?
Click to Reveal Step-by-Step Solution

1. Derivation of $\hat{\sigma}^2_{\text{MLE}}$

$$\frac{\partial \ell}{\partial (\sigma^2)} = -\frac{n}{2\sigma^2} + \frac{1}{2(\sigma^2)^2}\sum_{i=1}^n (X_i - \bar{X})^2 = 0$$ $$\mathbf{\hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2} \quad \blacksquare$$

2. Mathematical Expectation

$$\mathbb{E}[\hat{\sigma}^2_{\text{MLE}}] = \frac{1}{n}\mathbb{E}\left[\sum_{i=1}^n(X_i - \bar{X})^2\right] = \frac{1}{n}(n - 1)\sigma^2 = \mathbf{\frac{n - 1}{n}\sigma^2}$$
Surprising Truth: Maximum Likelihood Estimators are NOT guaranteed to be unbiased! For finite sample size $n$, $\hat{\sigma}^2_{\text{MLE}}$ is biased. However, because $\lim_{n \to \infty} \frac{n-1}{n} = 1$, it is asymptotically unbiased!
