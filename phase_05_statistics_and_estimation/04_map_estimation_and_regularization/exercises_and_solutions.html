Problem 1: Precision-Weighted 1D Gaussian Mean MAP Estimation

Easy

Let $X_1, \dots, X_n \sim \mathcal{N}(\mu, \sigma^2)$ with known noise $\sigma^2$. We place a Gaussian prior $\mu \sim \mathcal{N}(\mu_0, \sigma_0^2)$.

  1. Write the log-posterior $J(\mu) = \ln P(D \mid \mu) + \ln P(\mu)$.
  2. Differentiate with respect to $\mu$ and solve for $\hat{\mu}_{\text{MAP}}$.
  3. Express $\hat{\mu}_{\text{MAP}}$ using precision $\tau = 1/\text{Var}$, with $\tau_{\text{data}} = \frac{n}{\sigma^2}$ and $\tau_{\text{prior}} = \frac{1}{\sigma_0^2}$.
  4. Evaluate what happens as $n \to \infty$ or $\sigma_0^2 \to \infty$.
Click to Reveal Step-by-Step Solution

1. Log-Posterior

$$J(\mu) = -\frac{1}{2\sigma^2}\sum_{i=1}^n(X_i - \mu)^2 - \frac{1}{2\sigma_0^2}(\mu - \mu_0)^2 + C$$

2. Derivative & Solution

$$\frac{dJ}{d\mu} = \frac{n}{\sigma^2}(\bar{X} - \mu) - \frac{1}{\sigma_0^2}(\mu - \mu_0) = 0$$ $$\mathbf{\hat{\mu}_{\text{MAP}} = \frac{\frac{n}{\sigma^2}\bar{X} + \frac{1}{\sigma_0^2}\mu_0}{\frac{n}{\sigma^2} + \frac{1}{\sigma_0^2}}}$$

3. Precision-Weighted Form

$$\mathbf{\hat{\mu}_{\text{MAP}} = \frac{\tau_{\text{data}}\bar{X} + \tau_{\text{prior}}\mu_0}{\tau_{\text{data}} + \tau_{\text{prior}}}} \quad \blacksquare$$
Interpretation: The MAP estimate is a weighted compromise between sample evidence and prior belief. As $n \to \infty$, data precision $\tau_{\text{data}} \to \infty$, causing $\hat{\mu}_{\text{MAP}} \to \bar{X} = \hat{\mu}_{\text{MLE}}$!

Problem 2: Closed-Form Ridge Regression Matrix MAP Derivation

Medium

In linear regression, $\mathbf{y} \sim \mathcal{N}(X\mathbf{w}, \sigma^2 I_n)$ with Gaussian prior $\mathbf{w} \sim \mathcal{N}(\mathbf{0}, \sigma_0^2 I_d)$.

  1. Write the vector log-posterior $J(\mathbf{w})$.
  2. Compute the vector gradient $\nabla_{\mathbf{w}} J(\mathbf{w})$.
  3. Set the gradient to zero and derive $\hat{\mathbf{w}}_{\text{MAP}} = (X^T X + \lambda I_d)^{-1} X^T \mathbf{y}$ where $\lambda = \frac{\sigma^2}{\sigma_0^2}$.
  4. Explain why $(X^T X + \lambda I_d)$ is guaranteed invertible even when features exceed samples ($d > n$).
Click to Reveal Step-by-Step Solution

1. Matrix Log-Posterior

$$J(\mathbf{w}) = -\frac{1}{2\sigma^2}(\mathbf{y} - X\mathbf{w})^T(\mathbf{y} - X\mathbf{w}) - \frac{1}{2\sigma_0^2}\mathbf{w}^T\mathbf{w}$$

2. Vector Gradient

$$\nabla_{\mathbf{w}} J(\mathbf{w}) = \frac{1}{\sigma^2} X^T(\mathbf{y} - X\mathbf{w}) - \frac{1}{\sigma_0^2}\mathbf{w} = 0$$

3. Deriving the Solution

$$\frac{1}{\sigma^2} X^T X \mathbf{w} + \frac{1}{\sigma_0^2}\mathbf{w} = \frac{1}{\sigma^2} X^T \mathbf{y} \implies \left(X^T X + \frac{\sigma^2}{\sigma_0^2}I_d\right)\mathbf{w} = X^T \mathbf{y}$$ $$\mathbf{\hat{\mathbf{w}}_{\text{MAP}} = (X^T X + \lambda I_d)^{-1} X^T \mathbf{y}} \quad \blacksquare$$
Numerical Stability: When $d > n$, $X^T X$ is singular. Adding $\lambda I$ shifts all eigenvalues by $+\lambda > 0$, guaranteeing positive definiteness and full invertibility!

Problem 3: The Subgradient Calculus of L1 Sparsity (Soft-Thresholding)

Challenging

Consider the 1D Lasso objective: $f(w) = \frac{1}{2}(w - a)^2 + \lambda |w|$. Its subgradient is $\partial |w| = \{+1\}$ if $w > 0$, $[-1, 1]$ if $w = 0$, and $\{-1\}$ if $w < 0$.

  1. Find $w^*$ for $w > 0$.
  2. Find $w^*$ for $w < 0$.
  3. Using $0 \in \partial f(0)$, prove that $w^* = 0$ if and only if $|a| \le \lambda$.
  4. State the unified soft-thresholding operator: $w^* = \operatorname{sign}(a)\max(0, |a| - \lambda)$.
Click to Reveal Step-by-Step Solution

1. Positive Branch ($w > 0$)

$$f'(w) = (w - a) + \lambda = 0 \implies \mathbf{w^* = a - \lambda} \quad (\text{Valid when } a > \lambda)$$

2. Negative Branch ($w < 0$)

$$f'(w) = (w - a) - \lambda = 0 \implies \mathbf{w^* = a + \lambda} \quad (\text{Valid when } a < -\lambda)$$

3. Zero Branch ($w = 0$)

$$\partial f(0) = -a + [-\lambda, \lambda] = [-a - \lambda, \, -a + \lambda]$$ $$0 \in [-a - \lambda, \, -a + \lambda] \iff -\lambda \le a \le \lambda \iff \mathbf{|a| \le \lambda}$$

4. Unified Soft-Thresholding Operator

$$\mathbf{w^* = \operatorname{sign}(a) \max(0, \, |a| - \lambda)} \quad \blacksquare$$
The Origin of L1 Sparsity: Any feature whose unregularized correlation $|a|$ is below threshold $\lambda$ is forced to exact zero!
