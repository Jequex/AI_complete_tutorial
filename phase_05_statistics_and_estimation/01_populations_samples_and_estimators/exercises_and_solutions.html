Problem 1: Sample Statistics & The Bessel Ratio on Numerical Data

Easy

An AI engineer logs the inference latency (in milliseconds) of 4 consecutive requests to a neural model:

$$X = \{ 4.0, \, 7.0, \, 10.0, \, 15.0 \}$$
  1. Calculate the sample mean $\bar{X}$.
  2. Compute the sum of squared deviations $\sum_{i=1}^4 (X_i - \bar{X})^2$.
  3. Compute the naive sample variance $S_n^2$ (dividing by $n = 4$).
  4. Compute the unbiased Bessel-corrected sample variance $S^2$ (dividing by $n - 1 = 3$).
  5. Confirm that $\frac{S_n^2}{S^2} = \frac{n - 1}{n}$.
Click to Reveal Step-by-Step Solution

1. Sample Mean

$$\bar{X} = \frac{4.0 + 7.0 + 10.0 + 15.0}{4} = \frac{36.0}{4} = \mathbf{9.0 \text{ ms}}$$

2. Squared Deviations

  • $(4.0 - 9.0)^2 = (-5.0)^2 = 25.0$
  • $(7.0 - 9.0)^2 = (-2.0)^2 = 4.0$
  • $(10.0 - 9.0)^2 = (+1.0)^2 = 1.0$
  • $(15.0 - 9.0)^2 = (+6.0)^2 = 36.0$
$$\sum_{i=1}^4 (X_i - \bar{X})^2 = 25.0 + 4.0 + 1.0 + 36.0 = \mathbf{66.0}$$

3. Naive Sample Variance ($S_n^2$)

$$S_n^2 = \frac{66.0}{4} = \mathbf{16.5 \text{ ms}^2}$$

4. Unbiased Sample Variance ($S^2$)

$$S^2 = \frac{66.0}{4 - 1} = \frac{66.0}{3} = \mathbf{22.0 \text{ ms}^2}$$

5. Verification of the Ratio

$$\frac{S_n^2}{S^2} = \frac{16.5}{22.0} = 0.75 = \mathbf{\frac{3}{4} = \frac{n - 1}{n}} \quad \blacksquare$$

Problem 2: Standard Error Scaling in LLM Benchmark Evaluation

Medium

An AI evaluation engineer tests an LLM on a reasoning benchmark (MMLU). Each test prompt is scored binary: $1$ if correct, $0$ if wrong. The population standard deviation of binary success is $\sigma \approx 0.50$.

  1. If the engineer tests the model on $n = 100$ prompts, what is the Standard Error $\text{SE}(\bar{X})$ of the accuracy score?
  2. If the engineer wants to report benchmark accuracy with uncertainty of no more than $\pm 1\%$ ($\text{SE} \le 0.01$), what is the minimum number of evaluation prompts $n$ required?
  3. Why does this make comparing models that differ by only $0.5\%$ on 500 prompts statistically meaningless?
Click to Reveal Step-by-Step Solution

1. Standard Error for $n = 100$

$$\text{SE}(\bar{X}) = \frac{\sigma}{\sqrt{n}} = \frac{0.50}{\sqrt{100}} = \frac{0.50}{10} = \mathbf{0.05 \quad (5.0\%)}$$

2. Minimum Sample Size for $\text{SE} \le 0.01$

$$\frac{0.50}{\sqrt{n}} \le 0.01 \implies \sqrt{n} \ge \frac{0.50}{0.01} = 50 \implies n \ge 50^2 = \mathbf{2{,}500 \text{ prompts}}$$

3. Leaderboard Implication

Statistical Significance in AI: On 500 prompts, the standard error is $\frac{0.50}{\sqrt{500}} \approx 2.24\%$. Because the measurement noise ($2.24\%$) is more than 4 times larger than the observed difference ($0.50\%$), the difference is within random chance!

Problem 3: Optimal Weighting Proof & The Gauss-Markov Theorem

Challenging

Let $X_1, \dots, X_n$ be independent observations with mean $\mu$ and variance $\sigma^2$. Consider a general linear estimator:

$$\hat{\mu} = \sum_{i=1}^n w_i X_i$$
  1. Find the condition on weights $w_i$ such that $\hat{\mu}$ is an unbiased estimator of $\mu$.
  2. Write the formula for $\operatorname{Var}(\hat{\mu})$.
  3. Prove using the Cauchy-Schwarz inequality that the variance is strictly minimized when all weights are equal: $w_i = \frac{1}{n}$.
Click to Reveal Step-by-Step Solution

1. Unbiasedness Condition

$$\mathbb{E}[\hat{\mu}] = \sum_{i=1}^n w_i \mathbb{E}[X_i] = \mu \sum_{i=1}^n w_i \implies \mathbf{\sum_{i=1}^n w_i = 1}$$

2. Variance Formula

$$\operatorname{Var}(\hat{\mu}) = \sum_{i=1}^n w_i^2 \operatorname{Var}(X_i) = \mathbf{\sigma^2 \sum_{i=1}^n w_i^2}$$

3. Cauchy-Schwarz Proof

Apply Cauchy-Schwarz to $\mathbf{u} = [w_1, \dots, w_n]^T$ and $\mathbf{v} = [1, \dots, 1]^T$:

$$\left(\sum_{i=1}^n w_i \cdot 1\right)^2 \le \left(\sum_{i=1}^n w_i^2\right) \left(\sum_{i=1}^n 1^2\right)$$ $$1^2 \le \left(\sum_{i=1}^n w_i^2\right) \cdot n \implies \sum_{i=1}^n w_i^2 \ge \mathbf{\frac{1}{n}}$$

Equality holds if and only if $w_1 = w_2 = \dots = w_n = \frac{1}{n} \quad \blacksquare$

The Gauss-Markov Theorem: The simple arithmetic mean $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ is proven to be the Best Linear Unbiased Estimator (BLUE), possessing the lowest possible variance among all linear unbiased estimators!
