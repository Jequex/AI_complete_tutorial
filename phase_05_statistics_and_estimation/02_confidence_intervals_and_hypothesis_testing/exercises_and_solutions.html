Topic 5.2: Exercises & Solutions

Master confidence intervals, two-sample proportion tests for prompt engineering, and sample size calculations for statistical power.

Problem 1: 95% Confidence Interval for LLM Token Latency

Easy

An infrastructure engineer records output token generation latency across $n = 64$ benchmark queries:

  • Sample Mean: $\bar{X} = 42.5 \text{ ms}$
  • Sample Standard Deviation: $S = 8.0 \text{ ms}$

A production SLA requires that true average latency $\mu$ must not exceed $45.0 \text{ ms}$.

  1. Compute the Standard Error $\text{SE}(\bar{X})$.
  2. Calculate the 95% Confidence Interval for $\mu$ ($z_{0.025} = 1.96$).
  3. Does the model satisfy the SLA beyond reasonable doubt?
Click to Reveal Step-by-Step Solution

1. Standard Error

$$\text{SE}(\bar{X}) = \frac{S}{\sqrt{n}} = \frac{8.0}{\sqrt{64}} = \frac{8.0}{8} = \mathbf{1.0 \text{ ms}}$$

2. 95% Confidence Interval

$$\text{Margin} = 1.96 \times 1.0 = 1.96 \text{ ms}$$ $$\text{CI}_{95\%} = [42.5 - 1.96, \quad 42.5 + 1.96] = \mathbf{[40.54 \text{ ms}, \quad 44.46 \text{ ms}]}$$

3. SLA Decision

Conclusion: The entire 95% confidence interval $[40.54, 44.46]$ is strictly below the $45.0 \text{ ms}$ SLA limit. The model meets production requirements with 95% statistical confidence!

Problem 2: Two-Sample Proportion Hypothesis Test for Prompt Optimization

Medium

An NLP team tests a Chain-of-Thought prompt (Prompt B) against the baseline (Prompt A):

  • Prompt A: $n_A = 400$, $x_A = 240$ successes ($\hat{p}_A = 0.60$)
  • Prompt B: $n_B = 400$, $x_B = 272$ successes ($\hat{p}_B = 0.68$)
  1. State $H_0$ and $H_1$.
  2. Compute pooled proportion $\hat{p}$ and standard error of difference $\text{SE}_{\text{diff}}$.
  3. Calculate the $z$-test statistic.
  4. At significance level $\alpha = 0.05$ (critical value $1.96$), should Prompt B be deployed?
Click to Reveal Step-by-Step Solution

1. Hypotheses

$$H_0: p_B = p_A \quad \text{vs} \quad H_1: p_B \neq p_A$$

2. Pooled Proportion & Standard Error

$$\hat{p} = \frac{240 + 272}{800} = \mathbf{0.640}$$ $$\text{SE}_{\text{diff}} = \sqrt{(0.64)(0.36)\left(\frac{1}{400} + \frac{1}{400}\right)} = \sqrt{0.2304 \times 0.005} \approx \mathbf{0.03394}$$

3. $z$-Statistic

$$z = \frac{0.680 - 0.600}{0.03394} \approx \mathbf{+2.357}$$

4. Decision

Since $|z| = 2.357 > 1.96$, the two-tailed $p$-value is $p \approx 0.0184 < 0.05$.

Verdict: Reject $H_0$! Prompt B yields a statistically significant $+8\%$ improvement. Deploy Prompt B!

Problem 3: Required Sample Size Derivation for Statistical Power in A/B Testing

Challenging

Before launching an A/B test comparing baseline $p_1 = 0.80$ to improved model $p_2 = 0.85$ ($\Delta = 0.05$), the team needs $80\%$ statistical power ($z_\beta = 0.8416$) at significance level $\alpha = 0.05$ ($z_{\alpha/2} = 1.96$).

$$n = \frac{(z_{\alpha/2} + z_\beta)^2 \cdot [p_1(1 - p_1) + p_2(1 - p_2)]}{(p_2 - p_1)^2}$$
  1. Calculate the critical value factor $(z_{\alpha/2} + z_\beta)^2$.
  2. Calculate the variance sum $[p_1(1 - p_1) + p_2(1 - p_2)]$.
  3. Compute the required sample size $n$ per model.
  4. Explain why testing on only $n = 300$ samples results in a high probability of missing a real improvement.
Click to Reveal Step-by-Step Solution

1. Critical Factor

$$(1.96 + 0.8416)^2 = (2.8016)^2 \approx \mathbf{7.849}$$

2. Variance Sum

$$p_1(1 - p_1) + p_2(1 - p_2) = (0.80)(0.20) + (0.85)(0.15) = 0.160 + 0.1275 = \mathbf{0.2875}$$

3. Sample Size per Group

$$\Delta^2 = (0.05)^2 = 0.0025$$ $$n = \frac{7.849 \times 0.2875}{0.0025} \approx \mathbf{903 \text{ samples per group}}$$

4. Power Danger at $n = 300$

Statistical Power Trap: With only $n = 300$, power collapses to $\approx 36.5\%$. The engineering team would have a $63.5\%$ chance of missing a genuine 5% improvement simply because their benchmark was too small!
