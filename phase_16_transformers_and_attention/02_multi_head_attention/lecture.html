Topic 16.2: Multi-Head Attention

Jointly attending to information from different representation subspaces at different positions.

1. Executive Summary & The 12-Year-Old Analogy

Single-head scaled dot-product attention has an inherent bottleneck: it averages conflicting relationships together into a single blurry distribution.

In language, a single token often simultaneously participates in multiple relationships:

  • Syntactic: Subject-verb agreement (*"The cat [singular] jumps [singular]"*).
  • Coreference: Pronoun resolution (*"The animal didn't cross because it was tired"*).
  • Semantic: Predicate-object association (*"tired"* attributes state to *"animal"*).

Multi-Head Attention (MHA) splits the model's embedding dimension $d_{\text{model}}$ into $h$ separate heads with dimension $d_k = d_{\text{model}} / h$, performs attention in parallel across each subspace, concatenates the resulting heads, and projects them with an output matrix $W^O$.

$$\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$$ $$\text{where } \text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)$$

The 12-Year-Old Analogy: The Team of Specialized Detectives

Imagine a mysterious classroom incident:

  • The Single Detective (Single Head): One detective inspects footprints, broken rulers, student handwriting, and timestamps all at once. Their notes become a scrambled, indecipherable mess.
  • The Specialized Detective Squad (Multi-Head Attention): The Chief assigns 4 specialized detectives ($h = 4$):
    • Detective 1: Studies only grammar and handwriting.
    • Detective 2: Connects nicknames and pronouns to student names.
    • Detective 3: Listens for emotional motives and conflicts.
    • Detective 4: Verifies who was standing where on a physical map.
  • The Concatenation & Chief's Synthesis ($W^O$): All four detectives tape their 4 reports side-by-side. The Chief ($W^O$) synthesizes the four specialized reports into one final, coherent briefing!

2. Mathematical Symbol Decoder

Symbol Tensor Shape Domain Description & Meaning
$d_{\text{model}}$ Scalar $\mathbb{N}$ Embedding dimensionality (e.g. 512 in Vaswani et al., 4096 in LLaMA)
$h$ Scalar $\mathbb{N}$ Number of attention heads (e.g. 8, 32)
$d_k$ Scalar $d_{\text{model}} / h$ Query and Key feature dimension per head
$d_v$ Scalar $d_{\text{model}} / h$ Value feature dimension per head
$W_i^Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$ Matrix Parameters Linear query projection matrix for head $i$
$W_i^K \in \mathbb{R}^{d_{\text{model}} \times d_k}$ Matrix Parameters Linear key projection matrix for head $i$
$W_i^V \in \mathbb{R}^{d_{\text{model}} \times d_v}$ Matrix Parameters Linear value projection matrix for head $i$
$W^O \in \mathbb{R}^{h d_v \times d_{\text{model}}}$ Matrix Parameters Output projection matrix blending all concatenated heads
$\text{head}_i$ 3D Tensor $\mathbb{R}^{B \times T \times d_v}$ Attention output for individual head $i$

3. Computational Cost Invariance

A remarkable property of choosing $d_k = d_v = d_{\text{model}} / h$ is that Multi-Head Attention has the exact same computational cost as single-head attention of full dimension $d_{\text{model}}$:

$$\text{Single Head FLOPs} = \mathcal{O}(T^2 \cdot d_{\text{model}})$$ $$\text{Multi-Head FLOPs} = h \times \mathcal{O}(T^2 \cdot d_k) = h \times \mathcal{O}\left(T^2 \cdot \frac{d_{\text{model}}}{h}\right) = \mathcal{O}(T^2 \cdot d_{\text{model}})$$

The model acquires $h$ independent representational subspaces without paying any extra computational penalty!

4. Tensor Reshaping: Parallel Head Execution Without Loops

    Shape: [B, T, d_model]
           │
           ▼  (1) Projections: Q = X @ W_Q, K = X @ W_K, V = X @ W_V
    Shape: [B, T, d_model] = [B, T, h * d_k]
           │
           ▼  (2) Reshape to 4D: split d_model into [h, d_k]
    Shape: [B, T, h, d_k]
           │
           ▼  (3) Permute dimensions (swap axes 1 and 2):
    Shape: [B, h, T, d_k]
           │
           ▼  (4) Single Batched MatMul over (B * h) items simultaneously!
    Attention Output: [B, h, T, d_k]
           │
           ▼  (5) Permute back (swap axes 1 and 2):
    Shape: [B, T, h, d_k]
           │
           ▼  (6) Flatten last two dimensions:
    Shape: [B, T, h * d_k] = [B, T, d_model]
           │
           ▼  (7) Output projection: Out @ W^O
    Final Output: [B, T, d_model]
