Topic 11.4: Multilayer Perceptrons From Scratch

Constructing complete neural networks from scratch, solving the historic XOR problem, and unlocking non-linear boundaries.

1. Executive Summary & The 12-Year-Old Analogy

In 1969, Minsky and Papert proved that single-layer perceptrons could never solve the non-linear XOR problem, launching the first AI Winter. In 1986, Rumelhart, Hinton, and Williams revived the field by demonstrating that Multi-Layer Perceptrons (MLPs) with non-linear hidden layers and backpropagation solve XOR with 100% precision.

The 12-Year-Old Analogy: The Origami Brain
  • The Single Ruler (Single Layer): On a flat sheet of paper, you can only make one straight slice with a ruler. If red and blue dots are in alternating corners (XOR), no straight line can ever separate them. You are permanently capped at 50% to 75% accuracy.
  • Origami Creases (Hidden Layers): Instead of slicing the paper flat, hidden layers fold the paper diagonally! By folding the paper, the two red dots touch each other on one side, allowing a single straight cut from the output layer to separate them completely.
  • The Analytical Loop: Forward pass calculates guesses, loss checks errors, backward chain rule whispers adjustments to every crease, and weights update until the paper folds into perfection.

2. Mathematical Symbol Decoder

Symbol Domain Description & Meaning
$W^{[l]} \in \mathbb{R}^{n^{[l]} \times n^{[l-1]}}$ Matrix Weight matrix of layer $l$
$\mathbf{b}^{[l]} \in \mathbb{R}^{n^{[l]}}$ Vector Bias vector of layer $l$
$Z^{[l]} \in \mathbb{R}^{B \times n^{[l]}}$ Matrix Pre-activation batch matrix: $A^{[l-1]} (W^{[l]})^T + \mathbf{b}^{[l]}$
$A^{[l]} \in \mathbb{R}^{B \times n^{[l]}}$ Matrix Post-activation batch matrix: $g^{[l]}(Z^{[l]})$
$\delta^{[l]} \in \mathbb{R}^{B \times n^{[l]}}$ Matrix Error sensitivity tensor: $\frac{\partial \mathcal{L}}{\partial Z^{[l]}}$
$\odot$ Operator Hadamard (element-wise) multiplication

3. The XOR Inseparability Proof

A single linear perceptron requires weights $(w_1, w_2, b)$ to satisfy:

$$b \le 0 \quad (\text{from } 0,0 \to 0)$$ $$w_2 + b > 0 \quad (\text{from } 0,1 \to 1)$$ $$w_1 + b > 0 \quad (\text{from } 1,0 \to 1)$$ $$w_1 + w_2 + b \le 0 \quad (\text{from } 1,1 \to 0)$$

Adding the second and third inequalities yields $w_1 + w_2 + 2b > 0$. Since $w_1 + w_2 \le -b$, this implies $-b + 2b > 0 \implies b > 0$. This contradicts $b \le 0$. Hence, no single linear hyperplane can solve XOR.

4. Analytical Backpropagation Equations

The Analytical Backward Pass:

1. Output Layer Error:

$$\delta^{[L]} = A^{[L]} - Y$$

2. Hidden Layer Error Recursion ($l = L-1, \dots, 1$):

$$\delta^{[l]} = (\delta^{[l+1]} W^{[l+1]}) \odot g'\left(A^{[l]}\right)$$

3. Parameter Gradients:

$$\frac{\partial \mathcal{L}}{\partial W^{[l]}} = \frac{1}{B} (\delta^{[l]})^T A^{[l-1]}, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{b}^{[l]}} = \frac{1}{B} \sum_{i=1}^B \delta_i^{[l]}$$
