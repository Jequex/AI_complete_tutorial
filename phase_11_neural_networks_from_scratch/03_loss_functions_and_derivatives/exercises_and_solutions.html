Problem 1: Manual Calculation of MSE and its Gradients

Given true regression targets $\mathbf{y} = [3.0, -1.0, 4.5]^T$ and predictions $\hat{\mathbf{y}} = [2.6, -1.2, 5.0]^T$:

  1. Compute the MSE loss $\mathcal{L} = \frac{1}{2N}\sum (y_i - \hat{y}_i)^2$.
  2. Compute the gradient vector $\nabla_{\hat{\mathbf{y}}} \mathcal{L}$.
  3. Perform a gradient descent update on predictions with learning rate $\eta = 0.5$.
View Complete Solution

1. Loss calculation:

Errors: $e_1 = -0.4$, $e_2 = -0.2$, $e_3 = 0.5$. Squared sum $= 0.16 + 0.04 + 0.25 = 0.45$.

$$\mathcal{L} = \frac{0.45}{2 \times 3} = 0.075$$

2. Gradient vector:

$$\nabla_{\hat{\mathbf{y}}} \mathcal{L} = \frac{1}{3} [-0.4, -0.2, 0.5]^T \approx [-0.1333, -0.0667, 0.1667]^T$$

3. Updated predictions ($\hat{y} - 0.5 \nabla \mathcal{L}$):

$$\hat{\mathbf{y}}_{\text{new}} = [2.6667, -1.1667, 4.9167]^T$$

Problem 2: Softmax Jacobian & Categorical Cross-Entropy Gradient

Let $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$ and $\mathcal{L} = -\sum y_k \ln p_k$ with $\sum y_k = 1$.

  1. Prove that $\frac{\partial p_k}{\partial z_i} = p_k(\delta_{ki} - p_i)$.
  2. Prove that $\frac{\partial \mathcal{L}}{\partial z_i} = p_i - y_i$.
View Complete Solution

1. Softmax derivative:

For $k = i$, $\frac{\partial p_i}{\partial z_i} = \frac{e^{z_i}S - e^{2z_i}}{S^2} = p_i - p_i^2 = p_i(1 - p_i)$.

For $k \ne i$, $\frac{\partial p_k}{\partial z_i} = \frac{0 - e^{z_k}e^{z_i}}{S^2} = -p_k p_i$. Combining both: $p_k(\delta_{ki} - p_i)$.

2. CCE gradient:

$$\frac{\partial \mathcal{L}}{\partial z_i} = -\sum_k \frac{y_k}{p_k} p_k(\delta_{ki} - p_i) = -y_i + p_i \sum_k y_k = p_i - y_i$$

Problem 3: Quantitative Suppression of Easy Negatives in Focal Loss

Given 10,000 easy negatives ($p_t = 0.98$) and 10 hard positives ($p_t = 0.05$).

  1. Compute total BCE loss and the percentage dominated by the background.
  2. Compute total Focal Loss ($\gamma = 2.0, \alpha = 0.5$) and the resulting background percentage.
View Complete Solution

1. Standard BCE:

$\mathcal{L}_{\text{bg}} = -\ln(0.98) \approx 0.0202 \implies \text{Total BG} = 202.03$.

$\mathcal{L}_{\text{fg}} = -\ln(0.05) \approx 2.9957 \implies \text{Total FG} = 29.96$.

Total $= 231.99$. Background accounts for 87.1% of gradient noise.

2. Focal Loss:

$\mathcal{L}_{\text{FL, bg}} = 0.5(0.02)^2(0.0202) \approx 4.04 \times 10^{-6} \implies \text{Total BG} = 0.0404$.

$\mathcal{L}_{\text{FL, fg}} = 0.5(0.95)^2(2.9957) \approx 1.3518 \implies \text{Total FG} = 13.518$.

Total $= 13.558$. Background accounts for only 0.3%, preserving 99.7% of learning capacity for hard positives!
