Exercise 1: Analytical Derivation of the LSQ Step Size Gradient

Problem: In Learned Step Size Quantization (LSQ), simulated quantization is defined as: $$\hat{x}(x, s) = s \cdot \text{clip}\left( \left\lfloor \frac{x}{s} \right\rceil, \; q_{\min}, \; q_{\max} \right)$$ Derive $\frac{\partial \hat{x}}{\partial s}$ across underflow, in-bounds, and overflow regions using the Straight-Through Estimator.

View Complete Solution

Let $u = \frac{x}{s}$. Then $\frac{\partial u}{\partial s} = -\frac{x}{s^2}$.

  • Underflow ($u < q_{\min}$): $\hat{x} = s \cdot q_{\min} \implies \frac{\partial \hat{x}}{\partial s} = q_{\min}$.
  • Overflow ($u > q_{\max}$): $\hat{x} = s \cdot q_{\max} \implies \frac{\partial \hat{x}}{\partial s} = q_{\max}$.
  • In-bounds ($q_{\min} \le u \le q_{\max}$): By product rule: $$\frac{\partial \hat{x}}{\partial s} = \left\lfloor \frac{x}{s} \right\rceil + s \cdot \frac{\partial}{\partial s}\left( \left\lfloor \frac{x}{s} \right\rceil \right)$$ Using STE $\frac{\partial \lfloor v \rceil}{\partial v} \approx 1$: $$\frac{\partial \hat{x}}{\partial s} = \left\lfloor \frac{x}{s} \right\rceil + s \left( 1 \cdot \left( -\frac{x}{s^2} \right) \right) = \left\lfloor \frac{x}{s} \right\rceil - \frac{x}{s}$$
$$\boxed{\frac{\partial \hat{x}}{\partial s} = \begin{cases} q_{\min}, & \frac{x}{s} < q_{\min} \\ q_{\max}, & \frac{x}{s} > q_{\max} \\ \left\lfloor \frac{x}{s} \right\rceil - \frac{x}{s}, & q_{\min} \le \frac{x}{s} \le q_{\max} \end{cases}}$$

Exercise 2: Mathematical Analysis of STE Gradient Bias

Problem: Let $\mathcal{L}(y) = \frac{1}{2}(y - y^*)^2$ where $y = \lfloor x \rceil$. Contrast true gradient behavior with STE surrogate gradient behavior for $x = 1.2$ and $y^* = 2.0$.

View Complete Solution

1. True Derivative: $\frac{d\mathcal{L}}{dx} = (\lfloor x \rceil - y^*) \times 0 = 0 \text{ a.e.}$ Master weights never update.

2. STE Surrogate: Under STE, $\frac{d\lfloor x \rceil}{dx} \approx 1$. Thus $g_{\text{STE}}(x) = \lfloor x \rceil - y^*$.

3. Numerical Evaluation: At $x = 1.2$, $\lfloor 1.2 \rceil = 1.0$. The STE gradient is $1.0 - 2.0 = -1.0$. A gradient descent step with $\eta = 0.5$ updates $x \leftarrow 1.2 - 0.5(-1.0) = 1.7$. After the update, $\lfloor 1.7 \rceil = 2.0 = y^*$, reducing the loss to exactly $0.0$. The STE effectively escaped the zero-derivative plateau.

Exercise 3: Discrete KL-Divergence Calculation for Calibration

Problem: For activation distribution $P = [0.40, 0.30, 0.20, 0.10]$ quantized to 2 bins and reconstructed as $Q = [0.35, 0.35, 0.15, 0.15]$, compute $D_{\text{KL}}(P \parallel Q)$.

View Complete Solution

Recall $D_{\text{KL}}(P \parallel Q) = \sum_{i=1}^4 P(i) \ln(P(i) / Q(i))$:

  • Bin 1: $0.40 \ln(0.40 / 0.35) = 0.40 \ln(1.142857) \approx +0.053413$
  • Bin 2: $0.30 \ln(0.30 / 0.35) = 0.30 \ln(0.857143) \approx -0.046245$
  • Bin 3: $0.20 \ln(0.20 / 0.15) = 0.20 \ln(1.333333) \approx +0.057536$
  • Bin 4: $0.10 \ln(0.10 / 0.15) = 0.10 \ln(0.666667) \approx -0.040547$

Summing: $D_{\text{KL}}(P \parallel Q) = 0.053413 - 0.046245 + 0.057536 - 0.040547 = \mathbf{0.024157 \text{ nats}}$.
