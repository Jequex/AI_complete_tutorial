Exercise 1: Lagrange Multiplier Derivation for the Optimal Brain Surgeon Update

Problem: Minimize $\frac{1}{2} \Delta \mathbf{w}^\top \mathbf{H} \Delta \mathbf{w}$ subject to $\mathbf{e}_q^\top \Delta \mathbf{w} = \delta_q \triangleq w_q - \hat{w}_q$. Derive the closed-form compensation vector $\Delta \mathbf{w}$ and scalar loss penalty $\Delta E_q$.

View Complete Solution

1. Lagrangian: $\mathcal{L}(\Delta \mathbf{w}, \lambda) = \frac{1}{2} \Delta \mathbf{w}^\top \mathbf{H} \Delta \mathbf{w} + \lambda (\mathbf{e}_q^\top \Delta \mathbf{w} - \delta_q)$.

2. Stationary Point: $\mathbf{H} \Delta \mathbf{w} + \lambda \mathbf{e}_q = \mathbf{0} \implies \Delta \mathbf{w} = -\lambda \mathbf{H}^{-1} \mathbf{e}_q$.

Substituting into the constraint: $\mathbf{e}_q^\top (-\lambda \mathbf{H}^{-1} \mathbf{e}_q) = -\lambda [\mathbf{H}^{-1}]_{qq} = \delta_q \implies \lambda = -\frac{\delta_q}{[\mathbf{H}^{-1}]_{qq}}$.

Therefore: $$\boxed{\Delta \mathbf{w} = -\frac{w_q - \hat{w}_q}{[\mathbf{H}^{-1}]_{qq}} \mathbf{H}^{-1}_{:, q}}$$

3. Quadratic Penalty: $\Delta E_q = \frac{1}{2} \Delta \mathbf{w}^\top \mathbf{H} \Delta \mathbf{w} = \frac{1}{2} \lambda^2 [\mathbf{H}^{-1}]_{qq} = \boxed{\frac{(w_q - \hat{w}_q)^2}{2 [\mathbf{H}^{-1}]_{qq}}}$.

Exercise 2: Derivation of the Optimal SmoothQuant Scaling Factor

Problem: Let $X_j$ and $W_j$ be channel maximums. Show that setting $s_j = \frac{X_j^\alpha}{W_j^{1 - \alpha}}$ with $\alpha = 0.5$ makes the dynamic ranges of smoothed activations $\hat{X}_j = X_j / s_j$ and smoothed weights $\hat{W}_j = W_j s_j$ identical.

View Complete Solution

Equating $\hat{X}_j = \hat{W}_j$: $$\frac{X_j}{s_j} = W_j s_j \implies s_j^2 = \frac{X_j}{W_j} \implies s_j = \sqrt{\frac{X_j}{W_j}} = \frac{X_j^{0.5}}{W_j^{0.5}}$$

Comparing with $s_j = \frac{X_j^\alpha}{W_j^{1 - \alpha}}$, this matches exactly when $\alpha = 0.5$.

Under this choice, $\hat{X}_j = \hat{W}_j = \sqrt{X_j W_j}$. The outlier dynamic range is divided evenly between activations and weights, unlocking INT8 precision without clipping.

Exercise 3: Cholesky Factorization in GPTQ

Problem: How does Cholesky decomposition $\mathbf{H}^{-1} = \mathbf{L}\mathbf{L}^\top$ accelerate second-order quantization?

View Complete Solution

Frantar et al. (2022) prove that the compensation vector simplifies to $\frac{\mathbf{H}^{-1}_{:, q}}{[\mathbf{H}^{-1}]_{qq}} = \frac{\mathbf{L}_{:, q}}{L_{qq}}$.

Because $\mathbf{L}$ is lower-triangular ($L_{jq} = 0$ for $j < q$):

  • Quantizing column $q$ only updates subsequent columns $j > q$.
  • Already quantized weights $k < q$ are never disturbed.
  • The Cholesky factor depends only on calibration activations $\mathbf{X}$ and can be computed once upfront, enabling lazy block updates with fast matrix multiplications (`GEMM`).
