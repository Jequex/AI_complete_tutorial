Problem 1: Manual Calculation of Gaussian Prior KL Divergence (Easy)

Given latent parameters $\boldsymbol{\mu} = [0.8, -1.2, 0.0]^\top$ and $\boldsymbol{\gamma} = \log \boldsymbol{\sigma}^2 = [-0.5, 0.4, 0.0]^\top$, compute the exact component-wise and total KL divergence against $\mathcal{N}(0, \mathbf{I}_3)$.

View Complete Solution

Using $\text{KL}_j = -\frac{1}{2}(1 + \gamma_j - \mu_j^2 - \exp(\gamma_j))$:

  • Dim 1: $\text{KL}_1 = -0.5(1 - 0.5 - 0.64 - 0.60653) \approx 0.37327$
  • Dim 2: $\text{KL}_2 = -0.5(1 + 0.4 - 1.44 - 1.49182) \approx 0.76591$
  • Dim 3: $\text{KL}_3 = -0.5(1 + 0.0 - 0.0 - 1.0) = 0.0$ (Matches prior exactly)

Total KL Loss: $\mathcal{L}_{\text{KL}} \approx 0.37327 + 0.76591 + 0.0 \approx 1.13918$.

Problem 2: Proving the Exactness of ELBO at True Posterior (Medium)

Prove that $\text{ELBO} = \log p_\theta(x)$ if and only if $q_\phi(z \mid x) = p_\theta(z \mid x)$ almost everywhere.

View Complete Solution

From the divergence decomposition:

$$\log p_\theta(x) - \text{ELBO} = D_{\text{KL}}(q_\phi(z \mid x) \parallel p_\theta(z \mid x)) = \mathbb{E}_{q_\phi}\left[-\log \left(\frac{p_\theta(z \mid x)}{q_\phi(z \mid x)}\right)\right]$$

Since $-\log u$ is strictly convex, Jensen's inequality yields:

$$D_{\text{KL}}(q \parallel p) \ge -\log \left( \mathbb{E}_q\left[\frac{p(z|x)}{q(z|x)}\right] \right) = -\log(1) = 0$$

Strict convexity ensures equality holds if and only if the ratio $\frac{p_\theta(z \mid x)}{q_\phi(z \mid x)} = 1$ almost everywhere. Thus, the bound is exact if and only if the variational distribution matches the true posterior.
