Topic 13.3: Exercises & Solutions

Mathematical derivation of LeakyReLU initialization variance, fan-in vs fan-out trade-offs in inverted bottlenecks, and residual variance explosion in ResNets.

Problem 1: Generalized Kaiming Derivation for LeakyReLU

For $\text{LeakyReLU}(z)$ with slope $a \in [0, 1)$, derive the initialization variance $\sigma_w^2$ required to preserve activation variance across layers.

Solution 1

Integrating the second moment:

$$\mathbb{E}[\text{LeakyReLU}(z)^2] = \int_{-\infty}^0 (az)^2 p(z) \, dz + \int_0^\infty z^2 p(z) \, dz = a^2 \left(\frac{1}{2}\sigma_z^2\right) + \left(\frac{1}{2}\sigma_z^2\right) = \frac{1 + a^2}{2} \sigma_z^2$$

Setting $\text{Var}(x_l) = \text{Var}(x_{l-1})$:

$$\frac{1 + a^2}{2} n_{\text{in}} \sigma_w^2 = 1 \implies \sigma_w^2 = \frac{2}{(1 + a^2) n_{\text{in}}}$$

When $a=0$ (standard ReLU), this recovers $\frac{2}{n_{\text{in}}}$. When $a=1$ (linear), this recovers $\frac{1}{n_{\text{in}}}$.

Problem 2: ResNet Residual Variance Growth

In an unscaled 100-layer ResNet where each block adds $x_{l+1} = x_l + F(x_l)$ with $\text{Var}(F) = \text{Var}(x_l)$, what is $\text{Var}(x_{100})$, and how does production engineering solve this?

Solution 2

$$\text{Var}(x_{l+1}) = 2 \text{Var}(x_l) \implies \text{Var}(x_{100}) = 2^{100} \text{Var}(x_0) \approx 1.26 \times 10^{30}$$ Activations explode exponentially into $\text{NaN}$ values.

Zero-Init: Initialize the final batchnorm/linear layer of the residual branch to zero ($\gamma=0$). This forces $F(x) = 0$ at initialization, making the network behave as an identity function with invariant $\text{Var}(x_l) = 1.0$.
