Problem 1: Custom Collate Function for Variable-Length Sequences

Design a dynamic collate_fn that pads varying-length sequences in a mini-batch to the batch maximum $L_{\max}$ and returns a boolean attention mask $\mathbf{M} \in \{0, 1\}^{B \times L_{\max}}$.

Solution 1

def dynamic_collate(batch, pad_id=0):
    tokens = [item[0] for item in batch]
    labels = [item[1] for item in batch]
    max_len = max(len(seq) for seq in tokens)
    B = len(batch)

    padded = [[pad_id] * max_len for _ in range(B)]
    mask = [[0] * max_len for _ in range(B)]

    for b, seq in enumerate(tokens):
        for i, val in enumerate(seq):
            padded[b][i] = val
            mask[b][i] = 1

    return padded, mask, labels

Dynamic padding prevents wasting $\mathcal{O}(L^2)$ attention computation on global pad tokens when individual batches are short.

Problem 2: Mathematical Analysis of SGD with Momentum

For velocity recurrence $v_{t+1} = \beta v_t + g_t$, prove that under persistent gradient $g_t = G$, the effective step size is amplified by $\frac{1}{1 - \beta}$.

Solution 2

Unrolling the recurrence:

$$v_t = \sum_{k=0}^{t-1} \beta^{t-1-k} g_k$$

When $g_k = G$ is constant:

$$v_\infty = G \sum_{j=0}^\infty \beta^j = \frac{G}{1 - \beta}$$

With $\beta = 0.9$, the effective step size is $\Delta \theta = -\frac{\alpha}{1 - 0.9} G = -10 \alpha G$, yielding a $10\times$ speedup through valleys without divergence.

Problem 3: Diagnosing Untracked Buffers

Why must non-trainable state (like BatchNorm running statistics or step counts) be registered with self.register_buffer() rather than set as regular attributes?

Solution 3

Regular attributes are ignored by model.to("cuda") (causing device mismatches), omitted from model.state_dict() (preventing checkpoint restoration), and excluded from DistributedDataParallel multi-GPU state synchronization.
