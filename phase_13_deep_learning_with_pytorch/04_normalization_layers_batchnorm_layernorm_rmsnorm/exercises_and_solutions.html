Problem 1: Exact Analytical BatchNorm Backward Pass

Prove that the partial derivative of loss $\mathcal{L}$ with respect to batch input $x_i$ is given by:

$$\frac{\partial \mathcal{L}}{\partial x_i} = \frac{\gamma}{B \sqrt{\sigma^2 + \epsilon}} \left( B \frac{\partial \mathcal{L}}{\partial y_i} - \sum_{j=1}^B \frac{\partial \mathcal{L}}{\partial y_j} - \hat{x}_i \sum_{j=1}^B \frac{\partial \mathcal{L}}{\partial y_j} \hat{x}_j \right)$$

Solution 1

By applying multivariable chain rule through the numerator $\hat{x}_i$, the sample mean $\mu = \frac{1}{B}\sum x_k$, and sample variance $\sigma^2 = \frac{1}{B}\sum(x_k - \mu)^2$:

$$\frac{\partial \mathcal{L}}{\partial x_i} = \frac{\partial \mathcal{L}}{\partial \hat{x}_i}\frac{\partial \hat{x}_i}{\partial x_i} + \frac{\partial \mathcal{L}}{\partial \mu}\frac{\partial \mu}{\partial x_i} + \frac{\partial \mathcal{L}}{\partial \sigma^2}\frac{\partial \sigma^2}{\partial x_i}$$

Substituting $\frac{\partial \mu}{\partial x_i} = \frac{1}{B}$ and $\frac{\partial \sigma^2}{\partial x_i} = \frac{2(x_i - \mu)}{B}$ and collecting like terms recovers the exact scaled bracketed formula. Notice that summing over all $i$ yields zero identically ($\sum \frac{\partial \mathcal{L}}{\partial x_i} \equiv 0$).

Problem 2: Pre-LN vs Post-LN Architecture in Transformers

Why did modern LLMs (GPT-3, LLaMA) migrate from Post-LN ($x_{l+1} = \text{LN}(x_l + F(x_l))$) to Pre-LN ($x_{l+1} = x_l + F(\text{LN}(x_l))$)?

Solution 2

In Post-LN, gradients flowing backward from layer $L$ to layer $1$ are repeatedly multiplied by the Jacobian of the LayerNorm operator: $\prod \mathbf{J}_{\text{LN}}$, causing exponential decay in early layers and requiring delicate learning rate warmup.

In Pre-LN, the residual connection forms an uninhibited identity highway: $x_L = x_0 + \sum F(\text{LN}(x_l))$, ensuring $\frac{\partial x_L}{\partial x_0} = \mathbf{I} + \dots$, eliminating vanishing gradients out-of-the-box.

Problem 3: GPU Memory Bandwidth Analysis of RMSNorm

Explain why RMSNorm accelerates Transformer decoding compared to LayerNorm on GPU hardware.

Solution 3

Normalization is memory-bandwidth bound on modern GPUs. LayerNorm requires two distinct memory passes (first for mean $\mu$, second for variance $\sigma^2$) and loads both $\gamma$ and $\beta$. RMSNorm requires only a single memory reduction pass ($\sum x^2$) and omits $\beta$, reducing High Bandwidth Memory (HBM) data movement by 25%.
