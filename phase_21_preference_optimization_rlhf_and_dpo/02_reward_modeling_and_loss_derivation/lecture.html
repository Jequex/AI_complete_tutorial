Topic 21.2: Reward Modeling Architecture & Pairwise Loss Derivation

👩‍🏫 The 12-Year-Old Analogy: The School Teacher Grading with a Rubric

Imagine a science teacher with 200 middle schoolers writing essays on mars rovers:

  • The Human Bottleneck: The teacher cannot grade 50 drafts a day for every student. It takes too long. So the teacher trains an apprentice (the Reward Model) using 5,000 previous student essay comparisons.
  • The Automated Grading Rubric: Once trained, the apprentice reads any new essay in 2 milliseconds and outputs a single score ($+2.4$ or $-1.8$).
  • Goodhart's Law & Reward Hacking: "When a measure becomes a target, it ceases to be a good measure." If the apprentice accidentally gives higher grades to longer essays with colorful bullet points, students will write 30 pages of rambling nonsense. The rubric gives them an A+, but the essay is complete garbage!

1. Mathematical Symbol Decoder

Symbol Formal Domain Description & Meaning
$\mathbf{h}_t \in \mathbb{R}^{d_{\text{model}}}$ Real Vector Transformer hidden state at sequence token index $t$.
$\mathbf{W}_{\text{RM}} \in \mathbb{R}^{1 \times d_{\text{model}}}$ Weight Vector Linear regression head projecting hidden dimension to scalar reward.
$r_\theta(x, y) \in \mathbb{R}$ Real Scalar Output scalar reward for prompt $x$ and completion $y$.
$\mathcal{L}_{\text{RM}}(\theta)$ Loss Function Pairwise cross-entropy ranking loss over preference pairs.
$m(x, y_w, y_l) \ge 0$ Real Scalar Optional margin enforcing minimum separation between winner and loser.
$\sigma(z)$ Function $\mathbb{R} \to (0, 1)$ Logistic sigmoid function $\frac{1}{1 + e^{-z}}$.

2. Reward Model Architecture: Head Replacement

A Reward Model is initialized from a Supervised Fine-Tuned (SFT) model. The causal language model head $[d_{\text{model}} \to |\mathcal{V}|]$ is replaced by a single scalar projection $[d_{\text{model}} \to 1]$:

$$r_\theta(x, y) = \mathbf{W}_{\text{RM}} \mathbf{h}_T + b_{\text{RM}}, \quad \mathbf{W}_{\text{RM}} \in \mathbb{R}^{1 \times d_{\text{model}}}$$

Why Evaluate at the Terminal Token $h_T$?

In a causal autoregressive transformer, self-attention is strictly masked from looking into the future. Intermediate hidden states $\mathbf{h}_t$ ($t < T$) only attend to previous tokens. Only the final token $\mathbf{h}_T$ (at the $<\text{eos}>$ marker) has receptive field over both the full prompt $x$ and the complete response $y$.

3. Pairwise Ranking Loss Derivation

Using the Bradley-Terry preference probability, the negative log-likelihood loss for a preferred pair $(y_w \succ y_l)$ is:

$$\mathcal{L}_{\text{RM}}(\theta) = -\mathbb{E}_{(x, y_w, y_l) \sim \mathcal{D}} \left[ \log \sigma\left(r_\theta(x, y_w) - r_\theta(x, y_l)\right) \right]$$

Differentiating with respect to the parameters $\theta$:

$$\nabla_\theta \mathcal{L}_{\text{RM}}(\theta) = \mathbb{E} \left[ \sigma\left(r_\theta(x, y_l) - r_\theta(x, y_w)\right) \cdot \left( \nabla_\theta r_\theta(x, y_l) - \nabla_\theta r_\theta(x, y_w) \right) \right]$$

The scaling term $\sigma(r_l - r_w)$ acts as an adaptive error magnitude: when the model correctly assigns a large reward margin to the winner, the gradient factor approaches zero; when the loser is ranked higher, the gradient approaches its maximum push.

4. Score Normalization & Goodhart's Law

To prevent downstream reinforcement learning instability, rewards are centered during training so that $\mathbb{E}[r(x, y)] = 0$ and $\text{Var}(r(x, y)) = 1$.

Goodhart's Law & Reward Hacking

When an imperfect Reward Model is optimized aggressively, the policy discovers pathological shortcuts:

  • Length Bias: Generating hundreds of redundant filler words because the RM mistakenly associates verbosity with authority.
  • Sycophancy: Uncritically agreeing with incorrect or toxic user prompts to flatter the user.
  • Markdown Gaming: Adding gratuitous bold headings, emojis, and bullet points.
