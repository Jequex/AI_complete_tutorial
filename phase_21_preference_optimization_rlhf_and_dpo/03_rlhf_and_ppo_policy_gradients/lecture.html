Topic 21.3: RLHF & PPO Policy Gradients

🤸 The 12-Year-Old Analogy: The Gymnastics Coach with a Safety Bungee Cord

Imagine you are an elite gymnast practicing for the Olympics:

  • The Gymnast (The Policy Model $\pi_\theta$): You want to invent wild flips to get a perfect 10.0 score from the judges.
  • The Judge (The Reward Model $r_\phi$): Watches your moves and flashes a score.
  • The Danger (Reward Hacking): Left alone, you might bounce out the window onto a trampoline to avoid touching the floor. Technically you didn't fall, but you broke the sport!
  • The Coach's Bungee Cord (The Reference Model $\pi_{\text{ref}}$ & KL Penalty $\beta$): The coach hooks you to a bungee harness. You can leap high and improve your routine, but if you drift too far from proper gymnastics form, the bungee pulls you safely back. The KL penalty keeps the model coherent and prevents catastrophic drift.

1. Mathematical Symbol Decoder

Symbol Formal Domain Description & Meaning
$\pi_\theta(y \mid x)$ Policy Model Trainable autoregressive language model generating completions.
$\pi_{\text{ref}}(y \mid x)$ Reference Model Frozen SFT model providing baseline log-probabilities for KL penalty.
$r_\phi(x, y)$ Reward Model Frozen scoring network evaluating complete prompt-response pairs.
$V_\psi(s_t)$ Critic / Value Model Trainable network predicting expected cumulative return from prefix $s_t$.
$D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{ref}})$ Divergence $\ge 0$ Kullback-Leibler divergence between policy and reference distributions.
$\beta > 0$ Hyperparameter KL penalty coefficient controlling reference tether strength.
$r_t(\theta)$ Ratio Probability ratio $\frac{\pi_\theta(a_t \mid s_t)}{\pi_{\text{old}}(a_t \mid s_t)}$.
$\hat{A}_t$ Advantage Generalized Advantage Estimation (GAE) return over baseline.
$\epsilon \in (0, 0.3)$ Hyperparameter PPO surrogate clipping parameter (typically $0.1$ or $0.2$).

2. The RLHF Optimization Objective with KL Penalty

The global objective balances maximizing human preference reward with staying close to the initial SFT reference distribution:

$$\max_\theta \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi_\theta} \left[ r_\phi(x, y) \right] - \beta D_{\text{KL}}(\pi_\theta(y \mid x) \parallel \pi_{\text{ref}}(y \mid x))$$

In practice, this is implemented as a per-token reward signal:

$$R_t = \begin{cases} -\beta \left( \log \pi_\theta(y_t \mid s_t) - \log \pi_{\text{ref}}(y_t \mid s_t) \right) & \text{for } 1 \le t < T \\ r_\phi(x, y) - \beta \left( \log \pi_\theta(y_T \mid s_T) - \log \pi_{\text{ref}}(y_T \mid s_T) \right) & \text{for } t = T \end{cases}$$

3. The 4-Model System in Memory

PPO training requires coordinating four large language models in GPU VRAM concurrently:

  1. Actor Policy ($\pi_\theta$): Generates text, gradients enabled.
  2. Critic Value Network ($V_\psi$): Predicts state values, gradients enabled.
  3. Reference Model ($\pi_{\text{ref}}$): Computes baseline log-probs, frozen.
  4. Reward Model ($r_\phi$): Evaluates complete outputs, frozen.

For an 8B model, this memory footprint easily exceeds 160 GB VRAM, requiring heavy tensor parallelism and distributed infrastructure.

4. Proximal Policy Optimization (PPO) Clipped Surrogate Objective

To prevent destructive gradient steps from destabilizing the policy, PPO limits policy drift using the clipped surrogate loss:

$$\mathcal{L}^{\text{CLIP}}(\theta) = \hat{\mathbb{E}}_t \left[ \min\left( r_t(\theta) \hat{A}_t, \, \text{clip}(r_t(\theta), 1 - \epsilon, 1 + \epsilon) \hat{A}_t \right) \right]$$

Where $r_t(\theta) = \frac{\pi_\theta(a_t \mid s_t)}{\pi_{\text{old}}(a_t \mid s_t)}$. If a token was highly advantageous ($\hat{A}_t > 0$), probability can increase at most by a factor of $1 + \epsilon$ before the gradient is zeroed out.

5. Generalized Advantage Estimation (GAE)

GAE combines multi-step temporal difference residuals to balance bias and variance:

$$\delta_t^V = R_t + \gamma V(s_{t+1}) - V(s_t), \quad \hat{A}_t = \delta_t^V + (\gamma \lambda) \hat{A}_{t+1}$$

In language models, $\gamma = 1.0$ and $\lambda \approx 0.95$ provides smooth advantage estimates across conversational tokens.
