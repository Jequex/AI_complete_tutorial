Problem 1: 4-Model VRAM Arithmetic & Memory Footprint (Easy)

In a 7B model training setup in FP16 precision:

  1. Compute the memory for Actor (trainable), Critic (trainable), Reference (frozen), and Reward (frozen).
  2. What is the total static VRAM requirement?
  3. How many 80 GB GPUs are required?
View Complete Solution

Step 1: Trainable models require weights (14 GB) + gradients (14 GB) + AdamW moments (56 GB) = 84 GB each. Frozen models require weights only (14 GB each).

Step 2: $\text{Actor}(84) + \text{Critic}(84) + \text{Ref}(14) + \text{Reward}(14) = 196\text{ GB}$.

Step 3: $\frac{196}{80} \approx 2.45 \implies$ at least 3-4 enterprise 80 GB GPUs are required just to hold the model states.

Problem 2: Token-Level vs. Sequence-Level KL Divergence (Medium)

  1. Prove that $D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{ref}}) = \mathbb{E} \left[ \sum_{t=1}^T (\log \pi_\theta(y_t) - \log \pi_{\text{ref}}(y_t)) \right]$.
  2. Why does per-token reward distribution improve credit assignment over terminal lump-sum subtraction?
View Complete Solution

Step 1: Using $\log \prod_t a_t = \sum_t \log a_t$ and linearity of expectation, the log-likelihood ratio separates into individual token terms identically.

Step 2: Distributing the KL penalty across steps allows the Critic value network to assign credit to the exact tokens that deviated from the reference distribution, rather than penalizing the entire sequence uniformly at the end.

Problem 3: PPO Probability Ratio Clipping Analysis (Medium)

Given $\mathcal{L}^{\text{CLIP}} = \min(r_t \hat{A}_t, \, \text{clip}(r_t, 1-\epsilon, 1+\epsilon) \hat{A}_t)$ with $\epsilon = 0.20$:

  1. Evaluate for $\hat{A}_t = +4.0$ when $r_t = 1.50$.
  2. Evaluate for $\hat{A}_t = -3.0$ when $r_t = 0.60$.
View Complete Solution

Step 1: $\min(1.50 \times 4.0, 1.20 \times 4.0) = \min(6.0, 4.8) = 4.8$. Clipped! The gradient $\frac{\partial \mathcal{L}}{\partial r_t} = 0$, preventing over-aggressive updates.

Step 2: $\min(0.60 \times (-3.0), 0.80 \times (-3.0)) = \min(-1.8, -2.4) = -2.4$. Clipped! The gradient is zero, preventing excessive downward destruction of probability mass.

Problem 4: Hand Calculation of GAE Advantage on a 4-Token Trajectory (Hard)

Given $\gamma = 1.0, \lambda = 0.90$, values $V = [1.2, 1.5, 1.8, 2.0, 0.0]$, and rewards $R = [0.0, -0.1, 0.0, 3.0]$:

View Complete Solution

TD errors:

  • $\delta_0 = 0.0 + 1.5 - 1.2 = +0.30$
  • $\delta_1 = -0.1 + 1.8 - 1.5 = +0.20$
  • $\delta_2 = 0.0 + 2.0 - 1.8 = +0.20$
  • $\delta_3 = 3.0 + 0.0 - 2.0 = +1.00$

GAE recursion ($\hat{A}_t = \delta_t + 0.90 \hat{A}_{t+1}$):

  • $\hat{A}_3 = 1.00 + 0 = 1.000$
  • $\hat{A}_2 = 0.20 + 0.90(1.00) = 1.100$
  • $\hat{A}_1 = 0.20 + 0.90(1.10) = 1.190$
  • $\hat{A}_0 = 0.30 + 0.90(1.19) = 1.371$

The earliest token ($t=0$) receives the largest advantage, properly crediting the initial decisions that positioned the model to achieve the terminal reward.
