Topic 12.2: Exercises & Solutions — Reverse vs. Forward Mode Autodiff

Problem 1: Dual Number Manual Differentiation (Easy)

Evaluate $f(x) = \frac{x^2 + 1}{x - 2}$ at $x = 3 + 1\epsilon$ using dual numbers ($\epsilon^2 = 0$) and prove it equals the quotient rule derivative.

Solution:

Numerator: $(3+\epsilon)^2 + 1 = 9 + 6\epsilon + 1 = 10 + 6\epsilon$.

Denominator: $(3+\epsilon) - 2 = 1 + \epsilon$.

Quotient: $\frac{10 + 6\epsilon}{1 + \epsilon} = (10 + 6\epsilon)(1 - \epsilon) = 10 - 10\epsilon + 6\epsilon = 10 - 4\epsilon$.

Calculus quotient rule: $f'(x) = \frac{x^2 - 4x - 1}{(x-2)^2} \implies f'(3) = \frac{9 - 12 - 1}{1^2} = -4$. The dual coefficient matches $f'(3)$ identically.

Problem 2: Associativity & FLOP Count: JVP vs. VJP (Medium)

For $x \in \mathbb{R}^{10^6} \to h_1 \in \mathbb{R}^{1000} \to h_2 \in \mathbb{R}^{10} \to y \in \mathbb{R}^1$, calculate the FLOP count to find all input gradients via Forward-Mode vs. Reverse-Mode.

Solution:

  • Forward-Mode: Requires $10^6$ forward sweeps with basis vectors $e_i$. Each sweep costs $10^9$ FLOPs. Total = $10^6 \times 10^9 = 10^{15}$ FLOPs (1 PetaFLOP).
  • Reverse-Mode: Seed $u = [1.0]$. Step 1: $1 \times 10 = 10$ FLOPs. Step 2: $10 \times 1000 = 10,000$ FLOPs. Step 3: $1000 \times 10^6 = 10^9$ FLOPs. Total $\approx 10^9$ FLOPs (1 GigaFLOP).
  • Speedup: Reverse-Mode is $\mathbf{1,000,000\times}$ faster!

Problem 3: Activation Checkpointing Optimization (Hard)

For an $L$-layer model with activation memory $L \cdot M_{\text{act}}$, prove that segmenting into blocks of size $k = \sqrt{L}$ reduces peak memory from $\mathcal{O}(L)$ to $\mathcal{O}(\sqrt{L})$ with only 33% compute overhead.

Solution:

Peak memory with segment size $k$ is $M(k) = (\frac{L}{k} + k) M_{\text{act}}$. Setting $\frac{dM}{dk} = -\frac{L}{k^2} + 1 = 0 \implies k^* = \sqrt{L}$.

The resulting memory is $2\sqrt{L} M_{\text{act}} = \mathcal{O}(\sqrt{L})$. For $L=100$, memory drops from $100$ to $20$ units (80% reduction) at the cost of recomputing forward passes within each segment during backprop (33% training time overhead).
