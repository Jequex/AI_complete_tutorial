Topic 12.1: Exercises & Solutions — Computational Graphs

Problem 1: Manual Reverse-Mode Backprop on a Diamond Graph (Medium)

Given inputs $x = 3.0$ and $w = 2.0$ with graph:

  1. $z = x \cdot w$
  2. $h = x + z$
  3. $p = z^2$
  4. $L = h \cdot p$

Compute forward values and all backward adjoints $\bar{L}, \bar{p}, \bar{h}, \bar{z}, \bar{w}, \bar{x}$ using reverse topological order.

Solution:

Forward Pass:

  • $z = 3.0 \cdot 2.0 = 6.0$
  • $h = 3.0 + 6.0 = 9.0$
  • $p = 6.0^2 = 36.0$
  • $L = 9.0 \cdot 36.0 = 324.0$

Backward Adjoints:

  • $\bar{L} = 1.0$
  • $\bar{p} = \bar{L} \cdot h = 9.0$
  • $\bar{h} = \bar{L} \cdot p = 36.0$
  • $\bar{z} = \bar{h} \frac{\partial h}{\partial z} + \bar{p} \frac{\partial p}{\partial z} = (36.0 \cdot 1.0) + (9.0 \cdot 2(6.0)) = 36.0 + 108.0 = 144.0$
  • $\bar{w} = \bar{z} \cdot x = 144.0 \cdot 3.0 = 432.0$
  • $\bar{x} = \bar{z} \frac{\partial z}{\partial x} + \bar{h} \frac{\partial h}{\partial x} = (144.0 \cdot 2.0) + (36.0 \cdot 1.0) = 288.0 + 36.0 = 324.0$

Direct symbolic derivative verification: $L = x^3(w^2 + w^3) \implies \frac{\partial L}{\partial x} = 3(9)(12) = 324.0$, $\frac{\partial L}{\partial w} = 27(16) = 432.0$. Perfect match!

Problem 2: The Assignment Overwrite Bug vs. Accumulation (Easy)

Show why writing self.grad = ... instead of self.grad += ... causes a 50% underestimation of gradient on $f(x) = x + x$.

Solution:

For $f(x) = x + x = 2x$, the true gradient is $f'(x) = 2.0$. An autograd engine that overwrites with assignment replaces the first incoming gradient ($1.0$) with the second ($1.0$), resulting in $1.0$ rather than $2.0$. Relative error is $\frac{|2 - 1|}{2} = 50\%$.

Problem 3: Residual Connections as Gradient Highways (Hard)

Prove that for a residual connection $x_{l+1} = x_l + \mathcal{F}(x_l)$, the gradient satisfies $\frac{\partial L}{\partial x_l} = \frac{\partial L}{\partial x_{l+1}} (I + \frac{\partial \mathcal{F}}{\partial x_l})$ and explain why this eliminates vanishing gradients across 1,000 layers.

Solution:

The derivative across multiple layers decomposes into:

$$\frac{\partial L}{\partial x_l} = \frac{\partial L}{\partial x_K} \left( I + \sum_{j=l}^{K-1} \frac{\partial \mathcal{F}_j}{\partial x_l} \right)$$

The identity matrix term $I$ provides a direct, uninterrupted additive pathway for the gradient signal to flow from layer $K$ to layer $l$ without undergoing exponential decay $\lambda^{K-l} \to 0$.
