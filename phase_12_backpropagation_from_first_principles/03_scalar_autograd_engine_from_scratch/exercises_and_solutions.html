Topic 12.3: Exercises & Solutions — Scalar Autograd Engine

Problem 1: Implementing the Sigmoid Activation Function (Easy)

Derive $\sigma'(x) = \sigma(x)(1 - \sigma(x))$ and write the full Value.sigmoid() method.

Solution:

Using the quotient/chain rule on $(1 + e^{-x})^{-1}$ yields $\frac{e^{-x}}{(1+e^{-x})^2} = \frac{1}{1+e^{-x}}(1 - \frac{1}{1+e^{-x}}) = \sigma(x)(1 - \sigma(x))$.

def sigmoid(self):
    s = 1.0 / (1.0 + math.exp(-self.data))
    out = Value(s, (self,), "sigmoid")
    def _backward():
        self.grad += (s * (1.0 - s)) * out.grad
    out._backward = _backward
    return out

Problem 2: Hand Simulation of DFS Topological Sort (Medium)

Trace the post-order DFS on diamond graph $c = x^2 + 3x$ to prove that reverse topological traversal guarantees all downstream consumers accumulate their gradients into $x$ before $x$ is processed.

Solution:

Starting DFS at $c$: traverses to $a = x^2$, which traverses to $x$. $x$ has no dependencies, so it is appended to topo = [x]. Next $a$ finishes: topo = [x, a]. Next branch $b = 3x$ sees $x$ is already visited, finishes: topo = [x, a, b]. Finally $c$ finishes: topo = [x, a, b, c].

Reversing gives [c, b, a, x]. Thus, $c$ fires gradients into $b$ and $a$, and both $b$ and $a$ accumulate into $x$ before $x$ is finished!

Problem 3: Deriving the Softmax + Cross-Entropy Gradient Cancellation (Hard)

Prove that differentiating $L = -\ln(\hat{y}_k)$ with softmax $\hat{y}$ collapses analytically to $\frac{\partial L}{\partial z_i} = \hat{y}_i - y_i$.

Solution:

Expanding $L = \ln(\sum_j e^{z_j}) - z_k$. Differentiating with respect to $z_i$ gives $\frac{\partial L}{\partial z_i} = \frac{e^{z_i}}{\sum_j e^{z_j}} - \mathbb{I}(i = k) = \hat{y}_i - y_i$.

Production frameworks fuse this operation into a single kernel to prevent numerical overflow ($\exp(1000) \to \text{inf}$) and eliminate unnecessary memory round-trips.
