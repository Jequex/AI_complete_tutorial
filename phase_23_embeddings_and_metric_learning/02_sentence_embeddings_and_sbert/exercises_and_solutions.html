Problem 1: Mathematical Proof of the Anisotropy Cosine Floor (Easy)

Given unrelated representations $\mathbf{u} = \boldsymbol{\mu} + \boldsymbol{\epsilon}_u$ and $\mathbf{v} = \boldsymbol{\mu} + \boldsymbol{\epsilon}_v$ with $\|\boldsymbol{\mu}\|_2 = 10.0$ and $\mathbb{E}[\|\boldsymbol{\epsilon}\|^2] = 4.0$, show that expected cosine similarity is $\approx 0.96$.

View Complete Solution

The inner product expectation is $\mathbb{E}[\mathbf{u}^\top \mathbf{v}] = \|\boldsymbol{\mu}\|_2^2 = M^2$.

The expected norm is $\mathbb{E}[\|\mathbf{u}\|_2^2] = M^2 + \sigma^2$. Hence:

$$\mathbb{E}[\cos(\mathbf{u}, \mathbf{v})] \approx \frac{M^2}{M^2 + \sigma^2} = \frac{100}{100 + 4} \approx \mathbf{0.9615}$$

In contrast, an isotropic space ($M = 0$) yields $\mathbb{E}[\cos] = 0.0$.

Problem 2: SBERT NLI Head Gradient with Absolute Difference (Medium)

Derive the gradient of cross-entropy loss with respect to sentence embedding $\mathbf{u}$ when passed through the feature vector $[\mathbf{u}, \mathbf{v}, |\mathbf{u} - \mathbf{v}|]$.

View Complete Solution

Using the chain rule with block weight decomposition $\mathbf{W} = [\mathbf{W}_u; \mathbf{W}_v; \mathbf{W}_d]$:

$$\nabla_{\mathbf{u}} \mathcal{L} = \mathbf{W}_u \mathbf{g} + \text{sgn}(\mathbf{u} - \mathbf{v}) \odot (\mathbf{W}_d \mathbf{g})$$

The term $\text{sgn}(\mathbf{u} - \mathbf{v})$ acts as an attractive force for entailment pairs and a repulsive force for contradictions.

Problem 3: Derivation of BERT-Whitening (Hard)

Prove that $\tilde{\mathbf{u}} = (\mathbf{u} - \boldsymbol{\mu})\mathbf{U}\boldsymbol{\Lambda}^{-1/2}$ transforms arbitrary sentence embeddings into an isotropic distribution with covariance $\mathbf{I}_d$.

View Complete Solution

Covariance computation:

$$\text{Cov}(\tilde{\mathbf{u}}) = \mathbf{W}^\top \boldsymbol{\Sigma} \mathbf{W} = (\mathbf{U} \boldsymbol{\Lambda}^{-1/2})^\top (\mathbf{U} \boldsymbol{\Lambda} \mathbf{U}^\top) (\mathbf{U} \boldsymbol{\Lambda}^{-1/2})$$

Applying orthogonality $\mathbf{U}^\top \mathbf{U} = \mathbf{I}$:

$$\text{Cov}(\tilde{\mathbf{u}}) = \boldsymbol{\Lambda}^{-1/2} \mathbf{I} \boldsymbol{\Lambda} \mathbf{I} \boldsymbol{\Lambda}^{-1/2} = \boldsymbol{\Lambda}^{-1/2} \boldsymbol{\Lambda} \boldsymbol{\Lambda}^{-1/2} = \mathbf{I}_d$$

This stretches the narrow squashed cone back into a uniform hypersphere.

Problem 4: Retrieval Scalability Analysis (Medium)

Compare Cross-Encoder vs Bi-Encoder (SBERT) latency on searching $1,000,000$ documents.

View Complete Solution

Cross-Encoder: $1,000,000 \times 25 \text{ ms} = 25,000 \text{ s} \approx 6.94 \text{ hours}$.

Bi-Encoder: $10 \text{ ms (encode query)} + 2.5 \text{ ms (cosine dot products)} = \mathbf{12.5 \text{ ms}}$.

Speedup: $2,000,000\times$ faster, making real-time search viable.
