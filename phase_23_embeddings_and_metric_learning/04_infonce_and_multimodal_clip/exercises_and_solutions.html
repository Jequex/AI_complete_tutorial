Problem 1: InfoNCE Mutual Information Lower Bound Proof (Hard)

Prove that minimizing InfoNCE over $K$ negative samples bounds mutual information:

$$I(X; Y) \ge \log(K) - \mathcal{L}_{\text{InfoNCE}}$$
View Complete Solution

By Bayes' rule with uniform prior $P(C = 0) = \frac{1}{K+1}$, the true posterior is $\frac{\frac{p(y_0|x)}{p(y_0)}}{\sum_m \frac{p(y_m|x)}{p(y_m)}}$.

Applying Jensen's inequality to concave $-\log(1 + z)$ and computing expectation over marginal negatives $\mathbb{E}_{p(y)}[\frac{p(y|x)}{p(y)}] = 1$, the sum over $K$ negatives evaluates to $K$:

$$\mathcal{L}_{\text{InfoNCE}} \ge \log(K) - \mathbb{E}_{p(x, y)} \left[ \log \frac{p(y \mid x)}{p(y)} \right] = \log(K) - I(X; Y)$$

Problem 2: InfoNCE Analytical Gradients with Temperature (Medium)

Derive the gradient of InfoNCE loss with respect to query vector $q \in \mathbb{R}^d$.

View Complete Solution

Using softmax probabilities $p_j = \frac{e^{s_j/\tau}}{\sum_m e^{s_m/\tau}}$:

$$\nabla_q \mathcal{L} = \frac{1}{\tau} \left( \sum_{j=0}^K p_j k_j - k_0 \right)$$

Query $q$ is pulled directly toward the positive key $k_0$ and pushed away from the probability-weighted mass of negative keys $\sum_{j=1}^K p_j k_j$.

Problem 3: CLIP Batch Scaling & Memory Footprint (Medium)

For batch size $N = 32,768$, calculate total pairs and matrix memory overhead.

View Complete Solution

Total Matrix Elements: $N^2 = 32,768^2 = 1,073,741,824$ elements (~1.07 billion pairs).

Memory Footprint: $1.07 \times 10^9 \times 4 \text{ bytes} = \mathbf{4.0 \text{ GiB}}$ VRAM.

Each image is contrasted against $K = 32,767$ negatives, tightening the MI bound to $\log(32,767) \approx 10.40$ nats.

Problem 4: Zero-Shot Prompt Engineering (Medium)

Contrast raw label prompting (`"weapon"`) vs contextualized prompting (`"a photo of a deadly dangerous metallic weapon"` vs `"a photo of a plastic colorful toy"`).

View Complete Solution

Raw labels suffer from polysemy and lack domain grounding. Contextualized prompt templates project text into visual sub-regions that match texture, color, and scene attributes. Prompt ensembling averages out stylistic templates, boosting zero-shot accuracy by 3–5% without retraining.
