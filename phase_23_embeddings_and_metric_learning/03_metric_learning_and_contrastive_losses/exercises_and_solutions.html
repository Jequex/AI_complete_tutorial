Analytical derivations of Contrastive Loss springs, Triplet Loss relative boundaries, and Semi-Hard negative mining classification.

Problem 1: Contrastive Loss Gradient Step & Equilibrium (Easy)

Given 2D points $f(x_1) = [1.0, 2.0]^\top$ and $f(x_2) = [4.0, 6.0]^\top$ with margin $m = 8.0$, compare positive and negative gradient updates.

View Complete Solution

Euclidean distance: $D = \sqrt{(-3)^2 + (-4)^2} = 5.0$.

Positive Pair: $\nabla_{f(x_1)} \mathcal{L} = f(x_1) - f(x_2) = [-3.0, -4.0]^\top$ (attractive pull).

Negative Pair: Since $D = 5.0 < m = 8.0$, repulsive force: $\nabla_{f(x_1)} \mathcal{L} = -(8 - 5)\frac{1}{5}[-3.0, -4.0]^\top = [+1.8, +2.4]^\top$ (repelling push away from $f(x_2)$).

Problem 2: Triplet Loss Negative Mining Classification (Medium)

Given $D_{ap} = 0.36$ and margin $\alpha = 0.40$, classify four candidate negatives with distances $0.20, 0.50, 0.72, 0.95$.

View Complete Solution

Threshold range: $[D_{ap}, D_{ap} + \alpha] = [0.36, 0.76]$.

  • $D = 0.20 < 0.36$: Hard Negative (Loss = 0.56).
  • $D = 0.50 \in [0.36, 0.76]$: Semi-Hard Negative (Loss = 0.26). Selected by FaceNet.
  • $D = 0.72 \in [0.36, 0.76]$: Semi-Hard Negative (Loss = 0.04).
  • $D = 0.95 > 0.76$: Easy Negative (Loss = 0.00). Provides zero gradient.

Problem 3: Geometric Boundary of Zero Triplet Loss (Hard)

Prove that for anchor at origin and positive at $[1, 0]^\top$ with margin $\alpha = 1.0$, the zero-loss boundary is a circle of radius $\sqrt{2}$.

View Complete Solution

Condition for zero triplet loss: $\|a - p\|^2 - \|a - n\|^2 + \alpha \le 0$.

Substituting $a=[0, 0]^\top, p=[1, 0]^\top \implies 1.0 - (x^2 + y^2) + 1.0 \le 0 \implies x^2 + y^2 \ge 2.0$.

The boundary curve is a circle of radius $R = \sqrt{2} \approx 1.414$ centered at the anchor.
