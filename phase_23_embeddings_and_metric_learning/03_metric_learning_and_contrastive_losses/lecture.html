Topic 23.3: Metric Learning & Contrastive Losses

Metric Learning Principles, Contrastive Loss (Hadsell et al. 2006), Triplet Loss (FaceNet), and Online Negative Mining Strategies.

The 12-Year-Old Analogy: Magnets with Matching and Repelling Poles

Imagine sorting a box of magnetic puzzle pieces:

  • The Snap-Together Spring (Positives): Two puzzle pieces from the same hero have opposite poles (North and South). When you release them, they snap together until distance is zero: $\frac{1}{2} D^2$.
  • The Push-Away Shield (Negatives & Margin $m$): Two pieces from different characters have matching poles (North and North). If they get closer than 3 inches ($m$), they violently push each other away! But once they are safely beyond 3 inches, the repulsion shuts off ($\max(0, m - D) = 0$) so they don't blast out of the galaxy!
  • The Goldilocks Negatives (Semi-Hard Mining): Easy negatives (apple vs car tire) require zero thought. Hard negatives (apple vs apple-perfumed pear) trigger confusion. Semi-hard negatives (apple vs real pear) present the exact right challenge to train an expert sniffer dog!

2. Contrastive Loss (Hadsell, Chopra, LeCun 2006)

Contrastive loss enforces an absolute margin $m$ between pairs:

$$\mathcal{L}_{\text{contrastive}} = \frac{1}{2} (1 - y) D^2 + \frac{1}{2} y \max(0, m - D)^2$$

Analytical gradient behavior:

  • Positive Pair ($y = 0$): $\nabla_{f(x_1)} \mathcal{L} = f(x_1) - f(x_2)$ (attractive Hooke's spring).
  • Negative Pair ($y = 1$): If $D < m$, $\nabla_{f(x_1)} \mathcal{L} = -(m - D) \frac{f(x_1) - f(x_2)}{D}$ (repulsive electrostatic push). If $D \ge m$, gradient is $\mathbf{0}$.

3. Triplet Loss (Schroff et al. 2015, FaceNet)

Triplet loss optimizes relative rank ordering between an anchor $a$, a positive $p$, and a negative $n$:

$$\mathcal{L}_{\text{triplet}} = \max\left(0, \|f(a) - f(p)\|_2^2 - \|f(a) - f(n)\|_2^2 + \alpha\right)$$

When the loss is active ($D_{ap} - D_{an} + \alpha > 0$):

$$\nabla_{f(a)} \mathcal{L} = 2(f(n) - f(p))$$ $$\nabla_{f(p)} \mathcal{L} = 2(f(p) - f(a))$$ $$\nabla_{f(n)} \mathcal{L} = 2(f(a) - f(n))$$

4. Negative Mining Strategies

    0 ───────────── D_ap ──────────────── D_ap + alpha ────────────────► D_an
           |                      |                          |
           |   Hard Negatives     |   Semi-Hard Negatives    |   Easy Negatives
           |  (D_an < D_ap)       | (D_ap < D_an < D_ap + a) |  (D_an > D_ap + a)
           |  Loss > alpha        | 0 < Loss < alpha         |  Loss = 0.0
  • Easy Negatives ($D_{an} > D_{ap} + \alpha$): Produce zero loss; model learns nothing.
  • Hard Negatives ($D_{an} < D_{ap}$): Negative is closer than positive; can cause gradient explosion if overused early.
  • Semi-Hard Negatives ($D_{ap} < D_{an} < D_{ap} + \alpha$): Farther than positive yet inside margin $\alpha$. Proven essential for stable convergence.
