Phase 30: Efficient Inference & Serving

Deconstructing the LLM inference bottleneck, hardware Roofline dynamics, PagedAttention virtual memory, lossless speculative decoding, KV cache compression, and production serving telemetry.

01. The Inference Bottleneck & The Roofline Model

Prefill phase (compute-bound, high arithmetic intensity $\mathcal{O}(S)$ FLOPs/byte) vs Decode phase (memory-bandwidth bound, arithmetic intensity $\approx 1$ FLOP/byte), Roofline analysis of LLM generation, KV cache memory footprint formula: $\text{Mem}_{\text{KV}} = 4 \cdot n_{\text{layers}} \cdot n_{\text{heads}} \cdot d_{\text{head}} \cdot b \cdot s$ bytes, and the fundamental 4-way tradeoff: Latency $\leftrightarrow$ Throughput $\leftrightarrow$ Memory $\leftrightarrow$ Cost.

02. PagedAttention & Continuous Batching (vLLM)

Static batching vs Continuous / Iteration-level batching (Orca), resolving GPU under-utilization from early termination, KV cache memory fragmentation (internal: pre-allocating max context; external: variable sequence lifetimes), PagedAttention (vLLM, Kwon et al. 2023): OS-style virtual memory paging, physical block pool, logical block tables, non-contiguous physical allocations, and copy-on-write fork mechanics for parallel sampling.

03. Speculative Decoding

Speculative execution in LLMs (Leviathan et al. 2023, Chen et al. 2023), small draft model $M_q$ generating $\gamma$ candidate tokens, large target model $M_p$ evaluating all $\gamma+1$ tokens in a single parallel forward pass, modified rejection sampling acceptance criterion: $\alpha = \min(1, p(x)/q(x))$, residual recovery distribution $(p(x) - q(x))^+$, complete mathematical proof that the output distribution is identically equal to target model $M_p$, and speedup factor $\mathbb{E}[\alpha]$.

04. KV Cache Compression & Tensor Parallel Serving

Architectural KV compression: Multi-Head Attention (MHA) vs Multi-Query Attention (MQA, Shazeer 2019) vs Grouped-Query Attention (GQA, Ainslie et al. 2023); Dynamic KV eviction: Heavy Hitter Oracle (H2O, Zhang et al. 2023) identifying high-attention sink tokens + recency window; Tensor Parallel serving: distributing KV cache across $N$ GPUs with Megatron column/row parallel linear projections.

05. Serving Benchmarks & Telemetry: TTFT, ITL, TPS

Serving telemetry & SLA metrics: Time to First Token (TTFT, prefill latency), Inter-Token Latency (ITL / Time Per Output Token TPOT), Tokens Per Second (TPS, throughput: system TPS vs user TPS), tail latency percentiles (p50, p90, p99), Little's Law $L = \lambda W$, Poisson arrival queues and load testing simulation.
