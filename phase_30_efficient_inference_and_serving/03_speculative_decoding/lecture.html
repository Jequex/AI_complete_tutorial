Topic 30.3

Speculative Decoding

Mathematical proof of distribution equivalence, modified rejection sampling, and $2\times\text{--}3\times$ lossless wall-clock acceleration.

1. The 12-Year-Old Intuition

Imagine a world-famous professor writing a complex novel. Because they are deep in thought, composing one sentence takes them 10 seconds.

A fast 10-year-old student sits beside them and drafts 5 words in 0.2 seconds: ["The", "treaty", "was", "signed", "today"].

The professor glances across all 5 words simultaneously in a single 10-second pass:

  • Word 1 ("The") → Approved!
  • Word 2 ("treaty") → Approved!
  • Word 3 ("was") → Approved!
  • Word 4 ("signed") → Rejected! Replaced with "ratified". Word 5 is thrown out.

In 10 seconds, the professor approved 4 high-quality words (a $4\times$ speedup), and the final book is 100% faithful to the professor's exact vocabulary and intellect.

2. Mathematical Symbol Decoder

Symbol Name Domain / Type Formal / System Definition
$M_p$ Target Model LLM ($p(x)$) High-capacity, high-latency model whose distribution is strictly preserved.
$M_q$ Draft Model LLM ($q(x)$) Small, low-latency speculative model generating $\gamma$ draft tokens.
$\gamma$ Speculative Horizon Integer $\ge 1$ Number of candidate tokens speculated per iteration.
$\alpha(x)$ Acceptance Probability $[0, 1]$ $\min\left(1, \frac{p(x)}{q(x)}\right)$
$p'(x)$ Residual Distribution $\Delta(\mathcal{V})$ $\frac{(p(x) - q(x))^+}{\sum_{x'} (p(x') - q(x'))^+}$
$\beta$ Mean Acceptance Rate $[0, 1]$ $\mathbb{E}_{x \sim q}[\alpha(x)] = 1 - D_{\text{TV}}(p, q)$

3. Formal Proof of Exact Distribution Equivalence

We prove that the probability of emitting any token $x$ under speculative decoding equals $p(x)$ exactly:

The Two-Path Emission Decomposition

$$\mathbb{P}_{\text{spec}}(X = x) = \mathbb{P}(\text{Accepted and } x) + \mathbb{P}(\text{Rejected and } x)$$ $$= q(x) \cdot \min\left(1, \frac{p(x)}{q(x)}\right) + (1 - \beta) \cdot \frac{(p(x) - q(x))^+}{1 - \beta}$$ $$= \min(p(x), q(x)) + (p(x) - q(x))^+$$
  • If $p(x) \ge q(x)$: $\min(p(x), q(x)) + (p(x) - q(x)) = q(x) + p(x) - q(x) = \mathbf{p(x)}$.
  • If $p(x) < q(x)$: $\min(p(x), q(x)) + 0 = \mathbf{p(x)}$.
$$\therefore \quad \boxed{\mathbb{P}_{\text{spec}}(X = x) = p(x) \quad \forall x \in \mathcal{V}}$$

Speculative decoding introduces zero loss in accuracy, zero drift in perplexity, and perfectly preserves model temperature and sampling behavior.

4. Theoretical Speedup Bound

The expected number of emitted tokens per target model forward step is:

$$\boxed{\mathbb{E}[N] = \frac{1 - \beta^{\gamma+1}}{1 - \beta}}$$

Given draft-to-target cost ratio $r = c_{\text{draft}} / c_{\text{target}}$, the wall-clock speedup is:

$$\text{Speedup } S = \frac{\frac{1 - \beta^{\gamma+1}}{1 - \beta}}{1 + \gamma \cdot r}$$
