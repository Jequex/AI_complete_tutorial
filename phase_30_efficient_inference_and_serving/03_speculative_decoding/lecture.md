# Topic 03: Speculative Decoding

## 1. Introduction & 12-Year-Old Intuition

Imagine you are a brilliant, world-renowned professor writing a 500-page historical treatise. 

Because you are meticulous and hold a vast library in your mind, writing a single sentence takes you **10 seconds** of deep contemplation. 

To help you write faster, the university assigns you a lightning-fast 10-year-old student assistant:
- The student can write **5 sentences per second**, but their grammar and vocabulary are simpler and they make occasional mistakes.
- How can you collaborate without lowering the quality of your masterpiece by even 0.0001%?

Here is the protocol:
1. **The Draft**: You sit back and tell the student: *"Write the next 5 words you think should come next."* In a fraction of a second, the student drafts: `["The", "declaration", "was", "signed", "today"]`.
2. **The Parallel Review**: You don't read them one word at a time over 50 seconds. You look at all 5 words **simultaneously in a single 10-second glance** (because reading multiple words takes you no longer than reading one word!).
3. **The Verdict**:
   - You check word 1 (`"The"`): *"Approved."*
   - You check word 2 (`"declaration"`): *"Approved."*
   - You check word 3 (`"was"`): *"Approved."*
   - You check word 4 (`"signed"`): *"No! A treaty isn't signed; it is ratified."* You cross out `"signed"`, replace it with `"ratified"`, and discard word 5.

In that single 10-second window, you produced **4 perfect, high-level words** (`"The declaration was ratified"`). Without the student assistant, writing 4 words would have taken you 40 seconds. You achieved a **$4\times$ speedup**, yet every single word that entered the final book conforms 100% to your world-class standards!

This is **Speculative Decoding** (Leviathan et al., 2023; Chen et al., 2023). A tiny, fast "draft model" speculates candidate tokens, and a massive, slow "target model" verifies all candidates in parallel in a single forward pass.

## 2. Mathematical Symbol Decoder

| Symbol | Name | Domain / Type | Engineering Significance |
| :--- | :--- | :--- | :--- |
| $M_p$ | Target Model | Autoregressive LLM (e.g. 70B) | High-capacity, slow, authoritative model whose distribution must be preserved exactly. |
| $M_q$ | Draft Model | Autoregressive LLM (e.g. 1B) | Lightweight, ultra-fast model used to speculate candidate tokens. |
| $\gamma$ | Speculative Lookahead Horizon | Integer (typically 3 to 6) | Number of candidate tokens generated by the draft model per round. |
| $p(x)$ | Target Distribution | Categorical: $\Delta(\mathcal{V})$ | Softmax probabilities over vocabulary $\mathcal{V}$ conditioned on prefix under $M_p$. |
| $q(x)$ | Draft Distribution | Categorical: $\Delta(\mathcal{V})$ | Softmax probabilities over vocabulary $\mathcal{V}$ conditioned on prefix under $M_q$. |
| $\alpha(x)$ | Acceptance Probability | Scalar $\in [0, 1]$ | Modified rejection sampling threshold: $\min\left(1, \frac{p(x)}{q(x)}\right)$. |
| $p'(x)$ | Residual Recovery Distribution | Categorical: $\Delta(\mathcal{V})$ | Adjusted probability distribution sampled when a candidate token is rejected. |
| $D_{\text{TV}}(p, q)$ | Total Variation Distance | Scalar $\in [0, 1]$ | Statistical distance: $\frac{1}{2} \sum_{x \in \mathcal{V}} |p(x) - q(x)|$. |
| $\beta$ | Mean Acceptance Rate | Scalar $\in [0, 1]$ | Expected fraction of draft tokens accepted: $\mathbb{E}_{x \sim q}[\alpha(x)] = 1 - D_{\text{TV}}(p, q)$. |
| $\mathbb{E}[N]$ | Expected Tokens per Round | Real $\in [1, \gamma + 1]$ | Average number of accepted tokens generated per target forward pass. |

## 3. The Speculative Decoding Protocol

Given prompt prefix $x_{<t}$:

```
                              SPECULATIVE DECODING ROUND
                                          │
                  ┌───────────────────────┴───────────────────────┐
                  ▼                                               ▼
         [Step 1: Draft Model M_q]                      [Step 2: Target Model M_p]
     Autoregressively generates gamma                Evaluates all gamma+1 positions
           candidate tokens:                          in a SINGLE parallel forward pass:
         x_1, x_2, ..., x_gamma                      p_1(x), p_2(x), ..., p_{gamma+1}(x)
                  │                                               │
                  └───────────────────────┬───────────────────────┘
                                          │
                                          ▼
                         [Step 3: Rejection Sampling Filter]
                     For i = 1, 2, ..., gamma:
                       Draw r_i ~ Uniform(0, 1)
                       Accept x_i if r_i <= min(1, p_i(x_i) / q_i(x_i))
                                          │
                     ┌────────────────────┴────────────────────┐
                     ▼                                         ▼
           If x_k is REJECTED:                      If ALL gamma ACCEPTED:
   • Discard x_k, ..., x_gamma              • Accept x_1, ..., x_gamma
   • Sample replacement token from:         • Sample bonus token gamma+1 from:
     p'_k(x) = (p_k(x) - q_k(x))^+ / Z        p_{gamma+1}(x) directly from M_p
   • Terminate round (k tokens emitted)     • Terminate round (gamma+1 tokens emitted)
```

### 3.1 Why Is Verification Parallel?
Recall from Topic 01 that the target model's decode step is memory-bandwidth bound. Running 1 token through a 70B model takes almost the exact same wall-clock time as running 5 tokens through the model, because the bottleneck is loading the 140 GB weights from HBM to SRAM!

The target model computes logits for all $\gamma + 1$ positions in **one single matrix-matrix forward pass**.

## 4. Modified Rejection Sampling & The Residual Distribution

When testing candidate token $x \sim q$, the acceptance probability is:

$$\boxed{\alpha(x) = \min\left(1, \frac{p(x)}{q(x)}\right)}$$

If $p(x) \ge q(x)$, the target model considers the token *at least as likely* as the draft model did, so $\alpha(x) = 1.0$ (it is accepted unconditionally).

If $p(x) < q(x)$, the candidate is accepted with probability $\frac{p(x)}{q(x)}$.

### The Residual Distribution $p'(x)$
If candidate $x$ is rejected, we cannot simply sample from $p(x)$. Sampling naively from $p(x)$ would introduce positive sampling bias toward high-overlap tokens!
Instead, we must sample the replacement token from the **positive difference (residual)** distribution:

$$\boxed{p'(x) = \frac{(p(x) - q(x))^+}{\sum_{x' \in \mathcal{V}} (p(x') - q(x'))^+}}$$

where $(z)^+ \triangleq \max(0, z)$.

---

## 5. Formal Mathematical Proof of Exact Distribution Equivalence

We now prove the central theorem of Speculative Decoding (Leviathan et al., 2023):
> **Theorem**: The distribution of the token $X$ emitted by the speculative decoding rejection sampler is identical to the target distribution $p(x)$, i.e., $\mathbb{P}_{\text{spec}}(X = x) = p(x)$ for all $x \in \mathcal{V}$.

### Step 1: Compute Overall Acceptance Probability $\beta$
The probability that candidate $x \sim q$ is accepted is:
$$\beta = \sum_{x \in \mathcal{V}} q(x) \cdot \min\left(1, \frac{p(x)}{q(x)}\right) = \sum_{x \in \mathcal{V}} \min(q(x), p(x))$$

Using the algebraic identity $\min(a, b) = \frac{a + b - |a - b|}{2}$:
$$\beta = \sum_{x \in \mathcal{V}} \frac{p(x) + q(x) - |p(x) - q(x)|}{2} = \frac{1 + 1 - 2 D_{\text{TV}}(p, q)}{2} = \mathbf{1 - D_{\text{TV}}(p, q)}$$

### Step 2: Normalize the Residual Distribution $p'(x)$
Notice that:
$$(p(x) - q(x))^+ = p(x) - \min(p(x), q(x))$$
Summing over all vocabulary elements $x \in \mathcal{V}$:
$$\sum_{x \in \mathcal{V}} (p(x) - q(x))^+ = \sum_{x \in \mathcal{V}} p(x) - \sum_{x \in \mathcal{V}} \min(p(x), q(x)) = 1 - \beta$$

Therefore, the normalizing constant $Z = \sum_{x'} (p(x') - q(x'))^+ = 1 - \beta$.
Thus, the residual distribution simplifies to:
$$\boxed{p'(x) = \frac{(p(x) - q(x))^+}{1 - \beta}}$$

### Step 3: Compute Total Emitted Probability $\mathbb{P}_{\text{spec}}(X = x)$
A token $x$ can be emitted along two mutually exclusive paths:
1. $x$ was sampled by draft $q$ and **accepted**:
   $$\mathbb{P}(\text{Accepted and } X = x) = q(x) \cdot \min\left(1, \frac{p(x)}{q(x)}\right) = \min(p(x), q(x))$$
2. The candidate was **rejected**, and $x$ was sampled from the residual distribution $p'$:
   $$\mathbb{P}(\text{Rejected and } X = x) = (1 - \beta) \cdot p'(x) = (1 - \beta) \cdot \frac{(p(x) - q(x))^+}{1 - \beta} = (p(x) - q(x))^+$$

Summing both paths:
$$\mathbb{P}_{\text{spec}}(X = x) = \min(p(x), q(x)) + (p(x) - q(x))^+$$

- **Case A**: If $p(x) \ge q(x)$:
  $$\min(p(x), q(x)) = q(x), \quad (p(x) - q(x))^+ = p(x) - q(x)$$
  $$\mathbb{P}_{\text{spec}}(X = x) = q(x) + p(x) - q(x) = \mathbf{p(x)}$$

- **Case B**: If $p(x) < q(x)$:
  $$\min(p(x), q(x)) = p(x), \quad (p(x) - q(x))^+ = 0$$
  $$\mathbb{P}_{\text{spec}}(X = x) = p(x) + 0 = \mathbf{p(x)}$$

In all cases, $\mathbb{P}_{\text{spec}}(X = x) = p(x)$ identically. $\blacksquare$

**Crucial Takeaway**: Speculative decoding is **NOT an approximation**. It is a mathematically lossless acceleration technique. No perplexity is degraded, and output quality is 100% bit-for-bit identical to native sampling from the target model.

## 6. Expected Speedup Analysis

Let $\beta$ be the mean acceptance rate per token ($\beta \in [0, 1]$).
In a round of lookahead $\gamma$, the probability that the first $k$ tokens are accepted is $\beta^k$.

The expected number of emitted tokens per round $\mathbb{E}[N]$ is:

$$\mathbb{E}[N] = 1 + \sum_{k=1}^{\gamma} \beta^k = 1 + \beta \frac{1 - \beta^\gamma}{1 - \beta} = \boxed{\frac{1 - \beta^{\gamma+1}}{1 - \beta}}$$

- If $\beta \to 0$ (terrible draft model): $\mathbb{E}[N] = 1$ token per round.
- If $\beta \to 1$ (perfect draft model): $\mathbb{E}[N] = \gamma + 1$ tokens per round.

### Wall-Clock Speedup Ratio $S$
Let:
- $c_{\text{draft}}$ = time for 1 forward pass of the draft model.
- $c_{\text{target}}$ = time for 1 parallel verification pass of the target model.
- $r = c_{\text{draft}} / c_{\text{target}}$ (typically $r \approx 0.05\text{--}0.10$ for a 1B draft vs 70B target).

$$\text{Speedup } S = \frac{\mathbb{E}[N] \cdot c_{\text{target}}}{\gamma \cdot c_{\text{draft}} + c_{\text{target}}} = \boxed{\frac{\frac{1 - \beta^{\gamma+1}}{1 - \beta}}{1 + \gamma \cdot r}}$$

For $\beta = 0.8, \gamma = 5, r = 0.05$:
$$\mathbb{E}[N] = \frac{1 - (0.8)^6}{1 - 0.8} = \frac{1 - 0.262}{0.2} = 3.69 \text{ tokens/round}$$
$$\text{Cost} = 1 + (5 \times 0.05) = 1.25 \times c_{\text{target}}$$
$$\text{Speedup } S = \frac{3.69}{1.25} \approx \mathbf{2.95\times \text{ Wall-Clock Speedup!}}$$
