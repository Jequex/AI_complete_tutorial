Exercise 1: Numerical Verification of Rejection Sampling Equivalence

Given vocabulary $\mathcal{V} = \{w_1, w_2, w_3, w_4\}$ with target distribution $p = [0.10, 0.50, 0.30, 0.10]$ and draft distribution $q = [0.40, 0.30, 0.10, 0.20]$.

  1. Compute the individual token acceptance probabilities $\alpha(w_i)$ and mean acceptance rate $\beta$.
  2. Verify that $\beta = 1 - D_{\text{TV}}(p, q)$.
  3. Derive the residual recovery distribution $p'(w_i)$.
  4. Verify numerically that $\mathbb{P}_{\text{spec}}(w_i) = p(w_i)$ for all tokens.
View Complete Step-by-Step Solution

1. Acceptance Probabilities & Mean Rate $\beta$

$$\alpha(w_1) = \min(1, 0.1/0.4) = 0.25, \quad \alpha(w_2) = 1.0, \quad \alpha(w_3) = 1.0, \quad \alpha(w_4) = 0.50$$ $$\beta = (0.4)(0.25) + (0.3)(1.0) + (0.1)(1.0) + (0.2)(0.5) = \mathbf{0.60}$$

2. Total Variation Verification

$$D_{\text{TV}}(p, q) = \frac{1}{2} (|0.1-0.4| + |0.5-0.3| + |0.3-0.1| + |0.1-0.2|) = \frac{0.80}{2} = 0.40$$ $$\beta = 1 - D_{\text{TV}}(p, q) = 1 - 0.40 = \mathbf{0.60} \quad \checkmark$$

3. Residual Distribution $p'$

$$(p - q)^+ = [0.0, 0.20, 0.20, 0.0] \implies Z = 0.40 = 1 - \beta$$ $$p' = [0.0, 0.50, 0.50, 0.0]$$

4. Total Emitted Probabilities

$$\mathbb{P}_{\text{spec}}(w_1) = 0.40 \times 0.25 + 0.40 \times 0 = \mathbf{0.10} = p(w_1)$$ $$\mathbb{P}_{\text{spec}}(w_2) = 0.30 \times 1.00 + 0.40 \times 0.50 = \mathbf{0.50} = p(w_2)$$ $$\mathbb{P}_{\text{spec}}(w_3) = 0.10 \times 1.00 + 0.40 \times 0.50 = \mathbf{0.30} = p(w_3)$$ $$\mathbb{P}_{\text{spec}}(w_4) = 0.20 \times 0.50 + 0.40 \times 0 = \mathbf{0.10} = p(w_4)$$

Every token's emission probability is mathematically identical to $p(x)$!

Exercise 2: Optimal Lookahead Horizon $\gamma^*$ Optimization

For token acceptance rate $\beta = 0.75$ and draft-to-target forward pass cost ratio $r = 0.06$, find the optimal lookahead $\gamma^*$ that maximizes generation speedup.

View Complete Step-by-Step Solution

The speedup formula is $S(\gamma) = \frac{1 - \beta^{\gamma+1}}{(1 - \beta)(1 + \gamma r)}$.

  • $\gamma = 3$: $\mathbb{E}[N] = 2.73$, Cost = $1.18$ → Speedup = $2.317\times$
  • $\gamma = 5$: $\mathbb{E}[N] = 3.29$, Cost = $1.30$ → Speedup = $2.529\times$
  • $\gamma = 6$: $\mathbb{E}[N] = 3.47$, Cost = $1.36$ → Speedup = $2.549\times$ (Maximum)
  • $\gamma = 7$: $\mathbb{E}[N] = 3.60$, Cost = $1.42$ → Speedup = $2.535\times$

The optimum occurs at $\gamma^* = 6$. For $\gamma > 6$, the marginal benefit of another token $\beta^{\gamma+1}$ is outweighed by the linear cost $r$ of the draft model.
