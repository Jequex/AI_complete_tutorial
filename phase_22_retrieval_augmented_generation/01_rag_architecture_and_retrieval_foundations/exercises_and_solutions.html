Problem 1: Parametric vs. Non-Parametric Memory Scaling Analysis (Easy)

An enterprise organization possesses $N = 10^7$ document passages of length $L = 200$ tokens. Compare:

  • Strategy A: Continual fine-tuning of a 70B parameter model.
  • Strategy B: Indexing into a vector database with embedding dimension $d = 1024$ (FP16).

1. Calculate the raw storage footprint of the vector index in gigabytes.
2. Contrast the compute complexity and turnaround time when 10,000 documents are updated weekly.

View Complete Solution

Step 1: Storage Calculation:
Each vector takes $1024 \times 2 \text{ bytes} = 2048 \text{ bytes} = 2 \text{ KB}$.
For $10^7$ passages: $$\text{Total Size} = 10^7 \times 2048 \text{ bytes} = 20.48 \text{ GB}$$ The entire 10-million document index fits inside ordinary server RAM.

Step 2: Update Complexity:
Strategy A requires fine-tuning 70B parameters over $2 \times 10^6$ tokens, requiring $\sim 2.5 \times 10^{18}$ FLOPs, distributed clusters, and hours of compute, risking catastrophic forgetting.
Strategy B only embeds the 10,000 updated passages (milliseconds per doc) and updates vector records in $\mathcal{O}(\log N)$ time with zero downtime and zero parameter degradation.

Problem 3: Groundedness & Hallucination Upper Bound (Hard)

Let parametric accuracy be $P(a_i \in \mathcal{A}) = 0.65$. Under RAG, retrieval recall is $0.92$, conditioned on which grounded accuracy is $0.98$. When retrieval fails, the model falls back to parametric memory with probability $0.10$ or refuses with probability $0.90$.

1. Calculate the expected hallucination rate per claim for RAG vs. Parametric Only.
2. For an answer with $M = 5$ independent claims, compute the probability that the entire answer is 100% hallucination-free.

View Complete Solution

Step 1: Expected Hallucination Rate:
Parametric Only: $1 - 0.65 = 35\%$.
RAG (attempted answer): $$P(a_i \in \mathcal{A}) = (0.98 \times 0.92) + (0.65 \times 0.08) = 0.9016 + 0.0520 = 0.9536$$ Hallucination rate = $1 - 0.9536 = 4.64\%$. (An 86.7% relative reduction).

Step 2: 5-Claim Hallucination-Free Probability:
Parametric: $(0.65)^5 \approx 11.6\%$. (88.4% chance of containing a hallucination).
RAG: $(0.9536)^5 \approx 78.9\%$. (Nearly 7x improvement in completely factual answers).
