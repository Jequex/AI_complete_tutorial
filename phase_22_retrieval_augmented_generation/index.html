Phase 22

Retrieval-Augmented Generation (RAG)

From Static Closed-Book Parametric Models to Dynamic Non-Parametric Dual-Memory Systems

Architectural Paradigm

Pre-trained autoregressive weights constitute static parametric memory: frozen floating-point matrices susceptible to hallucinations, temporal obsolescence, and complete lack of verifiable provenance. Phase 22 builds the end-to-end Retrieval-Augmented Generation (RAG) architecture from first principles in pure Python 3 with zero external dependencies: document ingestion, token chunking taxonomies, vector databases, approximate nearest neighbor (ANN) search via HNSW graphs, hybrid lexical-dense search with Reciprocal Rank Fusion (RRF), Cross-Encoder reranking, and quantitative RAGAS evaluation.

01. RAG Architecture & Retrieval Foundations

Parametric memory vs. non-parametric memory. The canonical two-stage RAG pipeline (Ingestion → Chunking → Embedding → Indexing → Retrieval → Augmentation → Generation). Elimination of hallucinations, temporal recency updates without weight backprop, and verifiable source attribution.

02. Document Chunking & Embedding Strategies

The Chunk Size Dilemma: precision vs context fragmentation. Comprehensive chunking taxonomy: fixed-size sliding window with overlap ($N$ tokens, $K$ overlap), recursive character splitting, document-structure/Markdown splitting, and semantic similarity boundary chunking via cosine thresholds.

03. Vector Databases & Approximate Nearest Neighbors (ANN)

The $\mathcal{O}(N \cdot d)$ brute-force bottleneck. Geometric distance metrics (Cosine similarity, Euclidean distance, Dot product) and equivalence on the unit sphere. Hierarchical Navigable Small World (HNSW) multi-layer skip-lists, greedy routing, $M$ and $ef$ parameter dials, and IVF-PQ product quantization.

04. Hybrid Search & Reranking

Sparse lexical search (Okapi BM25: term frequency saturation, Robertson-Spärck Jones IDF, length normalization) vs dense semantic search. Failure modes on alphanumeric identifiers and semantic paraphrases. Reciprocal Rank Fusion (RRF, $k=60$) and two-stage Bi-Encoder to Cross-Encoder reranking.

05. Context Construction & RAG Evaluation

The "Lost in the Middle" U-shaped attention curve (Liu et al., 2023) and primacy-recency context reordering. Context distillation. The RAGAS evaluation framework: Faithfulness (Groundedness), Answer Relevance, Context Precision (Mean Average Precision), and Context Recall.
