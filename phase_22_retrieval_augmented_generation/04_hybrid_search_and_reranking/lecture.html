Topic 22.4: Hybrid Search & Reranking

Fusing Sparse Okapi BM25 and Dense Bi-Encoders via Reciprocal Rank Fusion and Cross-Encoders

Executive Summary

Pure sparse search (BM25) fails on semantic paraphrases, while pure dense search fails on rare alphanumeric strings and exact serial identifiers. Hybrid Search combines sparse inverted indices with dense vector embeddings using Reciprocal Rank Fusion (RRF) and refines results with a high-capacity Cross-Encoder Reranker.

💡 The 12-Year-Old Analogy: The Fast Keyword Detective & The Deep Reading Judge

Imagine a police investigation:

Officer Ctrl+F (BM25): Searches millions of files for exact license plate numbers like "TX-904-B" in 0.1 seconds. But if you ask for a "stolen luxury sports car", he walks right past a file describing a "hijacked red Ferrari" because the exact words don't match!

Detective Semantic (Dense Bi-Encoder): Knows instantly that a "hijacked red Ferrari" is a luxury car, but she cannot distinguish random license plate numbers.

The RRF Hybrid Team + Cross-Encoder Judge: Both detectives pull their top 20 candidate files. The Chief Judge sits at a desk, places the suspect profile side-by-side with each file, reads every word carefully with full cross-attention, and picks the perfect match!

1. Mathematical Symbol Decoder

Symbol Formal Domain Description & Meaning
$f(q_i, D)$ Integer ($\mathbb{N}_0$) Term frequency of query token $q_i$ in document $D$.
$k_1$ Hyperparameter ($\sim 1.5$) Term frequency saturation parameter.
$b$ Hyperparameter ($\sim 0.75$) Document length normalization penalizing excessively long chunks.
$\text{IDF}(q_i)$ Scalar ($\mathbb{R}$) Inverse Document Frequency weighting rare terms.
$r_m(d)$ Integer ($\mathbb{N}$) 1-based rank position of document $d$ in retriever model $m$.
$k_{\text{RRF}}$ Constant ($\approx 60$) Smoothing factor ensuring stable rank aggregation.

2. Okapi BM25 Formulation

$$\text{BM25}(D, Q) = \sum_{i=1}^m \text{IDF}(q_i) \cdot \frac{f(q_i, D) \cdot (k_1 + 1)}{f(q_i, D) + k_1 \cdot \left(1 - b + b \cdot \frac{|D|}{\text{avgdl}}\right)}$$

BM25 replaces linear term frequency with an asymptotic saturation curve bounded at $k_1 + 1$, preventing keyword stuffing from breaking search relevance.

3. Reciprocal Rank Fusion (RRF)

To fuse unbounded BM25 scores with bounded cosine similarity scores without arbitrary normalization scales:

$$\boxed{\text{RRF}(d) = \sum_{m \in \mathcal{M}} \frac{1}{k_{\text{RRF}} + r_m(d)}}$$

4. Two-Stage Retrieval: Bi-Encoder vs. Cross-Encoder

Architecture Bi-Encoder (Candidate Generation) Cross-Encoder (Reranker)
Input Format $E_Q(Q)$ and $E_D(D)$ encoded independently $\text{Transformer}([CLS] \circ Q \circ [SEP] \circ D)$
Cross Attention None (Dot product of final vectors) Full all-to-all token attention
Candidate Scale $10^6 - 10^9$ documents via HNSW Top $20 - 50$ candidate documents
Latency $< 5 \text{ ms}$ $15 - 50 \text{ ms}$

5. Summary Checklist

  • ☑ Sparse search solves exact keyword matching; Dense search solves semantic synonym matching.
  • ☑ BM25 term frequency saturates at $k_1 + 1$ and normalizes document lengths with $b$.
  • ☑ RRF provides an unsupervised, scale-free framework to merge disparate candidate lists.
  • ☑ Two-stage retrieval combines the speed of Bi-Encoders with the accuracy of Cross-Encoders.
