Problem 1: Context Precision (Mean Average Precision) Calculation (Easy)

Pipeline A retrieves relevance vector $\mathbf{v}_A = [1, 0, 1, 0, 0]$. Pipeline B retrieves $\mathbf{v}_B = [0, 1, 0, 1, 0]$.

1. Compute Precision@$k$ for both pipelines.
2. Calculate the final Context Precision (MAP) score.
3. Explain why early ranking is prioritized.

View Complete Solution

Step 1 & 2: MAP Derivation:
Pipeline A: $\text{Prec@}1 = 1.0, \text{Prec@}3 = 2/3 \approx 0.667$.
$$\text{Context Precision}_A = \frac{1.0 + 0.667}{2} = 83.4\%$$ Pipeline B: $\text{Prec@}2 = 0.5, \text{Prec@}4 = 0.5$.
$$\text{Context Precision}_B = \frac{0.5 + 0.5}{2} = 50.0\%$$

Step 3: Ranking Insight: Although both retrieved 2 relevant chunks, Pipeline A ranks relevant items earlier, shielding the LLM from early distractor noise.

Problem 2: Proof of Lost-in-the-Middle Reordering Optimization (Medium)

Let attention fidelity be $P_{\text{attend}}(x) = 4(x - 0.5)^2 + 0.20$. Two facts have importance weights $w_1 = 0.70$ and $w_2 = 0.30$.

1. Compute expected attention score under Naive Layout ($x_1=0.25, x_2=0.50$).
2. Compute score under Primacy-Recency Layout ($x_1=0.0, x_2=1.0$).
3. Calculate the percentage gain.

View Complete Solution

Step 1: Naive: $(0.70 \times 0.45) + (0.30 \times 0.20) = 0.315 + 0.060 = 0.375$.

Step 2: Primacy-Recency: $(0.70 \times 1.00) + (0.30 \times 1.00) = 1.000$.

Step 3: Improvement: $\frac{1.000 - 0.375}{0.375} = 166.7\%$ relative gain in attention density purely from prompt layout restructuring.

Problem 3: RAG Failure Root-Cause Diagnostic Matrix (Hard)

Diagnose system failures across three enterprise cases:

  • Case 1: Low Faithfulness (0.20), High Precision (0.95), High Recall (0.90).
  • Case 2: High Faithfulness (0.98), Low Relevance (0.30), High Precision (0.90).
  • Case 3: High Faithfulness (0.95), High Relevance (0.85), Low Precision (0.25), Low Recall (0.35).
View Complete Solution

Diagnosis:
- Case 1: Generator Hallucination. The retriever found the right passages, but the generator ignored them and hallucinated.
- Case 2: Instruction Evasion. The model faithfully quoted context but answered a tangent rather than the user's specific prompt.
- Case 3: Retriever Failure. The retriever missed key chunks, but the generator faithfully operated on what was available without fabricating falsehoods.

Remediation: Case 1 requires prompt constraints and lower temperature. Case 3 requires hybrid search (BM25 + Dense + RRF) and improved chunking.
