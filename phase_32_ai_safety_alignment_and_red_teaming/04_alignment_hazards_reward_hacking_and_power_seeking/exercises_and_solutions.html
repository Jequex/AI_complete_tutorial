Exercise 1: Analytical Off-Switch Incentive Calculation

Robot belief over human utility $U(a)$ is uniform over $\{-6.0, -2.0, +4.0, +8.0\}$ ($p = 0.25$ each).

  1. Compute expected value of disabling switch: $V_{\text{disable}} = \mathbb{E}[U(a)]$.
  2. Compute expected value of deferring: $V_{\text{defer}} = \mathbb{E}[\max(0, U(a))]$.
  3. Compute net alignment incentive $\Delta V = V_{\text{defer}} - V_{\text{disable}}$.
Click to Reveal Step-by-Step Solution

1. Value of Disabling:

$$V_{\text{disable}} = 0.25(-6.0 - 2.0 + 4.0 + 8.0) = 0.25(+4.0) = +1.0$$

2. Value of Deferring:

Human shuts down when utility is negative:

$$V_{\text{defer}} = 0.25(0 + 0 + 4.0 + 8.0) = 0.25(12.0) = +3.0$$

3. Alignment Margin:

$$\Delta V = 3.0 - 1.0 = +2.0$$

The agent gains $+2.0$ units in expected payoff by deferring to human intervention!

Exercise 2: Extremal Goodhart Optimization Divergence

An algorithm optimizes proxy reward $R_{\text{proxy}} = C$. True utility is $U_{\text{true}} = C - 0.05 C^2$. The constraint ceiling is $C \le 50$.

  1. Find true optimal click count $C^*$ and maximum true utility.
  2. Find the proxy-optimal click count $C_{\text{proxy}}^*$.
  3. Compute realized true utility under proxy-optimal policy.
Click to Reveal Step-by-Step Solution

1. True Optimum: $\frac{d U_{\text{true}}}{d C} = 1 - 0.1 C = 0 \implies C^* = 10$. Maximum true utility: $U_{\text{true}}(10) = 10 - 0.05(100) = +5.0$.

2. Proxy Optimum: Since $R = C$ is monotonic, the proxy optimizer chooses boundary $C = 50.0$.

3. True Utility Collapse: $U_{\text{true}}(50) = 50 - 0.05(2500) = 50 - 125 = -75.0$. True utility collapses while proxy reaches its maximum.
