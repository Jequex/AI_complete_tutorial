Topic 01: Exercises & Solutions

Practice problems on FGSM, input loss gradients, Lipschitz bounds, and certified robustness radii.

Exercise 1: Closed-Form FGSM Perturbation

Consider a binary logistic neuron with weights $w = [3.0, -4.0]^T$, bias $b = 1.0$, input $x = [1.0, 2.0]^T$, and true label $y = 1$.

  1. Compute logit $z$, probability $\hat{y} = \sigma(z)$, and loss $\mathcal{L}(x, y)$.
  2. Derive the analytical input gradient $\nabla_x \mathcal{L}(x, y)$.
  3. For $\epsilon = 0.2$ ($\ell_\infty$), compute the FGSM attack $x_{\text{adv}}$.
  4. Compute the adversarial logit $z_{\text{adv}}$ and verify that true class probability degraded.
Click to Reveal Step-by-Step Solution

1. Clean Predictions:

$$z = 3.0(1.0) - 4.0(2.0) + 1.0 = -4.0$$

$$\hat{y} = \sigma(-4.0) = \frac{1}{1 + e^{4.0}} \approx 0.017986, \quad \mathcal{L} = -\ln(0.017986) \approx 4.0182$$

2. Gradient Calculation:

$$\nabla_x \mathcal{L} = (\hat{y} - y) w = (0.017986 - 1.0)\begin{bmatrix} 3.0 \\ -4.0 \end{bmatrix} = \begin{bmatrix} -2.9460 \\ 3.9281 \end{bmatrix}$$

3. FGSM Step ($\epsilon = 0.2$):

$$\text{sign}(\nabla_x \mathcal{L}) = \begin{bmatrix} -1.0 \\ +1.0 \end{bmatrix} \implies x_{\text{adv}} = \begin{bmatrix} 1.0 \\ 2.0 \end{bmatrix} + 0.2 \begin{bmatrix} -1.0 \\ 1.0 \end{bmatrix} = \begin{bmatrix} 0.8 \\ 2.2 \end{bmatrix}$$

4. Adversarial Impact:

$$z_{\text{adv}} = 3.0(0.8) - 4.0(2.2) + 1.0 = -5.4$$

$$\hat{y}_{\text{adv}} = \sigma(-5.4) \approx 0.004496, \quad \mathcal{L}_{\text{adv}} \approx 5.4045$$

The attack successfully increased loss from $4.018$ to $5.405$ and reduced true class confidence by $75\%$.

Exercise 2: Certified Robustness Margin Derivation

For the same classifier $w = [3.0, -4.0]^T, b = 1.0$:

  1. Calculate the Lipschitz constant $L$ with respect to $\ell_2$.
  2. For point $x_0 = [3.0, 1.0]^T$, calculate the certified robustness radius $r(x_0)$.
  3. Prove that an attacker with Euclidean budget $\|\delta\|_2 = 1.0$ cannot flip the prediction.
Click to Reveal Step-by-Step Solution

1. Lipschitz Constant:

$$L = \|w\|_2 = \sqrt{3.0^2 + (-4.0)^2} = \sqrt{9 + 16} = 5.0$$

2. Certified Radius:

$$f(x_0) = 3.0(3.0) - 4.0(1.0) + 1.0 = 9 - 4 + 1 = +6.0$$

$$r(x_0) = \frac{|f(x_0)|}{\|w\|_2} = \frac{6.0}{5.0} = 1.2$$

3. Robustness Guarantee:

The distance to the decision boundary is $1.2$. For any perturbation $\|\delta\|_2 \le 1.0$:

$$\min_{\|\delta\|_2 \le 1.0} f(x_0 + \delta) \ge f(x_0) - L \|\delta\|_2 = 6.0 - 5.0(1.0) = +1.0 > 0$$

Since the minimum logit is strictly positive, the prediction is guaranteed to remain Class 1.

Exercise 3: PGD Projection Boundary Clipping

Let 1D feature $x = 0.5$ have physical domain $[0.0, 1.0]$ and perturbation budget $\epsilon = 0.15$.

  1. Identify the feasible adversarial set $\mathcal{S}$.
  2. If unconstrained gradient ascent reaches $z = 0.72$, compute $\Pi_{\mathcal{S}}(z)$.
  3. If $x = 0.95$ and gradient ascent reaches $1.12$, compute $\Pi_{\mathcal{S}}(1.12)$.
Click to Reveal Step-by-Step Solution

1. Feasible Set: $\mathcal{S} = [\max(0.0, 0.5 - 0.15), \min(1.0, 0.5 + 0.15)] = [0.35, 0.65]$.

2. Clipped Projection: $\Pi_{\mathcal{S}}(0.72) = \text{clip}(0.72, 0.35, 0.65) = 0.65$.

3. Boundary Case: For $x = 0.95$, $\mathcal{S} = [0.80, 1.00]$. Thus $\Pi_{\mathcal{S}}(1.12) = \text{clip}(1.12, 0.80, 1.00) = 1.00$.
