Topic 15.4: Exercises & Solutions — Seq2Seq & Bahdanau Attention

Manual attention energy computations, dynamic context weighting, and bottleneck analysis.

Problem 1: Step-by-Step Manual Attention Calculation (Hard)

A decoder generates target token $i=1$ from state $s_0 = [1.0, 0.0]^T$. The source sequence has 3 annotations:

$h_1 = [1.0, 2.0]^T, \quad h_2 = [0.0, 1.0]^T, \quad h_3 = [-1.0, 0.0]^T$.

Parameters: $W_a = I_2, U_a = 0.5 I_2, b_a = \mathbf{0}, v_a = [1.0, 1.0]^T$.

  1. Compute alignment energies $e_{1,1}, e_{1,2}, e_{1,3}$.
  2. Compute attention softmax weights $\alpha_{1,1}, \alpha_{1,2}, \alpha_{1,3}$ and verify sum to $1.0$.
  3. Compute context vector $c_1$.

Solution

1. Alignment Energies ($W_a s_0 = [1.0, 0.0]^T$):

  • $e_{1,1} = [1, 1]^T \tanh([1.5, 1.0]^T) \approx 0.9051 + 0.7616 \approx 1.6667$
  • $e_{1,2} = [1, 1]^T \tanh([1.0, 0.5]^T) \approx 0.7616 + 0.4621 \approx 1.2237$
  • $e_{1,3} = [1, 1]^T \tanh([0.5, 0.0]^T) \approx 0.4621 + 0.0 \approx 0.4621$

2. Softmax Normalization:

$\sum \exp(e) \approx 5.2947 + 3.3997 + 1.5874 = 10.2818$

  • $\alpha_{1,1} = 5.2947 / 10.2818 \approx 0.5149$
  • $\alpha_{1,2} = 3.3997 / 10.2818 \approx 0.3307$
  • $\alpha_{1,3} = 1.5874 / 10.2818 \approx 0.1544$
  • Sum: $0.5149 + 0.3307 + 0.1544 = 1.0000$

3. Context Vector:

$$c_1 = 0.5149 [1, 2]^T + 0.3307 [0, 1]^T + 0.1544 [-1, 0]^T = [0.3605, 1.3605]^T$$

Problem 2: Bahdanau (Additive) vs Luong (Dot-Product) Attention (Medium)

Compare the computational scaling and reasons why modern Transformers chose dot-product over additive attention.

Solution

Additive attention requires evaluating non-linear elementwise $\tanh(W s + U h)$ for all source positions, creating branching overhead on GPUs. Dot-product attention ($Q K^T$) can be executed as a single massive matrix multiplication (`GEMM`) highly optimized on tensor cores.

Problem 3: Shannon Channel Bottleneck (Easy)

Why does fixed-vector compression collapse on long text sequences?

Solution

A static 512-dim vector has fixed Shannon channel capacity ($16,384$ bits for float32). Semantic information in natural language scales linearly as $\mathcal{O}(T_x)$. Bypassing this fixed capacity requires an attention mechanism that scales memory dynamically as $\mathcal{O}(T_x)$.
