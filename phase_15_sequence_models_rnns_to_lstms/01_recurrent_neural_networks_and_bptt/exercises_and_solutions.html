Topic 15.1: Exercises & Solutions — Recurrent Neural Networks & BPTT

Analytical derivation of BPTT adjoints, operator norm proofs for gradient decay, and clipping geometry.

Problem 1: Step-by-Step Manual BPTT on a 2-Step RNN (Hard)

Consider a scalar recurrent network with $w_{hh} = 0.5$, $w_{xh} = 1.0$, $w_{hy} = 2.0$, and $b_h = 0.0$. Let initial state $h_0 = 0.0$.

Inputs: $x_1 = 0.8$, $x_2 = -0.4$. Targets: $y_1 = 1.0$, $y_2 = 0.0$ under MSE loss $L_t = \frac{1}{2}(\hat{y}_t - y_t)^2$.

  1. Compute the forward pass values for $h_1, \hat{y}_1, L_1, h_2, \hat{y}_2, L_2$, and total loss $L$.
  2. Compute adjoints $\frac{\partial L}{\partial h_2}$ and $\frac{\partial L}{\partial h_1}$ using BPTT.
  3. Compute the accumulated gradient $\frac{\partial L}{\partial w_{hh}}$.

Solution

1. Forward Evaluation:

  • $a_1 = 0.5(0.0) + 1.0(0.8) = 0.8 \implies h_1 = \tanh(0.8) \approx 0.6640$
  • $\hat{y}_1 = 2.0(0.6640) = 1.3280 \implies L_1 = \frac{1}{2}(1.3280 - 1.0)^2 \approx 0.0538$
  • $a_2 = 0.5(0.6640) + 1.0(-0.4) = -0.0680 \implies h_2 = \tanh(-0.0680) \approx -0.0679$
  • $\hat{y}_2 = 2.0(-0.0679) = -0.1358 \implies L_2 = \frac{1}{2}(-0.1358 - 0.0)^2 \approx 0.0092$
  • Total loss: $L = 0.0538 + 0.0092 = 0.0630$

2. Backward Adjoints:

$$\frac{\partial L}{\partial h_2} = (\hat{y}_2 - y_2) w_{hy} = (-0.1358)(2.0) = -0.2716$$ $$\delta_2 = \frac{\partial L}{\partial h_2} (1 - h_2^2) = -0.2716(1 - (-0.0679)^2) \approx -0.2703$$ $$\frac{\partial L}{\partial h_1} = (\hat{y}_1 - y_1) w_{hy} + \delta_2 w_{hh} = (0.3280)(2.0) + (-0.2703)(0.5) = 0.6560 - 0.1352 = 0.5208$$

3. Gradient Accumulation:

$$\delta_1 = \frac{\partial L}{\partial h_1} (1 - h_1^2) = 0.5208(1 - 0.6640^2) \approx 0.2912$$ $$\frac{\partial L}{\partial w_{hh}} = \delta_1 h_0 + \delta_2 h_1 = (0.2912)(0.0) + (-0.2703)(0.6640) = -0.1795$$

Problem 2: Mathematical Proof of Gradient Vanishing Bound (Medium)

Let an Elman RNN have hidden transition $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t)$, with spectral norm $\|W_{hh}\|_2 \le \gamma < 1$.

  1. Prove by induction that $\left\| \frac{\partial h_t}{\partial h_k} \right\|_2 \le \gamma^{t-k}$ for all $k < t$.
  2. If $\gamma = 0.75$, calculate the percentage of gradient norm surviving after $\Delta t = 25$ timesteps.

Solution

1. The Jacobian at step $j$ is $\frac{\partial h_j}{\partial h_{j-1}} = D_j W_{hh}$, where $D_j = \text{diag}(1 - h_j^2)$. Since $1 - h_{j,i}^2 \in (0, 1]$, $\|D_j\|_2 \le 1.0$.

For $\Delta t = 1$, $\|\frac{\partial h_t}{\partial h_{t-1}}\|_2 \le \|D_t\|_2 \|W_{hh}\|_2 \le \gamma^1$.

Assuming $\|\frac{\partial h_{t-1}}{\partial h_k}\|_2 \le \gamma^{t-1-k}$, by operator submultiplicativity:

$$\left\| \frac{\partial h_t}{\partial h_k} \right\|_2 = \left\| \frac{\partial h_t}{\partial h_{t-1}} \frac{\partial h_{t-1}}{\partial h_k} \right\|_2 \le \gamma \cdot \gamma^{t-1-k} = \gamma^{t-k} \quad \blacksquare$$

2. For $\gamma = 0.75$ and $\Delta t = 25$:

$$\gamma^{25} = (0.75)^{25} \approx 0.0007525 \quad (\approx 0.075\%)$$

Over $99.92\%$ of the gradient norm is eradicated!

Problem 3: Geometry of Gradient Clipping (Easy)

Let $\mathbf{g} = [6.0, -8.0, 0.0]^T$, with threshold $\tau = 5.0$. Verify that clipping leaves direction unaltered.

Solution

Norm: $\|\mathbf{g}\|_2 = \sqrt{6^2 + (-8)^2 + 0^2} = \sqrt{100} = 10.0$.

Since $10.0 > 5.0$, scale factor is $\alpha = \frac{5.0}{10.0} = 0.5 \implies \mathbf{g}_{\text{clip}} = [3.0, -4.0, 0.0]^T$.

$$\cos(\theta) = \frac{\mathbf{g} \cdot \mathbf{g}_{\text{clip}}}{\|\mathbf{g}\|_2 \|\mathbf{g}_{\text{clip}}\|_2} = \frac{6(3) + (-8)(-4)}{10.0 \times 5.0} = \frac{18 + 32}{50.0} = 1.000000$$
