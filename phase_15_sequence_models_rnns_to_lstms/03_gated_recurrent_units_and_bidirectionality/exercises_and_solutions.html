Topic 15.3: Exercises & Solutions — GRUs & Bidirectionality

Analytical GRU state updates, parameter trade-offs, and causal vs non-causal constraints.

Problem 1: Step-by-Step Manual GRU Forward Pass (Hard)

A single-cell GRU has parameters:

  • $W_r = [0, 0], b_r = -2.0$
  • $W_z = [0, 0], b_z = 1.0$
  • $W_{hh} = 2.0, W_{xh} = 1.0, b_h = 0.0$

Given $h_0 = 1.0$ and $x_1 = 0.5$:

  1. Compute reset gate $r_1$ and update gate $z_1$.
  2. Compute candidate state $\tilde{h}_1$.
  3. Compute final updated hidden state $h_1$.

Solution

1. Gates:

  • $r_1 = \sigma(-2.0) \approx 0.1192$
  • $z_1 = \sigma(1.0) \approx 0.7311$

2. Candidate Hidden State:

$$r_1 \cdot h_0 = 0.1192(1.0) = 0.1192$$ $$a_h = 2.0(0.1192) + 1.0(0.5) + 0.0 = 0.2384 + 0.5 = 0.7384$$ $$\tilde{h}_1 = \tanh(0.7384) \approx 0.6282$$

3. Hidden State Interpolation:

$$h_1 = (1 - 0.7311)(1.0) + 0.7311(0.6282) = 0.2689 + 0.4593 = 0.7282$$

Problem 2: Bidirectional GRU vs Unidirectional LSTM Parameter Trade-Off (Medium)

Compare a Unidirectional LSTM with $d_h = 512$ against a Bidirectional GRU with $d_h = 256$ per direction (both yielding 512-dim output representation) with input $d_x = 100$.

Solution

Uni-LSTM: $4 \times 512(512 + 100 + 1) = 2,048 \times 613 = 1,255,424$ parameters.

Bi-GRU: $2 \times [3 \times 256(256 + 100 + 1)] = 2 \times [768 \times 357] = 2 \times 274,176 = 548,352$ parameters.

$$\text{Reduction} = \frac{1,255,424 - 548,352}{1,255,424} \times 100\% \approx 56.3\%$$

The Bi-GRU requires $56.3\%$ fewer parameters while providing future context!

Problem 3: Causal Generation Barrier (Easy)

Why can't an autoregressive text generator (like an LLM decoder) use a bidirectional recurrent network?

Solution

During inference, tokens are generated one by one into the future. Tokens $y_{t+1}, \dots, y_T$ do not exist yet. A backward RNN cannot run backward from non-existent future tokens.
