Topic 15.2: Long Short-Term Memory (LSTM) Networks

The Constant Error Carousel, additive memory highways, and the mathematical proof of gradient preservation across long temporal horizons.

Executive Summary

Standard RNNs suffer from catastrophic vanishing gradients due to repeated multiplications by the recurrent Jacobian matrix $\text{diag}(1 - h^2) W_{hh}$. In 1997, Hochreiter & Schmidhuber solved this with the Long Short-Term Memory (LSTM) architecture. By isolating an internal linear Cell State ($c_t$) and regulating it with four non-linear gating mechanisms (Forget, Input, Candidate, Output), the network establishes an additive highway where gradients flow backward across hundreds of timesteps with derivative $\frac{\partial c_t}{\partial c_{t-1}} \approx 1.0$.

1. The 12-Year-Old Analogy: The Executive Assistant & The Heavy Iron Safe

Imagine you are an executive whose working memory expires every few seconds. To manage your company, you employ an elite executive assistant:

  • The Heavy Iron Safe ($c_t$ — Cell State): Behind your desk sits a persistent ledger book. It is never overwritten automatically; it simply endures from year to year.
  • The Forget Gate ($f_t$ — The Eraser): When a new document arrives, the assistant checks the ledger: "Did any client cancel their contract?" Obsolete details are erased ($f_t = 0$), while active projects are left intact ($f_t = 1$).
  • The Input Gate ($i_t \odot \tilde{c}_t$ — The Ink Pen): The assistant drafts candidate facts ($\tilde{c}_t$). If the information is valuable ($i_t \approx 1$), they add it into the ledger using addition ($+$).
  • The Output Gate ($o_t$ — The Highlighter): When asked for a status update ($h_t$), the assistant highlights only the pertinent parts ($o_t \odot \tanh(c_t)$) to produce a brief executive summary.

2. Mathematical Symbol Decoder

Symbol Domain Description
$c_t \in \mathbb{R}^{d_h}$ Vector Space Cell State: the long-term additive memory highway
$h_t \in \mathbb{R}^{d_h}$ Vector Space Hidden State: short-term working output exposed to downstream layers
$f_t \in (0, 1)^{d_h}$ Sigmoid Gate Forget Gate: fraction of previous cell memory $c_{t-1}$ to retain
$i_t \in (0, 1)^{d_h}$ Sigmoid Gate Input Gate: fraction of candidate state $\tilde{c}_t$ to store into $c_t$
$\tilde{c}_t \in (-1, 1)^{d_h}$ $\tanh$ State Candidate State: newly synthesized memory features
$o_t \in (0, 1)^{d_h}$ Sigmoid Gate Output Gate: fraction of cell state to expose in hidden state $h_t$

3. The LSTM Gating Mechanism

Let $v_t = [h_{t-1}, x_t]$. The canonical equations are:

$$f_t = \sigma(W_f v_t + b_f)$$ $$i_t = \sigma(W_i v_t + b_i)$$ $$\tilde{c}_t = \tanh(W_c v_t + b_c)$$ $$\boxed{c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t}$$ $$o_t = \sigma(W_o v_t + b_o)$$ $$\boxed{h_t = o_t \odot \tanh(c_t)}$$

4. Mathematical Proof of Gradient Flow: The Constant Error Carousel

The sensitivity of the cell state $c_t$ with respect to its previous value $c_{t-1}$ is:

$$\frac{\partial c_t}{\partial c_{t-1}} = \text{diag}(f_t) + \mathcal{O}\left(\frac{\partial h_{t-1}}{\partial c_{t-1}}\right)$$

Over $T - k$ timesteps, the cumulative gradient flow along the cell state highway is:

$$\frac{\partial c_T}{\partial c_k} = \prod_{j=k+1}^T \frac{\partial c_j}{\partial c_{j-1}} \approx \prod_{j=k+1}^T \text{diag}(f_j)$$

Why Gradients Do Not Vanish in LSTMs

  1. No Recurrent Weight Matrix ($W_{hh}$): There is no matrix multiplication along the cell state sequence! The Jacobian is purely diagonal.
  2. No Vanishing Activations: The factor $(1 - \tanh^2(a)) \le 1.0$ that crushed Elman RNN gradients is eliminated from the cell state recurrence.
  3. The Highway State ($f_j \approx 1$): When the forget gate is open ($f_j \approx 1.0$), $\frac{\partial c_T}{\partial c_k} \approx 1.0$. Error signals traverse 50 or 100 timesteps without exponential attenuation.
