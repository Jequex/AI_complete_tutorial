Topic 15.2: Exercises & Solutions — Long Short-Term Memory (LSTM)

Gating calculations, parameter count scaling laws, and constant error carousel derivations.

Problem 1: Step-by-Step Manual Forward Pass of an LSTM Cell (Hard)

A single-neuron LSTM cell ($d_x = 1, d_h = 1$) has parameters:

  • $W_f = [0.0, 0.0], b_f = 2.0$
  • $W_i = [1.0, 2.0], b_i = -1.0$
  • $W_c = [0.5, 1.0], b_c = 0.0$
  • $W_o = [0.0, 1.0], b_o = 0.0$

Given initial state $h_0 = 0.5, c_0 = 1.0$, and input $x_1 = 1.0$:

  1. Compute the 4 gate activations: $f_1, i_1, \tilde{c}_1, o_1$.
  2. Compute the updated cell state $c_1$.
  3. Compute the emitted hidden state $h_1$.

Solution

1. Gate Activations ($v_1 = [0.5, 1.0]^T$):

  • $f_1 = \sigma(2.0) \approx 0.8808$
  • $i_1 = \sigma(1(0.5) + 2(1.0) - 1.0) = \sigma(1.5) \approx 0.8176$
  • $\tilde{c}_1 = \tanh(0.5(0.5) + 1.0(1.0)) = \tanh(1.25) \approx 0.8483$
  • $o_1 = \sigma(0(0.5) + 1(1.0)) = \sigma(1.0) \approx 0.7311$

2. Cell State:

$$c_1 = f_1 c_0 + i_1 \tilde{c}_1 = 0.8808(1.0) + 0.8176(0.8483) = 0.8808 + 0.6936 = 1.5744$$

3. Hidden State:

$$h_1 = o_1 \tanh(c_1) = 0.7311 \tanh(1.5744) \approx 0.7311(0.9175) \approx 0.6708$$

Problem 2: Parameter Count Scaling Law (Medium)

Derive the exact number of trainable parameters in an LSTM layer with input dim $d_x$ and hidden dim $d_h$, and compare against an Elman RNN.

Solution

An LSTM contains 4 linear transforms (Forget, Input, Candidate, Output). Each processes concatenated vector of dimension $d_h + d_x$ and outputs $d_h$ dimensions:

$$P_{\text{gate}} = d_h(d_h + d_x) + d_h = d_h(d_h + d_x + 1)$$ $$\boxed{P_{\text{LSTM}} = 4 \times d_h(d_h + d_x + 1)}$$

An Elman RNN has only 1 transition matrix set: $P_{\text{RNN}} = d_h(d_h + d_x + 1)$.

For $d_x = 128, d_h = 512$: $P_{\text{RNN}} = 328,192$ vs $P_{\text{LSTM}} = 1,312,768$ (exact $4\times$ ratio).

Problem 3: Constant Error Carousel Proof (Easy)

Prove that when $f_t = \mathbf{1}$ and $i_t = \mathbf{0}$ across $K$ steps, $\frac{\partial c_T}{\partial c_{T-K}} = I$.

Solution

Since $c_t = 1 \cdot c_{t-1} + 0 \cdot \tilde{c}_t = c_{t-1}$, the recurrence is an identity mapping $c_T = c_{T-K}$. The Jacobian of an identity map is the identity matrix $I$. Thus, gradients pass through with zero exponential attenuation.
