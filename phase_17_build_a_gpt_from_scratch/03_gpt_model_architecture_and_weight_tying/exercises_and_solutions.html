Problem 1: Manual Parameter Derivation for GPT-2 Small (Easy)

Derive the exact parameter count for GPT-2 Small ($V = 50{,}257$, $T_{\max} = 1024$, $d = 768$, $L = 12$, tied weights).

View Complete Solution
  • Token Embedding (wte): $50{,}257 \times 768 = 38{,}597{,}376$
  • Position Embedding (wpe): $1024 \times 768 = 786{,}432$
  • One Transformer Block:
    • Attention: $4 \times (768^2 + 768) = 2{,}362{,}368$
    • MLP: $8 \times 768^2 + 5 \times 768 = 4{,}722{,}432$
    • LayerNorms: $4 \times 768 = 3{,}072$
    • Total per block = $7{,}087{,}872$
  • 12 Blocks: $12 \times 7{,}087{,}872 = 85{,}054{,}464$
  • Final LayerNorm: $2 \times 768 = 1{,}536$
  • LM Head: $0$ (Tied to wte)

Total: $38{,}597{,}376 + 786{,}432 + 85{,}054{,}464 + 1{,}536 = \mathbf{124{,}439{,}808}$ parameters ($\approx 124.44\text{M}$).

Problem 2: Impact of Untied Weights on VRAM Footprint (Medium)

For a model with $V = 128{,}000$ and $d = 4096$, compute the extra parameters and training VRAM required if the LM head is untied.

View Complete Solution

Extra Parameters:
$$\Delta P = 128{,}000 \times 4096 = 524{,}288{,}000 \approx 524.29\text{ Million parameters}$$

VRAM in 16-bit Mixed Precision AdamW:
Weights (2B) + Gradients (2B) + Master weights (4B) + Momentum (4B) + Variance (4B) = 16 bytes/param.
$$\text{Memory} = 524{,}288{,}000 \times 16\text{ bytes} \approx 8.39\text{ GB (7.81 GiB)}$$

Problem 3: Log-Sum-Exp Trick for Numerical Stability (Hard)

Derive the numerically stable Log-Sum-Exp formula for cross-entropy loss that guarantees zero floating-point overflow.

View Complete Solution

Let $c = \max_k z_k$. Factoring $\exp(c)$:

$$\sum_{j=1}^V \exp(z_j) = \exp(c) \sum_{j=1}^V \exp(z_j - c)$$ $$\log\left(\sum_{j=1}^V \exp(z_j)\right) = c + \log\left(\sum_{j=1}^V \exp(z_j - c)\right)$$

The cross-entropy loss becomes:

$$\mathcal{L} = -(z_y - c) + \log\left(\sum_{j=1}^V \exp(z_j - c)\right)$$

Because $z_j - c \le 0$, the argument to the exponential is bounded by $0$, guaranteeing $\exp(z_j - c) \in (0, 1]$. Overflow is mathematically impossible.
