Topic 17.3: GPT Architecture & Weight Tying

Assembling the Full Autoregressive Transformer with Parameter Tying & Rigorous Counting Formulas

Executive Summary

The Generative Pre-trained Transformer (GPT) connects input token indices to next-token predictions through a unified sequence of modules: Token Embeddings, Learned Positional Embeddings, $N$ stacked Pre-LN Transformer blocks, a final LayerNorm, and an output Language Model (LM) Head. Through Weight Tying (Press & Wolf, 2017), the input embedding matrix $W_{\text{token}}$ is reused as the output linear head ($W_{\text{head}} = W_{\text{token}}^T$), eliminating over 38.6M parameters in GPT-2 Small while aligning input and output representations.

The 12-Year-Old Analogy: The Master Printing Press with Reusable Type Blocks

Imagine a master book printing press in 1450:

  • Lead Letter Blocks (Embeddings): You have a drawer of 50,257 lead word stamps ($W_{\text{token}}$) and a shelf of 1,024 slot numbers ($W_{\text{pos}}$). You combine them to stamp a 768-dimensional wax sculpture for each word.
  • The Factory of Editors (Transformer Blocks): The wax sculptures roll through 12 consecutive editing rooms where editors check grammar, tone, and context.
  • The Reusable Stamp Trick (Weight Tying): At the exit door, to decide what word comes next, you could forge 50,257 new copper stamps ($W_{\text{head}}$). But the clever printer re-uses the exact same lead blocks from the entrance drawer! If a block meant "cat" on entry, pressing it against the final sculpture tells you if the scene needs "cat" next. One set of blocks, zero wasted metal!

Weight Tying Formulation

By defining the output linear head as the transpose of the input token embedding:

$$W_{\text{head}} = W_{\text{token}}^T$$

The unnormalized logit for predicting token $v$ at position $t$ is the dot product:

$$z_{t, v} = \mathbf{h}_t^{(\text{final})} \cdot W_{\text{token}}[v, :]^T$$

This enforces metric consistency between token ingestion and token generation while reducing model memory footprint.

Closed-Form Parameter Counting Formula

$$\boxed{\text{Params} = (V + T_{\max})d + L(12 d^2 + 13 d) + 2d + \mathbb{I}[\text{untied}] \cdot V d}$$
