Problem 1: Manual Step-by-Step BPE Merge Tracing (Easy)

Consider the toy corpus composed of words with character frequencies:

  • l o w _ : 2 times
  • l o w e s t _ : 1 time
  • n e w e r _ : 1 time
  • w i d e r _ : 1 time
  1. What is the initial base vocabulary $\mathcal{V}_0$?
  2. Compute the frequencies of all adjacent character pairs.
  3. Identify the very first pair selected for merging and update the vocabulary.
View Complete Solution

Step 1: Initial base vocabulary:
$$\mathcal{V}_0 = \{ \text{'d', 'e', 'i', 'l', 'o', 'r', 's', 't', 'w', '\_'} \}, \quad |\mathcal{V}_0| = 10$$

Step 2: Adjacent pairs count:
(l, o): 3x, (o, w): 3x, (w, _): 2x, (w, e): 2x, (e, r): 2x, (r, _): 2x, all others 1x.

Step 3: The highest count is 3. By alphabetical order, select (l, o) → lo.
Updated vocabulary: $\mathcal{V}_1 = \mathcal{V}_0 \cup \{\text{'lo'}\}$.

Problem 2: Parameter Savings vs Quadratic Sequence Length Trade-off (Medium)

Suppose an LLM has embedding dimension $d_{\text{model}} = 4096$, processing documents of average length $L = 2048$ characters.

  • System A (Character-level): $V_A = 256$, average token count $T_A = 2048$.
  • System B (Subword BPE): $V_B = 50{,}000$, compression ratio $3.8$ chars/token ($T_B = 540$).

Compute embedding parameter count and self-attention FLOPs ($2 \cdot T^2 \cdot d_{\text{model}}$) for both systems.

View Complete Solution

1. Embedding Parameters ($V \times d_{\text{model}}$):
System A: $256 \times 4096 = 1.05\text{ M parameters}$
System B: $50{,}000 \times 4096 = 204.8\text{ M parameters}$

2. Self-Attention FLOPs ($2 \cdot T^2 \cdot d_{\text{model}}$):
System A: $2 \times (2048)^2 \times 4096 = 34.36\text{ GFLOPs}$
System B: $2 \times (540)^2 \times 4096 = 2.39\text{ GFLOPs}$

Speedup ratio: $34.36 / 2.39 \approx 14.38\times$ faster self-attention in every Transformer block!

Problem 3: Handling Emoji & Foreign Scripts via Byte Fallback (Hard)

The rocket emoji 🚀 is represented by 4 UTF-8 bytes: [240, 159, 154, 128]. Explain how byte-level BPE prevents Out-Of-Vocabulary failures on unseen emojis.

View Complete Solution

Unlike word-level models that collapse unknown strings into <UNK>, byte-level BPE initializes its vocabulary with all 256 individual byte values ($0 \dots 255$). If no merge rule has ever been learned for the rocket emoji, the tokenizer emits the 4 constituent byte IDs: $[240, 159, 154, 128]$. Upon decoding, the bytes are concatenated in order: b'\xf0\x9f\x9a\x80', which reconstructs 🚀 losslessly!
