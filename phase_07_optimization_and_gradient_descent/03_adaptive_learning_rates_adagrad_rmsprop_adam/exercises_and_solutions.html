Step-by-step hand calculations and analytical proofs on Adam moment tracking, AdaGrad freezing, and AdamW weight decay decoupling.

Problem 1: Manual Step-by-Step Adam Hand Calculation

Medium

Optimize parameter $\theta$ initialized at $\theta_0 = 1.0$ with $\eta = 0.01, \beta_1 = 0.9, \beta_2 = 0.99, \epsilon = 10^{-6}$. Gradients received: $g_1 = 0.40$, $g_2 = 0.20$.

  1. Compute $m_1, v_1, \hat{m}_1, \hat{v}_1$, and updated parameter $\theta_1$.
  2. Compute $m_2, v_2, \hat{m}_2, \hat{v}_2$, and updated parameter $\theta_2$.
  3. Explain the critical role of bias correction in preventing step-size distortion.
Click to view step-by-step solution

1. Step 1 ($t = 1$):

$$m_1 = 0.9(0) + 0.1(0.40) = 0.040, \quad v_1 = 0.99(0) + 0.01(0.40^2) = 0.00160$$ $$\hat{m}_1 = \frac{0.040}{1 - 0.9^1} = \frac{0.040}{0.10} = 0.400, \quad \hat{v}_1 = \frac{0.00160}{1 - 0.99^1} = \frac{0.00160}{0.01} = 0.160$$ $$\Delta \theta_1 = -\frac{0.01}{\sqrt{0.160} + 10^{-6}}(0.400) = -0.010 \implies \theta_1 = 1.0 - 0.010 = 0.990$$

2. Step 2 ($t = 2$):

$$m_2 = 0.9(0.040) + 0.1(0.20) = 0.056, \quad v_2 = 0.99(0.0016) + 0.01(0.04) = 0.001984$$ $$\hat{m}_2 = \frac{0.056}{1 - 0.9^2} = \frac{0.056}{0.19} \approx 0.2947, \quad \hat{v}_2 = \frac{0.001984}{1 - 0.99^2} = \frac{0.001984}{0.0199} \approx 0.0997$$ $$\Delta \theta_2 = -\frac{0.01}{\sqrt{0.0997}}(0.2947) \approx -0.009335 \implies \theta_2 = 0.980665$$

3. Bias Correction Significance: Without $(1-\beta_1^t)$ and $(1-\beta_2^t)$, uncorrected moments are dominated by initial zero-initialization, causing wild initial step anomalies.

Problem 2: AdaGrad Monotonic Freezing Proof

Easy

In AdaGrad, $G_t = \sum_{k=1}^t g_k^2$. Prove that under constant gradient $g_k = c > 0$, the parameter update decays as $\mathcal{O}(1/\sqrt{t})$ and cumulative distance is bounded by $\mathcal{O}(\sqrt{T})$.

Click to view step-by-step solution

Accumulator: $G_t = t \cdot c^2$.

Step Size: $\Delta \theta_t = \frac{\eta}{\sqrt{t c^2}} c = \frac{\eta}{\sqrt{t}} = \mathcal{O}(1/\sqrt{t})$.

Total Distance:

$$\sum_{t=1}^T \frac{\eta}{\sqrt{t}} \approx \eta \int_1^T t^{-1/2} dt = 2\eta (\sqrt{T} - 1) = \mathcal{O}(\sqrt{T})$$ Standard SGD traverses $\mathcal{O}(T)$. AdaGrad's rapid step decay makes it freeze prematurely before exploring deep non-convex valleys.

Problem 3: AdamW vs L2 Regularization Mathematical Proof

Hard

Prove that standard Adam with $L_2$ decay applies effective shrinkage $\frac{\eta \lambda}{\sqrt{\hat{v}_t} + \epsilon} \theta_t$, whereas AdamW applies uniform shrinkage $\eta \lambda \theta_t$. Calculate the shrinkage discrepancy between frequent and rare token weights.

Click to view step-by-step solution

$L_2$ Penalty in Adam: Gradients become $\nabla \mathcal{L} + \lambda \theta$. The moment update divides the entire term by $\sqrt{\hat{v}_t}$, giving effective decay $\frac{\eta \lambda}{\sqrt{\hat{v}_t}} \theta_t$.

AdamW: Weight decay is subtracted directly: $\theta_{t+1} = (1 - \eta \lambda)\theta_t - \frac{\eta}{\sqrt{\hat{v}_t}+\epsilon} \hat{m}_t$.

Discrepancy: For frequent token ($\hat{v}=100$) vs rare token ($\hat{v}=0.01$):

$$\text{Ratio} = \frac{\sqrt{100}}{\sqrt{0.01}} = \frac{10}{0.1} = 100\times$$ Standard Adam penalizes rare tokens 100 times harder than frequent ones! AdamW fixes this critical bug.

Problem 4: Scale Invariance of Adam Step Sizes

Medium

Prove that scaling the loss function by a positive scalar $c > 0$ ($\tilde{\mathcal{L}} = c \mathcal{L}$) leaves Adam updates unchanged.

Click to view step-by-step solution

$\tilde{g}_t = c g_t \implies \tilde{m}_t = c m_t$ and $\tilde{v}_t = c^2 v_t$.

Therefore $\sqrt{\hat{\tilde{v}}_t} = c \sqrt{\hat{v}_t}$.

$$\Delta \tilde{\theta} = -\frac{\eta}{c \sqrt{\hat{v}_t}} (c \hat{m}_t) = -\frac{\eta}{\sqrt{\hat{v}_t}} \hat{m}_t = \Delta \theta$$ The scaling constant $c$ cancels exactly, providing automatic scale invariance.
