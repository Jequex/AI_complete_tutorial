Problem 1: Convexity Proof via Hessian

Easy

Prove that the log-barrier function $f(x) = -\sum_{i=1}^n \ln(x_i)$ on $\mathbb{R}_{++}^n$ is strictly convex by computing its Hessian matrix.

Click to view step-by-step solution

Gradient: $\frac{\partial f}{\partial x_i} = -1/x_i$.

Hessian Matrix: $H(x) = \text{diag}(1/x_1^2, \dots, 1/x_n^2)$.

For any non-zero vector $z \ne 0$:

$$z^T H(x) z = \sum_{i=1}^n \frac{z_i^2}{x_i^2} > 0$$ Since $x_i > 0$ and $z \ne 0$, $H(x) \succ 0$ (strictly positive definite), proving $f(x)$ is strictly convex.

Problem 2: Hand-Solved Constrained Optimization via KKT

Medium

Minimize $f(x_1, x_2) = x_1^2 + x_2^2$ subject to $g(x_1, x_2) = 2 - (x_1 + x_2) \le 0$. Solve analytically using the four KKT conditions.

Click to view step-by-step solution

Lagrangian: $\mathcal{L}(x, \lambda) = x_1^2 + x_2^2 + \lambda(2 - x_1 - x_2)$.

Stationarity: $2x_1^* = \lambda^*, 2x_2^* = \lambda^* \implies x_1^* = x_2^* = \lambda^* / 2$.

Case $\lambda = 0$: Gives $(0, 0)$, which violates $x_1 + x_2 \ge 2$.

Case $\lambda > 0$: Constraint is active: $\frac{\lambda^*}{2} + \frac{\lambda^*}{2} = 2 \implies \lambda^* = 2$.

Therefore, $x_1^* = 1.0, x_2^* = 1.0$, with minimum loss $f(1, 1) = 2.0$. All 4 KKT conditions are verified.

Problem 3: SVM Dual Formulation from KKT

Hard

Derive the dual quadratic program of hard-margin SVM: $\min \frac{1}{2}\|w\|^2$ s.t. $y_i(w^T x_i + b) \ge 1$. Explain how complementary slackness reveals "support vectors".

Click to view step-by-step solution

Lagrangian: $\mathcal{L}(w, b, \alpha) = \frac{1}{2}\|w\|^2 + \sum \alpha_i [1 - y_i(w^T x_i + b)]$.

Stationarity: $w = \sum \alpha_i y_i x_i$ and $\sum \alpha_i y_i = 0$.

Substituting back yields the Dual problem: $\max_\alpha \sum \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^T x_j$ s.t. $\alpha_i \ge 0, \sum \alpha_i y_i = 0$.

Support Vectors: By complementary slackness $\alpha_i [1 - y_i(w^T x_i + b)] = 0$, points with $y_i(w^T x_i + b) > 1$ have $\alpha_i = 0$. Only boundary points where the margin is tight have $\alpha_i > 0$.

Problem 4: Euclidean Projection Operator Derivation

Medium

Derive the projection operator $\Pi_C(z)$ for the closed Euclidean ball $C = \{x \in \mathbb{R}^d : \|x\|_2 \le R\}$.

Click to view step-by-step solution

If $\|z\| \le R$, $z \in C \implies \Pi_C(z) = z$.

If $\|z\| > R$, solving $\min \frac{1}{2}\|y - z\|^2$ s.t. $\frac{1}{2}\|y\|^2 \le \frac{1}{2}R^2$ gives stationarity $y - z + \lambda y = 0 \implies y = \frac{z}{1+\lambda}$. Since $\|y\| = R$, $1 + \lambda = \frac{\|z\|}{R}$.

$$\Pi_C(z) = \begin{cases} z & \text{if } \|z\| \le R \\ R \frac{z}{\|z\|} & \text{if } \|z\| > R \end{cases}$$
