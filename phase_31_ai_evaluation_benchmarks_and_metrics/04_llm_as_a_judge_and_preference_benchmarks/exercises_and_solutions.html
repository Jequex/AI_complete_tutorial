Exercise 1: Bradley-Terry Win Expectations & Elo Updates

Model $A$ ($R_A = 1650$) plays Model $B$ ($R_B = 1500$) with $K = 32$.

Tasks:

  1. Compute expected win probabilities $E_A$ and $E_B$.
  2. Compute updated ratings $R_A', R_B'$ if Model $A$ wins ($S_A = 1$).
  3. Compute updated ratings $R_A', R_B'$ if underdog Model $B$ wins ($S_A = 0$). Verify total point conservation.
View Complete Solution

1. Expected Scores:

$$E_A = \frac{1}{1 + 10^{(1500 - 1650)/400}} = \frac{1}{1 + 10^{-0.375}} \approx \frac{1}{1.4217} = \mathbf{70.34\%}, \qquad E_B = \mathbf{29.66\%}$$

2. Case 1 (A Wins):

$$R_A' = 1650 + 32(1 - 0.7034) = \mathbf{1659.49}, \qquad R_B' = 1500 - 9.49 = \mathbf{1490.51}$$

3. Case 2 (B Wins):

$$R_A' = 1650 + 32(0 - 0.7034) = \mathbf{1627.49}, \qquad R_B' = 1500 + 22.51 = \mathbf{1522.51}$$

Conservation check: $1627.49 + 1522.51 = 3150.00 = 1650 + 1500$ (verified).

Exercise 2: Position Bias & Swapping De-biasing

An automated judge has a $65\%$ preference for Position 1 regardless of response content. Models $A$ and $B$ are identical in quality.

Tasks: Compare naive evaluation (A placed in Pos 1 for all 100 queries) against bidirectional position-swapping.

View Complete Solution

1. Naive Unidirectional: Model $A$ appears to win $65\%$ of matches, publishing an invalid claim of superiority.

2. Bidirectional Swapping:

  • $\mathbb{P}(\text{A Wins Both}) = 0.65 \times 0.35 = \mathbf{22.75\%}$
  • $\mathbb{P}(\text{B Wins Both}) = 0.35 \times 0.65 = \mathbf{22.75\%}$
  • $\mathbb{P}(\text{Tie}) = 1 - (0.2275 + 0.2275) = \mathbf{54.50\%}$
$$\text{Effective Ratio} = \frac{22.75\%}{22.75\% + 22.75\%} = \mathbf{50.0\%}$$

Position-swapping eliminates the $65\%$ order bias and reveals true parity.

Exercise 3: Bradley-Terry Maximum Likelihood Estimation

In a 3-model tournament, match wins are: $W_{12} = 30, W_{21} = 10$; $W_{13} = 40, W_{31} = 10$; $W_{23} = 20, W_{32} = 20$.

Tasks: Formulate the log-likelihood function and solve for optimal relative latent parameters setting $\pi_3 = 1.0$ and $R_3 = 1000$.

View Complete Solution

Setting $\pi_3 = 1.0$: By symmetry between $M_2$ and $M_3$ ($20\text{--}20$), $\pi_2 = 1.0$.

Solving the gradient condition $\frac{\partial \ln \mathcal{L}}{\partial \pi_1} = 0$:

$$\frac{70}{\pi_1} - \frac{40}{\pi_1 + 1} - \frac{50}{\pi_1 + 1} = 0 \implies \pi_1 \approx \mathbf{3.00}$$

Converting to Elo ratings ($R_i = 1000 + 400 \log_{10} \pi_i$):

$$\mathbf{R_3 = 1000, \qquad R_2 = 1000, \qquad R_1 = 1000 + 400\log_{10}(3.0) \approx 1191}$$
