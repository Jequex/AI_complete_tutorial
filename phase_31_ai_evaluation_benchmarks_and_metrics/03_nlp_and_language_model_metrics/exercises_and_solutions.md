### Exercise 1: Language Model Cross-Entropy Loss & Perplexity

A generative language model evaluates an evaluation sequence of $N = 5$ tokens:
$$X = (\text{"The"}, \text{"quantum"}, \text{"computer"}, \text{"factored"}, \text{"numbers"})$$

The autoregressive conditional probabilities assigned by the model are:
- $P(x_1) = 0.20$
- $P(x_2 \mid x_1) = 0.05$
- $P(x_3 \mid x_{<3}) = 0.40$
- $P(x_4 \mid x_{<4}) = 0.10$
- $P(x_5 \mid x_{<5}) = 0.25$

**Questions:**
1. Compute the overall joint probability $P(X)$ of the sequence.
2. Compute the per-token cross-entropy loss in natural nats ($\mathcal{L}_{\text{CE}}$) and in base-2 bits ($H_2$).
3. Compute the Perplexity ($PPL$) of the model on this sequence. Interpret the number as an effective branching factor.

---

#### Solution to Exercise 1

**1. Joint Sequence Probability $P(X)$:**
$$P(X) = \prod_{i=1}^5 P(x_i \mid x_{<i}) = 0.20 \times 0.05 \times 0.40 \times 0.10 \times 0.25 = 0.000100 = \mathbf{1.0 \times 10^{-4}}$$

**2. Cross-Entropy Loss:**
In natural nats:
$$\mathcal{L}_{\text{CE}} = -\frac{1}{5} \sum_{i=1}^5 \ln P(x_i \mid x_{<i}) = -\frac{1}{5} \ln(10^{-4}) = -\frac{1}{5}(-9.21034) \approx \mathbf{1.8421 \text{ nats/token}}$$

In bits (base-2):
$$H_2 = \frac{\mathcal{L}_{\text{CE}}}{\ln(2)} = \frac{1.8421}{0.69315} \approx \mathbf{2.6575 \text{ bits/token}}$$

**3. Perplexity ($PPL$):**
$$PPL = \exp(\mathcal{L}_{\text{CE}}) = \exp(1.8421) = (10^{-4})^{-1/5} = (10000)^{0.2} = \mathbf{6.3096}$$
Equivalently:
$$PPL = 2^{H_2} = 2^{2.6575} \approx \mathbf{6.31}$$
**Interpretation**: On average across this sequence, predicting each next token was as difficult for the model as guessing uniformly at random among $\approx 6.31$ words.

### Exercise 2: BLEU-4 Calculation with Modified Precision & Brevity Penalty

Consider a candidate translation generated by an LLM and a gold reference translation:
- **Candidate ($C$)**: `"the defense attorney argued the case vigorously"` (length $c = 6$)
- **Reference ($R$)**: `"the defense lawyer argued the case very vigorously yesterday"` (length $r = 9$)

**Questions:**
1. Extract all unigrams, bigrams, trigrams, and 4-grams from Candidate.
2. For $n \in \{1, 2, 3, 4\}$, compute the clipped count of matching $n$-grams and the modified precision $p_n$.
3. Compute the Brevity Penalty ($BP$).
4. Calculate the geometric mean and the final $\text{BLEU}-4$ score.

---

#### Solution to Exercise 2

**1. Candidate Lengths and $n$-grams:**
- Lengths: $c = 6$, $r = 9$.

**2. Clipped Precisions:**
- **$n = 1$ (Unigrams)**:
  * Candidate unigrams (6 total): `["the", "defense", "attorney", "argued", "the", "case", "vigorously"]` &rarr; note word count is 7:
    1: `"the"`, 2: `"defense"`, 3: `"attorney"`, 4: `"argued"`, 5: `"the"`, 6: `"case"`, 7: `"vigorously"` ($c = 7$).
  * Reference word count ($r = 9$): `["the", "defense", "lawyer", "argued", "the", "case", "very", "vigorously", "yesterday"]`.
  * Candidate counts: `"the"`: 2, `"defense"`: 1, `"attorney"`: 1, `"argued"`: 1, `"case"`: 1, `"vigorously"`: 1.
  * Reference max counts: `"the"`: 2, `"defense"`: 1, `"argued"`: 1, `"case"`: 1, `"vigorously"`: 1, `"attorney"`: 0.
  * Clipped matching counts:
    - `"the"`: $\min(2, 2) = 2$
    - `"defense"`: $\min(1, 1) = 1$
    - `"attorney"`: $\min(1, 0) = 0$
    - `"argued"`: $\min(1, 1) = 1$
    - `"case"`: $\min(1, 1) = 1$
    - `"vigorously"`: $\min(1, 1) = 1$
  * Total clipped matches: $2 + 1 + 0 + 1 + 1 + 1 = 6$.
  * $$p_1 = \frac{6}{7} \approx \mathbf{0.8571}$$

- **$n = 2$ (Bigrams)** ($c - 1 = 6$ total bigrams):
  * Candidate bigrams:
    1. `"the defense"` (in ref: yes, count 1) &rarr; match
    2. `"defense attorney"` (in ref: no)
    3. `"attorney argued"` (in ref: no)
    4. `"argued the"` (in ref: yes, count 1) &rarr; match
    5. `"the case"` (in ref: yes, count 1) &rarr; match
    6. `"case vigorously"` (in ref: no, ref has `"case very"`)
  * Matches: 3.
  * $$p_2 = \frac{3}{6} = \mathbf{0.5000}$$

- **$n = 3$ (Trigrams)** ($c - 2 = 5$ total trigrams):
  * Candidate trigrams:
    1. `"the defense attorney"` (no)
    2. `"defense attorney argued"` (no)
    3. `"attorney argued the"` (no)
    4. `"argued the case"` (in ref: yes, count 1) &rarr; match
    5. `"the case vigorously"` (no, ref has `"the case very"`)
  * Matches: 1.
  * $$p_3 = \frac{1}{5} = \mathbf{0.2000}$$

- **$n = 4$ (4-grams)** ($c - 3 = 4$ total 4-grams):
  * Candidate 4-grams:
    1. `"the defense attorney argued"` (no)
    2. `"defense attorney argued the"` (no)
    3. `"attorney argued the case"` (no)
    4. `"argued the case vigorously"` (no)
  * Matches: 0.
  * With raw $p_4 = 0$, un-smoothed BLEU drops to 0. Using standard Chen-Cherry additive smoothing ($p_4 = \frac{0 + 0.1}{4} = 0.025$):
  * $$p_4 \approx \mathbf{0.0250}$$

**3. Brevity Penalty ($BP$):**
Since $c = 7 \le r = 9$:
$$BP = \exp\left(1 - \frac{r}{c}\right) = \exp\left(1 - \frac{9}{7}\right) = \exp\left(-\frac{2}{7}\right) \approx e^{-0.2857} \approx \mathbf{0.7515}$$

**4. Final BLEU-4:**
$$\text{Geometric Mean} = (p_1 \cdot p_2 \cdot p_3 \cdot p_4)^{1/4} = (0.8571 \times 0.5000 \times 0.2000 \times 0.0250)^{0.25} = (0.002143)^{0.25} \approx \mathbf{0.2150}$$
$$\text{BLEU}-4 = BP \times 0.2150 = 0.7515 \times 0.2150 \approx \mathbf{0.1616 \text{ (or } 16.16\%)}$$

### Exercise 3: ROUGE-L via 2D Dynamic Programming & SQuAD Token $F_1$

Consider:
- **Candidate ($C$)**: `"machine learning models require data"` ($n = 5$ tokens)
- **Reference ($R$)**: `"modern machine learning algorithms require large clean data"` ($m = 7$ tokens)

**Questions:**
1. Construct the $5 \times 7$ Dynamic Programming table $L[i, j]$ to compute the Longest Common Subsequence ($\text{LCS}$).
2. Compute $R_{\text{LCS}}$, $P_{\text{LCS}}$, and $F_{\text{LCS}}$ ($\beta = 1.0$).
3. In a question answering task, suppose:
   - Prediction: `"The Apollo 11 mission"`
   - Gold References: `["Apollo 11", "Apollo eleven mission"]`
   Perform SQuAD normalization and compute the Exact Match (EM) and Token-level $F_1$ against the reference set.

---

#### Solution to Exercise 3

**1. LCS Dynamic Programming Table:**
Tokens:
- $C = [\text{"machine"}, \text{"learning"}, \text{"models"}, \text{"require"}, \text{"data"}]$
- $R = [\text{"modern"}, \text{"machine"}, \text{"learning"}, \text{"algorithms"}, \text{"require"}, \text{"large"}, \text{"clean"}, \text{"data"}]$ (length $m = 8$).

Let's compute $L[i, j]$:
- $c_1 =$ `"machine"` matches $r_2 =$ `"machine"` &rarr; $\text{LCS} = 1$.
- $c_2 =$ `"learning"` matches $r_3 =$ `"learning"` &rarr; $\text{LCS} = 2$.
- $c_3 =$ `"models"` does not match &rarr; $\text{LCS} = 2$.
- $c_4 =$ `"require"` matches $r_5 =$ `"require"` &rarr; $\text{LCS} = 3$.
- $c_5 =$ `"data"` matches $r_8 =$ `"data"` &rarr; $\text{LCS} = 4$.

Longest Common Subsequence is:
$$\text{LCS}(C, R) = (\text{"machine"}, \text{"learning"}, \text{"require"}, \text{"data"}) \implies \mathbf{\text{LCS} = 4}$$

**2. ROUGE-L Metrics:**
- Candidate length $n = 5$.
- Reference length $m = 8$.
- Recall: $R_{\text{LCS}} = \frac{4}{8} = \mathbf{0.500}$
- Precision: $P_{\text{LCS}} = \frac{4}{5} = \mathbf{0.800}$
- $F_{\text{LCS}}$ ($\beta = 1$):
  $$F_{\text{LCS}} = \frac{2 \cdot R_{\text{LCS}} \cdot P_{\text{LCS}}}{R_{\text{LCS}} + P_{\text{LCS}}} = \frac{2 \times 0.500 \times 0.800}{0.500 + 0.800} = \frac{0.800}{1.300} \approx \mathbf{0.6154}$$

**3. SQuAD QA Normalization, EM, and Token $F_1$:**
Prediction: `"The Apollo 11 mission"`
- Normalization (lowercase, strip `"the"`, collapse whitespace):
  $$\text{norm}(\text{pred}) = \text{"apollo 11 mission"} \implies T_{\text{pred}} = \{\text{"apollo"}, \text{"11"}, \text{"mission}\} \quad (|T_{\text{pred}}| = 3)$$

Gold References:
- $R_1$: `"Apollo 11"` &rarr; $\text{norm}(R_1) = \text{"apollo 11"}$ ($|T_{R_1}| = 2$)
- $R_2$: `"Apollo eleven mission"` &rarr; $\text{norm}(R_2) = \text{"apollo eleven mission"}$ ($|T_{R_2}| = 3$)

**Exact Match (EM):**
- $\text{norm}(\text{pred}) \ne \text{norm}(R_1)$ (`"apollo 11 mission"` $\ne$ `"apollo 11"`)
- $\text{norm}(\text{pred}) \ne \text{norm}(R_2)$ (`"apollo 11 mission"` $\ne$ `"apollo eleven mission"`)
- $\mathbf{\text{EM} = 0}$

**Token-Level $F_1$:**
- Against $R_1$:
  * Shared tokens: `{"apollo", "11"}` &rarr; count = 2
  * $\text{Prec} = 2 / 3$, $\text{Rec} = 2 / 2 = 1.0$
  * $F_1(R_1) = \frac{2 \times (2/3) \times 1}{2/3 + 1} = \frac{4/3}{5/3} = \frac{4}{5} = \mathbf{0.800}$
- Against $R_2$:
  * Shared tokens: `{"apollo", "mission"}` &rarr; count = 2
  * $\text{Prec} = 2 / 3$, $\text{Rec} = 2 / 3$
  * $F_1(R_2) = \mathbf{0.667}$

Taking the maximum across references:
$$\boxed{F_1 = \max(0.800, 0.667) = \mathbf{0.800 \text{ (or } 80.0\%)}}$$
Even though $\text{EM} = 0$, the model captures $80\%$ of the key answer content!
