Exercise 1: Perplexity and Cross-Entropy Loss

A sequence of $N = 5$ tokens is evaluated by a model with conditional probabilities: $P = [0.20, 0.05, 0.40, 0.10, 0.25]$.

Tasks: Compute sequence joint probability $P(X)$, cross-entropy loss in natural nats and bits, and Perplexity ($PPL$).

View Complete Solution

1. Joint Probability: $P(X) = 0.20 \times 0.05 \times 0.40 \times 0.10 \times 0.25 = \mathbf{1.0 \times 10^{-4}}$.

2. Cross-Entropy Loss:

$$\mathcal{L}_{\text{CE}} = -\frac{1}{5}\ln(10^{-4}) \approx \mathbf{1.8421 \text{ nats/token}}, \qquad H_2 = \frac{1.8421}{\ln 2} \approx \mathbf{2.6575 \text{ bits/token}}$$

3. Perplexity:

$$PPL = \exp(1.8421) = (10{,}000)^{0.2} = \mathbf{6.3096}$$

The model's uncertainty is equivalent to choosing uniformly among $\approx 6.31$ words at each step.

Exercise 2: BLEU-4 Calculation by Hand

Candidate ($c = 7$): "the defense attorney argued the case vigorously".
Reference ($r = 9$): "the defense lawyer argued the case very vigorously yesterday".

Tasks: Compute modified precisions $p_1, p_2, p_3, p_4$ (with Chen-Cherry smoothing for $p_4$), Brevity Penalty $BP$, and BLEU-4 score.

View Complete Solution

1. Precisions:

  • $p_1 = 6/7 \approx 0.8571$ (clipped matches: the(2), defense(1), argued(1), case(1), vigorously(1))
  • $p_2 = 3/6 = 0.5000$ (matches: "the defense", "argued the", "the case")
  • $p_3 = 1/5 = 0.2000$ (match: "argued the case")
  • $p_4 = 0.1 / 4 = 0.0250$ (smoothed)

2. Brevity Penalty: Since $c = 7 < r = 9$:

$$BP = \exp\left(1 - \frac{9}{7}\right) = \exp\left(-\frac{2}{7}\right) \approx \mathbf{0.7515}$$

3. Final BLEU-4:

$$\text{BLEU}-4 = 0.7515 \times (0.8571 \times 0.5000 \times 0.2000 \times 0.0250)^{1/4} \approx 0.7515 \times 0.2150 \approx \mathbf{16.16\%}$$

Exercise 3: ROUGE-L via 2D Dynamic Programming & SQuAD Token F1

Candidate: "machine learning models require data" ($n = 5$).
Reference: "modern machine learning algorithms require large clean data" ($m = 8$).

Tasks:

  1. Find the Longest Common Subsequence ($\text{LCS}$) length and compute ROUGE-L ($F_{\text{LCS}}$ with $\beta = 1$).
  2. For prediction "The Apollo 11 mission" against gold set ["Apollo 11", "Apollo eleven mission"], compute SQuAD Exact Match (EM) and Token-level F1.
View Complete Solution

1. ROUGE-L:

Matching sequence: ["machine", "learning", "require", "data"] → $\text{LCS} = 4$.

$$R_{\text{LCS}} = \frac{4}{8} = 0.500, \quad P_{\text{LCS}} = \frac{4}{5} = 0.800 \implies F_{\text{LCS}} = \frac{2 \times 0.500 \times 0.800}{0.500 + 0.800} \approx \mathbf{0.6154}$$

2. SQuAD QA Normalization:

Normalized prediction: "apollo 11 mission".

  • Against "apollo 11": $\text{EM} = 0$, Shared = 2 → $\text{Prec} = 2/3$, $\text{Rec} = 2/2 = 1.0 \implies F_1 = \mathbf{0.800}$.
  • Against "apollo eleven mission": $\text{EM} = 0$, Shared = 2 → $\text{Prec} = 2/3$, $\text{Rec} = 2/3 \implies F_1 = \mathbf{0.667}$.
$$\mathbf{\text{EM} = 0, \qquad \text{Token } F_1 = \max(0.800, 0.667) = 0.800 \text{ (80.0\%)}}$$
