Phase 08

Classical Machine Learning

From closed-form Normal Equations and logistic log-odds to Decision Trees, Random Forests, Support Vector Machines, and Naive Bayes.

8.1 Linear Regression & The Normal Equation Analytical & Iterative

Derivation of the closed-form Normal Equation $w^* = (X^T X)^{-1} X^T y$ from $\nabla_w \text{MSE} = 0$, orthogonal projection onto column space $\text{Col}(X)$, iterative Gradient Descent scaling laws, and Ridge Regularization.

Interactive Lecture Exercises & Solutions Run Lab (Pure Python)
8.2 Logistic Regression & Binary Classification Probabilistic Classifier

The Sigmoid activation $\sigma(z) = \frac{1}{1 + e^{-z}}$, log-odds (logits), maximum likelihood estimation via Binary Cross-Entropy loss, and the mathematical identity linking BCE gradients to linear regression.

Interactive Lecture Exercises & Solutions Run Lab (Pure Python)
8.3 Decision Trees & Ensemble Methods Non-Linear Trees

Gini Impurity, Shannon Entropy, and Information Gain. CART recursive tree growing, Bagging, Random Forests feature subsampling variance reduction, and Gradient Boosted Decision Trees (GBDT) fitting pseudo-residuals.

Interactive Lecture Exercises & Solutions Run Lab (Pure Python)
8.4 Support Vector Machines & The Kernel Trick Maximum Margin

Geometric and functional margins, primal soft-margin SVM via Hinge Loss subgradient descent, Wolfe Dual formulation via KKT multipliers, and the infinite-dimensional Radial Basis Function (RBF) Kernel Trick.

Interactive Lecture Exercises & Solutions Run Lab (Pure Python)
8.5 Naive Bayes & K-Nearest Neighbors (KNN) Generative & Instance-Based

Multinomial and Gaussian Naive Bayes with conditional independence, Laplace (add-1) smoothing, non-parametric lazy KNN with Minkowski distance metrics, and the geometric breakdown of the Curse of Dimensionality.

Interactive Lecture Exercises & Solutions Run Lab (Pure Python)
