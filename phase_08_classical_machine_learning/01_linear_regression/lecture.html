Topic 8.1: Linear Regression & The Normal Equation

Mastering closed-form analytical solutions and iterative gradient descent for continuous modeling.

The 12-Year-Old Analogy: The Lemonade Stand Line of Best Fit

Imagine you run a lemonade stand on hot summer afternoons. You want to predict how many cups of ice-cold lemonade you will sell tomorrow based on the forecast temperature.

You plot your history on graph paper: temperature on the $x$-axis, cups sold on the $y$-axis. The dots tilt upwards—hotter days clearly mean more thirsty customers—but the dots don't line up in a perfect laser line because of random factors (a nearby baseball game, or sudden cloud cover).

To predict future sales, you lay an uncooked strand of spaghetti across the paper. The spaghetti is your linear model ($\hat{y} = w \cdot x + b$). How do you position it? Imagine tiny elastic rubber bands tying each dot to the spaghetti. If the spaghetti is too high, rubber bands pull it down; if it is too low, they pull it up. Because energy scales with the square of the stretch, the rubber bands pull with Mean Squared Error (MSE) force!

The Normal Equation is like a magic mathematical balance beam that calculates the exact slope and intercept where all rubber bands exert zero net rotational torque—in a single algebraic snap. Meanwhile, Gradient Descent is gently tilting the stick millimeter by millimeter until all tension vanishes.

1. Mathematical Formulation

For $N$ training samples with $d$ features, the linear model hypothesis is:

$$\hat{y}^{(i)} = w_0 + \sum_{j=1}^d w_j x_j^{(i)} = x^{(i) T} w$$

In matrix-vector notation:

$$\hat{y} = Xw$$

We define the Mean Squared Error (MSE) objective function as:

$$J(w) = \frac{1}{2N} \sum_{i=1}^N \left(\hat{y}^{(i)} - y^{(i)}\right)^2 = \frac{1}{2N} \|Xw - y\|_2^2$$

Expanding the $L_2$ norm via the inner product identity $\|v\|_2^2 = v^T v$:

$$\begin{aligned} J(w) &= \frac{1}{2N} (Xw - y)^T (Xw - y) \\ &= \frac{1}{2N} \left(w^T X^T X w - w^T X^T y - y^T X w + y^T y\right) \end{aligned}$$

Since $w^T X^T y$ is a scalar ($1 \times 1$), $(w^T X^T y)^T = y^T X w$. Combining the identical scalar terms:

$$J(w) = \frac{1}{2N} \left(w^T X^T X w - 2 y^T X w + y^T y\right)$$

2. Deriving the Normal Equation: $\nabla_w J(w) = 0$

To find the optimal weight vector $w^*$, we compute the matrix derivative $\nabla_w J(w)$ and set it to zero:

  • $\frac{\partial}{\partial w} \left(w^T (X^T X) w\right) = 2 X^T X w$ (since $X^T X$ is symmetric)
  • $\frac{\partial}{\partial w} \left(2 y^T X w\right) = 2 X^T y$
  • $\frac{\partial}{\partial w} \left(y^T y\right) = \mathbf{0}$

Combining the components:

$$\nabla_w J(w) = \frac{1}{2N} \left(2 X^T X w - 2 X^T y\right) = \frac{1}{N} \left(X^T X w - X^T y\right)$$

Setting the gradient to zero:

$$X^T X w - X^T y = \mathbf{0} \implies X^T X w = X^T y$$

Multiplying by the matrix inverse $(X^T X)^{-1}$ (assuming $X$ has full column rank):

The Normal Equation: $$w^* = (X^T X)^{-1} X^T y$$

3. Geometric Orthogonal Projection

The vector $y$ lives in $\mathbb{R}^N$. The columns of $X$ span the subspace $\text{Col}(X) \subset \mathbb{R}^N$. Any model prediction $\hat{y} = Xw$ lies on this hyperplane.

The residual vector $e = y - \hat{y}$ is minimized in Euclidean length if and only if $e$ is perpendicular (normal) to every column of $X$:

$$X^T e = \mathbf{0} \implies X^T (y - Xw^*) = \mathbf{0} \implies X^T X w^* = X^T y$$

4. Iterative Optimization: Gradient Descent

When the number of features $d$ is very large (e.g., $d > 10,000$), computing $(X^T X)^{-1}$ requires $\mathcal{O}(d^3)$ time and $\mathcal{O}(d^2)$ memory. Gradient descent provides a scalable alternative:

$$w_{t+1} = w_t - \eta \nabla_w J(w_t) = w_t - \frac{\eta}{N} X^T (Xw_t - y)$$

For each individual weight $w_j$:

$$w_j \leftarrow w_j - \frac{\eta}{N} \sum_{i=1}^N \left(\hat{y}^{(i)} - y^{(i)}\right) x_j^{(i)}$$

5. Invertibility & Ridge Regularization

If features are collinear or $N < d$, $X^T X$ is singular and cannot be inverted. Adding $L_2$ regularization (Ridge Regression) modifies the cost function:

$$J_{\text{ridge}}(w) = \frac{1}{2N} \|Xw - y\|_2^2 + \frac{\lambda}{2} \|w\|_2^2$$ $$\nabla_w J_{\text{ridge}}(w) = \frac{1}{N} (X^T X w - X^T y) + \lambda w = \mathbf{0}$$ $$w^* = \left(X^T X + N \lambda I\right)^{-1} X^T y$$

Since $X^T X \succeq 0$ and $N \lambda I \succ 0$, their sum is strictly positive definite and always invertible!

Summary of Key Insights

  • Normal Equation: Exact closed-form solution in $\mathcal{O}(d^3)$ time. Best for small-to-moderate feature counts.
  • Gradient Descent: Iterative $\mathcal{O}(N d)$ optimizer. Best for high-dimensional feature spaces and streaming data.
  • Convexity: Because the Hessian $\nabla^2 J(w) = \frac{1}{N} X^T X$ is positive semi-definite, linear regression has no local minima—every local minimum is global!
