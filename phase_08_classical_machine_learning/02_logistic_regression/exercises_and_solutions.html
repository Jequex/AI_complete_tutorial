Practical calculations in sigmoid activations, odds ratios, binary cross-entropy, and gradient descent.

Exercise 1: Sigmoid, Odds, and Log-Odds Hand Calculations

A logistic model has weights $w = [0.8, -1.2]^T$ and bias $b = 0.4$. For input $x = [2.0, 1.0]^T$, calculate the logit $z$, probability $\hat{y}$, and odds ratio $\frac{\hat{y}}{1 - \hat{y}}$.

View Complete Solution

Logit $z$: $z = (0.8)(2.0) + (-1.2)(1.0) + 0.4 = 1.6 - 1.2 + 0.4 = 0.8$.

Probability $\hat{y}$: $\sigma(0.8) = \frac{1}{1 + e^{-0.8}} \approx 0.6900$.

Odds Ratio: $\frac{0.6900}{1 - 0.6900} \approx 2.2255$.

Verification: $\ln(2.2255) \approx 0.8000 = z$.

Exercise 2: Binary Cross-Entropy Loss Computation

Evaluate a mini-batch of 3 samples with true labels $y = [1, 0, 1]^T$ and predicted probabilities $\hat{y} = [0.80, 0.25, 0.10]^T$. Compute individual sample losses and the total BCE loss.

View Complete Solution

$\ell_1 = -\ln(0.80) \approx 0.2231$

$\ell_2 = -\ln(1 - 0.25) = -\ln(0.75) \approx 0.2877$

$\ell_3 = -\ln(0.10) \approx 2.3026$ (Notice the massive penalty for a confident false prediction!)

Average BCE Loss: $\frac{0.2231 + 0.2877 + 2.3026}{3} \approx 0.9378$.

Exercise 3: Manual Gradient Descent Step

Using inputs $x = [1.0, -1.0, 2.0]^T$, true labels $y = [1, 0, 1]^T$, and predictions $\hat{y} = [0.8, 0.25, 0.10]^T$, calculate $\frac{\partial \mathcal{L}}{\partial w}$ and $\frac{\partial \mathcal{L}}{\partial b}$. Update parameters from $w_0 = 0.5, b_0 = 0$ with $\eta = 0.1$.

View Complete Solution

Errors $e = \hat{y} - y = [-0.20, +0.25, -0.90]^T$.

$\frac{\partial \mathcal{L}}{\partial w} = \frac{1}{3} [(-0.20)(1) + (0.25)(-1) + (-0.90)(2)] = \frac{-2.25}{3} = -0.75$.

$\frac{\partial \mathcal{L}}{\partial b} = \frac{1}{3} [-0.20 + 0.25 - 0.90] = \frac{-0.85}{3} \approx -0.2833$.

Updated Parameters: $w_1 = 0.5 - 0.1(-0.75) = 0.575$, $b_1 = 0 - 0.1(-0.2833) = 0.02833$.

Exercise 4: Decision Boundary Hyperplane

A classifier has weights $w_1 = 2, w_2 = -4$ and bias $b = 6$. Derive the decision boundary line $x_2 = m x_1 + c$ and test if the origin belongs to class 1.

View Complete Solution

Set logit to zero: $2x_1 - 4x_2 + 6 = 0 \implies 4x_2 = 2x_1 + 6 \implies x_2 = 0.5x_1 + 1.5$.

For origin $(0, 0)$: $z = 2(0) - 4(0) + 6 = 6 > 0 \implies \hat{y} = \sigma(6) \approx 0.9975$. The origin belongs firmly to the positive class.
