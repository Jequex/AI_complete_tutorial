Topic 8.2: Logistic Regression & Binary Classification

From linear log-odds and sigmoid activation to maximum likelihood estimation and binary cross-entropy gradients.

The 12-Year-Old Analogy: The Exam Pass/Fail Dimmer Switch

Imagine your school friends are studying for a difficult math exam. You want to build a machine that predicts whether a student will Pass ($y=1$) or Fail ($y=0$) based on how many hours they studied.

If you use a simple straight line, someone studying 80 hours gets predicted a "160% chance of passing", while someone studying 0 hours gets "-20%". But real probabilities can never go below 0% or above 100%!

Instead of a rigid ruler, you use an S-shaped silicon ramp: the Sigmoid function. No matter how few or many hours they study, the curve stays strictly between 0 and 1. The Binary Cross-Entropy Loss is a strict penalty for arrogance: if a student passes and your model predicted a 1% chance, it gets hit with an astronomical penalty; if the prediction is accurate, the penalty vanishes to zero!

Mathematical Symbol Decoder

$\text{logit}(p)$ Inverse sigmoid $\ln\left(\frac{p}{1-p}\right)$, natural log of odds ratio
$\mathcal{L}_{\text{BCE}}(w, b)$ Scalar loss Binary Cross-Entropy (Negative Log-Likelihood) loss

1. The Sigmoid Function & Log-Odds

The logistic sigmoid function transforms the unconstrained linear logit $z = w^T x + b \in \mathbb{R}$ into a calibrated probability:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

Its first derivative satisfies the famous self-referential property:

$$\frac{d}{dz} \sigma(z) = \sigma(z) (1 - \sigma(z))$$

Inverting the sigmoid equation reveals that the model is linear in the log-odds (logit):

$$\ln\left(\frac{P(y=1 \mid x)}{1 - P(y=1 \mid x)}\right) = w^T x + b$$

2. Maximum Likelihood & Binary Cross-Entropy Loss

Assuming labels follow independent Bernoulli distributions, the likelihood over $N$ observations is:

$$L(w, b) = \prod_{i=1}^N \left(\hat{y}^{(i)}\right)^{y^{(i)}} \left(1 - \hat{y}^{(i)}\right)^{1 - y^{(i)}}$$

Taking the negative average log-likelihood yields the Binary Cross-Entropy (BCE) Loss:

$$\mathcal{L}(w, b) = -\frac{1}{N} \sum_{i=1}^N \left[ y^{(i)} \ln \hat{y}^{(i)} + (1 - y^{(i)}) \ln\left(1 - \hat{y}^{(i)}\right) \right]$$

3. The Gradient Derivation via Chain Rule

Differentiating with respect to weight $w_j$ for sample $i$:

$$\frac{\partial \ell^{(i)}}{\partial w_j} = \frac{\partial \ell^{(i)}}{\partial \hat{y}^{(i)}} \cdot \frac{\partial \hat{y}^{(i)}}{\partial z^{(i)}} \cdot \frac{\partial z^{(i)}}{\partial w_j}$$ $$\frac{\partial \ell^{(i)}}{\partial w_j} = \left(\frac{\hat{y}^{(i)} - y^{(i)}}{\hat{y}^{(i)}(1 - \hat{y}^{(i)})}\right) \cdot \left(\hat{y}^{(i)}(1 - \hat{y}^{(i)})\right) \cdot x_j^{(i)} = \left(\hat{y}^{(i)} - y^{(i)}\right) x_j^{(i)}$$
Matrix Gradient Formulation: $$\nabla_w \mathcal{L} = \frac{1}{N} X^T (\hat{y} - y)$$

4. Convexity & Optimization Guarantee

The Hessian matrix of logistic regression is:

$$H = \nabla^2 \mathcal{L}(w) = \frac{1}{N} X^T D X$$

where $D = \text{diag}(\hat{y}^{(i)}(1 - \hat{y}^{(i)}))$. Since $0 < \hat{y}^{(i)} < 1$, $D_{ii} > 0$ for all samples. For any vector $v$:

$$v^T H v = \frac{1}{N} (Xv)^T D (Xv) \ge 0$$

Thus $H \succeq 0$, proving that the Binary Cross-Entropy loss surface is strictly convex with a unique global optimum!
