Geometric margin calculations, KKT conditions, Hinge Loss subgradients, and Mercer Kernel mappings.

Exercise 1: Geometric Margin & Hyperplane Distances

A 2D hyperplane has $w = [3, 4]^T, b = -5$. Compute the margin width $\frac{2}{\|w\|}$, and find the functional and geometric margins for $A=(1, 3, y=+1)$, $B=(0, 1, y=-1)$, and $C=(2, -0.25, y=+1)$.

View Complete Solution

$\|w\|_2 = \sqrt{3^2 + 4^2} = 5.0$. Total Margin Width: $\frac{2}{5.0} = 0.40$.

  • Point A: $z = 10 \implies \hat{\gamma} = +10.0, \quad \gamma = 2.0$. Safely outside margin.
  • Point B: $z = -1 \implies \hat{\gamma} = +1.0, \quad \gamma = 0.20$. Lies directly on margin boundary (Support Vector).
  • Point C: $z = 0 \implies \hat{\gamma} = 0.0, \quad \gamma = 0.0$. Sits on decision boundary ($\xi_C = 1.0$).

Exercise 2: KKT Conditions & Dual Support Vectors

Given dual variables $\alpha^* = [0.0, 3.2, 5.0, 0.0]$ with $C = 5.0$, classify which instances are support vectors, non-critical, or margin violators.

View Complete Solution
  • Points 2 and 3 are Support Vectors ($\alpha_i > 0$).
  • Points 1 and 4 are non-critical ($\alpha_i = 0$) and can be deleted without changing $w^*$.
  • Point 3 has $\alpha_3 = C = 5.0$, meaning it actively incurs a margin violation ($\xi_3 > 0$).

Exercise 3: Hinge Loss Subgradient Descent Step

With $w = [1, 1]^T, b = 0, \lambda = 0.01, \eta = 0.1$, evaluate sample $([2, -1], y=+1)$ and perform a subgradient step.

View Complete Solution

$z = 1.0 \implies y \cdot z = 1.0$. Point touches boundary.

Subgradient: $\nabla_w \mathcal{L} = -yx + \lambda w = [-2, 1]^T + 0.01[1, 1]^T = [-1.99, 1.01]^T$.

Updated weights: $w_{\text{new}} = [1, 1]^T - 0.1[-1.99, 1.01]^T = [1.199, 0.899]^T, \quad b_{\text{new}} = +0.10$.

Exercise 4: Polynomial Kernel Explicit 3D Map

Prove that the homogeneous quadratic kernel $K(x, z) = (x^T z)^2$ in 2D is equivalent to a dot product in 3D feature space.

View Complete Solution

$(x_1 z_1 + x_2 z_2)^2 = x_1^2 z_1^2 + 2 x_1 x_2 z_1 z_2 + x_2^2 z_2^2$.

Define mapping $\phi(x) = [x_1^2, \sqrt{2} x_1 x_2, x_2^2]^T$.

Then $\phi(x)^T \phi(z) = x_1^2 z_1^2 + 2 x_1 x_2 z_1 z_2 + x_2^2 z_2^2 = K(x, z)$. $\blacksquare$
