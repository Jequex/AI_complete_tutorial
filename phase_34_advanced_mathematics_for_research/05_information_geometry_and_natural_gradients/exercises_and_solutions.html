Topic 34.5: Exercises & Solutions

Exercise 1: Fisher Information Matrix of the Univariate Gaussian

For $p(x; \mu, \sigma) = \frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$ with parameters $\boldsymbol{\theta} = [\mu, \sigma]^\top$:

  1. Derive the score vector $\mathbf{s}(x) = [\partial \log p / \partial \mu, \partial \log p / \partial \sigma]^\top$.
  2. Compute the 4 components of the Fisher Information Matrix $\mathbf{F}(\mu, \sigma)$.
  3. Invert $\mathbf{F}$ and explain why Euclidean gradient descent fails when $\sigma$ is small.
View Complete Step-by-Step Solution

1. Score Vector

$$\frac{\partial \log p}{\partial \mu} = \frac{x - \mu}{\sigma^2}, \quad \frac{\partial \log p}{\partial \sigma} = -\frac{1}{\sigma} + \frac{(x - \mu)^2}{\sigma^3}$$

2. Fisher Information Components

$$F_{\mu\mu} = \frac{\mathbb{E}[(x-\mu)^2]}{\sigma^4} = \frac{1}{\sigma^2}, \quad F_{\mu\sigma} = 0, \quad F_{\sigma\sigma} = \frac{2}{\sigma^2}$$

3. Matrix and Inversion

$$\mathbf{F}(\mu, \sigma) = \begin{bmatrix} \frac{1}{\sigma^2} & 0 \\ 0 & \frac{2}{\sigma^2} \end{bmatrix}, \quad \mathbf{F}^{-1}(\mu, \sigma) = \begin{bmatrix} \sigma^2 & 0 \\ 0 & \frac{\sigma^2}{2} \end{bmatrix}$$

When $\sigma \to 0$, $F_{\mu\mu} \to \infty$. Euclidean steps take disastrously huge steps in probability space. Natural gradient premultiplies by $\sigma^2$, maintaining steady invariant step sizes.

Exercise 2: Fisher Matrix on Categorical Distributions

For categorical probabilities $p_k = \frac{e^{\theta_k}}{\sum_j e^{\theta_j}}$ on the simplex:

  1. Compute the score vector $\partial \log p_y / \partial \boldsymbol{\theta}$.
  2. Prove that $\mathbf{F}(\boldsymbol{\theta}) = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top$.
  3. Identify the 1D null space of $\mathbf{F}(\boldsymbol{\theta})$ and explain its origin.
View Complete Step-by-Step Solution

1. Score Vector

$$\mathbf{s}_y = \mathbf{e}_y - \mathbf{p}$$

2. Expected Outer Product

$$\mathbf{F}(\boldsymbol{\theta}) = \sum_{y=1}^K p_y (\mathbf{e}_y - \mathbf{p})(\mathbf{e}_y - \mathbf{p})^\top = \text{diag}(\mathbf{p}) - \mathbf{p}\mathbf{p}^\top$$

3. Null Space

$$\mathbf{F}\mathbf{1} = \mathbf{p} - \mathbf{p}(\mathbf{p}^\top \mathbf{1}) = \mathbf{p} - \mathbf{p}(1) = \mathbf{0}$$

The null space is spanned by the all-ones vector $\mathbf{1}$, which reflects the shift-invariance of the softmax function.

Exercise 3: Kronecker-Factored Approximate Curvature (K-FAC)

For a linear layer with $\mathbf{s}_{\mathbf{W}} = \mathbf{a} \otimes \mathbf{g}$:

  1. Formulate the exact Fisher matrix $\mathbf{F} = \mathbb{E}[(\mathbf{a}\mathbf{a}^\top) \otimes (\mathbf{g}\mathbf{g}^\top)]$.
  2. State the K-FAC expectation factorization $\mathbf{F}_{\text{KFAC}} = \mathbf{A} \otimes \mathbf{S}$.
  3. Show how $(A \otimes B)^{-1} = A^{-1} \otimes B^{-1}$ reduces inversion flops from $\mathcal{O}(d_{\text{in}}^3 d_{\text{out}}^3)$ to $\mathcal{O}(d_{\text{in}}^3 + d_{\text{out}}^3)$.
View Complete Step-by-Step Solution

1. Exact Fisher Matrix

$$\mathbf{F} = \mathbb{E}\left[ (\mathbf{a}\mathbf{a}^\top) \otimes (\mathbf{g}\mathbf{g}^\top) \right]$$

2. K-FAC Factorization

$$\mathbf{F}_{\text{KFAC}} \triangleq \mathbb{E}[\mathbf{a}\mathbf{a}^\top] \otimes \mathbb{E}[\mathbf{g}\mathbf{g}^\top] = \mathbf{A} \otimes \mathbf{S}$$

3. Computational Speedup

Inverting the full $(d_{\text{in}} d_{\text{out}}) \times (d_{\text{in}} d_{\text{out}})$ matrix costs $\mathcal{O}(d_{\text{in}}^3 d_{\text{out}}^3) \approx 10^{21}$ operations for $d=4096$. Inverting $\mathbf{A}$ and $\mathbf{S}$ separately via $(\mathbf{A} \otimes \mathbf{S})^{-1} = \mathbf{A}^{-1} \otimes \mathbf{S}^{-1}$ costs only $\mathcal{O}(d_{\text{in}}^3 + d_{\text{out}}^3) \approx 10^{11}$ operations, making exact natural gradient scalable to large models.
