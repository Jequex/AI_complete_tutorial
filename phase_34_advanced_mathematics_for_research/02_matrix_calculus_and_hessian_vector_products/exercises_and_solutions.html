Exercise 1: Matrix Calculus of Linear & Ridge Regression

Consider the objective $\mathcal{L}(\mathbf{w}) = \frac{1}{2N} \|\mathbf{X}\mathbf{w} - \mathbf{y}\|_2^2 + \frac{\lambda}{2} \|\mathbf{w}\|_2^2$ where $\mathbf{X} \in \mathbb{R}^{N \times d}$.

  1. Derive $\nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w})$ in denominator layout.
  2. Compute the exact Hessian matrix $\mathbf{H} = \nabla_{\mathbf{w}}^2 \mathcal{L}(\mathbf{w})$.
  3. Express the HVP $\mathbf{H}\mathbf{v}$ and compare its flop complexity against instantiating $\mathbf{H}$.
View Complete Step-by-Step Solution

1. Gradient Derivation

$$\nabla_{\mathbf{w}} \mathcal{L}(\mathbf{w}) = \frac{1}{N} \mathbf{X}^\top (\mathbf{X}\mathbf{w} - \mathbf{y}) + \lambda \mathbf{w}$$

2. Hessian Matrix

$$\mathbf{H} = \nabla_{\mathbf{w}}^2 \mathcal{L}(\mathbf{w}) = \frac{1}{N} \mathbf{X}^\top \mathbf{X} + \lambda \mathbf{I}_d$$

3. Associative HVP Complexity

$$\mathbf{H}\mathbf{v} = \frac{1}{N} \mathbf{X}^\top (\mathbf{X}\mathbf{v}) + \lambda \mathbf{v}$$

By computing $\mathbf{u} = \mathbf{X}\mathbf{v}$ first, operations scale as $\mathcal{O}(Nd)$ rather than $\mathcal{O}(Nd^2)$ for forming $\mathbf{X}^\top \mathbf{X}$. Zero $d \times d$ memory is required.

Exercise 2: Finite Difference Truncation Error vs Dual Arithmetic

Let $\text{HVP}_{\text{FD}}(h) = \frac{\mathbf{g}(\boldsymbol{\theta} + h \mathbf{v}) - \mathbf{g}(\boldsymbol{\theta} - h \mathbf{v})}{2h}$.

  1. Derive the leading-order error term using Taylor expansion.
  2. Show why optimal step size $h^* \approx \epsilon_{\text{mach}}^{1/3} \approx 10^{-6}$ and loses half of machine precision.
  3. Explain why Pearlmutter's dual-number $\mathcal{R}$-operator avoids this trade-off completely.
View Complete Step-by-Step Solution

1. Taylor Expansion

$$\text{HVP}_{\text{FD}}(h) = \mathbf{H}\mathbf{v} + \frac{h^2}{6} \nabla^4 f[\mathbf{v}, \mathbf{v}, \mathbf{v}] + \mathcal{O}(h^4)$$

The truncation error is strictly quadratic $\mathcal{O}(h^2)$.

2. Numerical Trade-off

Total numerical error combines catastrophic roundoff and truncation: $\mathcal{E}(h) \approx \frac{\epsilon_{\text{mach}}}{h} + C h^2$. Minimizing with respect to $h$ yields $h^* \sim \epsilon_{\text{mach}}^{1/3} \approx 10^{-6}$, leaving accuracy limited to $\approx 10^{-8}$.

3. Dual Number Solution

Pearlmutter's $\mathcal{R}$-operator algebra satisfies $\varepsilon^2 = 0$. Because no subtraction of displaced floats occurs, it delivers exact machine precision ($\approx 10^{-15}$) with zero parameter tuning.

Exercise 3: Matrix-Free Conjugate Gradient in TRPO

In TRPO, we solve $\mathbf{H}\mathbf{x} = \mathbf{g}$ using iterative Conjugate Gradient without forming $\mathbf{H}$.

  1. Write down the update equations for step size $\alpha_k$, iterate $\mathbf{x}_{k+1}$, and direction $\mathbf{p}_{k+1}$.
  2. For $n = 1,000,000$ and $K = 20$ iterations, compute total memory and HVP calls.
View Complete Step-by-Step Solution

1. Conjugate Gradient Algorithm

$$\mathbf{q}_k = \text{hvp}(\mathbf{p}_k), \quad \alpha_k = \frac{\mathbf{r}_k^\top \mathbf{r}_k}{\mathbf{p}_k^\top \mathbf{q}_k}$$ $$\mathbf{x}_{k+1} = \mathbf{x}_k + \alpha_k \mathbf{p}_k, \quad \mathbf{r}_{k+1} = \mathbf{r}_k - \alpha_k \mathbf{q}_k$$ $$\beta_k = \frac{\mathbf{r}_{k+1}^\top \mathbf{r}_{k+1}}{\mathbf{r}_k^\top \mathbf{r}_k}, \quad \mathbf{p}_{k+1} = \mathbf{r}_{k+1} + \beta_k \mathbf{p}_k$$

2. Memory & Complexity

Total HVP evaluations: exactly $K = 20$. Memory: four $n$-dimensional vectors ($32\text{ MB}$), avoiding the $8\text{ Terabytes}$ required to store $\mathbf{H}$.
