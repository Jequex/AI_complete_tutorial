Exercise 1: Dual Derivation of the Support Vector Machine

For the primal hard-margin SVM: $\min_{\mathbf{w}, b} \frac{1}{2}\|\mathbf{w}\|_2^2$ s.t. $y_i(\mathbf{w}^\top \mathbf{x}_i + b) \ge 1$.

  1. Write the Lagrangian $\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha})$.
  2. Apply KKT stationarity to express $\mathbf{w}^*$ in terms of $\boldsymbol{\alpha}$.
  3. Derive the Wolfe dual problem.
  4. Show why the decision boundary depends only on support vectors.
View Complete Step-by-Step Solution

1. Lagrangian Function

$$\mathcal{L}(\mathbf{w}, b, \boldsymbol{\alpha}) = \frac{1}{2}\|\mathbf{w}\|_2^2 + \sum_{i=1}^N \alpha_i (1 - y_i(\mathbf{w}^\top \mathbf{x}_i + b)), \quad \alpha_i \ge 0$$

2. KKT Stationarity

$$\nabla_{\mathbf{w}}\mathcal{L} = \mathbf{0} \implies \mathbf{w}^* = \sum_{i=1}^N \alpha_i y_i \mathbf{x}_i, \quad \frac{\partial \mathcal{L}}{\partial b} = 0 \implies \sum_{i=1}^N \alpha_i y_i = 0$$

3. Wolfe Dual Problem

$$\max_{\boldsymbol{\alpha} \ge \mathbf{0}} \sum_{i=1}^N \alpha_i - \frac{1}{2}\sum_{i,j=1}^N \alpha_i \alpha_j y_i y_j (\mathbf{x}_i^\top \mathbf{x}_j) \quad \text{s.t.} \quad \sum_{i=1}^N \alpha_i y_i = 0$$

4. Support Vector Sparsity

By complementary slackness $\alpha_i (1 - y_i(\mathbf{w}^\top \mathbf{x}_i + b)) = 0$. For points inside the margin ($y_i(\mathbf{w}^\top \mathbf{x}_i + b) > 1$), $\alpha_i = 0$. Multipliers are positive only for points on the margin boundaries.

Exercise 2: Water-Filling Capacity via KKT Multipliers

Maximize Shannon capacity $\sum_{k=1}^K \ln(1 + p_k/\sigma_k^2)$ subject to $\sum p_k = P_{\text{total}}$ and $p_k \ge 0$.

  1. State the Lagrangian with multipliers $\nu$ and $\lambda_k \ge 0$.
  2. Formulate KKT stationarity.
  3. Derive the water-filling solution $p_k^* = \max(0, 1/\nu - \sigma_k^2)$.
View Complete Step-by-Step Solution

1. Lagrangian

$$\mathcal{L} = -\sum_{k=1}^K \ln\left(1 + \frac{p_k}{\sigma_k^2}\right) + \nu \left(\sum p_k - P_{\text{total}}\right) - \sum \lambda_k p_k$$

2. Stationarity

$$\frac{\partial \mathcal{L}}{\partial p_k} = -\frac{1}{p_k + \sigma_k^2} + \nu - \lambda_k = 0 \implies \frac{1}{p_k + \sigma_k^2} = \nu - \lambda_k$$

3. Water-Filling Threshold

From complementary slackness $\lambda_k p_k = 0$: if $p_k > 0$, $\lambda_k = 0 \implies p_k = 1/\nu - \sigma_k^2$. If $p_k = 0$, $\lambda_k \ge 0 \implies 1/\nu \le \sigma_k^2$. Hence $p_k^* = \max(0, 1/\nu^* - \sigma_k^2)$.

Exercise 3: Quadratic Penalty vs Augmented Lagrangian

Compare the Quadratic Penalty $\mathcal{L}_\rho = f(\mathbf{x}) + \frac{\rho}{2}c(\mathbf{x})^2$ against Augmented Lagrangian $\mathcal{L}_{\text{ALM}} = f(\mathbf{x}) + \nu c(\mathbf{x}) + \frac{\rho}{2}c(\mathbf{x})^2$.

  1. Show why quadratic penalties require $\rho \to \infty$ for exact feasibility.
  2. Explain how ALM avoids Hessian ill-conditioning at finite $\rho$.
View Complete Step-by-Step Solution

1. Constraint Violation in Pure Penalty

$$\nabla \mathcal{L}_\rho = \nabla f + \rho c(\mathbf{x})\nabla c = \mathbf{0} \implies c(\mathbf{x}_\rho) \approx \frac{\nu^*}{\rho}$$

To eliminate constraint violation, $\rho \to \infty$ is strictly required.

2. Condition Number Preservation in ALM

As $\rho \to \infty$, the penalty Hessian condition number explodes: $\kappa(\nabla^2 \mathcal{L}_\rho) \sim \mathcal{O}(\rho)$. In contrast, ALM updates dual multiplier $\nu_{k+1} = \nu_k + \rho c(\mathbf{x}_k)$, converging to the exact KKT solution at modest, fixed $\rho$ without numerical ill-conditioning.
