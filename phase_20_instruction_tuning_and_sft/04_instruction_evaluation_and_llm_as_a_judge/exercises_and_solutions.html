Problem 1: Bidirectional Consensus Win-Rate Calculation (Easy)

A judge with heavy position bias evaluates Model Alpha vs Model Beta across 100 prompts. In Pass 1, Model Alpha appears in slot A and achieves 70 wins and 10 ties (naive win rate 75%). When order is swapped in Pass 2, only 20 prompts result in Model Alpha winning both passes.

  1. Compute the naive win rate.
  2. Compute the debiased bidirectional consensus win rate.
  3. Identify the false advantage eliminated by order swapping.
View Complete Solution

Step 1: Naive Win Rate: $\frac{70 + 0.5 \times 10}{100} = 75.0\%$.

Step 2: Debiased Consensus: $M_\alpha$ wins 20, $M_\beta$ wins 15, ties/contradictions = 65.
$$\text{WinRate}_{\text{debiased}} = \frac{20 + 0.5 \times 65}{100} = 52.5\%$$

Step 3: Bias Elimination: $75.0\% - 52.5\% = 22.5$ percentage points of artificial advantage removed.

Problem 2: Bradley-Terry Maximum Likelihood Gradient Derivation (Medium)

Derive the gradient of the Bradley-Terry log-likelihood with respect to latent skill parameter $r_i$.

View Complete Solution

Using the property that $\frac{d}{du}\log \sigma(u) = 1 - \sigma(u)$ and $p_{ij} = \sigma(r_i - r_j)$: $$\frac{\partial \ell}{\partial r_i} = \sum_{j \ne i} \left( W_{ij} (1 - p_{ij}) - W_{ji} p_{ij} \right) = \sum_{j \ne i} \left( W_{ij} - N_{ij} P(i \succ j) \right)$$ At the optimum $\nabla \ell = \mathbf{0}$, the model's total observed wins equal its total expected wins across all matchups.

Problem 3: Verbosity Bias & Length Penalty Function Design (Hard)

A judge has utility $U(y) = Q(y) + 0.5 \ln(L)$. An inferior model with $Q=2.4, L=600$ defeats a superior concise model with $Q=3.0, L=150$ due to verbosity.

View Complete Solution

Biased Utilities: $U_1 = 3.0 + 2.505 = 5.505$, $U_2 = 2.4 + 3.200 = 5.600$.
Biased win probability for inferior model: $P(2 \succ 1) = \frac{1}{1 + e^{-0.095}} \approx 52.37\%$.
Penalty Function: $\Pi(L_1, L_2) = 0.5 \ln(L_2 / L_1) = 0.695$.
Adjusted utility difference: $\Delta U_{\text{adj}} = 0.095 - 0.695 = -0.60$. Corrected win rate for Model 1 rises to $64.57\%$.
