Problem 1: Numerical Calculation of Masked vs. Unmasked Cross-Entropy (Easy)

A sequence of 4 tokens comprises 2 prompt tokens and 2 response tokens. Output probabilities at each transition step are provided.

  1. Identify the target label sequence under unmasked vs masked SFT training.
  2. Compute the exact loss values for both modes.
View Complete Solution

Step 1: Targets:
- Unmasked: $\mathbf{t}_{\text{unmasked}} = [1, 3, 0]$
- Masked: $\mathbf{t}_{\text{masked}} = [-100, 3, 0]$ (prompt transition masked out).

Step 2: Loss Calculations:
- $\mathcal{L}_{\text{unmasked}} = \frac{-\ln(0.4) - \ln(0.6) - \ln(0.8)}{3} \approx 0.5501$
- $\mathcal{L}_{\text{SFT}} = \frac{-\ln(0.6) - \ln(0.8)}{2} \approx 0.3670$
Masked loss measures strictly the answer prediction performance without penalty from the question.

Problem 2: Gradient Flow Analysis on Masked Positions (Medium)

Derive the weight update gradient $\frac{\partial \mathcal{L}}{\partial W}$ and prove that prompt positions contribute identically zero gradient.

View Complete Solution

Derivation:
For any active position $t$, $\frac{\partial \ell_t}{\partial \mathbf{z}_t} = \mathbf{p}_t - \mathbf{e}_{y_t}$. For masked positions where $y_t = -100$, $\ell_t \equiv 0 \implies \frac{\partial \ell_t}{\partial \mathbf{z}_t} = \mathbf{0}$.
$$\frac{\partial \mathcal{L}}{\partial W} = \frac{1}{N_{\text{active}}} \sum_{t=1}^T \mathbb{I}[y_t \ne -100] \mathbf{h}_t^T (\mathbf{p}_t - \mathbf{e}_{y_t}) = \frac{1}{N_{\text{active}}} \sum_{t \in \mathcal{T}_{\text{resp}}} \mathbf{h}_t^T (\mathbf{p}_t - \mathbf{e}_{y_t})$$ All terms from $t \in \mathcal{T}_{\text{prompt}}$ evaluate to zero.

Problem 3: Gradient Dilution & Effective Sample Efficiency (Hard)

Analyze an LLM trained on 3,600-token documents summarized into 400-token summaries.

View Complete Solution

Active Supervision Ratio:
In unmasked training, only $10\%$ of tokens correspond to the actual task. In masked SFT, $100\%$ of active tokens correspond to target responses.
Gradient Dilution: $90\%$ of parameter updates in unmasked training are driven by document text memorization ($\alpha = 0.90$). This causes capacity stealing and destructive gradient interference against instruction following.
