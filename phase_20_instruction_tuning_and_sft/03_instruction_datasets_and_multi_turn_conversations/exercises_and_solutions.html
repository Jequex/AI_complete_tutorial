Problem 1: Self-Instruct ROUGE-L Deduplication Tracing (Easy)

In Self-Instruct, instructions are compared against the dataset with ROUGE-L ($F_{\text{LCS}}$) and rejected if $\ge 0.70$. Compare candidate "Write a python function to reverse an integer list" against existing "Write a python function to reverse a list".

View Complete Solution

Step 1: Lengths: $|s_1| = 8$, $|s_2| = 9$.

Step 2: LCS: Shared 7 words (["Write", "a", "python", "function", "to", "reverse", "list"]).

Step 3: ROUGE-L F1: $$F_{\text{LCS}} = \frac{2 \times \text{LCS}}{|s_1| + |s_2|} = \frac{14}{17} \approx 0.8235$$

Decision: $0.8235 \ge 0.70$. Redundant candidate is discarded.

Problem 2: Multi-Turn Loss Mask Construction (Medium)

Construct the target label vector for a 4-turn dialogue (user, asst, user, asst) of length 15 tokens.

View Complete Solution

User tokens predict intermediate query tokens and are masked out (-100). The final token of user turns predicts the first assistant token and is supervised. All assistant body and closing tokens are supervised:
$$\mathbf{t} = [-100, -100, -100, -100, a_1, a_2, -100, -100, -100, -100, -100, -100, a_3, a_4]$$ Total active tokens = 4.

Problem 3: Function Calling Masking & Environment Leakage Proof (Hard)

Prove why supervising external API responses (<tool_response>) damages calibration and causes hallucinations.

View Complete Solution

External tool outputs are stochastic real-world observations ($o \sim P_{\text{env}}(o \mid c)$). Training with cross-entropy penalizes the model for failing to memorize external database states, incentivizing it to hallucinate fake responses and skip tool calls altogether at test time. Tool responses must serve as conditional context with label -100.
