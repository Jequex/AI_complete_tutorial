Phase 20

Instruction Tuning & Supervised Fine-Tuning (SFT)

From Raw Internet Auto-Completer to Aligned Conversational Assistant

Architectural Paradigm

Pre-trained language models predict the next token across arbitrary web documents, lacking conversational alignment. Phase 20 covers the mathematical and algorithmic techniques required to transform base models into helpful, honest, and harmless assistants: chat templates, loss masking on prompt tokens (ignore_index = -100), synthetic instruction generation (Self-Instruct, Evol-Instruct), multi-turn conversation modeling with tool use, and automated evaluation using debiased LLM-as-a-Judge harnesses.

01. Base Models vs. Instruct Models & Chat Templates

The fundamental shift from web continuation to instruction following. The HHH Triad (Helpfulness, Honesty, Harmlessness), prompt formats (Stanford Alpaca vs OpenAI ChatML vs Meta LLaMA 3), special control tokens, and generation prompt mechanics.

02. Supervised Fine-Tuning & The Loss Masking Mechanism

The SFT objective function, sequence concatenation, and the critical necessity of loss masking on prompt tokens (target = -100). Analytical proof that unmasked loss forces prompt memorization and wastes capacity. Shift dynamics and zero gradient guarantees.

03. Instruction Datasets, Multi-Turn Conversations & Function Calling

Instruction dataset engineering via Self-Instruct (with ROUGE-L deduplication) and Evol-Instruct (depth/breadth mutations). Multi-turn dialogue tree serialization, loss mask vectors, function schema injection, tool invocation generation, and environmental response masking.

04. Instruction Evaluation & The LLM-as-a-Judge Framework

Ground-truth benchmarks (MMLU, GSM8K, HumanEval pass@k) vs open-ended conversational suites (MT-Bench, AlpacaEval). Automated evaluation using frontier judges, cognitive biases (Position, Verbosity, Self-Enhancement), bidirectional order swapping, and Bradley-Terry Elo modeling.
