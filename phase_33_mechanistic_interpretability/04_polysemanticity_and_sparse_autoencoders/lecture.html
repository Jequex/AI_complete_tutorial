Topic 33.4

Polysemanticity & Sparse Autoencoders (SAEs)

The Superposition Hypothesis, overcomplete dictionary learning, and extracting monosemantic latent features with L1 regularization.

1. Introduction & 12-Year-Old Intuition

Imagine a small suitcase that only holds 2 books ($d = 2$). But you want to pack 5 books ($D = 5$). You tear the covers off and interleave the pages at slight angles so that all 5 fit.

When you reach into a pocket, you grab a page with Harry Potter, calculus, and a cookie recipe all mixed together! That is Polysemanticity: a single neuron responding to multiple unrelated concepts.

Why does this work? Because you only read one book at a time (Feature Sparsity). The network packs thousands of concepts into high-dimensional space by making them almost perpendicular. A Sparse Autoencoder (SAE) is the machine that untangles this suitcase into clean, separate, individual concepts.

2. Mathematical Symbol Decoder

Symbol Entity Domain Interpretability Significance
$d$ Residual Stream Dimension Integer The bottleneck dimension of the model activations (e.g., 4096).
$D$ Dictionary Feature Count Integer, $D \gg d$ Overcomplete feature space dimension (e.g., $16d$ or $32d$).
$\mathbf{v}_k$ Feature Direction Vector $\mathbb{R}^d, \|\mathbf{v}_k\|=1$ True ground-truth latent concept vector packed in superposition.
$\mathbf{z}$ SAE Latent Code $\mathbb{R}^D$ Sparse feature activations: $\mathbf{z} = \text{ReLU}(W_{\text{enc}}\mathbf{x} + \mathbf{b}_{\text{enc}})$.
$W_{\text{dec}}$ SAE Decoder Matrix $\mathbb{R}^{d \times D}$ Dictionary atoms; columns are constrained to $\|\mathbf{w}_j^{\text{dec}}\|_2 = 1$.
$\lambda$ $L_1$ Sparsity Weight Real scalar $> 0$ Loss coefficient penalizing non-zero latent feature activations.

3. The Sparse Autoencoder Objective

An SAE maps polysemantic activations $\mathbf{x} \in \mathbb{R}^d$ into an overcomplete sparse latent representation $\mathbf{z} \in \mathbb{R}^D$ and reconstructs $\hat{\mathbf{x}}$:

$$\mathbf{z} = \text{ReLU}(W_{\text{enc}} \mathbf{x} + \mathbf{b}_{\text{enc}}), \quad \hat{\mathbf{x}} = W_{\text{dec}} \mathbf{z} + \mathbf{b}_{\text{dec}}$$

The optimization loss is:

$$\boxed{\mathcal{L}_{\text{SAE}} = \frac{1}{B} \sum_{i=1}^B \left( \|\mathbf{x}^{(i)} - \hat{\mathbf{x}}^{(i)}\|_2^2 + \lambda \sum_{j=1}^D |z_j^{(i)}| \right)}$$
Unit-Norm Constraint: The columns of $W_{\text{dec}}$ must be explicitly normalized to $\|\mathbf{w}_j^{\text{dec}}\|_2 = 1$ to prevent the optimizer from arbitrarily shrinking $\mathbf{z}$ while blowing up $W_{\text{dec}}$.
