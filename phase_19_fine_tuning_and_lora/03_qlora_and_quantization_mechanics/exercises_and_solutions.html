Problem 1: Manual Symmetric Uniform INT8 and INT4 Quantization (Easy)

Given weight block $\mathbf{w} = [-0.12, \; 0.04, \; -0.28, \; 0.56]$:

  1. Compute the symmetric INT8 scale $S_8$ and quantized values $\mathbf{q}_8$.
  2. Compute dequantized $\tilde{\mathbf{w}}_8$ and MSE.
  3. Compute the symmetric INT4 scale $S_4$, quantized values $\mathbf{q}_4$, and MSE.
View Complete Solution

INT8 Quantization:

$$\alpha_{\max} = 0.56, \quad S_8 = \frac{0.56}{127} \approx 0.00440945$$ $$\mathbf{q}_8 = [-27, \; 9, \; -64, \; 127], \quad \text{MSE}_8 \approx \mathbf{1.46 \times 10^{-6}}$$

INT4 Quantization:

$$S_4 = \frac{0.56}{7} = 0.080000$$ $$\mathbf{q}_4 = [-2, \; 1, \; -4, \; 7], \quad \text{MSE}_4 = \mathbf{1.20 \times 10^{-3}}$$

INT4 error is $\approx 800\times$ higher than INT8 due to having only 16 quantization levels.

Problem 2: Double Quantization Memory Budget for a 70B Model (Hard)

Compare the static memory required to fine-tune LLaMA-3-70B ($N = 70.6 \times 10^9$) under:

  1. Unquantized FP16 Base + LoRA
  2. 4-bit QLoRA without Double Quantization ($B_1 = 64$)
  3. 4-bit QLoRA with Double Quantization ($B_1 = 64, B_2 = 256$)
View Complete Solution
  • Unquantized FP16 Base: $131.50\text{ GB (Base)} + 2.10\text{ GB (LoRA)} = \mathbf{133.60\text{ GB}}$ (Requires multi-GPU cluster).
  • 4-bit QLoRA (No DQ): $32.88\text{ GB (Weights)} + 4.11\text{ GB (Scales)} + 2.10\text{ GB (LoRA)} = \mathbf{39.09\text{ GB}}$.
  • 4-bit QLoRA (With DQ): $32.88\text{ GB (Weights)} + 1.04\text{ GB (Scales)} + 2.10\text{ GB (LoRA)} = \mathbf{36.02\text{ GB}}$.

Conclusion: Double Quantization saves $3.07\text{ GB}$ of VRAM exclusively from scales, allowing the 70B model to easily fit within a single 80GB GPU with over $43\text{ GB}$ reserved for dynamic activations.
