Topic 19.1: Exercises & Solutions — Full Fine-Tuning vs. PEFT

Analytical practice problems on GPU memory footprinting, gradient interference dynamics, and Bayesian weight consolidation.

Problem 1: Full Fine-Tuning vs. PEFT VRAM Footprint Calculation (Easy)

An AI engineer plans to adapt a 14-billion parameter model ($N = 14 \times 10^9$) on a medical dataset. Consider two training configurations using standard mixed precision (FP16 model forward/backward pass, FP32 master weights, and AdamW optimizer):

  1. Configuration A: Full Fine-Tuning (FFT), where all $N$ parameters are updated.
  2. Configuration B: Parameter-Efficient Fine-Tuning (PEFT), where the base model is frozen in FP16, and an adapter containing $0.2\%$ of the total parameters ($M = 0.002 N$) is trained.

Tasks:

  • Calculate the exact static GPU memory footprint (in Gigabytes, $1\text{ GB} = 1024^3\text{ bytes}$) required by Configuration A.
  • Calculate the exact static memory footprint required by Configuration B.
  • Compute the percentage reduction in static memory achieved by PEFT.
View Complete Solution

Step 1: Configuration A (Full Fine-Tuning)

Under mixed-precision AdamW: $M_{\text{static}} = 16\text{ bytes per parameter}$.

  • Weights (FP16): $14 \times 10^9 \times 2 = 28 \text{ GB}$
  • Gradients (FP16): $14 \times 10^9 \times 2 = 28 \text{ GB}$
  • Master Weights (FP32): $14 \times 10^9 \times 4 = 56 \text{ GB}$
  • AdamW Moments $m_t + v_t$ (FP32): $14 \times 10^9 \times 8 = 112 \text{ GB}$
$$\text{Total Bytes} = 14 \times 10^9 \times 16 = 224 \times 10^9\text{ bytes} \implies M_{\text{FFT}} \approx \mathbf{208.62\text{ GB}}$$

Step 2: Configuration B (PEFT with 0.2% Parameters)

Frozen base requires only 2 bytes/param (weights only):

$$M_{\text{base}} = 14 \times 10^9 \times 2 = 28 \times 10^9\text{ bytes}$$

Adapter requires 16 bytes/param for $M = 28 \times 10^6$ parameters:

$$M_{\text{adapter}} = 28 \times 10^6 \times 16 = 0.448 \times 10^9\text{ bytes}$$ $$M_{\text{PEFT}} = \frac{28.448 \times 10^9}{1024^3} \approx \mathbf{26.49\text{ GB}}$$

Step 3: Memory Reduction

$$\text{Reduction} = \frac{208.62 - 26.49}{208.62} \times 100\% \approx \mathbf{87.30\%}$$

Problem 2: First- and Second-Order Gradient Interference Calculation (Medium)

Consider a toy 2-parameter model with $\mathbf{g}_A = [1.0, -2.0]^T$ and $\mathbf{H}_A = \begin{bmatrix} 4.0 & 0.0 \\ 0.0 & 2.0 \end{bmatrix}$. We perform a gradient step on Task B with learning rate $\eta = 0.1$: $\Delta \theta = -\eta \mathbf{g}_B$.

Compare two gradients:

  • Scenario I (Orthogonal): $\mathbf{g}_B^{(I)} = [2.0, 1.0]^T$
  • Scenario II (Conflicting): $\mathbf{g}_B^{(II)} = [-3.0, 2.0]^T$

Calculate $\Delta \mathcal{L}_A \approx -\eta \langle \mathbf{g}_A, \mathbf{g}_B \rangle + \frac{\eta^2}{2} \mathbf{g}_B^T \mathbf{H}_A \mathbf{g}_B$.

View Complete Solution

Scenario I: Orthogonal Task

$$\langle \mathbf{g}_A, \mathbf{g}_B^{(I)} \rangle = (1)(2) + (-2)(1) = 0.0 \implies -\eta \langle \mathbf{g}_A, \mathbf{g}_B \rangle = 0.0$$ $$\frac{\eta^2}{2} \mathbf{g}_B^T \mathbf{H}_A \mathbf{g}_B = 0.005 \times [2(8) + 1(2)] = 0.005 \times 18.0 = +0.09$$ $$\Delta \mathcal{L}_A^{(I)} = \mathbf{+0.09}$$

Scenario II: Conflicting Task

$$\langle \mathbf{g}_A, \mathbf{g}_B^{(II)} \rangle = (1)(-3) + (-2)(2) = -7.0 \implies -\eta \langle \mathbf{g}_A, \mathbf{g}_B \rangle = -0.1 \times (-7.0) = \mathbf{+0.70}$$ $$\frac{\eta^2}{2} \mathbf{g}_B^T \mathbf{H}_A \mathbf{g}_B = 0.005 \times [(-3)(-12) + 2(4)] = 0.005 \times 44.0 = \mathbf{+0.22}$$ $$\Delta \mathcal{L}_A^{(II)} = +0.70 + 0.22 = \mathbf{+0.92}$$

Conclusion: Conflicting gradient directions produce an order of magnitude higher error spikes ($+0.92$ vs $+0.09$), showing the exact mechanism of catastrophic forgetting.
