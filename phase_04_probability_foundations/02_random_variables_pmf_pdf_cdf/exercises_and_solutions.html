Problem 1: PDF Normalization Constant & CDF Calculus

Medium

A continuous random variable $X$ has density $f(x) = c x^2$ on $[0, 3]$, and $0$ elsewhere.

  1. Determine $c$ such that $\int f(x) dx = 1$.
  2. Derive CDF $F_X(x)$.
  3. Find $P(1 \le X \le 2)$.
  4. Find the distribution median $m$ where $F(m) = 0.5$.
Click to Reveal Step-by-Step Solution
1. Normalization: $$\int_0^3 c x^2 dx = \left[ c \frac{x^3}{3} \right]_0^3 = 9c = 1 \implies c = \frac{1}{9}$$
2. CDF: $$F_X(x) = \int_0^x \frac{1}{9} t^2 dt = \frac{x^3}{27} \quad (\text{for } 0 \le x \le 3)$$
3. Interval Probability: $$P(1 \le X \le 2) = F(2) - F(1) = \frac{8 - 1}{27} = \frac{7}{27} \approx 0.2593$$
4. Median: $$\frac{m^3}{27} = 0.5 \implies m^3 = 13.5 \implies m \approx 2.3811$$

Problem 2: Inverse Transform Sampling for Pareto Distribution

Medium

For the Pareto distribution $f(x) = \frac{\alpha x_m^\alpha}{x^{\alpha+1}}$ ($x \ge x_m$):

  1. Derive CDF $F(x)$.
  2. Derive the inverse CDF $F^{-1}(u)$ to generate samples from uniform random numbers $u \sim \text{Uniform}(0, 1)$.
Click to Reveal Step-by-Step Solution
1. CDF: $$F(x) = \int_{x_m}^x \alpha x_m^\alpha t^{-\alpha-1} dt = 1 - \left(\frac{x_m}{x}\right)^\alpha$$
2. Inverse CDF: $$u = 1 - \left(\frac{x_m}{x}\right)^\alpha \implies \left(\frac{x_m}{x}\right)^\alpha = 1 - u \implies x = x_m (1 - u)^{-1/\alpha}$$ $$X = \frac{x_m}{U^{1/\alpha}}$$

Problem 3: Joint Probability Matrix & Independence Test

Challenging

Given the sensor joint distribution matrix $P(X, Y)$:

$Y = 0$ $Y = 1$
$X = 0$ 0.54 0.06
$X = 1$ 0.16 0.24
  1. Compute marginals $P(X)$ and $P(Y)$.
  2. Compute $P(Y = 1 \mid X = 1)$.
  3. Are $X$ and $Y$ statistically independent?
Click to Reveal Step-by-Step Solution
1. Marginals: $$P(X=0) = 0.54 + 0.06 = 0.60, \quad P(X=1) = 0.16 + 0.24 = 0.40$$ $$P(Y=0) = 0.54 + 0.16 = 0.70, \quad P(Y=1) = 0.06 + 0.24 = 0.30$$
2. Conditional: $$P(Y = 1 \mid X = 1) = \frac{P(X=1, Y=1)}{P(X=1)} = \frac{0.24}{0.40} = 0.60$$
3. Independence Check: $$P(X=1) \times P(Y=1) = 0.40 \times 0.30 = 0.12 \neq 0.24 = P(X=1, Y=1)$$ Since the joint probability does not equal the product of marginals, $X$ and $Y$ are NOT independent.
