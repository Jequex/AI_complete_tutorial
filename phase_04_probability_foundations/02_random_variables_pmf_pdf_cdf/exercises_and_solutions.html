Problem 1: PDF Normalization Constant & CDF Calculus

Medium

🧒 The Context: Rain density is modeled as $f_X(x) = c x^2$ on interval $[0, 3]$.

  1. Find constant $c$ such that total area equals $1.0$.
  2. Derive CDF $F_X(x)$.
  3. Calculate $P(1 \le X \le 2)$.
  4. Find the median $m$ ($F_X(m) = 0.5$).
Click to view solution for Problem 1
1. Normalization Constant: $\int_0^3 c x^2 dx = c [x^3/3]_0^3 = 9c = 1 \implies \mathbf{c = 1/9}$.
2. Cumulative Distribution Function: $F_X(x) = \int_0^x \frac{1}{9} t^2 dt = \mathbf{\frac{x^3}{27}}$ for $0 \le x \le 3$.
3. Interval Probability: $P(1 \le X \le 2) = F(2) - F(1) = \frac{8}{27} - \frac{1}{27} = \mathbf{\frac{7}{27} \approx 0.2593}$.
4. Median $m$: $\frac{m^3}{27} = 0.5 \implies m^3 = 13.5 \implies \mathbf{m \approx 2.3811}$.

Problem 2: Inverse Transform Sampling for the Pareto Distribution

Medium

🧒 The Context: Heavy-tailed wealth distribution $F_X(x) = 1 - (x_m/x)^\alpha$ for $x \ge x_m$.

  1. Invert the CDF formula to find quantile function $X = F^{-1}(U)$.
  2. Sample $X$ for $x_m = 10, \alpha = 2$ and $U = 0.75$.
  3. Sample $X$ for $U = 0.99$ and observe heavy-tailed growth.
Click to view solution for Problem 2
1. Inverse CDF Derivation: $u = 1 - (x_m/x)^\alpha \implies 1 - u = (x_m/x)^\alpha \implies \mathbf{x = x_m (1 - u)^{-1/\alpha}}$.
2. Draw at 75th Percentile: $X = 10 / (1 - 0.75)^{1/2} = 10 / 0.50 = \mathbf{20.0}$.
3. Draw at 99th Percentile: $X = 10 / (1 - 0.99)^{1/2} = 10 / 0.10 = \mathbf{100.0}$ ($5\times$ jump!).

Problem 3: Joint Distribution Matrix: Marginals & Conditioning

Challenging

🧒 The Context: Camera $X \in \{0, 1\}$ and mic $Y \in \{0, 1\}$ joint probabilities: $P(0, 0)=0.4, P(0, 1)=0.1, P(1, 0)=0.2, P(1, 1)=0.3$.

  1. Compute marginals $p_X(x)$ and $p_Y(y)$.
  2. Compute $P(Y = 1 \mid X = 1)$.
  3. Test statistical independence.
Click to view solution for Problem 3
1. Marginals: $p_X(0) = 0.50, p_X(1) = 0.50$;   $p_Y(0) = 0.60, p_Y(1) = 0.40$.
2. Conditional Probability: $P(Y = 1 \mid X = 1) = \frac{P(1, 1)}{p_X(1)} = \frac{0.30}{0.50} = \mathbf{0.60} \quad (60\%)$.
3. Independence Test: $P(1, 1) = 0.30$, but $p_X(1) p_Y(1) = 0.50 \times 0.40 = 0.20$. Because $0.30 \neq 0.20$, the sensors are dependent!
