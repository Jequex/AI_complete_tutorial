Topic 4.2: Random Variables, PMF, PDF & CDF

Discrete vs Continuous Uncertainty, The Density Paradox, and Inverse Transform Sampling

1. Symbol Decoder Table

Symbol Name Formal Meaning 12-Year-Old Analogy

2. Discrete vs Continuous Variables

Discrete: Probability Mass Function (PMF)

Discrete variables take countable values. The PMF yields exact point probabilities:

$$p_X(x) \ge 0, \quad \sum_{x} p_X(x) = 1.0$$

⚠️ The Continuous PDF Paradox ($P(X = x) = 0$):
For a continuous variable, the probability of selecting an exact infinite-precision number (e.g. $1.75000000\dots$) is strictly zero! We can only measure probability over an interval:

$$P(a \le X \le b) = \int_a^b f_X(x) \, dx$$

Note: The density $f_X(x)$ can exceed 1.0, but the total integrated area is always 1.0!

3. The Cumulative Distribution Function (CDF)

The CDF $F_X(x) = P(X \le x)$ connects to the PDF through calculus:

$$F_X(x) = \int_{-\infty}^x f_X(t) \, dt \quad \Longleftrightarrow \quad f_X(x) = \frac{d}{dx} F_X(x)$$

4. Inverse Transform Sampling

How Computers Sample from Distributions:
If $U \sim \text{Uniform}(0, 1)$, then $X = F^{-1}(U)$ follows the exact target distribution!

For an Exponential distribution with parameter $\lambda$ ($F(x) = 1 - e^{-\lambda x}$):

import random
import math

def sample_exponential(lambda_param: float) -> float:
    # Inverse CDF: x = -ln(1 - u) / lambda
    u = random.random()
    return -math.log(1.0 - u) / lambda_param
