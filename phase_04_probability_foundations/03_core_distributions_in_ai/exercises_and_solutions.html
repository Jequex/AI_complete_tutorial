Problem 1: Derivation of Bernoulli MLE & BCE Loss

Medium

🧒 The Context: Maya observes $N$ puppies with binary collar tags $y_i \in \{0, 1\}$.

  1. Write the Likelihood $L(p) = \prod p^{y_i} (1-p)^{1-y_i}$.
  2. Take the log-likelihood $\ell(p) = \ln L(p)$.
  3. Differentiate and solve for $\hat{p}_{\text{MLE}}$.
  4. Show equivalence to Binary Cross-Entropy (BCE) loss.
Click to view solution for Problem 1
1. Log-Likelihood: $\ell(p) = \sum_{i=1}^N [y_i \ln(p) + (1 - y_i) \ln(1 - p)]$.
2. Derivation: $\frac{d\ell}{dp} = \frac{1}{p} \sum y_i - \frac{1}{1-p} \sum (1 - y_i) = 0 \implies \mathbf{\hat{p}_{\text{MLE}} = \frac{1}{N} \sum_{i=1}^N y_i}$.
3. BCE Loss Identity: $\mathcal{L}_{\text{BCE}} = -\frac{1}{N}\ell(p) = -\frac{1}{N}\sum [y_i \ln(p) + (1 - y_i)\ln(1 - p)]$. Minimizing BCE is identical to maximizing Bernoulli likelihood!

Problem 2: 2D Multivariate Gaussian Density by Hand

Medium

🧒 The Context: 2D puppy height-weight Gaussian with $\mu = [2.0, 2.0]^T$ and $\Sigma = \operatorname{diag}(1.0, 4.0)$ evaluated at $\mathbf{x} = [3.0, 4.0]^T$.

  1. Compute difference vector $\mathbf{x} - \mu$.
  2. Compute Mahalanobis distance squared $d_M^2$.
  3. Calculate exact density $f(\mathbf{x})$.
Click to view solution for Problem 2
1. Difference Vector: $\mathbf{x} - \mu = [3 - 2, 4 - 2]^T = [1.0, 2.0]^T$.
2. Mahalanobis Squared Distance: $d_M^2 = [1, 2] \begin{bmatrix} 1 & 0 \\ 0 & 0.25 \end{bmatrix} \begin{bmatrix} 1 \\ 2 \end{bmatrix} = 1(1) + 2(0.5) = \mathbf{2.0}$.
3. Density Value: Normalizer is $\frac{1}{2\pi \times 2.0} = \frac{1}{4\pi} \approx 0.07958$. $$f(\mathbf{x}) = 0.07958 \times e^{-1} \approx \mathbf{0.02927}$$

Problem 3: The VAE Reparameterization Trick

Challenging

🧒 The Context: VAE latent variable $z = \mu + \sigma \epsilon$ with $\mu = 1.5, \sigma = 0.8, \epsilon = 0.5$ and loss $\mathcal{L} = (z - 3.0)^2$.

  1. Compute forward values of $z$ and loss $\mathcal{L}$.
  2. Compute $\frac{\partial \mathcal{L}}{\partial z}$.
  3. Compute gradients $\frac{\partial \mathcal{L}}{\partial \mu}$ and $\frac{\partial \mathcal{L}}{\partial \sigma}$.
Click to view solution for Problem 3
1. Forward Pass: $z = 1.5 + 0.8(0.5) = \mathbf{1.9}$. Loss $\mathcal{L} = (1.9 - 3.0)^2 = \mathbf{1.21}$.
2. Latent Gradient: $\frac{\partial \mathcal{L}}{\partial z} = 2(1.9 - 3.0) = \mathbf{-2.2}$.
3. Parameter Gradients: $$\frac{\partial \mathcal{L}}{\partial \mu} = (-2.2) \times 1.0 = \mathbf{-2.2}, \quad \frac{\partial \mathcal{L}}{\partial \sigma} = (-2.2) \times 0.5 = \mathbf{-1.1}$$ Gradients flow seamlessly back into the encoder!
