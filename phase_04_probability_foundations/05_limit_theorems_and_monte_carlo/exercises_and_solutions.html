Problem 1: CLT & Benchmark Sample Sizing ($\pm 1\%$ Margin of Error)

Medium

🧒 The Context: Evaluating model accuracy $p \approx 0.80$ with $95\%$ confidence ($Z = 1.96$) to achieve margin of error $E \le 0.01$.

  1. State standard error $\text{SE}(\hat{p}) = \sqrt{p(1-p)/n}$.
  2. Calculate minimum required sample size $n$.
  3. Compute worst-case sample size when $p$ is unknown.
Click to view solution for Problem 1
1. Standard Error: $\text{SE}(\hat{p}) = \sqrt{\frac{p(1-p)}{n}}$.
2. Sample Size for $p = 0.80$: $$n \ge \frac{1.96^2 \times (0.80)(0.20)}{0.01^2} = \frac{3.8416 \times 0.16}{0.0001} \approx \mathbf{6{,}147 \text{ questions}}.$$
3. Worst-Case Sample Size: Max variance is $0.5 \times 0.5 = 0.25$. $$n_{\text{worst}} \ge \frac{3.8416 \times 0.25}{0.0001} = \mathbf{9{,}604 \text{ questions}}.$$

Problem 2: Monte Carlo Integration for Gaussian Error Function

Medium

🧒 The Context: Estimating $I = \int_0^1 e^{-x^2} dx$ using 4 uniform samples $x = [0.2, 0.5, 0.7, 0.9]$.

  1. Compute $g(x_i) = e^{-x_i^2}$ for all 4 points.
  2. Calculate the sample mean estimate $\hat{I}_4$.
  3. Compare with true integral $I \approx 0.7468$.
Click to view solution for Problem 2
1. Sample Evaluations: $e^{-(0.2)^2} \approx 0.9608, \quad e^{-(0.5)^2} \approx 0.7788, \quad e^{-(0.7)^2} \approx 0.6126, \quad e^{-(0.9)^2} \approx 0.4449$.
2. Monte Carlo Average: $$\hat{I}_4 = \frac{0.9608 + 0.7788 + 0.6126 + 0.4449}{4} = \frac{2.7971}{4} = \mathbf{0.6993}.$$
3. Accuracy Comparison: True value is $0.7468$. With just 4 samples, error is $< 6\%$!

Problem 3: LLM Decoding Arithmetic: Temperature, Top-K & Top-P

Challenging

🧒 The Context: Candidate words with raw logits $\mathbf{z} = [4.0, 3.0, 2.0, 1.0, 0.0]^T$ for {"apple", "banana", "cherry", "date", "eggplant"}.

  1. Compute baseline Softmax probabilities at $T = 1.0$.
  2. Compute low temperature probabilities at $T = 0.5$.
  3. Apply Top-$k = 2$ Truncation.
  4. Apply Top-$p = 0.85$ (Nucleus) Sampling.
Click to view solution for Problem 3
1. Baseline Softmax ($T = 1.0$): Sum of exponentials is $85.79$. Probabilities are: apple: $63.6\%$, banana: $23.4\%$, cherry: $8.6\%$, date: $3.2\%$, eggplant: $1.2\%$.
2. Low Temperature ($T = 0.5$): Logits doubled to $[8, 6, 4, 2, 0]$. "Apple" jumps from $63.6\%$ to $\mathbf{86.5\%}$ dominance!
3. Top-$k = 2$ Truncation: Keep {"apple", "banana"}. Normalized: apple $\approx \mathbf{73.1\%}$, banana $\approx \mathbf{26.9\%}$.
4. Top-$p = 0.85$ Nucleus Sampling: $p(\text{apple}) + p(\text{banana}) = 63.6\% + 23.4\% = 87.0\% \ge 85\%$. Surviving nucleus is {"apple", "banana"}, trimming the tail to prevent hallucinations!
