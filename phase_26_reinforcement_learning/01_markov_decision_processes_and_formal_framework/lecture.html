Topic 26.1: Markov Decision Processes & Formal Framework

The foundational mathematics of sequential decision-making under uncertainty.

12-Year-Old Intuition: The Enchanted Board Game

Imagine playing an enchanted board game like Jumanji. You stand on square 14. A magical guardian appears and asks: "Which direction will you step next?"

Notice something fundamental: the guardian does not care if you took 2 turns to reach square 14 or 50 turns. The guardian does not care if you arrived by hopping, tumbling backwards, or riding an eagle. The rules of what happens next—your odds of stepping into a trap, grabbing a coin, or sliding down a chute—depend strictly and entirely on where you stand right now (square 14) and what action you pick right now.

This is the Markov Property: The future is independent of the past given the present. Coins collected immediately are shiny and valuable; coins promised 10 turns later have gathered dust and decay by a discount factor $\gamma$.

1. Mathematical Symbol Decoder

Symbol Name Formal Domain Physical / Computational Meaning
$\mathcal{S}$ State Space Set or manifold All possible environmental situations or board configurations.
$\mathcal{A}$ Action Space Set or manifold All allowable decisions available to the agent.
$\mathcal{P}$ (or $T$) Transition Kernel $\mathcal{S} \times \mathcal{A} \times \mathcal{S} \to [0, 1]$ $\mathcal{P}(s' \mid s, a)$: probability of reaching state $s'$ given action $a$ in state $s$.
$\mathcal{R}$ Reward Function $\mathcal{S} \times \mathcal{A} \to \mathbb{R}$ Scalar feedback signal $R(s, a)$ delivered immediately following action $a$ in state $s$.
$\gamma$ Discount Factor $\gamma \in [0, 1)$ Temporal decay rate balancing immediate gratification against delayed long-term return.
$\tau$ Trajectory / Episode $(s_0, a_0, s_1, \dots, s_T)$ Ordered sequence of states, actions, and rewards experienced across time.
$\pi(a \mid s)$ Policy $\mathcal{S} \times \mathcal{A} \to [0, 1]$ The agent's decision rule: conditional probability distribution over actions given state $s$.
$G_t$ Discounted Return $\mathbb{R}$ Total cumulative discounted reward accumulated from step $t$ onward: $\sum_{k=0}^\infty \gamma^k R_{t+k+1}$.
$V^\pi(s)$ State-Value Function $\mathcal{S} \to \mathbb{R}$ Expected future return starting from state $s$ following policy $\pi$.
$Q^\pi(s, a)$ Action-Value Function $\mathcal{S} \times \mathcal{A} \to \mathbb{R}$ Expected future return starting from state $s$, executing action $a$, and following $\pi$ thereafter.

2. Formal Definition of the MDP 5-Tuple

A discrete-time Markov Decision Process is the tuple:

$$\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle$$

The Markov Property

A stochastic process satisfies the Markov property if the transition dynamics depend solely on the current state-action pair:

$$\mathbb{P}(S_{t+1} = s_{t+1}, R_{t+1} = r_{t+1} \mid S_t = s_t, A_t = a_t, \dots, S_0 = s_0, A_0 = a_0) = \mathbb{P}(S_{t+1} = s_{t+1}, R_{t+1} = r_{t+1} \mid S_t = s_t, A_t = a_t)$$

When the observation from the environment is incomplete (e.g. single video frame without velocity), the state is non-Markovian. We resolve this by history-stacking (e.g., Frame Stacking in Atari DQN) or recurrent belief-state tracking.

3. Trajectory Probability & Discounted Return

Given an initial state distribution $\rho_0(s_0)$, the probability measure over trajectories $\tau = (s_0, a_0, s_1, \dots, s_H)$ under policy $\pi$ is:

$$\mathbb{P}(\tau \mid \pi) = \rho_0(s_0) \prod_{t=0}^{H-1} \pi(a_t \mid s_t) \mathcal{P}(s_{t+1} \mid s_t, a_t)$$

The return $G_t$ is the geometrically discounted future reward sum:

$$G_t \triangleq \sum_{k=0}^\infty \gamma^k R_{t+k+1}$$

Why Geometric Discounting $\gamma^k$?

  1. Bounded Convergence: If rewards are bounded by $|R_t| \le R_{\max}$, then $|G_t| \le \frac{R_{\max}}{1 - \gamma} < \infty$.
  2. Time Consistency: The relative valuation of two rewards separated by $\Delta t$ steps is $\gamma^{\Delta t}$, remaining identical regardless of when the evaluation is made.
  3. Poisson Survival Probability: Setting $\gamma$ is mathematically identical to a process that terminates at every step with hazard rate $p_{\text{die}} = 1 - \gamma$.

4. Value Functions and the Fundamental Identity

The state-value function $V^\pi(s)$ and action-value function $Q^\pi(s, a)$ are defined as expectations over trajectories:

$$V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]$$ $$Q^\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t = s, A_t = a]$$

By the law of total expectation, marginalizing over actions:

$$V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) Q^\pi(s, a)$$

Decomposing $G_t = R_{t+1} + \gamma G_{t+1}$ yields the one-step recursive relation:

$$Q^\pi(s, a) = \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^\pi(s')$$

5. Exact Analytical Matrix Solution

For finite state spaces, let $\mathbf{v}^\pi \in \mathbb{R}^{|\mathcal{S}|}$, $\mathbf{r}^\pi \in \mathbb{R}^{|\mathcal{S}|}$ where $r^\pi(s) = \sum_a \pi(a \mid s) \mathcal{R}(s, a)$, and $\mathbf{P}^\pi \in \mathbb{R}^{|\mathcal{S}| \times |\mathcal{S}|}$ where $\mathbf{P}^\pi_{i, j} = \sum_a \pi(a \mid s_i) \mathcal{P}(s_j \mid s_i, a)$.

The Bellman expectation system is linear:

$$\mathbf{v}^\pi = \mathbf{r}^\pi + \gamma \mathbf{P}^\pi \mathbf{v}^\pi \iff (\mathbf{I} - \gamma \mathbf{P}^\pi) \mathbf{v}^\pi = \mathbf{r}^\pi$$

Since $\rho(\gamma \mathbf{P}^\pi) \le \gamma < 1$, $(\mathbf{I} - \gamma \mathbf{P}^\pi)$ is non-singular and invertible via Neumann expansion:

$$\mathbf{v}^\pi = (\mathbf{I} - \gamma \mathbf{P}^\pi)^{-1} \mathbf{r}^\pi$$

Summary Checklist

  • MDP 5-Tuple: $\langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma \rangle$.
  • Markov Property: History is irrelevant given the current state.
  • Return $G_t$: Sum of discounted future rewards, bounded by $\frac{R_{\max}}{1 - \gamma}$.
  • Bridge: $V^\pi(s) = \sum_a \pi(a \mid s) Q^\pi(s, a)$.
  • Matrix Solver: Exact values can be computed directly in $O(|\mathcal{S}|^3)$ time.
