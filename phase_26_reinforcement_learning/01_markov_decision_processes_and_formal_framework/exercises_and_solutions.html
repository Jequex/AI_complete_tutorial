Exercise 1: Geometric Discounting as a Constant Termination Hazard

Suppose an environment terminates at every discrete time step with a fixed probability $p \in (0, 1)$, independent of history. If the process does not terminate, the agent receives reward $R_t$. If the process terminates, it transitions to an absorbing terminal state with reward 0 forever.

Show that evaluating the undiscounted expected return in this terminating environment is mathematically equivalent to evaluating the discounted return with discount factor $\gamma = 1 - p$ in an infinite-horizon non-terminating environment.

View Complete Solution

Let $T \in \{1, 2, 3, \dots\}$ be the random time step at which the process terminates. At each step, survival occurs with probability $1 - p$.

The probability that the agent survives for at least $k$ steps is:

$$\mathbb{P}(T \ge k) = (1 - p)^{k-1}$$

The expected undiscounted return across the stochastic lifetime $T$ is:

$$\mathbb{E}\left[ \sum_{t=1}^T R_t \right] = \mathbb{E}\left[ \sum_{t=1}^\infty R_t \cdot \mathbb{I}(T \ge t) \right]$$

By linearity of expectation and independence:

$$= \sum_{t=1}^\infty R_t \cdot \mathbb{P}(T \ge t) = \sum_{t=1}^\infty R_t (1 - p)^{t-1}$$

Letting $k = t - 1$ and defining $\gamma \triangleq 1 - p \in (0, 1)$:

$$= \sum_{k=0}^\infty \gamma^k R_{k+1}$$

This is precisely the definition of the discounted return $G_0$ with discount factor $\gamma = 1 - p$. Geometric discounting is therefore mathematically isomorphic to an ongoing survival process with constant failure rate $p = 1 - \gamma$.

Exercise 2: Strict Invertibility of $(\mathbf{I} - \gamma \mathbf{P}^\pi)$ via Gershgorin Circle Theorem

Let $\mathbf{P}^\pi \in \mathbb{R}^{N \times N}$ be a valid row-stochastic transition matrix (i.e. $\sum_{j=1}^N P_{ij} = 1$ and $P_{ij} \ge 0$). Let $\gamma \in [0, 1)$.

Prove that the matrix $\mathbf{A} = \mathbf{I} - \gamma \mathbf{P}^\pi$ is strictly diagonally dominant and therefore invertible.

View Complete Solution

A square matrix $\mathbf{A}$ is strictly diagonally dominant if for every row $i$:

$$|A_{ii}| > \sum_{j \neq i} |A_{ij}|$$

Evaluating $\mathbf{A} = \mathbf{I} - \gamma \mathbf{P}^\pi$:

  • Diagonal elements: $A_{ii} = 1 - \gamma P_{ii} > 0$
  • Off-diagonal elements: $A_{ij} = -\gamma P_{ij}$ for $j \neq i$

Summing the off-diagonal elements in row $i$:

$$\sum_{j \neq i} |A_{ij}| = \sum_{j \neq i} \gamma P_{ij} = \gamma \sum_{j \neq i} P_{ij} = \gamma (1 - P_{ii})$$

Subtracting from the diagonal term:

$$|A_{ii}| - \sum_{j \neq i} |A_{ij}| = (1 - \gamma P_{ii}) - \gamma (1 - P_{ii}) = 1 - \gamma$$

Since $\gamma < 1$, $1 - \gamma > 0$ strictly for every row $i$.

By the Levy-Desplanques Theorem (corollary of the Gershgorin Circle Theorem), every strictly diagonally dominant matrix has zero in no Gershgorin disc and is strictly non-singular. Hence $(\mathbf{I} - \gamma \mathbf{P}^\pi)^{-1}$ exists, guaranteeing a unique solution $\mathbf{v}^\pi$.

Exercise 3: Exact Value Computation on a 3-State World

Consider a 3-state environment $\mathcal{S} = \{s_1, s_2, s_3\}$:

  • State $s_1$: transition to $s_2$ with probability 1.0, reward $R(s_1) = 0$.
  • State $s_2$: transition to $s_3$ with prob $0.8$, transition to $s_1$ with prob $0.2$, reward $R(s_2) = +1$.
  • State $s_3$: absorbing terminal state with reward 0 forever ($P(s_3 \mid s_3) = 1, R(s_3) = 0$).

With $\gamma = 0.9$, compute exact values $V(s_1), V(s_2), V(s_3)$.

View Complete Solution

Terminal state: $V(s_3) = 0$.

Bellman equations for states $s_1, s_2$:

$$V(s_1) = 0 + 0.9 V(s_2) = 0.9 V(s_2)$$ $$V(s_2) = 1 + 0.9 [ 0.2 V(s_1) + 0.8 V(s_3) ] = 1 + 0.18 V(s_1)$$

Substituting $V(s_1)$:

$$V(s_2) = 1 + 0.18 (0.9 V(s_2)) = 1 + 0.162 V(s_2)$$ $$(1 - 0.162) V(s_2) = 1 \implies 0.838 V(s_2) = 1 \implies V(s_2) = \frac{1}{0.838} \approx 1.1933$$ $$V(s_1) = 0.9 \times 1.193317 \approx 1.0740$$

Result: $V(s_1) \approx 1.0740$, $V(s_2) \approx 1.1933$, $V(s_3) = 0.0$.

Exercise 4: Markovian State Augmentation

A physical system has position $x_t \in \mathbb{R}$ governed by $x_{t+1} = 2x_t - x_{t-1} + \Delta t^2 a_t + \epsilon_t$. Explain why $S_t = x_t$ violates the Markov property, and show how state augmentation restores it.

View Complete Solution

Non-Markovian nature: $P(x_{t+1} \mid x_t, a_t, x_{t-1}) \neq P(x_{t+1} \mid x_t, a_t)$ because position alone omits velocity $v_t \approx (x_t - x_{t-1})/\Delta t$.

Augmentation: Define $\tilde{S}_t = [x_t, \, x_{t-1}]^T$. Then:

$$\tilde{S}_{t+1} = \begin{bmatrix} x_{t+1} \\ x_t \end{bmatrix} = \begin{bmatrix} 2 & -1 \\ 1 & 0 \end{bmatrix} \begin{bmatrix} x_t \\ x_{t-1} \end{bmatrix} + \begin{bmatrix} \Delta t^2 \\ 0 \end{bmatrix} a_t + \begin{bmatrix} \epsilon_t \\ 0 \end{bmatrix}$$

The conditional probability $P(\tilde{S}_{t+1} \mid \tilde{S}_t, a_t)$ is fully self-contained, restoring the Markov property.
