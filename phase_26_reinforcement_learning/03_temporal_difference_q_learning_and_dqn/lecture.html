Topic 26.3: Temporal Difference, Q-Learning & Deep Q-Networks (DQN)

From model-free tabular TD learning to stabilizing deep neural Q-networks via replay memory and target networks.

12-Year-Old Intuition: Predicting the Bus Ride Home

Imagine guessing how long your bus ride home from school will take on a rainy Monday.

The Monte Carlo Way: You guess 30 minutes when leaving the school gates. You ride the bus, get stuck in traffic, and walk inside your house 52 minutes later. Only then do you compute your error: "My school gate guess was off by 22 minutes!"

The Temporal Difference (TD) Way: You guess 30 minutes. After 5 minutes, you turn onto the highway and see an enormous traffic jam. Your updated prediction immediately leaps to 60 minutes. You update your original guess right then and there: "Because reaching this jam means 60 minutes, my initial guess was too low!"

TD learning means learning a guess from a guess, updating predictions before the final outcome even happens.

1. Mathematical Symbol Decoder

Symbol Name Formal Domain Mathematical & Algorithmic Meaning
$\delta_t$ TD Error $\mathbb{R}$ One-step discrepancy: $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$.
$\alpha$ Learning Rate $(0, 1]$ Fraction of the error propagated into current parameter estimates.
$\theta$ Online Network Weights $\mathbb{R}^D$ Parameters optimized by SGD at each mini-batch step.
$\theta^-$ Target Network Weights $\mathbb{R}^D$ Slowly updated parameter copy used to evaluate regression targets without moving the goalpost.
$\mathcal{D}$ Replay Buffer Capacity $N$ Ring buffer storing transition tuples $(s, a, r, s', d)$ to break autocorrelation.
$y_i$ DQN Target Value $\mathbb{R}$ Target label: $r_i + \gamma (1 - d_i) \max_{a'} Q(s_i', a'; \theta^-)$.

2. Monte Carlo vs Temporal Difference TD(0)

Mathematical Comparison

Monte Carlo: $V(S_t) \leftarrow V(S_t) + \alpha [G_t - V(S_t)]$ where $G_t = \sum_{k=0}^{T-t-1} \gamma^k R_{t+k+1}$.
Unbiased ($\mathbb{E}[G_t \mid S_t] = V^\pi(S_t)$), but high variance because it sums many stochastic transitions.

TD(0): $V(S_t) \leftarrow V(S_t) + \alpha [R_{t+1} + \gamma V(S_{t+1}) - V(S_t)]$.
Biased initially due to bootstrapping from $V(S_{t+1})$, but significantly lower variance and updates immediately every step.

3. SARSA vs Q-Learning

On-Policy SARSA

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma Q(S_{t+1}, A_{t+1}) - Q(S_t, A_t) \right]$$

Uses the actual next action $A_{t+1} \sim \pi$. Evaluates the policy being actively followed, including accidental exploration mistakes.

Off-Policy Q-Learning (Watkins 1989)

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ R_{t+1} + \gamma \max_{a'} Q(S_{t+1}, a') - Q(S_t, A_t) \right]$$

Evaluates the greedy action $\max_{a'} Q(S_{t+1}, a')$ regardless of which exploratory action the agent actually chose. Directly estimates $Q^*(s, a)$.

4. Deep Q-Networks (DQN, Mnih et al. 2015)

Combining neural network function approximation with off-policy TD learning introduces the Deadly Triad of instability:

  1. Function Approximation: Generalization can inadvertently alter values of distant states.
  2. Bootstrapping: Target depends on the function itself.
  3. Off-Policy Learning: Training distribution differs from target policy distribution.

DQN's Architectural Remedies

1. Experience Replay Buffer $\mathcal{D}$: Uniformly sampling $(s, a, r, s', d) \sim \mathcal{D}$ breaks sequential correlation and restores an i.i.d. training regime.

2. Target Network $Q_{\theta^-}$: Freezes target computation using parameter set $\theta^-$, updated only every $C$ steps:

$$\mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s', d) \sim \mathcal{D}} \left[ \left( r + \gamma(1 - d) \max_{a'} Q(s', a'; \theta^-) - Q(s, a; \theta) \right)^2 \right]$$
