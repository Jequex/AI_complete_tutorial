Topic 26.2: Bellman Equations & Dynamic Programming

The Bellman expectation and optimality operators, the Banach fixed-point theorem, contraction mapping proof, and exact Dynamic Programming.

12-Year-Old Intuition: The Giant Pyramid

Imagine climbing a pyramid with thousands of stone steps. At the top sits a glittering diamond chest. Every step has gold or spikes.

To find the richest path to the top, do you need to test all 10 billion possible zigzag paths? No! Think backwards from the summit. If you are standing one step away from the diamond, your choice is obvious: step onto the diamond. One step before that, your value is simply: the gold on your next move plus the value of wherever you land.

This is Richard Bellman's Principle of Optimality: An optimal decision today leads directly into another optimal decision tomorrow.

1. Mathematical Symbol Decoder

Symbol Name Mathematical Domain Intuitive Meaning
$\mathcal{T}^\pi$ Bellman Expectation Operator $\mathbb{R}^{|\mathcal{S}|} \to \mathbb{R}^{|\mathcal{S}|}$ Applies one-step lookahead expected backup under fixed policy $\pi$.
$\mathcal{T}^*$ Bellman Optimality Operator $\mathbb{R}^{|\mathcal{S}|} \to \mathbb{R}^{|\mathcal{S}|}$ Applies greedy one-step lookahead maximum backup across all actions.
$\|\cdot\|_\infty$ Supremum / Infinity Norm $\mathbb{R}^{|\mathcal{S}|} \to \mathbb{R}_{\ge 0}$ $\|V\|_\infty = \max_{s \in \mathcal{S}} |V(s)|$: maximum worst-case error across the entire state space.
$V^*$ Optimal State-Value Function $\mathcal{S} \to \mathbb{R}$ Maximum achievable expected return from each state under the best policy.
$Q^*$ Optimal Action-Value Function $\mathcal{S} \times \mathcal{A} \to \mathbb{R}$ Maximum return starting from $s$, taking action $a$, and acting optimally thereafter.

2. Bellman Expectation & Optimality Equations

Bellman Expectation Equations

$$V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^\pi(s') \right]$$ $$Q^\pi(s, a) = \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a')$$

Bellman Optimality Equations

$$V^*(s) = \max_{a \in \mathcal{A}} \left[ \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) V^*(s') \right]$$ $$Q^*(s, a) = \mathcal{R}(s, a) + \gamma \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \max_{a' \in \mathcal{A}} Q^*(s', a')$$

Because the $\max$ operator is non-linear, $V^*$ cannot be solved with standard linear matrix inversion. It is solved via contraction fixed-point iterations.

3. The Bellman Contraction Mapping Proof

Let $(\mathcal{T}^* V)(s) \triangleq \max_{a} \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$.

Step-by-Step Proof that $\|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty$

1. By definition, for any state $s$:

$$|(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| = \left| \max_a \left( \mathcal{R}(s,a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s,a) U(s') \right) - \max_b \left( \mathcal{R}(s,b) + \gamma \sum_{s'} \mathcal{P}(s' \mid s,b) V(s') \right) \right|$$

2. Lemma: $|\max_x f(x) - \max_x g(x)| \le \max_x |f(x) - g(x)|$. Applying this:

$$\le \max_{a \in \mathcal{A}} \left| \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) U(s') - \left( \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right) \right|$$

3. The immediate reward cancels out:

$$= \max_{a \in \mathcal{A}} \gamma \left| \sum_{s'} \mathcal{P}(s' \mid s, a) (U(s') - V(s')) \right|$$

4. By triangle inequality and bounding by the supremum norm $\|U - V\|_\infty = \max_{s''} |U(s'') - V(s'')|$:

$$\le \max_{a \in \mathcal{A}} \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) |U(s') - V(s')| \le \gamma \|U - V\|_\infty \max_{a \in \mathcal{A}} \sum_{s'} \mathcal{P}(s' \mid s, a)$$

5. Since $\sum_{s'} \mathcal{P}(s' \mid s, a) = 1$:

$$|(\mathcal{T}^* U)(s) - (\mathcal{T}^* V)(s)| \le \gamma \|U - V\|_\infty$$

6. Taking the maximum over all states $s \in \mathcal{S}$:

$$\|\mathcal{T}^* U - \mathcal{T}^* V\|_\infty \le \gamma \|U - V\|_\infty \quad \blacksquare$$

4. Dynamic Programming Algorithms

Policy Iteration vs Value Iteration

Policy Iteration: Alternates between exact Policy Evaluation ($V^{\pi_k} \leftarrow (\mathcal{T}^{\pi_k})^\infty$) and greedy Policy Improvement ($\pi_{k+1} \leftarrow \arg\max Q^{\pi_k}$). Guaranteed to terminate in finite iterations because the set of deterministic policies is finite ($|\mathcal{A}|^{|\mathcal{S}|}$).

Value Iteration: Truncates policy evaluation to a single Bellman optimality backup ($V_{k+1} \leftarrow \mathcal{T}^* V_k$). Converges geometrically at rate $\gamma$ to the unique fixed point $V^*$.
