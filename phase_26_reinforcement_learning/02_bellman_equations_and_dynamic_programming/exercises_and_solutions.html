Exercise 1: Monotonicity of the Bellman Operator

Let $U, V \in \mathbb{R}^{|\mathcal{S}|}$ satisfy $U(s) \le V(s)$ for all $s \in \mathcal{S}$ ($U \le V$). Prove that both $\mathcal{T}^\pi$ and $\mathcal{T}^*$ are monotonic:

  1. $\mathcal{T}^\pi U \le \mathcal{T}^\pi V$
  2. $\mathcal{T}^* U \le \mathcal{T}^* V$
View Complete Solution

Part 1 ($\mathcal{T}^\pi$):

$$(\mathcal{T}^\pi V)(s) - (\mathcal{T}^\pi U)(s) = \gamma \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \big( V(s') - U(s') \big)$$

Because $\pi \ge 0$, $\mathcal{P} \ge 0$, $\gamma \ge 0$, and $(V(s') - U(s')) \ge 0$, every term in the sum is non-negative. Hence $(\mathcal{T}^\pi V)(s) \ge (\mathcal{T}^\pi U)(s)$.

Part 2 ($\mathcal{T}^*$):

For each individual action $a \in \mathcal{A}$:

$$\mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) U(s') \le \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s')$$

Taking the maximum over all actions preserves the inequality:

$$\max_a \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) U(s') \right] \le \max_a \left[ \mathcal{R}(s, a) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, a) V(s') \right]$$ $$\implies \mathcal{T}^* U \le \mathcal{T}^* V \quad \blacksquare$$

Exercise 2: Proof of the Policy Improvement Theorem

Let $\pi$ and $\pi'$ be deterministic policies such that $Q^\pi(s, \pi'(s)) \ge V^\pi(s)$ for all $s \in \mathcal{S}$. Prove that $V^{\pi'}(s) \ge V^\pi(s)$ for all $s$.

View Complete Solution

From $V^\pi(s) \le Q^\pi(s, \pi'(s))$:

$$V^\pi(s) \le \mathcal{R}(s, \pi'(s)) + \gamma \sum_{s'} \mathcal{P}(s' \mid s, \pi'(s)) V^\pi(s') = (\mathcal{T}^{\pi'} V^\pi)(s)$$

Thus $V^\pi \le \mathcal{T}^{\pi'} V^\pi$. Applying $\mathcal{T}^{\pi'}$ repeatedly, monotonicity guarantees:

$$V^\pi \le \mathcal{T}^{\pi'} V^\pi \le (\mathcal{T}^{\pi'})^2 V^\pi \le \dots \le (\mathcal{T}^{\pi'})^k V^\pi$$

Taking $k \to \infty$:

$$V^\pi \le \lim_{k \to \infty} (\mathcal{T}^{\pi'})^k V^\pi = V^{\pi'} \quad \blacksquare$$

Exercise 3: Value Iteration Stopping Bound

Prove that if $\|V_{k+1} - V_k\|_\infty < \theta = \epsilon \frac{1 - \gamma}{2\gamma}$, then the greedy policy $\pi$ extracted from $V_{k+1}$ satisfies $\|V^\pi - V^*\|_\infty \le \epsilon$.

View Complete Solution

By contraction mapping triangle inequality expansion:

$$\|V_{k+1} - V^*\|_\infty \le \sum_{j=1}^\infty \|V_{k+j+1} - V_{k+j}\|_\infty \le \sum_{j=1}^\infty \gamma^j \|V_{k+1} - V_k\|_\infty = \frac{\gamma}{1 - \gamma} \|V_{k+1} - V_k\|_\infty$$

The gap between the greedy policy $V^\pi$ and $V^*$ satisfies:

$$\|V^\pi - V^*\|_\infty \le \frac{2\gamma}{1 - \gamma} \|V_{k+1} - V_k\|_\infty$$

Substituting $\theta = \epsilon \frac{1 - \gamma}{2\gamma}$ yields $\|V^\pi - V^*\|_\infty < \epsilon$.

Exercise 4: Manual Two-Sweep Value Iteration Trace

2-State MDP $\{A, B\}$, $\gamma = 0.5$, $V_0 = [0, 0]$:

  • State A: Act 1 → A ($P=1, R=+1$); Act 2 → B ($P=1, R=+3$).
  • State B: Act 1 → 50% B, 50% A ($R=+2$); Act 2 → A ($P=1, R=0$).

Trace 2 sweeps of synchronous Value Iteration.

View Complete Solution

Sweep 1:

  • $Q_1(A, 1) = 1 + 0.5(0) = 1.0$; $Q_1(A, 2) = 3 + 0.5(0) = 3.0 \implies V_1(A) = 3.0$ (Action 2)
  • $Q_1(B, 1) = 2 + 0.5(0) = 2.0$; $Q_1(B, 2) = 0 + 0.5(0) = 0.0 \implies V_1(B) = 2.0$ (Action 1)

Sweep 2 ($V_1 = [3.0, 2.0]$):

  • $Q_2(A, 1) = 1 + 0.5(3.0) = 2.5$; $Q_2(A, 2) = 3 + 0.5(2.0) = 4.0 \implies V_2(A) = 4.0$ (Action 2)
  • $Q_2(B, 1) = 2 + 0.5[0.5(2) + 0.5(3)] = 2 + 0.5(2.5) = 3.25$; $Q_2(B, 2) = 0 + 0.5(3.0) = 1.5 \implies V_2(B) = 3.25$ (Action 1)

Result: $V_1 = [3.0, 2.0]$, $V_2 = [4.0, 3.25]$.
