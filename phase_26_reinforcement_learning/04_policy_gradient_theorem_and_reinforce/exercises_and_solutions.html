Exercise 1: Causality Proof — Why Past Rewards Drop Out

Prove that for any past reward $r_{t'}$ with $t' \le t$:

$$\mathbb{E}_{\tau \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) r_{t'} \right] = \mathbf{0}$$
View Complete Solution

Condition on history up to state $s_t$ using the tower property:

$$\mathbb{E}_{\tau} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) r_{t'} \right] = \mathbb{E}_{\tau_{0:t}} \left[ r_{t'} \mathbb{E}_{a_t \sim \pi_\theta} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \mid s_t \right] \right]$$

Evaluating the inner expectation:

$$\mathbb{E}_{a_t} \left[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right] = \sum_{a} \pi_\theta(a \mid s_t) \frac{\nabla_\theta \pi_\theta(a \mid s_t)}{\pi_\theta(a \mid s_t)} = \nabla_\theta \left( \sum_{a} \pi_\theta(a \mid s_t) \right) = \nabla_\theta (1) = \mathbf{0}$$

Therefore $\mathbb{E}[ \nabla_\theta \log \pi_\theta(a_t \mid s_t) r_{t'} ] = \mathbf{0} \quad \blacksquare$. Past rewards cannot correlate with future decisions.

Exercise 2: Derivation of the Softmax Score Function

For discrete policy $\pi_\theta(a \mid s) = \frac{\exp(\boldsymbol{\theta}_a^T \mathbf{x}(s))}{\sum_b \exp(\boldsymbol{\theta}_b^T \mathbf{x}(s))}$, derive $\nabla_{\boldsymbol{\theta}_k} \log \pi_\theta(a \mid s)$.

View Complete Solution
$$\log \pi_\theta(a \mid s) = \boldsymbol{\theta}_a^T \mathbf{x}(s) - \log \sum_b \exp(\boldsymbol{\theta}_b^T \mathbf{x}(s))$$ $$\nabla_{\boldsymbol{\theta}_k} \log \pi_\theta(a \mid s) = \mathbb{I}(a = k) \mathbf{x}(s) - \frac{\exp(\boldsymbol{\theta}_k^T \mathbf{x}(s))}{\sum_b \exp(\boldsymbol{\theta}_b^T \mathbf{x}(s))} \mathbf{x}(s)$$ $$= \mathbf{x}(s) \left[ \mathbb{I}(a = k) - \pi_\theta(k \mid s) \right] \quad \blacksquare$$

Exercise 3: Variance-Minimizing Baseline $b^*$

For estimator $\hat{g}(b) = g(R - b)$, find the scalar baseline $b^*$ that minimizes variance $\text{Var}(\hat{g}(b))$.

View Complete Solution

Since $\mathbb{E}[g b] = 0$, $\mathbb{E}[\hat{g}]$ is constant. Minimizing variance is minimizing $\mathbb{E}[g^2 (R - b)^2]$:

$$\frac{d}{db} \mathbb{E}\left[ g^2 (R^2 - 2 b R + b^2) \right] = -2 \mathbb{E}[g^2 R] + 2 b \mathbb{E}[g^2] = 0 \implies b^* = \frac{\mathbb{E}[g^2 R]}{\mathbb{E}[g^2]}$$

This justifies using $V(s) \approx \mathbb{E}[R \mid s]$ as the standard baseline.
