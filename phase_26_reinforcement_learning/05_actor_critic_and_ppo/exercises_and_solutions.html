Exercise 1: Algebraic Equivalence of GAE

Prove that $(1 - \lambda) \sum_{k=1}^\infty \lambda^{k-1} \hat{A}_t^{(k)}$ where $\hat{A}_t^{(k)} = \sum_{l=0}^{k-1} \gamma^l \delta_{t+l}^V$ is identically equal to:

$$\hat{A}_t^{\text{GAE}(\gamma, \lambda)} = \sum_{l=0}^\infty (\gamma \lambda)^l \delta_{t+l}^V$$
View Complete Solution

Expanding and swapping sums with $k \ge l + 1$:

$$\hat{A}_t^{\text{GAE}} = (1 - \lambda) \sum_{l=0}^\infty \gamma^l \delta_{t+l}^V \left( \sum_{k=l+1}^\infty \lambda^{k-1} \right)$$

Using the geometric sum $\sum_{m=l}^\infty \lambda^m = \frac{\lambda^l}{1 - \lambda}$:

$$= (1 - \lambda) \sum_{l=0}^\infty \gamma^l \delta_{t+l}^V \left( \frac{\lambda^l}{1 - \lambda} \right) = \sum_{l=0}^\infty (\gamma \lambda)^l \delta_{t+l}^V \quad \blacksquare$$

Exercise 2: Subgradient Analysis of the PPO Clipped Objective

For $L(r) = \min(r \hat{A}, \text{clip}(r, 1 - \epsilon, 1 + \epsilon)\hat{A})$, derive $\frac{\partial L}{\partial r}$ and identify where the gradient vanishes.

View Complete Solution

Case 1 ($\hat{A} > 0$):

$$L(r) = \begin{cases} r \hat{A} & \text{if } r \le 1 + \epsilon \\ (1 + \epsilon)\hat{A} & \text{if } r > 1 + \epsilon \end{cases} \implies \frac{\partial L}{\partial r} = \begin{cases} \hat{A} & \text{if } r < 1 + \epsilon \\ 0 & \text{if } r > 1 + \epsilon \end{cases}$$

Case 2 ($\hat{A} < 0$):

$$L(r) = \begin{cases} (1 - \epsilon)\hat{A} & \text{if } r < 1 - \epsilon \\ r \hat{A} & \text{if } r \ge 1 - \epsilon \end{cases} \implies \frac{\partial L}{\partial r} = \begin{cases} 0 & \text{if } r < 1 - \epsilon \\ \hat{A} & \text{if } r > 1 - \epsilon \end{cases}$$

The gradient is zeroed out whenever $r > 1 + \epsilon$ (with positive advantage) or $r < 1 - \epsilon$ (with negative advantage), safeguarding the policy against explosive shifts.

Exercise 3: Analytical Entropy Gradient

Derive $\nabla_\theta \mathcal{H}(\pi_\theta)$ for Shannon entropy $\mathcal{H} = -\sum_a \pi(a) \log \pi(a)$.

View Complete Solution
$$\nabla_\theta \mathcal{H} = -\sum_a \nabla_\theta \pi(a) \log \pi(a) - \sum_a \pi(a) \frac{\nabla_\theta \pi(a)}{\pi(a)}$$

Since $\sum_a \nabla_\theta \pi(a) = \nabla_\theta(1) = 0$, the second sum drops out:

$$\nabla_\theta \mathcal{H}(\pi_\theta) = -\sum_{a \in \mathcal{A}} \nabla_\theta \pi_\theta(a \mid s) \log \pi_\theta(a \mid s) = -\mathbb{E}_{a \sim \pi} [\nabla_\theta \log \pi_\theta(a \mid s) \log \pi_\theta(a \mid s)] \quad \blacksquare$$
