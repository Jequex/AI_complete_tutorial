Topic 9.4: Exercises & Solutions

Practical problems verifying KDE density calculations, Silverman's bandwidth, Mahalanobis distances on correlated outliers, and Isolation Forest scores.

Problem 1: 1D Kernel Density Evaluation Hand Calculation

Easy

Given two sample points $x_1 = 0.0, x_2 = 2.0$, evaluate the KDE density estimate $\hat{f}(x)$ at $x = 1.0$ and $x = 0.0$ using a Gaussian kernel with bandwidth $h = 1.0$.

View Complete Solution

With $N = 2, h = 1.0$:

$$\hat{f}(x) = \frac{1}{2\sqrt{2\pi}} \left( e^{-x^2 / 2} + e^{-(x - 2)^2 / 2} \right) \approx 0.19947 \left( e^{-x^2 / 2} + e^{-(x - 2)^2 / 2} \right)$$
  • At $x = 1.0$: $\hat{f}(1.0) = 0.19947 (e^{-0.5} + e^{-0.5}) = 0.19947 (2 \times 0.60653) \approx 0.242$
  • At $x = 0.0$: $\hat{f}(0.0) = 0.19947 (1.0 + e^{-2.0}) = 0.19947 (1.0 + 0.1353) \approx 0.226$

Problem 2: Silverman's Rule of Thumb Calculation

Easy

A dataset has $N = 100,000$ points with standard deviation $\hat{\sigma} = 0.02$. Compute optimal bandwidth $h_{\text{opt}} = 1.06 \, \hat{\sigma} \, N^{-1/5}$.

View Complete Solution
$$N^{-1/5} = (10^5)^{-1/5} = 10^{-1} = 0.1$$ $$h_{\text{opt}} = 1.06 \times 0.02 \times 0.1 = 0.00212$$

Problem 3: Mahalanobis Distance for Correlated Outlier

Medium

Given mean $\mu = \begin{pmatrix} 0 \\ 0 \end{pmatrix}$ and covariance $\Sigma = \begin{pmatrix} 2 & 1 \\ 1 & 1 \end{pmatrix}$. Compute the Mahalanobis distances for $x_A = \begin{pmatrix} 1 \\ 1 \end{pmatrix}$ and $x_B = \begin{pmatrix} 1 \\ -1 \end{pmatrix}$. Explain why they differ despite having equal Euclidean distance.

View Complete Solution

Inverse covariance matrix: $\det(\Sigma) = 1 \implies \Sigma^{-1} = \begin{pmatrix} 1 & -1 \\ -1 & 2 \end{pmatrix}$.

  • For $x_A = (1, 1)^T$: $$x_A^T \Sigma^{-1} x_A = \begin{pmatrix} 1 & 1 \end{pmatrix} \begin{pmatrix} 0 \\ 1 \end{pmatrix} = 1.0 \implies D_M(x_A) = \sqrt{1.0} = 1.0$$
  • For $x_B = (1, -1)^T$: $$x_B^T \Sigma^{-1} x_B = \begin{pmatrix} 1 & -1 \end{pmatrix} \begin{pmatrix} 2 \\ -3 \end{pmatrix} = 2 + 3 = 5.0 \implies D_M(x_B) = \sqrt{5.0} \approx 2.236$$

Explanation: Features 1 and 2 positively co-vary ($\Sigma_{12} = 1$). $x_A = (1, 1)$ aligns with this correlation, while $x_B = (1, -1)$ violates it, yielding over double the Mahalanobis distance.

Problem 4: Isolation Forest Anomaly Score Calculation

Hard

For $n = 256$, $c(256) \approx 10.245$. Calculate the anomaly score $s(x, n) = 2^{-\mathbb{E}[h(x)] / c(n)}$ for an outlier with $\mathbb{E}[h] = 2.0$ versus an inlier with $\mathbb{E}[h] = 9.5$.

View Complete Solution
  • For Outlier ($\mathbb{E}[h] = 2.0$): $$\text{Score} = 2^{-2.0 / 10.245} = 2^{-0.1952} \approx 0.873 \quad (\text{Flagged as Anomaly } \ge 0.6)$$
  • For Inlier ($\mathbb{E}[h] = 9.5$): $$\text{Score} = 2^{-9.5 / 10.245} = 2^{-0.9273} \approx 0.526 \quad (\text{Normal Inlier } < 0.6)$$
