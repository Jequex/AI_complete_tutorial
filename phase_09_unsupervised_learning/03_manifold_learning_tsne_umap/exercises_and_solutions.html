Problem 1: High-Dimensional Gaussian Affinities Hand Calculation

Easy

Consider three points on a 1D line: $x_1 = 0.0, x_2 = 1.0, x_3 = 4.0$ with fixed variance $\sigma^2 = 2.0$ ($2\sigma^2 = 4.0$). Compute the normalized conditional probabilities $p_{2|1}$ and $p_{3|1}$.

View Complete Solution

Unnormalized weights $w_{j|1} = \exp(-d^2 / 4.0)$:

  • $x_2 = 1.0$: $d^2 = 1.0 \implies w_{2|1} = e^{-0.25} \approx 0.7788$
  • $x_3 = 4.0$: $d^2 = 16.0 \implies w_{3|1} = e^{-4.0} \approx 0.0183$

Sum: $0.7788 + 0.0183 = 0.7971$.

Normalized probabilities:

  • $p_{2|1} = 0.7788 / 0.7971 \approx 97.7\%$
  • $p_{3|1} = 0.0183 / 0.7971 \approx 2.3\%$

Due to exponential decay, distant points have near-zero influence, focusing t-SNE on local neighborhoods.

Problem 2: Derivative of the Student-t Kernel

Medium

Let $w_{ij} = (1 + \|y_i - y_j\|_2^2)^{-1}$. Prove that $\frac{\partial w_{ij}}{\partial y_i} = -2 w_{ij}^2 (y_i - y_j)$.

View Complete Solution

Let $u = 1 + \|y_i - y_j\|_2^2$. Then $w_{ij} = u^{-1}$.

By the chain rule:

$$\frac{\partial w_{ij}}{\partial y_i} = \frac{d(u^{-1})}{du} \nabla_{y_i} u = (-u^{-2})(2(y_i - y_j)) = -2 w_{ij}^2 (y_i - y_j) \quad \blacksquare$$

Problem 3: Two-Point 1D t-SNE Gradient Hand Calculation

Medium

Suppose $y_1 = 0.0, y_2 = 2.0$, and $p_{12} = 0.5$. Compute the analytical gradient $\frac{\partial \mathcal{L}}{\partial y_1}$ and interpret whether coordinates move.

View Complete Solution

Squared distance: $d^2 = (0 - 2)^2 = 4 \implies w_{12} = \frac{1}{1 + 4} = 0.2$.

Partition function: $Z = w_{12} + w_{21} = 0.4 \implies q_{12} = \frac{0.2}{0.4} = 0.5$.

Gradient:

$$\frac{\partial \mathcal{L}}{\partial y_1} = 4 (p_{12} - q_{12})(1 + d^2)^{-1} (y_1 - y_2) = 4 (0.5 - 0.5)(0.2)(-2.0) = 0.0$$

The system is in equilibrium because the embedded probability $q_{12}$ matches target $p_{12}$ perfectly.

Problem 4: t-SNE vs UMAP Objective Comparison

Hard

Why does UMAP preserve global structure significantly better than t-SNE when distinct clusters are placed near each other?

View Complete Solution

When two distant points ($p_{ij} \approx 0$) are placed close in 2D ($q_{ij} > 0$):

  • In t-SNE: $\text{Loss} = p_{ij} \ln \frac{p_{ij}}{q_{ij}} \approx 0 \cdot \ln(0) = 0$. t-SNE suffers almost no penalty for placing non-neighbors close to each other.
  • In UMAP: The second cross-entropy term is $(1 - p_{ij}) \ln \frac{1 - p_{ij}}{1 - q_{ij}} = -\ln(1 - q_{ij})$. As $q_{ij} \to 1$, $-\ln(1 - q_{ij}) \to \infty$.

This explicit global repulsion penalizes false attractions and forces entire distinct clusters apart, preserving global macro-topology.
