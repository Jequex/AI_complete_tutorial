Topic 9.2: Exercises & Solutions

Rigorous problems covering 2D covariance calculation, Lagrange multiplier orthogonality proofs, SVD singular values, and Eckart-Young reconstruction error.

Problem 1: 2D Hand Calculation of PCA

Easy

Consider three centered 2D data points: $X_c = \begin{pmatrix} -2 & -1 \\ 0 & 0 \\ 2 & 1 \end{pmatrix}$.

  1. Compute the sample covariance matrix $C = \frac{1}{N-1} X_c^T X_c$ ($N = 3$).
  2. Compute eigenvalues $\lambda_1, \lambda_2$ of $C$.
  3. Compute the normalized first principal component $w_1$.
  4. What percentage of total variance is captured by $w_1$?
View Complete Solution

Step 1: Compute covariance matrix:

$$X_c^T X_c = \begin{pmatrix} 8 & 4 \\ 4 & 2 \end{pmatrix} \implies C = \frac{1}{2} \begin{pmatrix} 8 & 4 \\ 4 & 2 \end{pmatrix} = \begin{pmatrix} 4 & 2 \\ 2 & 1 \end{pmatrix}$$

Step 2: Characteristic equation:

$$\det(C - \lambda I) = (4 - \lambda)(1 - \lambda) - 4 = \lambda^2 - 5\lambda = 0 \implies \lambda_1 = 5, \; \lambda_2 = 0$$

Step 3: First eigenvector:

$$(C - 5I) w_1 = 0 \implies \begin{pmatrix} -1 & 2 \\ 2 & -4 \end{pmatrix} \begin{pmatrix} w_{11} \\ w_{12} \end{pmatrix} = 0 \implies w_{11} = 2w_{12}$$

Normalizing: $w_1 = \begin{pmatrix} 2/\sqrt{5} \\ 1/\sqrt{5} \end{pmatrix} \approx \begin{pmatrix} 0.8944 \\ 0.4472 \end{pmatrix}$.

Step 4: Explained Variance Ratio:

$$\text{EVR}_1 = \frac{5}{5 + 0} = 1.0 \quad (100\%)$$

Problem 2: Lagrange Multiplier Proof of Orthogonality

Medium

When finding the second component $w_2$, we maximize $w_2^T C w_2$ subject to $\|w_2\|_2 = 1$ and $w_1^T w_2 = 0$. Prove that the multiplier for the orthogonality constraint must equal zero.

View Complete Solution

Form the Lagrangian:

$$\mathcal{L}(w_2, \lambda_2, \phi) = w_2^T C w_2 - \lambda_2 (w_2^T w_2 - 1) - \phi (w_1^T w_2)$$

Differentiate and set to zero:

$$\nabla_{w_2} \mathcal{L} = 2 C w_2 - 2 \lambda_2 w_2 - \phi w_1 = 0$$

Pre-multiply by $w_1^T$:

$$2 w_1^T C w_2 - 2 \lambda_2 (w_1^T w_2) - \phi (w_1^T w_1) = 0$$

Since $C w_1 = \lambda_1 w_1$ and $w_1^T w_2 = 0$, $w_1^T C w_2 = \lambda_1 (w_1^T w_2) = 0$. Because $w_1^T w_1 = 1$:

$$0 - 0 - \phi(1) = 0 \implies \phi = 0$$

Thus $C w_2 = \lambda_2 w_2$. Subsequent principal components are simply the remaining orthogonal eigenvectors of $C$. $\blacksquare$

Problem 3: SVD Singular Values vs Covariance Eigenvalues

Medium

A centered dataset $X_c \in \mathbb{R}^{101 \times 4}$ has singular values $\sigma = (20.0, 10.0, 4.0, 1.0)$. Compute the eigenvalues $\lambda_j$ of the covariance matrix and determine how many components are needed to capture $\ge 95\%$ of the variance.

View Complete Solution

Using $\lambda_j = \frac{\sigma_j^2}{N - 1} = \frac{\sigma_j^2}{100}$:

  • $\lambda_1 = 400 / 100 = 4.0$ (EVR: $4.0 / 5.17 \approx 77.37\%$)
  • $\lambda_2 = 100 / 100 = 1.0$ (EVR: $1.0 / 5.17 \approx 19.34\%$)
  • $\lambda_3 = 16 / 100 = 0.16$ (EVR: $0.16 / 5.17 \approx 3.09\%$)
  • $\lambda_4 = 1 / 100 = 0.01$ (EVR: $0.01 / 5.17 \approx 0.19\%$)

Cumulative variance with 2 components: $77.37\% + 19.34\% = 96.71\% \ge 95\%$. Retaining 2 components is sufficient.

Problem 4: Frobenius Norm Reconstruction Error

Hard

State the Eckart-Young-Mirsky Theorem. If centered data has singular values $\sigma = (10, 6, 2)$, compute the exact Frobenius norm error $\|X_c - \hat{X}_2\|_F$ when truncating to rank 2.

View Complete Solution

Eckart-Young-Mirsky Theorem: The truncated SVD $\hat{X}_k = \sum_{j=1}^k \sigma_j u_j v_j^T$ achieves the minimum reconstruction error among all rank-$k$ matrices: $\min_{\text{rank}(A) \le k} \|X - A\|_F = \sqrt{\sum_{j=k+1}^r \sigma_j^2}$.

Calculation: Discarding the 3rd component ($\sigma_3 = 2$):

$$\|X_c - \hat{X}_2\|_F^2 = \sigma_3^2 = 2^2 = 4 \implies \|X_c - \hat{X}_2\|_F = \sqrt{4} = 2.0$$
