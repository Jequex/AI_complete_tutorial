Problem 1: Lloyd's Algorithm Hand Calculation

Easy

Consider four 1D data points: $X = \{1.0, 2.0, 6.0, 7.0\}$. Suppose we set $K = 2$ and initialize centroids at $\mu_1^{(0)} = 1.0$ and $\mu_2^{(0)} = 5.0$.

  1. Compute the cluster assignments $r_{ik}$ for iteration 0.
  2. Compute the updated centroids $\mu_1^{(1)}$ and $\mu_2^{(1)}$.
  3. Check if the algorithm converges at iteration 1.
  4. Compute the final Inertia $J$.
View Complete Solution

Step 1: Distance calculation & assignment:

  • $x_1 = 1.0$: $|1.0 - 1.0| = 0$, $|1.0 - 5.0| = 4 \implies x_1 \in C_1$.
  • $x_2 = 2.0$: $|2.0 - 1.0| = 1$, $|2.0 - 5.0| = 3 \implies x_2 \in C_1$.
  • $x_3 = 6.0$: $|6.0 - 1.0| = 5$, $|6.0 - 5.0| = 1 \implies x_3 \in C_2$.
  • $x_4 = 7.0$: $|7.0 - 1.0| = 6$, $|7.0 - 5.0| = 2 \implies x_4 \in C_2$.

Groupings: $C_1 = \{1.0, 2.0\}$, $C_2 = \{6.0, 7.0\}$.

Step 2: Centroid updates:

$$\mu_1^{(1)} = \frac{1.0 + 2.0}{2} = 1.5, \quad \mu_2^{(1)} = \frac{6.0 + 7.0}{2} = 6.5$$

Step 3: Convergence check:

Re-evaluating distances with $\mu_1 = 1.5$ and $\mu_2 = 6.5$, assignments do not change. Centroids remain identical ($\mu_1^{(2)} = 1.5, \mu_2^{(2)} = 6.5$). The algorithm converges in 1 iteration!

Step 4: Final Inertia:

$$J = (1.0 - 1.5)^2 + (2.0 - 1.5)^2 + (6.0 - 6.5)^2 + (7.0 - 6.5)^2 = 4 \times 0.25 = 1.0$$

Problem 2: Lagrange Multiplier Derivation of GMM Mixture Weights

Medium

In the M-step of the EM algorithm for GMMs, we maximize the expected complete-data log-likelihood with respect to mixture weights $\pi = (\pi_1, \dots, \pi_K)$:

$$\max_{\pi} \sum_{i=1}^N \sum_{k=1}^K \gamma_{ik} \ln \pi_k \quad \text{s.t.} \quad \sum_{k=1}^K \pi_k = 1, \; \pi_k \ge 0$$

Using Lagrange multipliers, prove that the optimal update is $\pi_k^* = \frac{N_k}{N}$, where $N_k = \sum_{i=1}^N \gamma_{ik}$.

View Complete Solution

Form the Lagrangian:

$$\Lambda(\pi, \lambda) = \sum_{i=1}^N \sum_{k=1}^K \gamma_{ik} \ln \pi_k + \lambda \left(1 - \sum_{k=1}^K \pi_k\right)$$

Differentiate with respect to $\pi_k$:

$$\frac{\partial \Lambda}{\partial \pi_k} = \sum_{i=1}^N \frac{\gamma_{ik}}{\pi_k} - \lambda = 0 \implies \sum_{i=1}^N \gamma_{ik} = \lambda \pi_k \implies N_k = \lambda \pi_k$$

Solve for $\lambda$: Summing over all $k$:

$$\sum_{k=1}^K N_k = \lambda \sum_{k=1}^K \pi_k = \lambda(1) = \lambda$$

Since $\sum_{k=1}^K \gamma_{ik} = 1$ for every point $i$, $\sum_{k=1}^K N_k = \sum_{i=1}^N 1 = N \implies \lambda = N$.

Substituting back: $\pi_k^* = \frac{N_k}{N}$. $\blacksquare$

Problem 3: K-Means++ Seeding Probability

Medium

Given 4 points in 2D: $x_1 = (0, 0)$, $x_2 = (1, 0)$, $x_3 = (0, 1)$, $x_4 = (10, 10)$. The first centroid is chosen at $\mu_1 = (0, 0)$. Compute the exact probability $P(x_i)$ of selecting each point as the second centroid $\mu_2$.

View Complete Solution

Squared distances:

  • $D(x_1)^2 = 0$
  • $D(x_2)^2 = 1^2 + 0^2 = 1$
  • $D(x_3)^2 = 0^2 + 1^2 = 1$
  • $D(x_4)^2 = 10^2 + 10^2 = 200$

Total sum: $\sum D(x)^2 = 0 + 1 + 1 + 200 = 202$.

Probabilities:

  • $P(x_1) = 0 / 202 = 0\%$
  • $P(x_2) = 1 / 202 \approx 0.495\%$
  • $P(x_3) = 1 / 202 \approx 0.495\%$
  • $P(x_4) = 200 / 202 \approx 99.01\%$

This demonstrates how K-Means++ aggressively seeds distant clusters, avoiding wasted redundant centroids.

Problem 4: DBSCAN Point Categorization

Hard

Given 1D points $X = \{1, 2, 2.5, 3, 7, 8, 15\}$ with $\epsilon = 1.2$ and $\text{MinPts} = 3$:

  1. Identify all Core Points.
  2. Identify all Border Points.
  3. Identify all Noise Points.
  4. List the final clusters.
View Complete Solution

$\epsilon$-Neighborhoods ($|x_j - x_i| \le 1.2$):

  • $x = 1$: $\{1, 2\}$, count = 2.
  • $x = 2$: $\{1, 2, 2.5, 3\}$, count = 4 $\ge 3 \implies$ Core Point.
  • $x = 2.5$: $\{2, 2.5, 3\}$, count = 3 $\ge 3 \implies$ Core Point.
  • $x = 3$: $\{2, 2.5, 3\}$, count = 3 $\ge 3 \implies$ Core Point.
  • $x = 7$: $\{7, 8\}$, count = 2.
  • $x = 8$: $\{7, 8\}$, count = 2.
  • $x = 15$: $\{15\}$, count = 1.

Classification:

  • Core Points: $\{2, 2.5, 3\}$.
  • Border Points: $\{1\}$ (count = 2 < 3, but $|1 - 2| \le 1.2$, so it is within $\epsilon$ of core point 2).
  • Noise Points: $\{7, 8, 15\}$ (neither core nor within $\epsilon$ of any core point).

Final Output: One cluster $\{1, 2, 2.5, 3\}$ and noise $\{7, 8, 15\}$.
