Topic 01: MCP Architecture & JSON-RPC 2.0 Wire Format

Client-Host-Server topology, JSON-RPC 2.0 framing, standard error codes, and batch processing.

1. The 12-Year-Old Intuitive Analogy: The Universal USB-C Cable for AI

Imagine you have a state-of-the-art gaming console, but every accessory requires a proprietary physical cable. The controller has a 9-pin triangular plug, the headset requires a flat 30-pin connector, and the external storage uses a threaded screw-in connector. Every time a new gadget appears, developers must invent a brand new custom adapter.

Before late 2024, AI agents operated in this exact fragmentation nightmare: every LLM application had to create bespoke integration code for PostgreSQL, GitHub, Slack, file trees, and search engines.

The Solution: The Model Context Protocol (MCP) is the universal USB-C connector for AI models. By standardizing message passing over JSON-RPC 2.0, any AI client can communicate with any data provider or tool server across a unified, open specification.

2. Complete Mathematical & Protocol Symbol Glossary

Symbol / Term Formal Wire Representation Protocol Function
$\mathcal{H}$ Host Process The user-facing orchestrator (e.g. IDE, Desktop agent runtime) that hosts the LLM.
$\mathcal{S}$ MCP Server Lightweight process exposing Resources, Tools, and Prompts to the host.
$\mathcal{T}_{\text{stdio}}$ Standard I/O Transport Bidirectional communication framed by newline delimiter (\n) over standard pipes.
$\mathcal{T}_{\text{sse}}$ HTTP + SSE Transport Chunked streaming over HTTP with text/event-stream.
$\text{jsonrpc}$ "2.0" strict string Protocol version indicator. Mandatory on all requests and responses.
$\text{id}$ String, Integer, or null Correlation token pairing an asynchronous response with its originating request.
$\mathcal{N}$ Notification Object Message without an id. Receiver must NEVER reply.

4. Standard JSON-RPC 2.0 Error Codes

Code Definition Trigger Description
-32700 Parse Error Malformed JSON string received by the parser.
-32600 Invalid Request JSON is valid, but missing required structure or wrong jsonrpc version.
-32601 Method Not Found The requested RPC method is not registered on the receiver.
-32602 Invalid Params The method arguments violate schema types or missing fields.
-32603 Internal Error Uncaught execution fault inside server logic.
