Topic 02: MCP Primitives — Resources & Dynamic Context

URI schemes, RFC 6570 templates, real-time push subscriptions, and bounded context injection.

1. The 12-Year-Old Intuitive Analogy: The Magical Library Barcode Scanner

Imagine visiting an infinite library. If you tried to carry every book in your backpack, you would be crushed by the weight. Instead, each book, database sheet, and live news printer is stamped with a unique barcode (a URI).

Whenever your AI assistant needs facts, it scans the catalog, retrieves only the exact document required, and when a live news feed prints a new update, the librarian rings a chime so the assistant can re-read the page. In MCP, these uniform, read-only documents are called Resources.

2. Complete Protocol Symbol Glossary

Symbol / Term Protocol Method / Format Description
$\mathcal{U}$ URI (RFC 3986) Unique resource identifier (e.g. file:///app.py, db://users/10).
$\mathcal{T}_{\text{URI}}$ RFC 6570 URI Template Parameterized resource pattern with variable placeholders ({var}).
$\text{resources/list}$ Catalog RPC Lists static resources available on the server with cursor-based pagination.
$\text{resources/read}$ Content Retrieval RPC Returns content array containing UTF-8 text or Base64 blob.
$\text{resources/subscribe}$ Subscription RPC Registers interest in receiving change events for a specific resource URI.
$\mathcal{N}_{\text{updated}}$ notifications/resources/updated Push notification sent to subscribed clients when resource contents mutate.

4. Context Window Delimited Framing

To safely incorporate resources into the prompt without vulnerability to prompt injection:

System: You are an AI assistant. The following authoritative resources have been retrieved:

--- BEGIN RESOURCE: file:///workspace/config.json (MIME: application/json) ---
{
  "environment": "production",
  "max_workers": 16
}
--- END RESOURCE: file:///workspace/config.json ---

User: How many workers are configured?
