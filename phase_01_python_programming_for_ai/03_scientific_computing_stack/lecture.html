1. NumPy: Contiguous Memory & SIMD Acceleration

The 12-Year-Old Analogy: Pointer Lists vs Solid Crayon Boxes

In standard Python, a list of numbers is a list of pointers pointing to separate heap-allocated objects scattered in RAM. Accessing them requires chasing pointers and unpacking C structures.

A NumPy array is a solid box of crayons: contiguous bytes aligned in physical memory. The CPU loads them into fast L1/L2 cache and processes them using SIMD (Single Instruction, Multiple Data) instructions—often 100x faster than pure Python loops!

import numpy as np

# Creating contiguous multidimensional arrays
x = np.array([[1.0, 2.0], [3.0, 4.0]], dtype=np.float32)

# Vectorized matrix multiplication (@)
y = x @ x
print("Result:\n", y)

2. pandas: Data Cleaning & Feature Engineering

Before training deep neural networks, raw data must be loaded, sanitized, and transformed.

Key Indexing Distinction:
  • df.loc['row_label', 'column_name']: Look up by explicit label name.
  • df.iloc[row_idx, col_idx]: Look up strictly by integer position 0, 1, 2....
import pandas as pd

df = pd.DataFrame({
    "prompt": ["hello", "tell me a joke", "summarize doc"],
    "tokens": [1, 4, 2],
    "latency_ms": [12.4, 35.2, 19.8]
})

# Filter fast responses under 20ms
fast_df = df[df["latency_ms"] < 20.0]
# Impute missing values
df_cleaned = df.fillna(0)

3. Matplotlib: Publication-Ready AI Curves

Using the object-oriented Figure and Axes hierarchy ensures full control over charts, subplots, and export resolutions.

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(8, 4), dpi=150)
epochs = [1, 2, 3, 4, 5]
loss = [2.3, 1.4, 0.8, 0.45, 0.32]

ax.plot(epochs, loss, marker='o', color='#4338ca', lw=2, label="Train Loss")
ax.set_title("Training Loss Convergence", fontweight="bold")
ax.set_xlabel("Epoch")
ax.set_ylabel("Cross Entropy Loss")
ax.grid(True, alpha=0.3)
ax.legend()
plt.tight_layout()

4. SciPy: Mathematical Optimization

SciPy provides high-performance scientific routines for convex optimization, probability distributions, and sparse matrix representations.

from scipy.optimize import minimize

# Finding the minimum of a parabolic loss function f(w) = (w - 3.5)^2 + 10
result = minimize(lambda w: (w[0] - 3.5)**2 + 10.0, x0=[0.0], method="BFGS")
print("Optimized parameter:", result.x[0])  # ~3.5000

5. REST APIs & Streaming JSON Lines (.jsonl)

Fine-tuning datasets for modern LLMs are formatted as .jsonl files where each line is an independent JSON record:

import json

# Streaming JSONL without loading full file into memory
with open("fine_tuning_data.jsonl", "r") as f:
    for line in f:
        sample = json.loads(line)
        prompt, completion = sample["prompt"], sample["completion"]
