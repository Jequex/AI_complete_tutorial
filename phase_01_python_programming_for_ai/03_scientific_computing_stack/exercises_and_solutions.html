Problem 1: NumPy Memory Strides and Slicing Views

Medium

A 2D array of 32-bit floats (4 bytes each) has shape $(4, 5)$ in C-contiguous order.

  1. What is the total memory footprint in bytes?
  2. What is the stride tuple in bytes?
  3. If sliced with A[::2, ::2], what are the new shape and strides? Does this allocate a new buffer in RAM?
Click to Reveal Step-by-Step Solution
1. Total Memory: $$\text{Bytes} = 4 \times 5 \times 4 \text{ bytes} = 80 \text{ bytes}$$
2. Stride Tuple: Each column step advances 4 bytes. Each row step advances $5 \times 4 = 20$ bytes. $$\text{Strides} = (20, 4)$$
3. Sliced Array A[::2, ::2]: New shape is $(2, 3)$. The strides double along each axis: $(40, 8)$. Memory allocation: No new data is allocated; it is an instantaneous $O(1)$ pointer view.

Problem 2: pandas Data Cleaning Pipeline for LLMs

Medium

Write a pandas cleaning function clean_prompt_dataset(df) that removes nulls, strips whitespace, filters prompts under 2 words or over 2048 words, and removes duplicates.

Click to Reveal Step-by-Step Solution 
import pandas as pd

def clean_prompt_dataset(df: pd.DataFrame) -> pd.DataFrame:
    df_clean = df.dropna(subset=["prompt"]).copy()
    df_clean["prompt"] = df_clean["prompt"].astype(str).str.strip()
    df_clean = df_clean[df_clean["prompt"] != ""]
    
    # Token length estimate
    df_clean["token_estimate"] = df_clean["prompt"].apply(lambda p: len(p.split()))
    df_clean = df_clean[(df_clean["token_estimate"] >= 2) & (df_clean["token_estimate"] <= 2048)]
    
    return df_clean.drop_duplicates(subset=["prompt"]).reset_index(drop=True)

Problem 3: JSONL Streaming Dataset Splitter

Challenging

Implement a streaming function split_jsonl_dataset(in_path, train_path, val_path, val_ratio, seed) that divides a multi-gigabyte dataset line-by-line without causing Out-Of-Memory errors.

Click to Reveal Step-by-Step Solution 
import json
import random

def split_jsonl_dataset(input_path, train_path, val_path, val_ratio=0.2, seed=42):
    random.seed(seed)
    train_n, val_n = 0, 0
    with open(input_path, "r", encoding="utf-8") as in_f, \
         open(train_path, "w", encoding="utf-8") as tr_f, \
         open(val_path, "w", encoding="utf-8") as va_f:
        for line in in_f:
            if not line.strip():
                continue
            rec = json.loads(line)
            if random.random() < val_ratio:
                va_f.write(json.dumps(rec) + "\n")
                val_n += 1
            else:
                tr_f.write(json.dumps(rec) + "\n")
                train_n += 1
    return train_n, val_n
