Topic 1.4: Capstone Project — Building a Micro-Tensor Library

Designing a Mini-PyTorch Numerical Computing Engine from Scratch in Pure Python

1. The Anatomy of a Tensor

Under the Hood of PyTorch and NumPy

A tensor is fundamentally composed of three components:

  • 1D Storage Buffer: A single continuous array holding raw floating-point numbers.
  • Shape Tuple: The dimensional sizes, e.g. (rows, cols).
  • Strides Tuple: Step sizes needed to jump in the flat 1D buffer to advance along each dimension.

For any 2D coordinate $(r, c)$, the 1D index in memory is calculated via:

$$\text{flat\_index}(r, c) = r \times S_0 + c \times S_1$$

2. Zero-Copy Transposition

In classical programming, transposing a matrix creates a new matrix and copies every value. In high-performance tensor engines, transposition is an $O(1)$ constant-time operation that merely swaps the shape and strides metadata while sharing the exact same underlying 1D data buffer!

Stride Swap Magic: $$\text{Matrix } A: \text{Shape } (M, N), \text{Strides } (N, 1)$$ $$\text{Matrix } A^T: \text{Shape } (N, M), \text{Strides } (1, N)$$

3. The Desired Target API

Our micro-tensor engine will support standard deep learning syntax:

# Instantiation
x = Tensor([[1.0, 2.0], [3.0, 4.0]])

# Matrix Multiplication Operator
y = x @ x

# Transposition (Zero-Copy)
y_trans = y.T

# Elementwise Arithmetic & Reductions
z = y + 10.0
total = z.sum()
