Topic 1.4: Capstone Project — Building a Micro-Tensor Library

Welcome to the Capstone Project for Phase 1! In this project, we demystify deep learning engines by building a pure Python tensor library supporting multi-dimensional strides, zero-copy transposition, matrix multiplication, and a complete neural network forward pass.

1. 🧒 The 12-Year-Old Analogy: The Conveyor Belt & The Cardboard Divider

Tensors are Flat Conveyor Belts in Memory

A tensor is not a nested list. It consists of:

  1. Storage (The Conveyor Belt): A single flat 1D continuous array of numbers in RAM.
  2. Shape (The Cardboard Dividers): Dimensions telling your brain how many rows and columns to imagine.
  3. Strides (The Step Ruler): Offsets telling the CPU how many items to skip along the conveyor belt to move by 1 in each dimension.
$$\text{flat\_index}(r, c) = r \cdot S_0 + c \cdot S_1$$

2. Zero-Copy Operations: The Transposition Mirror Trick

🧒 The 12-Year-Old Analogy: Tilting Your Head vs. Moving Heavy Bricks

To transpose a matrix from $(2, 3)$ to $(3, 2)$, you don't pick up and move the numbers! You simply swap the shape tuple to $(3, 2)$ and swap the strides tuple to $(1, 3)$. It executes in $\mathcal{O}(1)$ time with zero memory copies!

3. Matrix Multiplication: The Core Workhorse (@)

Entrywise Product Formula

$$C_{i, j} = \sum_{k=0}^{K-1} A_{i, k} \times B_{k, j}$$

🧒 What the math is actually doing: Row $i$ of Matrix $A$ hugs Column $j$ of Matrix $B$. Matching pairs multiply together and sum into a single output score $C_{i, j}$.
