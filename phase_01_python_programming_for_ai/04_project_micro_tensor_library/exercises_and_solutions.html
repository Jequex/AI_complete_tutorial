Problem 1: Stride Calculus & Contiguous Memory Views

Medium

Calculate the row-major strides for a 3D tensor of shape $(B=2, T=3, D=4)$, and explain why transposing a 2D matrix of shape $(2, 3)$ with strides $(3, 1)$ into $A^T$ with shape $(3, 2)$ and strides $(1, 3)$ produces a non-contiguous tensor view.

Click to view solution for Problem 1

Part 1: Strides for (2, 3, 4)

$$S_2 = 1, \quad S_1 = 1 \times 4 = 4, \quad S_0 = 4 \times 3 = 12 \implies \mathbf{(12, 4, 1)}$$

Part 2: Contiguity Explanation

A C-contiguous $(3, 2)$ matrix requires strides $(2, 1)$ so adjacent column items sit next to each other in RAM. Strides $(1, 3)$ separate adjacent items in a row by 3 memory slots, making it non-contiguous.

Problem 2: Zero-Copy Stride Broadcasting

Medium

How does setting stride $S_0 = 0$ allow broadcasting a 1D bias vector $\mathbf{b} \in \mathbb{R}^N$ across $M$ rows of a batch matrix without allocating duplicate memory?

Click to view solution for Problem 2

When shape is $(M, N)$ and strides are $(0, 1)$, moving down row $r$ advances flat index by $r \times 0 = 0$. Every row re-reads the exact same $N$ floats in memory in $\mathcal{O}(1)$ time!

  1. $z_1 = [(2.0 \times 1.0) + (-1.0 \times -3.0) + 0.5, \quad (2.0 \times 2.0) + (-1.0 \times 0.5) - 1.0] = [\mathbf{5.5}, \mathbf{2.5}]$
