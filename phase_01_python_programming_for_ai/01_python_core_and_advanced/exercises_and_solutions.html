Problem 1: Memory Mutability, Reference Aliasing & Default Arguments

Medium

In AI training scripts, subtle bugs often emerge from unintended reference aliasing or default mutable arguments accumulating state across epochs.

Part A: Default Argument Output Prediction

def train_model(epoch_data, training_history=[]):
    training_history.append(epoch_data)
    return training_history

run_1 = train_model("loss: 0.85")
run_2 = train_model("loss: 0.62")
print("run_1 is run_2:", run_1 is run_2)
  1. What does run_1 contain after both calls?
  2. What does run_2 contain?
  3. Why does run_1 is run_2 return True?
  4. Rewrite the function so that calling it without a history always creates a fresh, independent list.

Part B: The Shallow List Multiplication Trap

row = [0.0, 0.0, 0.0]
matrix = [row] * 3
matrix[0][1] = 5.0

What is printed by print(matrix)? Explain why, and write the proper list comprehension.

Click to Reveal Step-by-Step Solution
Part A Solution:
  • run_1 is ['loss: 0.85', 'loss: 0.62']
  • run_2 is ['loss: 0.85', 'loss: 0.62']
  • run_1 is run_2 is True because Python creates default arguments once at definition time. Both variables point to the exact same list in RAM!
Corrected Code: 
def train_model(epoch_data, training_history=None):
    if training_history is None:
        training_history = []
    training_history.append(epoch_data)
    return training_history
Part B Solution:

Printed Output: [[0.0, 5.0, 0.0], [0.0, 5.0, 0.0], [0.0, 5.0, 0.0]]

Reason: The * 3 syntax replicates the pointer to row three times. All rows share the same memory address.

Correct Idiom: 
matrix = [[0.0 for _ in range(3)] for _ in range(3)]
matrix[0][1] = 5.0  # Only changes row 0!

Problem 2: Custom PyTorch-style Dataset & Lazy Batch Streamer

Medium

Build an OOP data pipeline with lazy streaming for text datasets.

  1. Create a class TextClassificationDataset implementing __len__ and __getitem__.
  2. Create a generator function stream_batches(dataset, batch_size, drop_last=False) that yields mini-batches without allocating memory for the entire dataset.
Click to Reveal Step-by-Step Solution 
class TextClassificationDataset:
    def __init__(self, texts: list[str], labels: list[int]):
        if len(texts) != len(labels):
            raise ValueError("Length mismatch between texts and labels.")
        self.texts = texts
        self.labels = labels

    def __len__(self) -> int:
        return len(self.texts)

    def __getitem__(self, idx: int) -> dict:
        return {
            "text": self.texts[idx],
            "label": self.labels[idx],
            "word_count": len(self.texts[idx].split())
        }

def stream_batches(dataset, batch_size: int, drop_last: bool = False):
    """Lazily yields mini-batches from a dataset."""
    batch = []
    for i in range(len(dataset)):
        batch.append(dataset[i])
        if len(batch) == batch_size:
            yield batch
            batch = []
    if batch and not drop_last:
        yield batch

Problem 3: Production AI Decorator: Shape Validation

Challenging

Write a decorator @validate_input_dim(expected_dim) that inspects the 2D matrix input x, checks that the number of columns matches expected_dim, and raises a custom ShapeMismatchError if mismatched.

Click to Reveal Step-by-Step Solution 
import functools

class ShapeMismatchError(Exception):
    pass

def validate_input_dim(expected_dim: int):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(x, *args, **kwargs):
            if not isinstance(x, list) or not x or not isinstance(x[0], list):
                raise TypeError("Input must be a 2D list matrix.")
            actual_dim = len(x[0])
            if actual_dim != expected_dim:
                raise ShapeMismatchError(
                    f"Expected {expected_dim} features, but got {actual_dim}."
                )
            return func(x, *args, **kwargs)
        return wrapper
    return decorator

# Usage
@validate_input_dim(expected_dim=4)
def forward_pass(x: list[list[float]]):
    return [sum(row) for row in x]

# Verified:
# forward_pass([[1, 2, 3, 4]]) -> Valid!
# forward_pass([[1, 2]])       -> Raises ShapeMismatchError!
