Problem 1: Unit Testing Numerical Invariants & Safe Softmax

Medium

The standard Softmax formula $\text{Softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$ overflows on inputs $\ge 710$ in 64-bit IEEE floating point. Show how subtracting the maximum logit $m = \max_k z_k$ stabilizes it, and compute safe softmax for $\mathbf{z} = [1000.0, 1001.0, 1002.0]$.

Click to view solution for Problem 1

Part 1: Proof of Invariance

$$\frac{e^{z_i - c}}{\sum_{j=1}^K e^{z_j - c}} = \frac{e^{z_i} \cdot e^{-c}}{e^{-c} \cdot \sum_{j=1}^K e^{z_j}} = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}$$

The constant $e^{-c}$ cancels out in numerator and denominator! When $c = \max_k z_k$, the largest exponent is $e^0 = 1.0$, avoiding overflow.

Part 2: Hand Calculation

  1. $m = 1002.0 \implies \mathbf{z} - m = [-2.0, -1.0, 0.0]$
  2. $e^{-2} \approx 0.1353, \quad e^{-1} \approx 0.3679, \quad e^0 = 1.0000$
  3. $\text{Sum} = 0.1353 + 0.3679 + 1.0000 = \mathbf{1.5032}$
  4. $p_1 = \frac{0.1353}{1.5032} \approx \mathbf{0.0900}, \quad p_2 = \frac{0.3679}{1.5032} \approx \mathbf{0.2447}, \quad p_3 = \frac{1.0000}{1.5032} \approx \mathbf{0.6653}$

Problem 2: Baseline Random Loss Invariant Check

Medium

You initialize a language model with a vocabulary of $V = 32,000$ tokens. What is the theoretical baseline cross-entropy loss $\mathcal{L}_{\text{random}}$ before training?

Click to view solution for Problem 2
$$\mathcal{L}_{\text{random}} = -\ln\left(\frac{1}{V}\right) = \ln(V)$$ $$\mathcal{L}_{\text{random}} = \ln(32,000) \approx \mathbf{10.3735}$$

If initial loss starts at 1.45 instead of ~10.37, it flags data leakage or an evaluation slicing bug in your test suite!

Problem 3: Algorithmic Profiling & Asymptotic Complexity

Challenging

Compare the time complexity of checking $N = 100,000$ items using a list ($\mathcal{O}(N^2)$) versus a hash set ($\mathcal{O}(N)$).

Click to view solution for Problem 3
  • List search ($\mathcal{O}(N^2)$): $5 \times 10^9$ operations $\approx \mathbf{1.39\text{ hours}}$
  • Hash set ($\mathcal{O}(N)$): $100,000$ operations $\approx \mathbf{0.1\text{ seconds}}$

Profiling identifies this bottleneck and yields a 50,000x speedup!
