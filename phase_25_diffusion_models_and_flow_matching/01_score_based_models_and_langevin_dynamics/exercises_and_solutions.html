Topic 25.1: Exercises & Solutions — Score-Based Models

Analytical derivations, integration by parts proofs, and denoising score matching properties.

Problem 1: Partition Function Vanishing Property Easy

Consider an unnormalized energy distribution $p(x) = \frac{1}{Z} \exp\left(-\frac{1}{4}x^4 + \frac{1}{2}x^2\right)$ over $\mathbb{R}$.

  1. Compute the analytical score $s(x) = \frac{d}{dx} \log p(x)$.
  2. Identify all roots where $s(x) = 0$.
  3. Classify each root as a stable mode or unstable anti-mode using the second derivative.
View Complete Solution

Step 1: Compute Score:

$$\log p(x) = -\log Z - \frac{1}{4}x^4 + \frac{1}{2}x^2$$ $$s(x) = \frac{d}{dx}\log p(x) = -x^3 + x = x(1 - x^2)$$

Notice that the normalizer $Z$ vanishes completely without computing the integral!

Step 2: Roots:

$$x(1 - x^2) = 0 \implies x \in \{-1, 0, +1\}$$

Step 3: Stability:

$$s'(x) = 1 - 3x^2$$
  • At $x = \pm 1$: $s'(\pm 1) = -2 < 0 \implies$ Stable modes (probability maxima).
  • At $x = 0$: $s'(0) = +1 > 0 \implies$ Unstable anti-mode (barrier between modes).

Problem 2: 1D Hyvärinen Integration by Parts Proof Medium

Prove from first principles using integration by parts that for differentiable densities $p(x)$ vanishing at infinity:

$$\mathbb{E}_{x \sim p(x)} \left[ s_\theta(x) \frac{d}{dx} \log p(x) \right] = -\mathbb{E}_{x \sim p(x)} [s_\theta'(x)]$$
View Complete Solution

Write the expectation in integral form:

$$\int_{-\infty}^{\infty} p(x) s_\theta(x) \frac{1}{p(x)} \frac{dp(x)}{dx} \, dx = \int_{-\infty}^{\infty} s_\theta(x) \frac{dp(x)}{dx} \, dx$$

Using integration by parts $\int u \, dv = [uv] - \int v \, du$ with $u = s_\theta(x), v = p(x)$:

$$= \left[ s_\theta(x) p(x) \right]_{-\infty}^{\infty} - \int_{-\infty}^{\infty} p(x) s_\theta'(x) \, dx$$

Because $p(x) s_\theta(x) \to 0$ as $|x| \to \infty$, the boundary term is 0. Hence:

$$= -\int_{-\infty}^{\infty} p(x) s_\theta'(x) \, dx = -\mathbb{E}_{p(x)} [s_\theta'(x)]$$

Problem 3: Analytical Equivalence in Denoising Score Matching Hard

Let $x \sim \mathcal{N}(\mu, \sigma_0^2)$ be perturbed by $\tilde{x} = x + \sigma \epsilon$ where $\epsilon \sim \mathcal{N}(0, 1)$. Prove that the Bayes-optimal denoising score estimator $s^*(\tilde{x}) = \mathbb{E}_{x \mid \tilde{x}}\left[-\frac{\tilde{x} - x}{\sigma^2}\right]$ is identical to the ground-truth marginal score $\nabla_{\tilde{x}} \log q_\sigma(\tilde{x})$.

View Complete Solution

Step 1: Marginal Score:

$$\tilde{x} \sim \mathcal{N}(\mu, \sigma_0^2 + \sigma^2) \implies \nabla_{\tilde{x}} \log q_\sigma(\tilde{x}) = -\frac{\tilde{x} - \mu}{\sigma_0^2 + \sigma^2}$$

Step 2: Conditional Expectation:

$$\mathbb{E}[x \mid \tilde{x}] = \mu + \frac{\sigma_0^2}{\sigma_0^2 + \sigma^2}(\tilde{x} - \mu) = \frac{\sigma^2 \mu + \sigma_0^2 \tilde{x}}{\sigma_0^2 + \sigma^2}$$

Step 3: Plug into DSM Estimator:

$$s^*(\tilde{x}) = -\frac{\tilde{x} - \mathbb{E}[x \mid \tilde{x}]}{\sigma^2} = -\frac{1}{\sigma^2}\left(\frac{\sigma^2(\tilde{x} - \mu)}{\sigma_0^2 + \sigma^2}\right) = -\frac{\tilde{x} - \mu}{\sigma_0^2 + \sigma^2}$$

Both expressions match identically!
