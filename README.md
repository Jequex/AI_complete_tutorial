# The Complete AI Mastery Curriculum: From Beginner to Researcher

Welcome to the comprehensive, first-principles learning repository for artificial intelligence, machine learning, deep learning, foundation models, and AI research engineering.

This curriculum follows [`initial_course_outline.md`](./initial_course_outline.md) and transforms it into a complete, structured textbook, interactive laboratory, and problem repository.

---

## 📚 Curriculum Structure & Standards

Every Phase in this curriculum follows a rigorous modular structure designed for reading and interactive exploration:
```text
phase_XX_name/
├── index.html                                 # Visual phase hub with topic cards & navigation
├── README.md                                  # Markdown overview, roadmap, & objectives
└── YY_topic_name/
    ├── lecture.html                           # Modern, readable lecture document with KaTeX math
    ├── exercises_and_solutions.html           # Interactive problem set with collapsible solutions
    ├── experiment.py                          # Fully executable, zero-dependency Python lab
    ├── lecture.md                             # Markdown version
    └── exercises_and_solutions.md             # Markdown problem set
```
