3. Flat Physical Memory & Strides

🔬 How PyTorch Represents Multidimensional Arrays in 1D RAM

Physical RAM is a flat 1D strip of memory addresses. A tensor is specified by its Shape and its Strides:

$$\text{Physical Address}(i, j) = (i \times \text{stride}_0) + (j \times \text{stride}_1)$$

Calling .transpose() or .permute() merely swaps the stride metadata without copying bytes in RAM! This makes tensor manipulation instantaneous.

4. Broadcasting Rules

Broadcasting allows elementwise arithmetic between tensors of different shapes by expanding dimensions of size 1:

Tensor A: (3, 1)  +  Tensor B: (1, 4)  -->  Broadcasted Output: (3, 4)

Working right-to-left: dimensions must either be identical or one of them must be 1.

5. Principal Component Analysis (PCA)

🧒 Maximum Variance Axis

Given data spread across high dimensions, PCA finds the axes where the data spread is widest. These axes are the eigenvectors of the covariance matrix, which correspond directly to the right singular vectors $V$ of the SVD!

Centered data $\tilde{X} = X - \mu$. SVD decomposition: $\tilde{X} = U \Sigma V^T$. The low-dimensional coordinates are:

$$\mathbf{Z = \tilde{X} V_k}$$
