Topic 2.5: Singular Value Decomposition (SVD)

The Swiss Army knife of linear algebra: $A = U \Sigma V^T$, low-rank approximation, and Eckart-Young data compression.

1. The 12-Year-Old Analogy: The 3-Step Space Dance

🧒 The Stretchy Dough Dance

Any matrix transformation $A$ can be decomposed into three simple dance steps:

  1. Step 1 (Rotate via $V^T$): Spin the ball of dough without changing its spherical shape.
  2. Step 2 (Stretch via $\Sigma$): Pull and squash the dough into an oval along coordinate axes by factors $\sigma_1 \ge \sigma_2 \ge \dots \ge 0$.
  3. Step 3 (Rotate via $U$): Spin the stretched ellipse into its final output orientation.
       Unit Circle              Rotated Circle           Stretched Ellipse            Final Output
            y                         y                          y                         y
            ▲                         ▲                          ▲                         ▲
         ┌──●──┐                   ┌──●──┐                    ┌───●───┐                 /───●───\
         │     │  ───( Vᵀ )───►    │     │   ───( Σ )───►     │       │  ───( U )───►  /         \
         └──●──┘                   └──●──┘                    └───●───┘                \───●───/
            └─────► x                 └─────► x                  └────────► x              └─────► x

$$\boxed{A = U \Sigma V^T}$$

2. Deconstructing the Components

Symbol Matrix Dimension Mathematical Properties Geometric Meaning
$A$ $m \times n$ Any real matrix Full linear mapping
$U$ $m \times m$ Orthogonal ($U^T U = I$) Output rotation matrix (eigenvectors of $A A^T$)
$\Sigma$ $m \times n$ Rectangular diagonal Sorted singular values ($\sigma_1 \ge \sigma_2 \ge \dots \ge 0$)
$V^T$ $n \times n$ Orthogonal ($V^T V = I$) Input rotation matrix (eigenvectors of $A^T A$)

3. The Sum of Outer Products View

SVD represents any matrix as a weighted sum of simple rank-1 layers:

$$\boxed{A = \sum_{i=1}^r \sigma_i \mathbf{u}_i \mathbf{v}_i^T = \sigma_1 \mathbf{u}_1 \mathbf{v}_1^T + \sigma_2 \mathbf{u}_2 \mathbf{v}_2^T + \dots + \sigma_r \mathbf{u}_r \mathbf{v}_r^T}$$

Because singular values decay rapidly ($\sigma_1 \gg \sigma_2 \gg \dots$), keeping only the top $k$ terms provides the **optimal low-rank approximation**:

$$A_k = \sum_{i=1}^k \sigma_i \mathbf{u}_i \mathbf{v}_i^T \approx A$$

4. The Eckart-Young Theorem & AI Compression

🔬 Mathematical Optimality of Truncated SVD

The Eckart-Young-Mirsky Theorem guarantees that $A_k$ is the absolute best rank-$k$ approximation of $A$ under the Frobenius norm:

$$\min_{\text{rank}(B) \le k} \|A - B\|_F = \|A - A_k\|_F = \sqrt{\sum_{j=k+1}^r \sigma_j^2}$$

🧒 Real AI Application: Image Compression

For a $1000 \times 1000$ image ($1,000,000$ pixels), keeping the top $k = 20$ singular values requires storing only $U_k$ ($20,000$), $\Sigma_k$ ($20$), and $V_k^T$ ($20,000$) = 40,020 numbers. That is a 96% compression ratio with virtually no loss of human-perceptible details!
