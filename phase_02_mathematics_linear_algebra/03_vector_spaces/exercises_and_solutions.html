Topic 2.3: Practice Exercises & Solutions

Testing linear independence, null space dimensions, solution uniqueness, and LoRA parameter math.

Problem 1: Testing Linear Independence & Redundancy

Given $\mathbf{v}_1 = [1, 2, 3]^T$, $\mathbf{v}_2 = [0, 1, 2]^T$, and $\mathbf{v}_3 = [2, 5, 8]^T$ in $\mathbb{R}^3$:

  • Part A: Form the linear system $c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + c_3 \mathbf{v}_3 = \mathbf{0}$.
  • Part B: Solve for $c_1, c_2, c_3$. Are the vectors independent?
  • Part C: What is the dimension and geometric shape of $\text{Span}(\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3)$?
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A & B: Solving the System

  1. $c_1 + 2c_3 = 0 \implies c_1 = -2c_3$
  2. $2c_1 + c_2 + 5c_3 = 0 \implies 2(-2c_3) + c_2 + 5c_3 = 0 \implies c_2 = -c_3$
  3. $3c_1 + 2c_2 + 8c_3 = 3(-2c_3) + 2(-c_3) + 8c_3 = 0$ (Consistent!)

Setting $c_3 = 1$ yields non-trivial solution $(c_1, c_2, c_3) = (-2, -1, 1) \neq (0, 0, 0)$. Thus, the vectors are Linearly Dependent! In fact, $\mathbf{v}_3 = 2\mathbf{v}_1 + \mathbf{v}_2$.

Part C: Dimension & Geometric Shape

Since $\mathbf{v}_3$ is redundant, the basis consists of $\{\mathbf{v}_1, \mathbf{v}_2\}$.

$$\text{Dimension} = \mathbf{2} \quad (\text{A flat 2D plane passing through } (0,0,0) \text{ in } \mathbb{R}^3)$$

Problem 2: The Rank-Nullity Theorem & Solution Uniqueness

A matrix $A \in \mathbb{R}^{5 \times 8}$ has $\text{Rank}(A) = 4$.

  • Part A: What is the dimension of input space $n$?
  • Part B: Calculate $\text{Nullity}(A)$.
  • Part C: Can any solution to $A\mathbf{x} = \mathbf{b}$ be unique?
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: $n = 8$ (number of columns).

Part B: $\text{Rank}(A) + \text{Nullity}(A) = n \implies 4 + \text{Nullity} = 8 \implies \mathbf{\text{Nullity}(A) = 4}$.

Part C: No solution can ever be unique! For any solution $\mathbf{x}_0$, adding any of the infinite vectors $\mathbf{z} \in \mathcal{N}(A)$ gives another valid solution: $A(\mathbf{x}_0 + \mathbf{z}) = A\mathbf{x}_0 + \mathbf{0} = \mathbf{b}$.

Problem 3: LoRA Parameter Reduction Calculation

A Transformer query matrix $W_Q \in \mathbb{R}^{4096 \times 4096}$ is fine-tuned via LoRA ($\Delta W = B A$) with rank $r = 8$.

  • Part A: Count parameters in full fine-tuning.
  • Part B: Count parameters in LoRA ($r = 8$).
  • Part C: Calculate the percentage reduction.
💡 Click to Reveal Step-by-Step Solution

Solution:

Part A: Full: $4096 \times 4096 = \mathbf{16,777,216}$ parameters.

Part B: LoRA: $(4096 \times 8) + (8 \times 4096) = 32,768 + 32,768 = \mathbf{65,536}$ parameters.

Part C: Reduction: $1 - \frac{65,536}{16,777,216} = 1 - 0.0039 = \mathbf{99.61\% \text{ reduction}}$!
