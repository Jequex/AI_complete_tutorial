Topic 2.3: Exercises & Detailed Solutions

Problem 1: Testing Linear Independence & Redundancy

Given $\mathbf{v}_1 = [1, 2, 3]^T$, $\mathbf{v}_2 = [0, 1, 2]^T$, and $\mathbf{v}_3 = [2, 5, 8]^T$, determine if they are linearly independent.

Click to view solution

Solving $c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + c_3 \mathbf{v}_3 = \mathbf{0}$ yields:

$$-2\mathbf{v}_1 - \mathbf{v}_2 + \mathbf{v}_3 = \mathbf{0} \implies \mathbf{v}_3 = 2\mathbf{v}_1 + \mathbf{v}_2$$

Because $\mathbf{v}_3$ is a linear combination of $\mathbf{v}_1$ and $\mathbf{v}_2$, the set is Linearly Dependent. Its span is a 2D plane in $\mathbb{R}^3$.

Problem 2: The Rank-Nullity Theorem & Solution Uniqueness

For $A \in \mathbb{R}^{5 \times 8}$ with $\text{Rank}(A) = 4$, compute $\text{Nullity}(A)$ and explain why solutions to $A\mathbf{x} = \mathbf{b}$ can never be unique.

Click to view solution $$\text{Rank}(A) + \text{Nullity}(A) = n \implies 4 + \text{Nullity}(A) = 8 \implies \text{Nullity}(A) = \mathbf{4}$$

Because the null space has dimension 4, adding any of the infinite vectors $\mathbf{z} \in \mathcal{N}(A)$ to a solution $\mathbf{x}_0$ gives another valid solution ($A(\mathbf{x}_0 + \mathbf{z}) = \mathbf{b}$). Solutions can never be unique.

Problem 3: LoRA Parameter Reduction Calculation

Compare full fine-tuning of $W \in \mathbb{R}^{4096 \times 4096}$ against LoRA rank $r = 8$ ($\Delta W = BA$).

Click to view solution
  • Full Parameters: $4096 \times 4096 = \mathbf{16,777,216}$
  • LoRA Parameters: $(4096 \times 8) + (8 \times 4096) = \mathbf{65,536}$
  • Parameter Reduction: $\left(1 - \frac{65,536}{16,777,216}\right) \times 100\% = \mathbf{99.609\%}$ reduction!
