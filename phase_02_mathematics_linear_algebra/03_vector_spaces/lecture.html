Topic 2.3: Vector Spaces, Span, Basis, and Rank

Deconstructing vector spaces, linear independence, the Column and Null spaces, and Rank-Nullity in AI.

1. The 12-Year-Old Analogy: The Redundant Teammate

🧒 The Video Game Team

Imagine your squad is exploring a 2D map:

  • Player 1 can only move East/West ($[1, 0]$).
  • Player 2 can only move North/South ($[0, 1]$).

Together, they can reach every single square on the map by combining steps!

Now, Player 3 arrives, moving Northeast ($[1, 1]$). Does Player 3 let the team reach any new ground? No! Player 3 is a combination of Player 1 and Player 2:

$$\begin{bmatrix} 1 \\ 1 \end{bmatrix} = 1 \cdot \begin{bmatrix} 1 \\ 0 \end{bmatrix} + 1 \cdot \begin{bmatrix} 0 \\ 1 \end{bmatrix}$$

Player 3 is linearly dependent (redundant)!

2. Linear Combinations & Span

A linear combination scales and sums vectors: $\mathbf{w} = \sum_{i=1}^k c_i \mathbf{v}_i$.

The Span is the entire geometric region reachable by all possible combinations:

$$\text{Span}(\mathbf{v}_1, \dots, \mathbf{v}_k) = \left\{ \sum_{i=1}^k c_i \mathbf{v}_i \;\middle|\; c_i \in \mathbb{R} \right\}$$

3. Linear Independence & Basis

🔬 Formal Definition of Independence

Vectors $\{\mathbf{v}_1, \dots, \mathbf{v}_k\}$ are linearly independent if and only if:

$$c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \dots + c_k \mathbf{v}_k = \mathbf{0} \implies c_1 = c_2 = \dots = c_k = 0$$

A Basis is the minimal set of linearly independent vectors that spans the entire space. The Dimension is the count of basis vectors.

4. The Column Space & Null Space of Matrix $A$

       INPUT SPACE (ℝⁿ)                               OUTPUT SPACE (ℝᵐ)
       
       ┌────────────────────────┐                    ┌────────────────────────┐
       │                        │                    │                        │
       │    x ──────────────────┼── Matrix A ───────►│  Ax ∈ C(A)             │
       │                        │                    │  (Column Space)        │
       │   [ Null Space N(A) ]  │                    │                        │
       │   all inputs squashed  │                    │                        │
       │   straight to zero! ───┼── Matrix A ───────►│  0 (Origin)            │
       │                        │                    │                        │
       └────────────────────────┘                    └────────────────────────┘
  • Column Space $\mathcal{C}(A)$: The span of all column vectors. It is the set of all possible outputs $A\mathbf{x}$.
  • Null Space $\mathcal{N}(A)$: The set of all input vectors squashed to zero: $\{\mathbf{x} \mid A\mathbf{x} = \mathbf{0}\}$.

5. The Rank-Nullity Theorem & LoRA

🔬 Conservation of Dimensions

$$\boxed{\text{Rank}(A) + \text{Nullity}(A) = n}$$

where $n$ is the number of input columns. Every dimension either survives into the output or collapses into the null space.

🧒 Real AI Application: LoRA (Low-Rank Adaptation)

In a 70B parameter LLM, updating full $4096 \times 4096$ matrices requires 16.7 million numbers per layer. By factoring the update into a low-rank matrix product $\Delta W = B \cdot A$ with rank $r = 16$, we only train $131,072$ numbers—a 99.2% parameter reduction!
